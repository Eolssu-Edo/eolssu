비밀번호, 이메일 인증번호, 신분증 사본을 보내지 마세요. 이 페이지는 이메일 요청 방법을 안내하며 버튼을 누르는 즉시 계정이 삭제되는 것은 아닙니다.

탈퇴 유예와 삭제 일정

계정 탈퇴 처리 후 30일 유예기간이 적용됩니다. 이 기간에 다시 로그인하면 탈퇴가 취소됩니다. 30일이 지난 뒤 최초 오전 4시(대한민국 표준시) 일괄 삭제에서 처리합니다. 저장소·DB 장애가 발생하면 후속 처리에서 재시도합니다. 개별 기록 삭제 요청은 계정 탈퇴와 구분하여 처리합니다.

저장하지 않은 녹음 원본의 업로드 후 30일 보관, 내 악보 원본 파일의 변환 종료(성공·실패) 즉시·늦어도 업로드 후 30분 안 삭제, 재생 음원의 생성 후 10분 보관은 탈퇴 유예와 별개입니다. 저장한 연습 기록의 녹음은 그 기록을 삭제하거나 탈퇴 삭제가 끝날 때까지 보관합니다. 탈퇴를 취소해도 보관기간이 늘어나거나 삭제된 녹음·악보 원본·재생 음원이 복원되지는 않습니다.

삭제되는 데이터와 남는 데이터

계정 삭제 시 이메일·비밀번호 해시·닉네임을 지우고 계정에 연결된 녹음, 연습 세션, 채점 결과, 음표별 결과, 학습 진도, 내 악보와 재생 음원, 곡별 설정, 약관 동의 기록 및 소셜 계정 연결을 삭제합니다. 이메일·비밀번호 해시·닉네임을 제거한 내부 회원 식별 행과 탈퇴 완료 상태는 남습니다.

DB 백업은 최대 30일 보관하므로 삭제 이전 사본이 해당 기간 동안 남을 수 있습니다. 개인정보 관리자 접근기록은 1년 보관합니다. 복원 시 삭제 내역을 재적용한 뒤 서비스에 연결합니다. 삭제 범위·보존 예외와 요청 처리 결과는 담당자가 확인하여 안내합니다.
