# Backend 작업 지침

- Spring Boot + Kotlin 기반 앱 API와 평가 요청·결과 관리를 구현한다. `backend/`는 독립 Gradle 프로젝트이며 실행·검증·패키지 배치는 [README](README.md)를 따른다. DB·AI 호출 방식은 실제 설정과 확정된 결정을 확인한다.
- 요청별 추론·채점은 `ai/`, 데이터셋 생성은 `data/`와 연계한다. 같은 판정·변환 로직을 별도로 복제하지 않는다.
- Frontend·AI와 주고받는 악보·음표 식별자, 시간·음높이 단위, 결과·오류 형식을 맞춘다. 계약을 바꾸면 영향받는 소비자와 관련 문서를 함께 확인한다.
- 음원 업로드·평가 연동 변경 시 허용 입력, 잘못된 파일, 분석 실패·시간 초과·중복 요청의 처리 결과를 검증한다. 실제 요구에 없는 큐·별도 서비스를 선제적으로 추가하지 않는다.
- 로직·입력 검증은 서버·DB 전체 기동 없이 검사하고, 쿼리·매핑·트랜잭션 변경에는 필요한 DB 통합 검사를 수행한다. AI 대역을 사용한 테스트를 실제 모델 검증으로 보고하지 않는다.
- API 연동·저장 방식 조사에서 비교한 대안과 확인된 제약은 `docs/knowledge/backend/`에 남기고, 채택한 계약은 관련 설계 문서와 연결한다.
- 프로젝트를 초기화하거나 실행 방식을 바꾸면 설치·실행·검증 명령과 비밀값 없는 환경변수 예시를 이 폴더의 README에 기록한다.
