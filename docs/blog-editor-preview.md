# 블로그 글 수정 서식과 미리보기

- 작업: S15P31E102-663
- 기준: 블로그 브랜치의 S15P31E102-660 일괄 반영

## 완료 조건

- 작성자는 본문과 같은 박스 안에서 원문·미리보기, 서식, 기본 색상 5개, 임시 저장을 한 줄로 사용한다. 좁은 화면에서는 도구만 가로로 스크롤한다.
- 미리보기에서도 같은 원문 입력칸에서 수정한다. 넓은 화면은 원문과 결과를 나란히 놓고, 좁은 화면은 위아래로 배치한다. 제목과 본문을 바꾸면 결과가 갱신된다.
- Markdown 서식과 사용자 지정 글자 색을 저장한 뒤 공개 글에서도 볼 수 있다. 기존 작성자 권한과 임시 저장·삭제·일괄 반영 절차를 적용한다.

## 구현 및 확인

1. 편집 화면에서 Markdown 원문을 하나만 유지하고, 미리보기에는 사이트와 함께 배포한 markdown-it 15.0.3을 사용한다. 배포 빌드가 오프라인으로 동작하므로 브라우저 번들과 MIT 라이선스를 포함한다.
2. 글자 색은 Markdown 링크의 예약된 프래그먼트에 6자리 HEX 값으로 저장한다. 미리보기와 Hugo 공개 글은 해당 프래그먼트만 글자 색으로 변환한다. 임의 HTML과 임의 CSS를 허용하지 않는다.
3. Hugo 0.145.0으로 일반 링크·위험한 링크·유효한 색·잘못된 색의 출력과 기존 글 렌더링을 확인한다. 브라우저에서 로그인 대역을 통해 원문, 실시간 미리보기, 모바일 도구막대와 임시 저장 요청을 확인한다. 기존 Python 편집 서버와 배포 회귀 검사도 실행한다.

## 검증 결과

- Hugo 0.145.0으로 사이트를 빌드하고 별도 테스트 글에서 글자색, 표, 체크 목록, 일반 링크와 위험한 URL·HTML 차단을 확인했습니다.
- Chrome 1100px·320px에서 미리보기 중 제목과 원문 수정, RGB 적용, 한 줄 도구막대와 모바일 스크롤, 임시 저장 요청에 담긴 원문을 확인했습니다. 작성자 세션과 저장 응답은 로컬 대역을 사용했습니다.
- 편집·조회수 API 28건과 배포·TIL 테스트 33건이 통과했습니다. 미리보기와 공개 글은 동일한 본문 CSS를 쓰며, Hugo의 코드 하이라이트나 일부 확장 문법은 미리보기와 다를 수 있습니다.
