# 곡별 장단 반주와 굿거리 굴림

S15P31E102-160·340. 2026-11-04 사용자 승인 범위. 기존 카탈로그·율명 업무는 유지한다.

## 동작과 경계

- 160은 실제 굴림 출처를 확인하고 굿거리의 현행5단계(기준4분음표99, 적용59/79/99/109/119)에 맞는 약1017/759/606/550/504ms 굴림 구간을 준비한다. 원본·가공·잔향·청음 상태를 구분한다.
- 340은 검수된 곡별 장단을 선택한 연습 속도에 맞춰 실제 소리로 재생한다. 등록10종의 미리듣기와 기존 모범 연주 배속을 유지한다.
- 곡별 검수 결과에는 악보 판본/원본 식별자, 장단 ID, 시작tick, 패턴1주기에 대응하는score tick 길이, 근거 또는 미연결 사유가 필요하다. 제목·장단명만으로 자동 매칭하거나 악보·음원BPM을 덮어쓰지 않는다.
- 이름 없는45개와 음악적 주법이 미검수인 세령산은 근거 없이 소리를 붙이지 않는다. 검수 가능한 곡부터 연결하고 나머지는 사유를 명시한다.
- 모범 연주에서는 실제 미디어 위치/수행 시간표를 기준으로, 연습에서는 현재 악보 위치/선택BPM을 기준으로 소리를 예약한다. 일시정지·탐색·구간반복·배속·화면이탈·백그라운드·계정변경에서 이전 예약과 소리를 정리한다.
- 평가 녹음의 기존 마이크 유입 방지 정책을 보존한다. 실제 악기 연주 속도 자동 추종은 범위 밖이다.
- API 확장이 필요하면 기존 필드 의미를 보존하는 선택적 반주 메타데이터로 제공하고, 검수되지 않은 악보와 구버전 응답에서는 반주를 사용하지 않는다.

### 구현 계약

CAT04는 선택적 `jangdanPlayback {jangdanId,name,startTick,cycleTicks,pattern:{beats,group}}`을 제공한다. 기존 `jangdan_id`·BPM 필드의 의미와 저장값을 보존한다. sourceId·scoreVersion·악보 의미 해시·기본BPM·카탈로그 패턴이 검수 목록과 일치할 때만 반주 정보를 반환한다. 곡마다 첫 정간에 검수 기본형 첫 박을 맞춘 교육용 반주이며 원본 연주자의 변주를 복원했다고 주장하지 않는다.

앱에는 녹음하지 않고 시간표대로 연습하는 `장단으로 연습` 시작/정지 경로를 추가한다. 장단 패널 미리듣기와 모범 연주 반주도 같은 세션에서 관리한다. Android는 PCM을 미리 읽은 SoundPool을 원음 속도1로 재생하고, 현재score tick으로 기한을 판단한다. 지나간 타격을 한꺼번에 밀어 재생하지 않는다. 지원하지 않는 플랫폼과 미검수 곡에서는 소리를 낼 수 없는 이유를 표시한다.

다섯 굴림 클립은 공식 실제 굴림을 오프라인 시간 압축한 파생물이다. 두 클립(기본99/빠른119)의 사용자 청음 의견은 수용됐으나 전체 클립의 전문 연주자 검수는 별도다.

## 검증과 완료 조건

1. 굴림5개는 출처·허용 조건·해시·실제 길이·피크·가공 과정이 기록되고 다른속도에맞는클립을 선택한다. 음악적 청음 미확인은 기술검사와 구분한다.
2. 운영107개 조사목록의 연결/보류 사유를 모두 남기고, 기준악보와 다른판본에는 잘못 연결되지 않는다.
3. 다른BPM/음가스케일로 같은속도를표현한곡, 굿거리 소박/큰박 정간형,5속도 선택, 정지/탐색/반복/백그라운드의 행동검사가 통과한다.
4. Android 실행과 실제 오디오 출력의 기술증거를 남긴다. 실기기/연주자청음/미지원플랫폼 상태는 별도 보고한다.
5. 작업단위커밋까지 수행하며 Push·MR·운영반영은 이번 요청에 포함하지 않는다.
