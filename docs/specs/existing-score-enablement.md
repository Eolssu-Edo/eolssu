# 기존 악보를 유지한 36곡 채점 활성화

- 작업: S15P31E102-704. 사용자 2026-11-10 요청으로 699의 악보 교정과 분리한다.
- 대상: 단소 36, 정악대금 51–78 중 62·63·65 제외, 산조대금 79–88. 정확히 36곡이다.
- 원본 대조 근거: S15P31E102-699의 공개 API 스냅샷과 동일 JGB 재변환 결과. 전곡 원보의 새 사람 검수나 실제 연주 정확도 승인을 뜻하지 않는다.

## 동작과 보존

기존 `score_json`, `source`, `score_version`, 제목·악기·음표 수·빠르기·장단·게시 상태와 모범 음원 행을 유지하고 `is_scorable`만 false에서 true로 바꾼다. DB의 `updated_at` 자동 갱신은 허용한다. `provenance.review`를 승격하지 않는다. 699의 교정 대상 10곡을 포함하거나 임의 곡을 추가하는 계획은 거절한다.

계획에는 곡 ID, 출처, 판본, 음표 수, 기본 BPM, 악기와 원본 악보 SHA-256을 고정한다. 기본 실행은 조회만 한다. 적용 전 전체 36곡의 신원·공개 상태·삭제 여부·악보 해시·현재 판본의 공개 음원 존재를 검사한다. 하나라도 다르면 쓰지 않는다.

실제 적용은 실행자가 공유 배포 lock 안에서 사전 백업한 뒤 수행한다. 한 트랜잭션에서 행을 잠그고 이전 조회와 같은 악보·상태를 확인한다. 이미 활성화된 동일 곡은 쓰지 않는다. 결과와 보존 조건을 별도 조회로 확인하며, 응답 유실 시 재실행 전에 조회 모드로 실제 상태를 확인한다.

## 완료 조건

- 계획의 대상은 정확히 36곡이고, 699 교정 대상과 겹치지 않는다.
- 격리 MySQL에서 전체 적용, 재실행 변경 0, 중간 충돌 시 전부 롤백, 악보·검수·음원 불변을 확인한다.
- 운영 적용 후 36곡 채점 가능과 원본·판본·음원 보존을 확인한다.
- 실제 AI 입력 계약 및 연동 확인은 통제 입력을 사용하며 실제 사람 연주 정확도 검증과 구분한다.
