# 악보 인식 오류 교정 (806)

- 요청: 로컬 테스트에서 발견한 음높이·성부·꾸밈음 오류를 수정한다.
- 범위: Audiveris 원본 출력과 독립 정답을 대조하고, 선율 선택과 인식 후처리를 교정한다. 원음 MIDI와 편집 저장 형식을 보존한다.
- 완료 조건: 작은별 42음, 환희의 송가 62음, 프레르자크 선율 64음, Amazing Grace 본음 47음의 음높이·시작·길이를 따로 대조한다. 다른 곡의 오인식을 임의 추정으로 바꾸지 않고 확인할 음으로 남긴다.
- 스캔 정간보: 사용자 후속 답변 “오선보 오류만 먼저 수정”에 따라 이번 작업에서 제외한다. 기존 S15P31E102-458은 유지한다.
- 검증: 작은 MusicXML 회귀 → 실제 PDF/PNG 변환 → 공통 악보 편집·저장·재조회. 무거운 런타임은 격리한 로컬 컨테이너에서만 실행한다.

## 채택한 교정 기준

- 높은 성부와 활동량이 비슷하면 기존 높은 성부를 유지한다. 본음 시작 수가 두 배 이상인 하성부가 있으면 지속음 반주 대신 그 성부를 고른다. 붙임줄·화음은 시작 하나다.
- Audiveris의 smallHeads·smallBeams를 켜고 legacy 영어 OCR 가중치를 이미지에 포함한다. 빠르기 지시문 안에서 일반음으로 읽힌 머리는 해당 지시문 영역을 별도 그림에서 제외해 재인식한다.
- 마디가 박자표보다 길어지는 인식 결과는 같은 시간 예산 안에서 그림을 1.25배로 확대해 한 번 다시 읽는다. 한 선율에서 본음과 앞뒤 꾸밈음을 유일하게 대응할 수 있고 음고를 모두 보존할 때, 초과 마디의 음가만 가져온다. 정상 마디와 본음·꾸밈음 구분은 보존한다. 다성부·모호한 대응은 교정하지 않는다. 보정 적용 사실과 남는 초과 마디를 표시한다.

## 추가 자료 회귀 교정 (784)

- 짧은 마지막 악단을 읽도록 Audiveris의 최소 오선 길이를 30에서 20 오선 간격으로 설정한다. 실제 AuClair의 15~16마디가 빠지는 재현을 기준으로 한다.
- 시작 수 2배 기준을 유지하면서, 더 활동적인 성부의 본음 길이 중앙값이 높은 성부의 절반 이하인 경우도 선율 후보로 고른다. 두 성부의 대표 음 길이가 비슷하면 높은 성부를 유지한다. 선택은 계속 `VOICE_GUESSED`로 알린다.
- 스캔 입력은 원래 크기·절반 크기로 격자를 못 찾았을 때 모델 기준 높이 3091px와 2/3 크기를 추가로 시도한다. 마지막 시도는 기존 `grid_boxes`의 엄격한 검출로 얇은 선과 여러 단의 순서를 보존한다. 율명·가사 교대 열 추정은 끄고, 명시적인 가사 열에 인접한 단일 율명 열만 받는다. 같은 쪽당 시간 예산·화소 제한을 지키고 bbox는 원본 좌표로 돌린다. 글자층 PDF의 정확한 율명·음가 보존 경로는 유지한다.

## 이미지 중청 음역 복원 (876)

- 스캔 모델이 청 음으로 읽었어도, 해당 음의 그림에 두 물수변의 점·아래 획이 명확하면 중청으로 복원한다. 청·중청을 구별하는 글자 구조를 근거로 하며 악기 음역이나 선율 문맥으로 올리지 않는다.
- 모델 격자와 기하 격자 경로에서 같은 기준을 적용한다. 모호한 그림과 비음표·이미 중청인 토큰은 유지하고, 율 이름·위치·시김새·confidence·bbox·시간을 보존한다. 글자층 PDF와 오선보 경로는 변경하지 않는다.
- 같은 PNG·JPEG·PDF의 율명·옥타브 대조와 기존 청 음의 거짓 승격 방지를 완료 조건으로 삼는다. 새 추론도 provenance의 inferred 상태를 유지한다.
