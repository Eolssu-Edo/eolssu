# 내 악보 음역과 수정 안내 (741)

## 사용자 확정 요구

- 율명·기호 입력판에 `배탁 / 탁 / 기본 / 청 / 중청` 버튼 5개를 동시에 표시하고 한 번 누르면 해당 음역을 선택한다. 최초 기본(옥타브 0)을 선택한다. 기본의 한자 영역은 비운다.
- 버튼의 한자와 한글을 각각 가운데 정렬한다. 정간 속 글자의 배치는 이번 요청이 아니다.
- 지원하지 않는 음은 누르면 추천 대체음을 표시하고 사용자가 고른 음만 적용한다. 자동 조옮김·원본 임의 변경은 하지 않는다.
- 제공된 Blue Valentine 두 PDF를 근거로 대려 미지원, 지속 4개, 6각 세로 점, 중모리/맞는 장단 없음의 원인을 설명한다.

## 구현 경계와 검증

- 음역 저장값(-2…2), 원본 음표 식별자·길이·위치·검수 연결을 보존한다. 서버 지원 목록을 실제 지원 기준으로 사용하고 악기 자체의 연주 가능 범위와 구별해 안내한다.
- 후보는 알려진 지원 음만 표시하고 현재 음과 가까운 높이부터 안내한다. 선택 전에는 악보를 바꾸지 않으며 한 번의 실행 취소로 되돌린다. 지원 목록 조회 실패를 실제 미지원으로 단정하지 않는다.
- 정상 지속음은 독립 음이 아니라 앞의 소리를 이어가는 위치다. 확인된 오류는 근원 음과 연결해 이유와 수정 동작을 제공한다.
- 장단 판단은 실제 각 길이·박 단위와 카탈로그 길이를 대조한다. 증거 없이 중모리를 추천하거나 호환 조건을 완화하지 않는다.
- 제공 PDF에서 확인된 벡터 쉼표 누락·각 경계 지속 변환 문제를 수정한다. 사용자의 후속 범위 결정으로 우물사이 전용 옥타브 점 인식은 제외하고, 글자 주변의 점으로 음역을 추정하지 않는다. 원본 파일과 기존 저장 악보를 자동 덮어쓰지 않는다.
- 좁은 휴대폰 입력판에서도 5개 버튼의 글자가 잘리지 않고 선택 상태·동작이 구별돼야 한다. 관련 상태/저장 회귀, Android 빌드와 실제 고정 입력 UI를 검증한다.
