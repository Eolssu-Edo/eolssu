# 약관 공개와 국내 녹음 저장

- Task: S15P31E102-300. 사용자 결정: 2026-10-30 국내 운영 서버의 비공개 디스크로 녹음 저장 전환 승인.
- 운영 주체: 이도(Edo). 연락처는 Notion 지정 네 토글과 약관 제공 준비 문서를 따른다.
- 탈퇴 요청 후 30일 유예·로그인 취소를 유지한다.
- 추가 승인: Naver SMTP를 출시 기본으로 준비하고 Gmail SMTP는 확장으로 유지한다. 문의 처리 완료 후 90일, 일반 로그 14일, 개인정보 관리자 접근기록 1년, DB 백업 최대 30일로 정한다. 정책 확정과 운영 적용 완료를 구분한다.

## 구현 계약

1. 로컬 저장은 명시적으로 `RECORDING_STORAGE_TYPE=local`일 때 선택한다. 기존 S3 구현은 이관 검증 전 보존한다.
2. 녹음 키와 DB 참조는 유지한다. 저장 루트는 웹 공개 경로와 분리하고 backend 전용 계정만 접근한다.
3. 읽기는 기존 15분 만료 URL 계약을 유지하는 HMAC 서명 GET으로 제공한다. 변조·만료·삭제·업로드 30일 경과 파일은 반환하지 않는다. 경로 이탈·심볼릭 링크를 거절한다.
4. 원본은 업로드 후 30일이 되면 읽기를 막고 정기 정리한다. 탈퇴 배치는 같은 저장소의 삭제 구현을 사용한다.
5. 앱 외 삭제 안내는 로그인·DB 없이 공개한다. 이메일로 계정·개별 자료 삭제를 접수하고, 등록 이메일 소유를 확인한다. 비밀번호·인증번호를 이메일로 요구하지 않는다.
6. 공개 문서 및 서명 읽기 경로만 GET 공개 목록에 추가한다. 회원 API 인증은 유지한다. 서명 읽기 쿼리는 프록시 접근 로그에 남기지 않는다.

## 검증 및 운영 전환

격리 임시 디렉터리에서 저장·읽기·삭제·경로 이탈·서명 변조·만료·30일 경계를 검사한다. 실제 HTTP로 익명·잘못된 쿠키의 공개 문서 접근과 보호 API의 401을 검사한다.

운영 전환 전 R2 객체와 DB 키를 대조하고 업로드 시각·크기·해시를 보존해 국내 디스크로 복사한다. 업로드를 일시 중지하고 누락·중복·만료를 재대조한 뒤 설정을 전환한다. R2 원본 삭제는 국내 사본과 실제 분석·삭제 검증 후 별도 확정한다. 전환을 검증하기 전 ‘국내 저장 전환 완료’로 게시하지 않는다.

메일 전송·문의, 소셜 제공자와 백업은 녹음 저장 전환만으로 국내 처리로 바뀌지 않는다. 해당 처리 경로의 고지는 별도로 실제 계약·처리 조건에 맞춘다.
