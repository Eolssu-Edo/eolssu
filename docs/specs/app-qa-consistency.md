# 앱 점검 후 안내 문구 일치

- 작업: S15P31E102-906. 2026-11-14 사용자가 F04 수정 후 U01·U02·U03도 수정하고 ‘장단 미지정’으로 통일하도록 요청했다.
- 기존 악보·계정·API·저장 데이터의 의미는 유지하고 다음 화면과 선택 상태에 맞는 안내만 변경한다.

## 기대 동작

1. F04: 빠르기 편집 연필의 접근성 이름은 ‘빠르기 변경’이다.
2. U01: 악보 추가의 하단 버튼은 ‘악보 정보 입력하기’로 표시한다. 정간보/오선보 종류를 고른 뒤 기존 악보 정보 입력 화면으로 이동한다. 실제 파일 선택 버튼은 그 화면에 유지한다.
3. U02: 추천 구간이 기본 선택되어 있으면 ‘추천 구간으로 시작하거나 다시 선택하세요’라고 안내한다. 추천 구간이 없으면 시작 정간 선택, 첫 정간을 누른 뒤에는 끝 정간 선택, 수동 선택을 마치면 선택한 구간 연습을 안내한다. 추천 구간으로 되돌리면 추천 안내도 복원한다. 시작·끝 선택과 버튼 활성 조건은 유지한다.
4. U03: 장단이 지정되지 않은 항목의 화면 표시는 ‘장단 미지정’으로 통일한다. 관련 선택·도움말도 같은 이름을 사용한다. null ID·빈 이름과 리듬/반주 보존 등 기존 동작은 변경하지 않는다.

## 완료 조건

- 추천 있음/없음, 수동 선택 중/완료, 추천으로 복귀의 안내 상태를 작은 상태 테스트로 검증한다.
- XML·생성된 Compose 리소스와 Android 테스트·필요한 컴파일 결과를 확인한다. 새 문자열을 표시하는 화면 연결을 대조한다.
- 설치 앱·다른 플랫폼에서 실제 확인하지 않은 범위는 별도로 남긴다.
