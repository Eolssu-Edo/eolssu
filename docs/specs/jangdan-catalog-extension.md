# 서비스 장단 카탈로그 확장

S15P31E102-411. CAT-08·10의 기존 응답 형식을 유지하며 출처에서 구음·칸·묶음·BPM 단위를 확인한 장단만 추가한다. 기존 ID 1~3, 곡의 장단 FK·BPM·공통 악보 tick·모범 음원은 변경하지 않는다. 소리 제작160·재생340은 범위 밖이다.

자진모리(ID 4)는 e-국악아카데미 기본형의 12칸·3+3+3+3, 점4분음표 BPM 96으로 추가한다. 중중모리(ID 5)는 국립국악원 국악사전 기본형의 12칸·3+3+3+3, 점4분음표 BPM 80으로 추가한다. 두 기본 BPM은 각각 출처 범위 96~108·80~90의 하한을 선택한 카탈로그 시작값이며 개별 곡의 빠르기나 모든 변형의 정답이 아니다. 상세 source에 근거와 선택을 명시한다.

구음은 선택한 기본형의 순서와 빈 지속 칸을 보존한다. beats는 8분음표 칸, group은 3칸씩 묶은 네 박이다. 목록 beatCount는 기존 계약대로 12, groupCount는 4다. 곡 이름을 보고 장단을 자동 연결하지 않는다. 나머지5종의 구음·단위·시작값 근거는 [조사 기록](../knowledge/backend/jangdan-catalog-extension.md)에 남긴다.

## 완료 조건과 검증

- V21은 단일 INSERT로 일곱 행을 추가하며 기존 ID·행과 곡 데이터를 보존한다. 충돌하면 기존 행을 덮어쓰지 않고 실패한다. 이미 적용한 V1~V20은 수정하지 않는다.
- 폐기 가능한 MySQL 8.4에서 신규 설치·기존 V20 업그레이드·Flyway 재실행을 확인한다. CAT-10·08 실제 HTTP에서 문자열 ID·BPM/단위·구음·묶음·출처·soundUrl=null을 대조한다.
- 실제 로컬 HTTP 응답을 FE 카탈로그 Repository와 읽기 화면 상태로 전달해 목록 선택·상세 데이터가 동일한지 확인한다. 실기기 화면·청취 검증과 구분한다.
- BE clean build·databaseTest, 관련 데이터 검사와 FE host 검사를 실행한다. 사용자의 후속 MR 요청에 따라 검증한 브랜치 Push와 Draft MR 생성을 포함한다. 운영 DB 적용·배포·병합은 포함하지 않는다.

## 보류5종 후속 작업

2026-11-03 사용자 요청으로 같은411에서 나머지 후보를 이어서 처리했다. MR 준비에서 나눴던 V21·V22는 운영 미적용을 확인한 뒤 사용자 요청에 따라 V21 하나로 통합한다. 기존3종을 보존하고 추가7종을 단일 INSERT로 등록한다. 행의 값·응답 형식·허용 BPM 단위·곡 연결은 바꾸지 않는다.

- 엇모리: 아카데미 <자진아라리>의 10칸 구음 `[덩,"",덕,쿵,"",쿵,"",덕,쿵,""]`, group `[3,2,3,2]`. 국악사전의 8분음표180을 4분음표90으로 정확히 환산한다(180/2). 소박이 다른 박을 균등4박으로 바꾸지 않는다.
- 단모리: 아카데미 장단통일안의 4/4 기본형 `[덩,"",따,따,궁,따,궁,""]`, group `[2,2,2,2]`. 국악원 장구 교재의 4/4·4분음표120~160 하한120을 시작값으로 사용한다. 아카데미 웹의 점4분음표116~144 표기를 오탈자로 단정하거나 숫자만 가져오지 않는다.
- 타령·계면가락도드리: 국악원 장구 교재 악보10·14의12소박 기본형과 group `[3,3,3,3]`를 대조한다. 원문 표23의 기닥·다와 표25의 덩을 보존한다. 두 곡 계통의 속도차는 source에 남긴다.
- 세령산: 교재 악보8의10정간 기본형 `[덩,"",덩,더러러러,"",궁,"",기닥,"",다]`, group `[3,2,2,3]`. 혼합 대강과 한 정간의3소박을 구분한다.
- 사용자는 서비스 시작값 재사용을 선택했다. 정악3종은 QUARTER48·48·63으로 등록하되 원문 확정 빠르기로 표시하지 않는다. 타령·계면가락도드리는 한 칸이8분음표, 세령산은 한 칸이점4분음표이며 각 구음 칸의 길이는 각각1/2·3/2 4분음표다. 새 ID는 엇모리6·단모리7·타령8·계면가락도드리9·세령산10이다.

완료 검사는 V20→V21의 기존3장단·곡/음원 보존과 충돌 시 신규7종의 부분 등록 방지, source/구음/group/단위/BPM의 데이터·DB·HTTP·FE 상태 일치다. 새로운 enum·음원 재생·메트로놈 타이밍·곡 FK 변경은 범위 밖이다.

## 기본 BPM 80% 하향 (S15P31E102-1073)

2026-11-17 사용자가 정간보 인식 악보의 기본 빠르기가 빠르다고 보고, 장단 기본 BPM을 앱 전체에서 한 값으로 맞춰 낮추기로 했다. V46은 모든 장단의 `default_bpm`을 이전 값의 80%로 반올림해 바꾸고, 편집 빠르기 하한 40보다 낮으면 40으로 둔다. 이전 기본값일 때만 바꾼다. `data/reference/jangdans.json`도 같은 값으로 맞춘다.

| 장단 | 단위 | 이전 | 현재 |
| --- | --- | ---: | ---: |
| 세마치·자진모리 | 점4분음표 | 96 | 77 |
| 굿거리 | 점4분음표 | 66 | 53 |
| 중중모리 | 점4분음표 | 80 | 64 |
| 자진타령 | 점4분음표 | 60 | 48 |
| 중모리 | 4분음표 | 88 | 70 |
| 엇모리 | 4분음표 | 90 | 72 |
| 단모리 | 4분음표 | 120 | 96 |
| 타령·계면가락도드리 | 4분음표 | 48 | 40 |
| 세령산 | 4분음표 | 63 | 50 |
| 4박 기본 반주 | 4분음표 | 160 | 128 |

- 이 값은 정간보 인식 저장(요청·인식 BPM이 없을 때), 장단 고르기 표시, 편집 중 장단 변경, 새 악보, 빠르기 표시가 없는 오선보의 박자표 기본값이 함께 쓴다.
- 곡별 `songs.default_bpm`과 이미 저장된 내 악보 `bpm`은 바꾸지 않는다. 위 출처 문단의 범위·하한 설명은 이전 값의 근거이며, 새 값은 출처 범위보다 느린 서비스 시작값이다.
- 장단 미리듣기 M4A(`jangdan-preview/v1`)는 이전 BPM으로 만든 파일이다. 새 BPM으로 다시 만들어 올리고 `catalog/jangdan-preview-sha256.properties`를 바꾸는 일은 이 작업에 포함하지 않는다.
