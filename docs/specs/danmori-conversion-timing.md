# 정간보 단모리 변환 시간 교정

- Task: S15P31E102-732 · Story: S15P31E102-318
- 요청: 단모리 정간보 변환 오류를 고치고 같은 오류의 기존 악보·음원을 찾아 교정한다. 블루 발렌타인은 모든 변경에서 제외한다.

## 동작과 범위

정간보 PDF 변환은 장단 패턴의 소박 수를 BPM 기준 박으로 환산한다. 단모리는 8분 소박 8개가 4분 박 4개이므로, 4정간 각은 정간당 1박이며 120 BPM에서 2초다. 패턴 배열 길이를 그대로 4분 박 수로 사용하지 않는다. 동일 환산식을 쓰는 다른 장단도 기존 데이터에 정의된 단위로 검증하며, 오선보 원보 시간축과 정상 공개 카탈로그 생성 경로는 보존한다.

기존 데이터 교정은 정간보 자동 변환 이력과 이전 환산식에 부합하는 시간축을 함께 확인한 대상만 수행한다. 현재 악보·검수 초안·연계 음원의 판본과 상태를 조사하고, 백업·동시 변경 검출·재실행 안전성·수정 후 재조회를 갖춘다. 블루 발렌타인과 그 파생 제목/식별자는 명시적으로 제외한다. 출처 또는 시간축이 모호하면 자동 수정하지 않고 미확인으로 보고한다.

음원은 요청 시 만들어 내려받는 임시 결과다. 기기에 이미 저장된 파일은 서버에서 덮어쓸 수 없다. 수정한 악보에서는 정상 길이 음원을 다시 생성할 수 있어야 하며, 남아 있는 구판 임시 결과는 기존 판본/만료 규칙에 따라 재사용되지 않도록 확인한다. 공개 곡은 장단명만으로 수정하지 않는다.

## 완료 기준

1. 작은 4정간 입력이 변경 전 4초, 변경 후 2초가 되는 회귀 검사를 실제 변환·합성 경계에서 확인한다.
2. 장단별 소박 단위, 오선보 시간축, 정상 기존 곡을 회귀 검증한다.
3. 운영에서 조사한 수·확인된 대상·제외·미확인·수정 수를 구분하고, 수정 시 백업·전후 해시·판본·길이 검증을 남긴다.
4. 블루 발렌타인은 변경하지 않는다. 대상이 없으면 0건으로 보고하고 불필요한 갱신을 하지 않는다.
5. 구현·검증과 작업 단위 커밋까지 수행한다. MR·병합·제품 코드 배포는 이 요청에 포함되지 않으며 운영 데이터 교정 결과와 구분한다.

## MR 준비 시 통합 범위

후속 MR 요청에 따라 최신 `develop`의 저장 검증과 통합한다. 정간당 tick 비율과 각 길이를 검사하는 프론트엔드도 같은 소박 음가를 사용하여, 정상 변환된 단모리 4박 각과 세령산의 정간당 3/2박을 장단 불일치로 거부하지 않아야 한다. 기존 짧은 마지막 각 처리와 세마치의 비정상 배치 거부는 유지한다. MR 생성·Push까지 진행하며 병합과 배포는 포함하지 않는다.
