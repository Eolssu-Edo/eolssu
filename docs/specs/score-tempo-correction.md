# 기존 악보 장단·빠르기 교정

S15P31E102-728, 2026-11-11. 사용자가 원보 장단 → 원보 빠르기 → 외부 장단 → 외부 빠르기 순서의 전수 조사와, 빠르기 미기재 시 장단 기반 보완 및 운영 악보·모범 음원 반영을 요청했다.

## 범위와 판정

공개 카탈로그 전체를 현재 판본으로 다시 읽고 곡·악기·원본 식별자별로 조사한다. 원보의 숫자와 단위가 있으면 우선한다. JGB 편집기 기본값은 원보에 인쇄된 빠르기와 구분한다. 외부 자료는 판본과 박/소박 대응이 맞는지 확인한다. 원보에 없는 숫자를 장단 기본값으로 채우면 `장단 기반 연습값`으로 기록하며 원전 지정값으로 주장하지 않는다. 전통 장단이 없는 연습곡과 박자 편곡은 그 사실과 미확인 범위를 기록한다.

## 변경과 보존

사용자가 별도 채팅에서 처리한다고 명시한 비행기 56·132·133·134번은 제외한다. 기존 숨김 악보도 조사하되 공개 상태는 유지하며, 이번 교정의 숨김 대상은 소금 아리랑 107번이다. 곡별 네 단계 근거·직접 시각 검토 범위·남은 미확인 사항은 [조사 기록](../knowledge/data/common/rhythm-metronome/README.md)에 남긴다.

현재 운영 공통 악보를 기준으로 장단명을 보완하고 실제 빠르기를 교정한다. 음높이·선율·가사·시김새·이벤트 ID·채점 가능 여부와 기존 교정 결과는 보존한다. 박 단위의 표기 오류는 독립 근거가 있는 경우에만 함께 보정한다. 바뀌는 악보는 판본을 1 올리고 동일 공통 악보에서 모범 M4A와 performance를 재생성한다. 기존 R2 객체를 덮어쓰지 않고 새 키를 사용한다.

운영 적용은 현재 행과 파일 해시의 사전 일치, 공유 배포 잠금, 백업 성공, 변경 대상 비교 후 단일 트랜잭션, 사후 재조회와 API·실제 오디오 바이트/길이 검증을 요구한다. 동시 수정이 있으면 중단하고 재검토한다. 이전 악보·음원·수행 파일과 정확한 행 복구 자료를 보존한다.

## 완료 조건

- 공개 전곡의 네 단계 근거와 적용/유지/보류 이유를 기록한다.
- BPM 숫자뿐 아니라 단위·정간 비율·장단 주기를 검산한다.
- 바뀐 곡의 악보·모범 음원·수행 시간표 판본과 해시가 일치한다.
- 이전 선율·음높이·이벤트·채점 상태가 보존되고 다른 곡의 행이 변하지 않는다.
- 운영 API 재조회, 재생 파일 해시·디코딩 길이와 반주 주기를 확인한다.

전문 연주자 청음은 음악적 정답 승인이며 이번 기술적 반영 검증과 구분한다. 숫자가 없고 장단도 확인되지 않은 곡에 장단을 만들어 넣지 않는다.
