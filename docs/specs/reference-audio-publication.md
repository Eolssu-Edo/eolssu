# 기본음·시김새 운영 게시

- Task: S15P31E102-368. 사용자 승인: 서버 R2·DB·읽기 설정 적용. 앱 내 재생 연결은 S15P31E102-367 담당 범위다.
- 기존 [카탈로그 계약](reference-audio-catalog.md)의 M4A 430개와 검증된 명시적 매핑을 게시한다. 기본음 219개, 시김새 207개/315관계이며 개별 라벨 대안 4개는 미연결로 유지한다. 원본 라벨·근거·채점 제외 정책은 보존한다.
- 운영 적용 전에 실제 Flyway 이력·보존 데이터·R2 설정을 읽어 확인하고 백업·복구 경계를 기록한다. 비밀값은 문서나 로그에 남기지 않는다.
- 통합 develop `2a0d4d9b`의 중복 V13은 먼저 병합된 `V13__reference_audio_assets.sql`을 보존하고 학습 마이그레이션을 `V14__learning_tracks_and_progress.sql`로 옮긴다. 학습 DDL·36개 시드 내용과 API 계약은 바꾸지 않는다.
- 새 폐기 MySQL 8.4 DB에서 V1~V14 적용·재실행·검증 및 전체 백엔드 검사를 통과해야 한다. 기존 검증 DB의 checksum repair는 하지 않는다. MySQL DDL은 원자적 롤백을 보장하지 않으므로 학습 V14의 데이터·제약 사전 확인을 유지한다.
- 운영 게시 완료는 실제 R2 객체·해시, DB의 자산·매핑 수, 게시 상태와 읽기 API를 확인한 뒤 기록한다. 로컬 빌드 통과만으로 배포 완료를 판단하지 않는다.

실행 상태는 [368 계획](../plans/S15P31E102-368.md), 검증·운영 근거는 [게시 기록](../knowledge/infra/reference-audio-publication.md)에 남긴다.
