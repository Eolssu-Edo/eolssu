# 악보 편집 재진입의 이조 위치

- 작업: [S15P31E102-929](https://ssafy.atlassian.net/browse/S15P31E102-929), 2026-11-15 사용자 제보와 요청.
- 기존 [893 최초 선택](score-authoring-consistency.md#이조-슬라이더-최초-선택과-표식-정렬-s15p31e102-893)의 0반음은 적용 이력이 없는 악보의 기본값이다. 적용 이력이 있는 편집본을 새로 열거나 입력판을 다시 계산할 때는 그 편집본의 마지막 적용 offset을 표시한다.
- 현재 초안의 `authoring.adaptation.transpose`를 우선하고, 초안이 없으면 확정판의 같은 메타데이터를 사용한다. -6~+6 정수의 기존 저장 계약을 사용하며 적용 이력이 없거나 유효하지 않으면 0을 표시한다. 추천을 마지막 적용값으로 오인하거나 음고에서 offset을 역추정하지 않는다.
- 표시 복원과 미리보기 선택은 음고·원본·초안·서버 저장을 바꾸지 않는다. 적용 버튼을 누른 경우에만 기존 원본 기준 변환을 수행한다. 같은 offset 재적용은 누적 이조하지 않는다. 되돌리기·다시 실행은 해당 편집본의 적용 이력과 함께 복원한다.
- 다른 악보와 계정에 선택값을 공유하지 않는다. 적용 전 미리보기만 바꾼 값은 저장된 이조 이력이 아니다.
- 고정 악보로 양수·음수·0, 초안/확정 저장과 재조회, 입력판 재생성, 되돌리기, 다른 악보·계정 경계를 확인한다. 실기기·iOS 검증은 자동 검사의 증거와 구분한다.
