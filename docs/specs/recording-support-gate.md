# 녹음 미지원 환경의 평가 시작 제한

- 작업: S15P31E102-305. S15P31E102-261 후속 수정, Story S15P31E102-109.
- 요청: 녹음 미지원 환경에서 평가 연주가 진행된 뒤 분석 오류로 끝나지 않도록 시작 전에 안내·차단한다.

## 동작과 범위

기존 DI의 `AudioRecorder` 등록 여부를 사용한다. 현재 Android는 녹음기를 등록하고 Web(JS·Wasm)과 iOS는 등록하지 않는다. 플랫폼 이름을 검사하거나 입력 크기 측정 여부(`measuresLevel`)를 녹음 지원 여부로 취급하지 않는다. iOS 녹음 구현은 S15P31E102-258의 범위다.

- 미지원이면 연습 화면의 준비·혼자 연습·모범 연주 상태에서 평가 시작/전환 버튼을 비활성화하고 녹음·평가 미지원 안내를 표시한다.
- 녹음 권한 요청·카운트다운·재시작·이어 연주를 직접 호출해도 녹음기가 없으면 진행하지 않는다.
- 악보 보기, 설정, 모범 연주 등 녹음하지 않는 연습은 유지한다.
- 녹음기가 있으면 기존 권한 흐름과 녹음·중단·재시작을 유지한다. 입력 크기를 측정하지 않는 녹음기도 평가할 수 있다.
- 저장된 녹음이 있는 정상 종료에서만 분석 화면으로 이동한다. 저장 실패는 기존 녹음 실패 안내로 처리한다.
- 녹음이 없을 때 예시 분석으로 대체하지 않는다. 서버 API·공통 오디오 인터페이스는 변경하지 않는다.

## 검증

공통 ViewModel 테스트로 미지원 진입 차단, 권한 거부, 정상 녹음 종료, 저장 실패, 중단·재시작을 검사한다. Android host 전체 테스트와 Android debug/Web Wasm 빌드를 실행하고 Web JS·Wasm 테스트로 공통 동작을 확인한다. iOS 빌드와 실제 기기 마이크 검증은 Mac/기기에서 별도로 수행하며 Windows 검사로 대체하지 않는다.

2026-10-30 Windows 검증 결과: Android host 488개 통과·기존 로컬 서버 미설정 검사 1개 skip, Web JS·Wasm 각각 483개 통과. Android debug APK와 Web Wasm 배포 빌드 성공. 로컬 CAT02/CAT04 악보 fixture로 준비·혼자 연습·모범 연주 화면의 안내와 평가 버튼 차단, 설정 패널 유지, 분석·업로드 POST 미발생을 확인했다. 최종 배포 빌드의 좁은 화면에서도 안내·시작 차단을 확인했다. iOS 빌드와 실기기 녹음은 미검증이다.
