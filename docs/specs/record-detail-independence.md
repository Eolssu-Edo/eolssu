# 기록 상세와 판본 조회

S15P31E102-454는 PRA-03의 세션 메타데이터와 EVA-01 점수를 조립해 목록 캐시 없이 기록을 연다. `songTitle`, `scoreVersion`, BPM, 시작 시각은 세션을 기준으로 삼는다. 목록은 이전 기록 비교 후보와 즉시 표시를 위한 보조 자료다.

과거 악보를 보관하지 않고 현재 공개 악보만 사용하던 이전 454 초안의 결정은 폐기한다. 745에서 보관하는 판본을 CAT-01과 CAT-04의 `scoreVersion` 쿼리로 함께 조회하며 응답 판본도 확인한다. 결과·기록·취약 구간·비교 모두 이 계약을 사용한다. 현재 판본에 잘못 끼워 맞추지 않는다.

점수·메모·녹음은 악보와 별개다. 악보가 숨김·404·네트워크 실패로 열리지 않으면 악보 영역에 재시도를 제공하고 나머지는 유지한다. 정간 오류와 소박 오류는 같은 당시 판본의 음 인덱스로 매핑한다. 다른 계정이나 다른 기록·판본의 비동기 응답은 재사용하지 않는다.

녹음 파일의 판본 캡처와 신규 세션의 현재 판본 검증은 453의 책임이다. 데이터 변경과 공개는 707, 판본 보관과 서버 응답은 745의 책임이다.
