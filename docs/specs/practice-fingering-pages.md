# 연습 운지 고정 페이지와 가사 표시

- 작업: S15P31E102-500 · Story: S15P31E102-32 · Epic: S15P31E102-20.
- 2026-11-05 사용자 요청 및 페이지 구성 확인에 따른 구현 계약.

## 동작과 보존

1. 원본 율명과 옥타브로 내장 운지를 찾는다. 17개 Yul enum으로 축소하지 않는다. 자료가 없는 실제 음은 ‘운지 자료 없음’으로 표시하고 실제 쉼만 ‘쉼’으로 표시한다. 내장표의 구멍·취법 자체는 근거 없이 바꾸지 않는다.
2. 운지 함께 보기는 실제 발음하는 율명이 최소 6개가 될 때까지 대강을 묶어 고정 페이지로 표시한다. 장음·쉼·빈 자리는 음 개수에서 제외하며 마지막 페이지는 남은 만큼 표시한다. 페이지 안에서는 연주 위치 강조만 바뀌고 스크롤하지 않는다. 끝 경계에서 즉시 다음 페이지로 넘기고 탐색·되감기에도 해당 페이지로 이동한다. 아래에는 현재 페이지 이후 실제 발음할 음 2개의 율명과 운지를 추가로 표시한다. 연주 전에는 이전·다음 페이지를 직접 선택할 수 있다.
3. 장음·빈 자리에는 운지를 그리지 않는다. 실제 쉼은 별도로 표시한다. 원본 표시 자리와 그림의 세로 정렬을 유지한다.
4. 가사는 원본 정간에 보존하며 표시할 때만 장음·구분 기호·한글이 아닌 문자를 제외한다. 원본 토큰의 위치를 유지해 한글 음절을 대응하는 표시 자리 옆에 놓는다. 메타 표식 `{세로표}`는 통째로 제거한다. 일반 정간보 곁줄과 운지 함께 보기에 적용한다.

대강 분절은 검수된 곡별 장단 연결의 tick을 우선하고, 연결이 없으면 원본 `ticksPerBeat / ticksPerJeonggan`과 장단의 소박 단위를 환산한다. 도라지타령처럼 원본 3정간·장단 9소박이면 대강 하나가 원본 1정간이다. 대강 하나가 1.5정간인 경우도 그 분수 위치를 유지해 실제 발음이 6개 이상이 되는 대강 끝에서 페이지를 나눈다. 페이지 경계가 표시 자리 안에 있으면 화면에 그릴 부분만 나누고 다음 페이지의 계속음은 장음으로 표시해 운지·가사를 반복하지 않는다. 원본 Score와 이벤트·ID·tick은 분할·변경하지 않는다. 페이지 내부 대강 선은 원본 표시 자리 경계에 맞을 때만 그린다. 장단 정보가 없으면 각을 보존 단위로 쓰고 대강을 추정하지 않는다. 마지막 페이지·미리보기는 남은 만큼만 표시한다. 작은 화면과 큰 글꼴에서는 사용자가 페이지 전체를 스크롤할 수 있지만 재생에 따른 자동 이동은 하지 않는다.

2026-11-05 후속 화면 확인에서 두 대강에 실제 음이 3개만 남는 사례를 확인했다. 사용자가 한 페이지에 5~6개 이상의 율명과 별도 미리보기 2개를 요청해, 기존 대강 2개 고정 개수는 위의 최소 6음 기준으로 대체한다. 대강의 시간·표시 경계 보존은 유지한다. 장음·빈 자리의 줄 높이는 실제 음보다 낮춰 율명과 운지를 함께 읽을 공간을 확보한다.

## 검증

내장 운지 전체의 율명·옥타브 대응, 청고·중청태·배이 이체자, 미지원 음과 쉼 구분, 대강 페이지 경계·이음 지속·탐색·마지막 페이지·다음 발음 2개, 장음 그림 제거, 기호 포함 가사 위치를 작은 고정 데이터로 검사한다. Android host 전체와 JS/Wasm 검사 및 가능한 실행 UI를 확인한다. Windows에서 iOS 실기기 검증은 별도 미확인으로 남긴다.

## 미리보기 표와 장단 안내 후속 변경 (2026-11-05)

사용자 요청으로 다음 두 음 미리보기를 현재 악보와 동일한 `운지법 | 율명 | 가사` 열의 세로 두 행으로 표시한다. 현재 페이지 밖 다음 두 발음을 그대로 사용하며 원본 슬롯의 한글 가사를 대응한다. 남은 음이 하나면 한 행, 없으면 끝 안내를 표시한다. 정상 장단 재생 상태 안내 카드는 제거한다. 장단 오류 안내와 재생 동작은 유지한다.
