# 정간보 시김새 기호 표시

## 원본 모양과 편집 입력 지원 (S15P31E102-920)

2026-11-15 사용자가 제공한 산조대금 진도아리랑 정간보와 “그대로 재현해”, “편집하기에서 지원되도록” 요청을 기준으로 아래 847의 표시 전용 범위를 확장한다.

- 반음올림표는 서양식 ♯ 대신 원본의 두 가로획과 오른쪽 연결획(ュ형)을 자체 벡터로 그린다. 한자 二나 대체 글꼴에 의존하지 않는다.
- 표시 registry 밖에 있던 혀치기·반음올림표·꺾는음·원문점을 같은 registry에 등록해 편집기 선택 목록에서도 제공한다. 기존 항목의 순서를 유지하고 뒤에 추가한다.
- 이름과 `@변형` 문자열, 선택 소박, 이벤트 ID·음고·tick·길이를 보존한다. 한 소박 3개 제한, 선택 해제·삭제·저장·재진입은 기존 편집 흐름을 따른다.
- 꺾는음과 흘림표는 그림을 공유해도 이름을 합치지 않는다. 원문점은 의미 미확정 원문 주석이며 반길이·끊는표로 재해석하지 않는다. 재생·채점의 해석 계약은 변경하지 않는다.
- 수용 기준: 네 항목의 선택·삭제·재선택과 공통 악보 JSON 저장/복원, 표시·편집 목록 차집합 해소, 첨부 원본과 벡터 모양 비교, 공통 회귀·Android/JS/Wasm 빌드 확인. 실제 UI와 iOS 미검증은 따로 기록한다.

## 이전 표시 전용 범위 (S15P31E102-847)

- 작업: S15P31E102-847. 진도아리랑 수정 뒤 사용자가 공개 악보 전체의 동일 현상 확인과 누락 매핑 수정을 요청했다. 화면 확인 없이 코드·데이터와 자동 검사로 검증한다.
- 기준: 최초 구현 `c5b01437`, 2026-11-13 공개 CAT-01의 108곡과 각 CAT-04 응답. 조회 시작·종료의 곡 ID·판본 목록이 같음을 확인한다.

## 표시와 보존

등록된 시김새는 기존 기호 그림을 사용한다. 혀치기(10개)·반음올림표(16개)·꺾는음(5개)의 빠진 표시 매핑을 추가한다. 혀치기는 공식 대금 교재 p164의 원과 윗획 기호, 반음올림표는 올림표(♯), 꺾는음은 기존 닫는 괄호 모양 기호로 표시한다. 꺾는음의 그림 재사용을 흘림표와의 음향적 동의어로 취급하지 않는다.

`이름@변형`은 기존 이름 추출을 그대로 쓰고 원본 문자열·위치 값을 보존한다. 이번 매핑은 표시 전용으로 기존 편집 입력 목록을 확장하지 않는다. 미확인 이름 처리와 접근성 이름, 이벤트·정간·소박 ID, tick, 재생·채점 계약과 운영 악보는 유지한다.

초기 진도아리랑 범위에서 제외했던 단소 몽금포타령의 `원문점` 1개는 전체 점검 요청에 따라 포함한다. 점 모양만 복원하고 의미 미확정 상태를 유지한다. 반길이표·끊는표로 해석하거나 음악 데이터를 변경하지 않는다. 개인 악보와 비공개 악보는 이 공개 카탈로그 전수 결과에 포함하지 않는다.

## 완료 조건

- 공개 108곡의 실제 시김새 396개·29종이 모두 기호 리소스로 해석되어 한글 대체 출력이 남지 않는다. 실패·누락 곡 없이 원본 판본·응답 해시와 곡별 결과를 기록한다.
- 전체 캡처의 모든 곡을 공통 악보 어댑터와 6개 연습 모드로 검사한다. 원본 이름·이벤트·tick과 기존 편집 입력 목록·기호 그림은 유지한다.
- 수정 전 회귀 검사의 실패와 수정 후 통과, Android host 회귀와 Android·JS·Wasm 컴파일 결과를 남긴다. UI·iOS 실기기 결과와 구분한다.
