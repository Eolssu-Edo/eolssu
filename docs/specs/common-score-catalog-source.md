# 기존 곡 복원과 공통 악보 원본

관련 작업은 [S15P31E102-477](https://ssafy.atlassian.net/browse/S15P31E102-477)이다.

- 제공 곡의 작업 원본은 공통 악보 JSON이다. 신규 작성, 수정, 검수, 적재에는 동일한 JSON을 사용한다. JGB는 출처 보관과 가져오기 입력으로 관리한다.
- 정간 가사는 같은 정간 ID의 선택 필드에 넣고, 연습 악보와 운지법의 가사 칸에 표시한다. 기존 JSON도 읽을 수 있어야 한다.
- 기존 곡은 원본 해시와 성부, 각·정간 배치를 확인한 뒤 가사를 복원한다. 악보 버전, 이벤트, 표시 단위, 기준음 및 틱을 보존한다.
- 공개 적재는 구버전 클라이언트의 파서 호환성과 가사 이용 조건을 확인한 후 진행한다. 검증용 자료와 실제 콘텐츠는 분리해 관리한다.

## 작성과 검수

각·정간·표시 단위와 이벤트를 공통 JSON에 직접 작성하고 식별자와 틱을 확인한다. 기본 BPM은 곡 카탈로그에 함께 기록한다. 음원에 곡별 표현이 필요하면 공통 JSON의 파일 해시와 연결한 표현 JSON을 같이 검수한다. 음원 생성기는 공통 JSON과 이 표현 파일을 직접 받는다. JGB에서 만든 판본은 원본 해시를 보존한다. 직접 작성한 악보는 내 악보 저장 경로처럼 공통 문서의 콘텐츠 해시를 기록한다. 기존 v1의 해시 필드명은 `provenance.jgbSha256`이다.

복원 결과와 원본 대조 범위는 [복원 검증 기록](../knowledge/data/catalog-notation-restoration.md)에 있다.
