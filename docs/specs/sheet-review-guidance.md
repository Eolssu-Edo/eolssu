# 저장·선택 위치의 검수 안내

- 저장 창에서 변환 당시 참고 안내와 현재 저장 제한을 구분한다. 원본 인식 과정의 notice는 사유와 확인할 내용을 보여 주며 저장을 막는 항목으로 취급하지 않는다.
- 서버가 제공한 쪽·원본 마디 위치를 가능한 범위에서 보존한다. 선택 위치의 정보 창은 기존대로 클릭한 정간·소박의 검수만 보여 준다. 연결하지 못한 위치를 추정하지 않는다.
- 같은 의미와 위치의 안내가 반복되면 한 줄과 횟수로 보여 준다. 서로 다른 사유·쪽·마디는 합치지 않는다. 안내 표시를 합쳐도 원래 issue ID·확인 상태·원본·악보는 바꾸지 않는다.
- 제보에서 확인한 PDF 빠르기 보완·성부 선택에 맞는 문구와 확인할 대상을 제공한다. 기존 박자·장단·인식 실패 등의 안내는 유지한다. 알 수 없는 사유는 원본 대조가 필요하다고 안내하며 알려진 사유로 가장하지 않는다.
- 미확인 검수와 지원하지 않는 음·빈칸·구조·장단·카탈로그 등의 현재 확정 저장 제한과 명시적 확인은 유지한다. 안내 열기·닫기·단순 저장 창 열기로 검수를 자동 확인하지 않는다.
