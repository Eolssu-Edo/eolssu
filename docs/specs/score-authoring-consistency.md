# 악보 추가·편집의 지원·변환·재생 일관성

## 인식 검수 이유의 정간 클릭 안내 (S15P31E102-890)

2026-11-13 사용자 요청으로 미확인 인식 검수가 있는 정간·소박을 누르면 **클릭한 위치의 기호와 그 위치에 연결된 검수 이유만** 안내한다. 후속 사용자 지시로 기존 전체 검수 창을 재사용하려던 선택을 대체한다. 클릭 창에는 전체 검수 건수·다른 정간의 오류·장단·전체 음역 요약을 넣지 않는다. 소박에 연결된 이벤트 검수는 그 이벤트를 가리키는 소박에만 표시하고, 정간 전체 검수는 그 정간의 소박에 적용한다.

기존 음고 교정 후보가 있으면 음고 교정 팝업과 대체음 선택을 유지하며, 추가 인식 사유도 선택한 소박·이벤트에 해당하는 것만 표시한다. 후보가 없는 쉼표는 클릭 전용 정보 창으로 안내한다. `LOW_CONFIDENCE`의 실제 `detail.reason`이 `GAP_IN_VOICE`일 때 **선율을 읽지 못해 쉼으로 채웠으니 확인 필요**를 표시한다. 이유가 없거나 다른 검수에는 이 문구를 추정해 사용하지 않는다.

클릭 전용 창은 닫기만 제공하며, 열거나 닫는 동작은 음·길이·원본 연결·검수 확인 상태를 바꾸지 않는다. 전체 검수 요약과 기존 `확인했어요`는 저장 버튼 경로에 유지한다. 이미 확인된 항목은 클릭 안내 대상으로 다시 열지 않으며, 다음 검수·되돌리기·미지원 음고 교정의 기존 동작을 보존한다. 외부 API와 저장 형식은 변경하지 않고 서버가 이미 제공하는 사유를 클라이언트 내부에서 유지한다.

## 해결된 음역 검수의 자동 해제 (S15P31E102-871)

2026-11-13 사용자 요청으로 이조 후 해결된 음역 오류를 자동 해제한다. 기존828의 변경 칸 재확인 정책 중 `UNREGISTERED_PITCH`·`OUT_OF_RANGE`만 현재 악보의 작성 지원음 판정으로 대체한다. 원본 검수 항목을 삭제하거나 사람의 확인 여부를 조작하지 않고 해결된 ID를 파생한다. 되돌리기로 지원하지 않는 음이 돌아오면 오류도 복원한다. 새로 열 때도 같은 악보와 카탈로그로 판정하고, 확정 저장에는 자동 해결된 ID도 전달한다.

빈칸·구조가 정상이고 현재 선택 악기·조율의 작성 지원음에 해당할 때만 음역 검수를 자동 해제한다. 현재 악기의 작성 카탈로그가 없거나 다른 악기·조율의 카탈로그만 있으면 전역 음 목록만으로 자동 해제하지 않는다. 인식 신뢰도·누락된 시김새 등 다른 종류의 검수와 아직 지원하지 않는 음은 유지한다. 반복 이음 칸을 여러 음표로 세지 않는 추천 음 수 계약과 원본 음고·식별자·시간 보존은 유지한다. 실제 사용자 PDF는 로컬 OMR 실행 및 동일 FE 경로로 추천·미해결 음 수를 확인하고, 원본과 인식 결과의 정확도 한계는 따로 기록한다.

## 추가 점검 후 수정 기준 (S15P31E102-828)

2026-11-13 사용자는 추가 점검의 웹 뒤로 가기 항목을 제외하고 나머지4건 수정을 요청했다. 미해결 음의 율명·옥타브는 다른 음의 시김새·구조 편집 후에도 보존한다. 표시 문자열의 제한 때문에 실제 음고를 다시 해석하지 않는다. 지원하지 않는 음의 최종 저장 차단과 원본·시간·식별자 보존 계약은 유지한다.

저장 오류 안내의 장단 변경은 실제 장단 선택창을 열어 선택·취소·명시적 해제가 가능해야 한다. 음역 맞추기로 내용이 달라진 인식 검토 칸은 일반 음 수정과 같은 규칙으로 확인 상태를 해제하고, 바뀌지 않은 칸의 확인은 유지한다. 내 악보 목록에 처음부터 FAILED인 항목이 있으면 변환 상세를 조회해 실패 원인별 안내에 사용하고 종료 상태의 무기한 반복 조회는 하지 않는다. 웹 브라우저 뒤로 가기 동작은 이번 수정 범위에서 제외한다.

검증은 미해결 고음·저음의 음고 보존과 수정·되돌리기, 장단 오류 안내의 실제 연결, 변경·미변경 칸의 확인 상태, 최초 실패 목록의 상세 조회·재진입·일시 실패를 포함한다. [작업 기록](../plans/S15P31E102-828.md)에 실행 결과와 한계를 남긴다.

### 음역 맞추기 입력판과 추천 (S15P31E102-820)

2026-11-12 사용자 요청·두 선택 답변과 미리보기 후 수정 요청으로 확정했다. 편집기의 첫 탭을 `음역 맞추기`로 두고 첫 진입 시에도 선택해 연다. 네 탭은 가로로 스크롤하며 기존 율명·시김새·정간 도구를 유지한다. 악기 선택, 1반음 단위 -6~+6 슬라이더, 음 수 요약과 적용을 제공한다. 슬라이더의 기본 추천 위치는 채운 마름모, 이조 폭 최소 대안은 빈 마름모로 표시하고 동일 위치이면 중복하지 않는다. 별도 추천 버튼·추천 기준 설명창·변경 내역 목록은 제공하지 않는다. `직접 수정 N음`은 `직접 고쳐야 할 음 N개`로 바꾼다. 입력판은200dp이며 긴 내용은 안에서 넘긴다. 검증 전용 상단 버튼은 사용자 미리보기에서 제거한다.

FE의 기본 추천은 **미해결 음 수 → 옥타브 이동 음 수 → 총 옥타브 이동량 → 이조 절댓값 → 부호** 순이다. 기존 위의 전역 이조 폭 우선 정책에서 FE 추천 순서만 대체한다. 이조 폭을 먼저 최소화한 대안도 별도 이유와 함께 보여주고, 같은 후보라면 중복 표시하지 않는다. 예를 들어 모두 해결 가능한 -1반음/옥타브 이동 2개와 +4반음/옥타브 이동 0개가 있으면 +4를 기본 추천한다. 입력값 변경은 미리보기이며 적용 전 악보를 바꾸지 않는다.

적용은 모든 현재 NOTE를 다시 맞추며 기존 개별 음높이·옥타브 수정은 보존하지 않는다. 원본과 안전하게 대응되는 음은 보존한 원본 음고로 재계산한다. 원본에 없는 새 음·안전한 대응을 복원할 수 없는 음은 현재 판본의 기준 음고를 사용한다(유지하기로 한 추가·삭제·분할과 모순되게 원본 악보 전체로 되돌리지 않는다). 제목·빠르기·장단·시김새·가사·정간 분할·쉼·이벤트 ID/시간은 유지한다. 적용 직전에 음높이 수정 덮어쓰기 경고를 띄우며 취소하면 내용과 선택을 유지한다. 적용은 한 번의 실행 취소로 복원한다. 원본 전체·추가/삭제를 초기화하는 동작은 사용자 답변으로 제외했다.

검증은 추천 순서/복수 위치 표시, 원본 기준 반복 적용/부분 편집/음고 덮어쓰기/다른 편집 보존, 적용 확인·취소·실행 취소 및 좁은 화면의 탭/슬라이더/드롭다운을 대상으로 한다. DATA 변환 알고리즘이나 서버 음역·원본 불변 계약은 변경하지 않는다.

지원음의 소유자는 기존 서버 카탈로그다. CAT06의 명목 탐색 음역 의미를 유지하고, 작성용 능력 조회를 추가한다. 물리 가이드/확인 상태, 운지 등록, 표기, 합성 능력, 최종 selectable과 사유를 구분한다. DATA의 기존 CAT profiles를 공통 자료로 사용하고 FE에 악기별 음을 하드코딩하지 않는다. 서버 저장과 선택한 다른 악기의 음원 생성도 동일 정책을 사용한다.

장단의 패턴 칸 음가는 카탈로그 데이터에서 관리하여 FE·BE·OMR·DATA에서 동일하게 읽는다. ID/이름/단위/패턴/주기가 일치해야 한다. 장단 없음은 null ID와 빈 이름을 함께 저장한다. 미해결 주기는 음표를 자동 늘리거나 줄이지 않고 장단 변경·명시적 해제 또는 위치 수정으로 해결한다.

원본 보존은 인식된 원래 음고·옥타브·eventId/위치와 변환 이력을 뜻한다. 기존 확정된 업로드 PDF 임시 보관·삭제 정책은 바꾸지 않는다. 재변환은 변환본에 누적하지 않고 보존한 기준에서 계산한다. 공통 악보 v1의 엄격한 필드를 임의 확장하지 않고, 편집 부가정보와 기존 수행 companion을 판본에 결합한다. 과거 원본이 없는 데이터는 원본 보유로 가장하지 않는다.

구간 빠르기는 DATA의 기존 SHA 결합 `common-score-expressions/v1`와 `performancePlan`을 선택적 형제 `expressions`로 연결한다. 이 계획의 bpm은 정간/분이므로 앱의 QUARTER/DOTTED_QUARTER와 변환해야 한다. 존재하지 않는 원본 계획을 생성 시간표만으로 확정 복원하지 않는다. 숫자 계획이 있으면 위치를 바꾸는 추가·삭제·분할·합침을 막고 짧게 안내한다. 서버도 이벤트 ID·시작·길이·칸 배치·박 단위 변경을 거절한다. 음고·쉼·악기·기본 BPM 변경은 허용한다. 사용자 확정대로 기본100/구간80에서 기본120으로 바꾸면120/96으로 한 번 비례 조정한다. 상세 수치 경계와 근거는 [빠르기 계약](../knowledge/data/score-authoring-tempo.md)을 따른다.

## 검증 경계

### 구간 빠르기와 음원 생성의 저장 경계 (S15P31E102-904)

음원 생성은 서버의 마지막 확정 악보와 companion을 사용한다. 기본 BPM·장단뿐 아니라 구간 빠르기의 추가·수정·삭제와 기준 BPM이 확정판과 다르면 먼저 저장하도록 안내하고 생성 요청을 보내지 않는다. 임시저장은 확정판을 바꾸지 않는다. 확정 저장이 성공하면 저장한 구간 빠르기로 생성할 수 있다. 기존 API·companion 형식과 빠르기 해석은 유지한다.

각 Task는 작은 고정 데이터로 실패를 먼저 재현하고 독립 단위/계약/API 검사를 수행한다. 통합 시 가져오기→지원음 선택/변환→편집→장단·빠르기→확정 저장→생성/시간표의 같은 음표 ID·음고·tick·판본을 대조한다. UI 빌드·호스트 테스트, 실제 API/DB, 실제 CAT 생성, 실기기 청취와 실물 악기 연주 검수는 별도 결과로 기록한다. 누락된 CAT 자산·FFmpeg 또는 기기 검증을 단위 테스트로 대체하여 완료라고 하지 않는다.
