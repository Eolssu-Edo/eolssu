# 단소 JGB 표현과 빠르기 보완

Task: S15P31E102-166. 2026-10-27 사용자 요청: 숨표·빈지속·농음·흘림을 조사해 적용 방법을 정하고 변환, 빠르기를 조사해 JSON에 저장, 진도아리랑·청성곡의 단소 원보까지 확인.

## 범위와 보존

Notion DATA의 단소41항목을 대상으로 한다. 원본 PDF/JGB를 덮어쓰지 않고 원본 해시와 파생 JGB·빠르기·정책·전사 위치를 연결한다. 악보에 없는 음을 오류 회피용으로 삭제하거나 자동전조하지 않는다. 소금·대금 확장은 하지 않는다. 공통 FE/AI/BE 계약과 채점은 변경하지 않는다.

## 재생 정책

- 숨표: 기존 목표는 무음120ms+release50ms. 마지막 전개음의 실제 길이L에 대해 총단축량=min(170ms,L/2), release=min(50ms,총단축량/2), 나머지는 무음으로 배분한다. 양자화 후에도 원음 절반을 남기며 다음 음의 시작·장단 길이는 유지한다. 이 수치는 국악 표준이 아닌 재생용 선택값이다. 명시 IR의 기존 breath_seconds는 그대로 유지하고 JGB가 새 정책을 적용해 유효값을 기록한다.
- 가변 release는 MIDI CC72에 기록한다. 이 프로젝트의 값127=50ms, 선형0~50ms 환산은 사용자 정의 CAT 재생 규약이며 MIDI 표준의 보편적인 절대시간 의미가 아니다. 기존50ms 음은 종전 재생을 유지한다.
- 빈지속: 분박 슬롯을 보존하는 지속 별칭. 같은 각의 앞 음을 연장하고 각 첫칸·쉼 뒤에는 쉼을 유지한다. 삭제하지 않는다.
- 농음·흘림: 농음은4Hz·depth0.08·지연0의 음량 요성, 흘림은 말미30%(최대200ms)에50cent 하강을 적용한다. 기존105의 추가 떨림은 유지한다. 긴 기호는 원보에서 확인한 범위를 파생본에 전개한다. 원문점은 의미 미확정 주석으로 보존하고 효과를 주지 않으며, 그 외 미지원 기호는 위치와 함께 보류한다.
- 느니르·니로나는 기호 사전의 상대음 진행, 덧길이·반길이는 합이 정간 시간을 보존하는 짝을 지원한다. 정선의1/18 quarter까지 정확히 표현하도록14400 PPQN을 사용한다.
- 빠르기: 사용자 표, 동일판본 명시값, 장단 공식범위에서 선택한 값, 사용자가 허용한 연습용 선택값을 구분한다. BPM의 기준 단위와 정간 환산값, URL·근거·확인일을 함께 저장한다.
- 숫자가 없는 곡은 사용자 승인60정간/분을 사용한다. 정간이 없는 청성곡의 수록 단소 오선보2줄은 연습용quarter60으로 따로 표시한다. 전체 조사·판본 교정은 [근거 문서](../knowledge/data/danso-expanded-auditions.md)에 기록한다.

## 검증

작은 고정 사례로 음높이·분박 시간·지속·숨의 실제 WAV 무음과 다음 음 시작 보존을 검사한다. MIDI를 다시 읽어 CC72·Pitch Bend가 반영되는지 검증한다. 기존 회귀 검사와 실제 CAT 변환을 실행한다. 단소41항목의 원본/파생/성공/보류 원인과 전체 처리량을 남긴다. 숫자 추정이나 발췌 전사는 원보의 확정값·전곡으로 표시하지 않는다.

## M4A 출력 확장 (2026-10-28)

사용자 요청으로 최종 기본 출력을 AAC-LC M4A(44.1kHz·mono·목표192kbps)로 정한다. 메모리의 합성 PCM을 FFmpeg에 전달하며 중간 WAV를 만들지 않는다. 생성 WAV의 상시 보관을 요구하지 않고 `--audio-format wav`로 검증 시에만 선택한다. JGB·빠르기·조율·표현 정책·CAT 샘플·코드·인코더 버전은 재생성을 위해 연결한다. 채점이 JGB 기준이라는 설명은 이번 출력 선택의 배경이며 다른 파트의 채점 계약을 확정하거나 수정하지 않는다.

단일/일괄 생성과 기본 미리듣기에서 실제 출력 형식을 사용한다. M4A 코덱·채널·샘플레이트·시작 시각·표시 길이·디코딩 PCM을 검사하고 AAC 패딩을 원본 길이와 구분한다. 인코더 누락·이전 형식 출력 폴더는 사전 거부하고 인코딩 실패 시 이전 결과를 보존한다. 비교 영상·실연 분석·시간 그래프는 이번 MR에 포함하지 않는다.
