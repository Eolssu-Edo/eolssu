Task: S15P31E102-166. 2026-10-27 사용자 요청: 숨표·빈지속·농음·흘림 조사와 변환. 2026-10-28 후속 요청: 풀어내림을 포함한 단소 시김새 누락 조사·구현, 빠르기 선택 검증, 필요한 변환 파이프라인만 MR 반영.

2026-10-28 추가 범위 확정: 사용자는166을 단소를 최대한 커버하는 방향으로 지정했다. 짧은 꾸밈·긴 지속·표현 종류·명시적 중간 빠르기·반복·변환 결과 보존을 같은 Task에서 보완한다. 모든 판본의 해석이나 실제 운지·호흡의 음색을 자동으로 완성했다고 선언하지 않는다.

## 범위와 보존

MR !87은 단소 JGB 또는 공통 악보 JSON 하나를 MIDI·CAT 음원으로 변환하는 파이프라인을 대상으로 한다. 원본 JGB를 덮어쓰지 않고 해시·음표 위치·변환 설정을 연결한다. 목록 일괄 처리·HTML 미리듣기·개별 판본 교정은 포함하지 않는다. 악보에 없는 음을 오류 회피용으로 삭제하거나 자동전조하지 않는다. 소금·대금 확장은 하지 않는다. 공통 FE/AI/BE 계약과 채점은 변경하지 않는다.

## 재생 정책

- 숨표: 기존 목표는 무음120ms+release50ms. 마지막 전개음의 실제 길이L에 대해 총단축량=min(170ms,L/2), release=min(50ms,총단축량/2), 나머지는 무음으로 배분한다. 양자화 후에도 원음 절반을 남기며 다음 음의 시작·장단 길이는 유지한다. 이 수치는 국악 표준이 아닌 재생용 선택값이다. 명시 IR의 기존 breath_seconds는 그대로 유지하고 JGB가 새 정책을 적용해 유효값을 기록한다.
- 가변 release는 MIDI CC72에 기록한다. 이 프로젝트의 값127=50ms, 선형0~50ms 환산은 사용자 정의 CAT 재생 규약이며 MIDI 표준의 보편적인 절대시간 의미가 아니다. 기존50ms 음은 종전 재생을 유지한다.
- 빈지속: 분박 슬롯을 보존하는 지속 별칭. 같은 각의 마지막 본음을 연장하고 뒤꾸밈은 끝으로 미룬다. 각 첫칸·쉼 뒤에는 쉼을 유지하며 숨표 뒤 연장은 거부한다.
- 농음·흘림: 농음은4Hz·depth0.08·지연0의 음량 요성, 흘림은 말미30%(최대200ms)에50cent 하강을 적용한다. 기존105의 추가 떨림은 유지한다. 긴 기호는 원보에서 확인한 범위를 파생본에 전개한다. 원문점은 의미 미확정 주석으로 보존하고 효과를 주지 않으며, 그 외 미지원 기호는 위치와 함께 보류한다.
- 공식 교육자료의 장식12종·율명 대용12종과 문서화한 호환 별칭을 지원한다. 새 기호 중 니느라니·느나르나니는 상류 registry와 다른 공식 음열을 선택해 대응표에 기록한다. 덧길이·반길이는 합이 정간 시간을 보존하는 짝을 지원한다. 정선의1/18 quarter까지 정확히 표현하도록14400 PPQN을 사용한다.
- 미는표는 말미50cent 상승, 풀어내림은 별도 음높이 농음+하행 근사로 구현한다. 끊는표는 release 포함 반길이, 늘임표는 표시된 자리2배로 구현한다. 수치·범위는 대응표에 기록하며 원문/연주 시간을 분리한다. 특강표는 강세 근사, 요성표·겹요성표·겹흘림·추성·퇴성은 수치와 근거를 명시한 로컬 표현 프로필을 사용한다. 격음·하성·꺾는음 등은 필요한 샘플·기호 대응·으뜸음 문맥을 구체적으로 알리고 중단한다. 공식 자료에 기본 의미가 있는 표현까지 의미 미상으로 분류하지 않는다.
- 빠르기: 최상위 `tempoBpmUserSet:true` 또는 명시적 `--bpm`이 있어야 변환한다. 기본 숫자·장단명·`--speed`는 선택 근거가 아니다. 플래그가 음악적 근거를 인증하지는 않으므로 선택 경로와 근거 미검증 상태를 기록한다. 정간 BPM과 quarter 환산값을 기록하며 속도 조사·자동 기본값 보충·원보 교정은 엔진에서 하지 않는다. 표현과 출력 선택의 근거는 [근거 문서](../knowledge/data/danso-expanded-auditions.md)에 기록한다.

## 검증

작은 고정 사례로 음높이·분박 시간·지속·숨의 실제 WAV 무음과 다음 음 시작 보존을 검사한다. MIDI를 다시 읽어 CC72·Pitch Bend가 반영되는지 검증한다. 기존 회귀 검사와 실제 CAT 변환을 실행한다. 실제 준비 입력의 원본·MIDI·음원 해시와 생성 길이를 확인한다. 숫자 추정이나 발췌 전사는 원보의 확정값·전곡으로 표시하지 않는다.

## M4A 출력 확장 (2026-10-28)

사용자 요청으로 최종 기본 출력을 AAC-LC M4A(44.1kHz·mono·목표192kbps)로 정한다. 메모리의 합성 PCM을 FFmpeg에 전달하며 중간 WAV를 만들지 않는다. 생성 WAV의 상시 보관을 요구하지 않고 `--audio-format wav`로 검증 시에만 선택한다. JGB·빠르기·조율·표현 정책·CAT 샘플·코드·인코더 버전은 재생성을 위해 연결한다. 채점이 JGB 기준이라는 설명은 이번 출력 선택의 배경이며 다른 파트의 채점 계약을 확정하거나 수정하지 않는다.

단일 CLI에서 선택한 음원 형식을 생성한다. M4A 코덱·채널·샘플레이트·시작 시각·표시 길이·디코딩 PCM을 검사하고 AAC 패딩을 원본 길이와 구분한다. 인코더 누락·이전 형식 출력 폴더는 사전 거부하고 인코딩 실패 시 이전 결과를 보존한다. 비교 영상·실연 분석·시간 그래프는 이번 MR에 포함하지 않는다.

## 단소 범위 확장

- JGB 꾸밈은 최대1/16 quarter를 유지하되 본음에 슬롯 절반 이상을 남기고 MIDI tick 단위로 줄인다. 원문과 실제 꾸밈 길이를 기록한다.
- 긴 음은 CAT 샘플의 안정 구간 검사를 통과했을 때만50ms crossfade로 연장한다. 원음이 충분한 경우 기존 파형을 보존하며 검증되지 않은 소음을 반복하지 않는다.
- 빠르기 변화·각 단위 반복은 원본 SHA256에 묶인 `danso-performance/v1` 로컬 계획으로 지정한다. 원문 정간 위치에 따른 선형 BPM 변화와 구간 적분, 반복 음 ID·원문 위치를 보존한다. native 빠르기 기호는 시간 슬롯을 차지하지 않으며 숫자 없는 상대 지시는 명시값을 요구한다.
- `danso-expression-profile/v1`은 표현별 근거와 음량/음높이 요성·piecewise 음높이 곡선을 지정한다. MIDI는 합산된 변화량에 따라2~12반음의 RPN 범위를 사용한다. 기존 범위의 입력은2반음을 유지한다.
- `instrument=all`은 명시적 `--assume-danso`로 선택할 때만 허용한다.600초는 변경 가능한 자원 한도이며 MIDI 빠르기는24bit Set Tempo 범위로 검사한다.
- 출력은 변환 전용 폴더를 묶음으로 교체하고 일반 rename 실패 시 이전 결과를 복구한다. 기존 개인 파일은 삭제하지 않으며 강제 종료·전원 손실 복구까지 보장하지 않는다.

명령·설정 예시는 [CLI README](../../data/src/playback/README.md#명시적-연주-계획과-표현-프로필), 근거와 남은 범위는 [확장 기록](../knowledge/data/danso-expanded-auditions.md#단소-범위-확장-2026-10-28)을 따른다.


## 표현 정책과 빠르기·반복 모듈 책임

2026-10-28 사용자 요청으로 JGB 표현 규칙을 `expressions.py`에 모으고 빠르기·반복 모듈은 `tempo_repeat.py`로 이름을 맞춘다. 음형·별칭·효과 수치·꾸밈/숨/늘임·떠이어 예외·미지원 사유·프로필 검증은 표현 모듈이 소유한다. `jgb.py`는 입력 문법과 원문/음표 연결, `tempo_repeat.py`는 시간 적분·반복 순서를 소유한다. 두 모듈은 최종 score를 만들 때 호출하며 MIDI 이후 음원 처리 단계가 추가된 것은 아니다.

테스트는 `test_expressions.py`, `test_tempo_repeat.py`로 구현 이름을 따른다. 문자열과 원문 위치를 함께 검사하는 JGB 회귀 검사는 `test_jgb.py`에 유지한다. 기존 CLI·설정 JSON·출력 metadata는 호환성을 유지하며 음악적 수치나 합성 알고리즘을 바꾸지 않는다.
