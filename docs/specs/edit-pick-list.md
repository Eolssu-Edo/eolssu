# 불러올 악보 고르기 목록 개선

- 작업: S15P31E102-886
- 요청: 악기 선택 뒤 제공 곡이 늦게 뜨는 흐름과 오래된 목록 UI를 개선한다.
- 추가 지시: 연습곡 고르기처럼 구성하고 ‘내 악보로 복사’를 하단 초록색 버튼으로 바꾼다.
- 후속 지시: 내 악보도 목록만 조회한다. 악보 본문을 받는 보충 조회를 제거한다.
- 추가 수정: 기존 목록의 긴 제목 가로 흐르기를 보존한다. 두 줄 말줄임으로 바꾼 초기 구현을 되돌리고 공통 songTitleMarquee를 재사용한다.
- 경계: EditPick 화면에 한정한다. S15P31E102-881의 악보 추가 첫 화면·변환 상태·내 악보 관리와 S15P31E102-347의 서버 연결은 변경하지 않는다.

## 동작과 화면

- 제공 곡과 내 악보의 조회·오류·재시도를 분리한다. 각 탭은 자기 데이터가 준비되면 표시하고 다른 탭의 실패나 지연을 기다리지 않는다.
- 악기를 바꾸면 이전 조회를 취소하고 선택·목록을 비운다. 취소를 늦게 처리한 이전 응답도 반영하지 않는다. 탭 전환은 진행 중인 조회를 다시 시작하지 않는다.
- 기존 제목 검색·정렬·악기 구분·내 악보 악기 미확인 처리·복사 멱등성과 편집 진입을 보존한다. 검색·정렬 변경으로 새 API를 호출하지 않는다.
- 내 악보는 SHT-01의 초안 우선 instrumentCode로만 필터링한다. 값이 null·누락·공백이면 미확인 수에 포함하고 목록에서 제외한다. SHT-08 본문 조회와 악기 캐시는 사용하지 않는다. 목록 갱신 실패는 내 악보 탭의 오류·재시도로 표시하며, 본문 조회로 보충하지 않는다. 본문은 선택 후 기존 편집기에서 조회한다.
- 기존 앱의 회색 바탕·흰 카드·연두 선택색, 악기 그림, 난이도 배지를 사용한다. 글자 타일·작은 라디오 대신 제목·장단·난이도와 체크 표시로 선택을 알린다.
- 악기와 탭은 로딩·오류 중에도 표시한다. 목록 로딩에는 진행 표시, 실패에는 다시 시도, 빈 결과에는 기존 안내를 제공한다. 하단 고정 버튼에서 복사 또는 선택한다.
- 라디오/탭 선택 의미·읽기 도구 상태 알림·최소 48dp 터치 영역을 제공한다. 휴대폰과 태블릿에서 목록 영역이 스크롤된다.

## 완료 조건

1. 내 악보 응답을 보류해도 제공 곡을 선택·복사할 수 있다. 제공 곡 실패도 내 악보를 막지 않는다.
2. 재시도는 실패한 탭만 다시 받고 악기 전환 뒤 늦은 응답·계정 변경 뒤 응답은 반영하지 않는다.
3. 기존 필터·초안·복사 회귀 검사와 Android host 테스트·Android 컴파일을 통과한다. 웹에서 실제 Compose 화면의 좁은 폭·태블릿 폭·선택·검색·로딩·오류를 확인한다.
4. 실기기 및 iOS 미검증은 별도로 표시한다. 수치 측정 없이 운영 속도 향상률을 주장하지 않는다.
