# 공개 비채점 10곡 교정과 채점 활성화

- 작업: S15P31E102-699. 사용자 2026-11-10 후속 요청으로 구현·검증·운영 데이터 반영과 채점 활성화를 승인했다.
- 조사 근거: [46곡 대조](../knowledge/data/catalog-notation-restoration.md#2026-11-10-채점-비활성-46곡-재점검).
- 대상: 19·32·37·45·50·62·63·65·104·109. 이외 곡과 기존 연주 기록은 보존한다.
- 적용 순서(사용자 확정): 9곡을 먼저 활성화하고, 62 오나라는 앱 호환 수정·배포 후 활성화한다. 현재 FE·Data 파서가 각 경계 NOTE 지속을 거절하므로 62를 먼저 변경하지 않는다.
- 기존 악보를 그대로 쓰는 나머지 36곡은 사용자의 분리 요청에 따라 S15P31E102-704로 처리한다.

## 교정

1. 104 소금 북천이 맑다커늘 1은 기존 검수 정답 `ngc-standard-2022-p202-part-1`을 적용한다. 빠진 청황, 5각의 길이·시작과 검수 숨표를 복구한다.
2. 62 정악대금 오나라는 4각 끝 남과 5각 첫 3정간을 이어 하나의 음으로 만든다. 기본 BPM 30에서 45.5–51초, 5.5초다. 전체 곡 길이와 다른 음은 유지한다.
3. 19·32·37·45·50·63·65의 독립 시김새에서 생성한 음을 앞 음에 합치고 해당 음에 원본 시김새를 기록한다. 단소의 기존 S15P31E102-449 합의를 같은 표현의 대금 곡에도 적용한다. 일반 음의 음높이·전체 길이·각 배치와 가사는 보존한다. 출처 매핑이 없거나 앞 음이 없는 경우 임의로 추정하지 않고 중단한다.
   - 합친 마지막 음의 숨표도 옮긴다. 현재 앱은 시김새를 본음 시작 위치에 표시하므로 원래 독립 기호의 화면 좌표까지 보존된다고 주장하지 않는다.
4. 109 소금 취타 고급은 기존 검수 정답 `ngc-standard-2022-p203`의 음표와 시김새를 적용한다. 재생에서 의도적으로 펼친 음열과 채점 정답 표현을 구분한다.
5. AI의 점수 정책·공통 JSON 스키마는 변경하지 않는다. 현재 시김새 음정 제외 규칙을 사용한다. 검토 방식과 근거를 기록하고 전문가 청감·사람의 전 정간 검수 완료를 새로 주장하지 않는다.

## 운영 적용과 재생 보존

- 각 곡의 악보 버전을 1에서 2로 올리고 음표 수를 맞춘다. 곡 ID·출처 ID·제목·난이도·기본 BPM·장단·게시 상태는 보존한다.
  - 109의 기존 버전 전용 fallback 장단 표시 `취타`는 새 악보의 music.jangdan에 같은 값으로 기록해 보존한다.
- 104와 109의 음원을 재생성한다. 109는 기존 명시적 시김새 음열을 유지하면서 교정본의 숨표 3곳을 반영한다. 나머지 7곡의 음원 bytes는 보존하고, 새 악보 ID·해시에 맞는 연주 위치 정보를 준비한다.
- 새 객체를 별도 키에 준비하고 해시·길이·위치 정보를 검사한다. 기존 음원 행·객체는 남긴다.
- 적용 전 최신 운영 행과 대상 판본·악보 해시를 재확인하고 백업한다. 악보 교체·새 버전 음원 연결·채점 활성화를 조건부 트랜잭션으로 적용한다. 다른 곡과 기존 연주 기록은 변경하지 않는다.
- 재실행은 추가 변경 없이 완료되어야 한다. 응답이 유실되면 다시 쓰기 전에 실제 상태를 조회한다.

## 완료 검증

- 교정 전 실패하는 작은 회귀 사례로 누락 음·음 길이·시김새 병합과 참조 무결성을 검사한다.
- 10곡 전체의 JSON 스키마, 연속 시간축, 정간·음표 참조, 음역, 이전 판본 대비 허용한 차이와 계획 해시를 검증한다.
- 운영 공개 상세·`/score`·모범 음원 및 수행 정보가 버전 2를 일관되게 제공하고, 10곡이 채점 가능으로 조회되어야 한다.
- 실제 AI 서비스를 통한 채점 실행을 확인한다. 통제된 입력의 연동 검증과 실제 사람 연주의 음악적 정확도 검증은 구분한다.
