## 표시와 동작

- `AI 연주 평가 시작`은 오른쪽 화살표 없이 글자만 가운데 표시한다. `정간보 쉽게 읽기` 그림 뒤에는 원 대신 `#EDF0EC`의 옅은 네모 종이를 겹친다. (2026-11-07 S15P31E102-554)

- 첫 화면은 일러스트 너비 165%, 가로 위치 18%, 위로 200×너비/390 이동. 그림 끝은 남색 `#1B2233`으로 이어진다.
- 400dp 스크롤 동안 smoothstep 보간으로 원본 잘림(너비 100%, 세로 62%)과 밝은 바탕으로 전환한다. 폰의 끝 그림 띠는 376dp, 아래 60dp~위쪽 경계를 포함한 90dp 구간은 흰 그라데이션이다.
- AI 버튼은 첫 화면 하단 88dp 위, 펼친 화면에서 그림 띠 아래 12dp. 제목은 버튼 10dp 위에서 시작해 스크롤 앞 60% 동안 그림 띠 아래 10dp 위로 이동한다. 제목 위에는 '얼쑤!' 글자 대신 흰 붓글씨 로고(96×50dp)를 두고, '우리 소리와 가까워지는 시간' 문구는 두지 않는다. (2026-11-03 S15P31E102-437)
- 상단의 마이페이지 판은 첫 화면에서 숨기고 스크롤 절반을 지나며 나타나 다 펼치면 온전히 보인다. 판은 스크롤 상자 밖에 있어 화면(안전 영역) 위 12dp · 내용 오른쪽 끝에 붙고, 낮은 화면에서 카드 끝까지 더 스크롤해도 같은 자리에 고정된다. 판 바탕은 그림이 비치게 불투명도 62%이고 왼쪽 위 로고 판은 두지 않는다. 누르면 마이페이지(MY-01)로 간다. (2026-11-03 S15P31E102-437)
- 홈에는 현재 악기 판을 두지 않는다. 연습 악기 드롭다운(단소·소금·산조대금·정악대금, 미확인이면 단소 표시)은 평가할 곡 고르기(SONG-01)·연습곡 고르기(SONG-03) 상단 바 오른쪽에 두고, 고르면 마이페이지와 같은 절차로 연습 악기를 바꾼다. (2026-11-07 S15P31E102-549)
- Android에서 홈이 화면 이동의 맨 아래(쌓인 화면 없음)일 때 시스템 뒤로 가기 첫 입력은 하단에 '뒤로 가기를 한 번 더 누르면 앱이 종료됩니다.'를 2초 동안 보이고, 2초 안에 다시 누르면 Activity를 닫는다. 2초가 지나면 처음 상태로 돌아간다. iOS·Web 뒤로 가기는 바꾸지 않는다. (2026-11-07 S15P31E102-549)
- 28dp 아래 화살표는 하단 44dp 위에서 2초마다 6dp 움직인다. 스크롤 초기에 사라지며 화살표·그림을 누르면 펼친다.
- 닫힌 상태에서 12% 초과 내리면 펼치고, 펼친 상태에서 15% 초과 올리면 접는다. 화면이 낮으면 펼친 상태 이후에도 카드 끝까지 스크롤할 수 있다.
- 터치 드래그·관성이 끝나면 자동 스냅을 바로 잇는다. 드래그가 아닌 휠 입력에는 기존 160ms 종료 유예를 유지해 연속 휠 이벤트 사이에 스냅하지 않는다.
- 버튼의 거친 SVG 붓 자국과 들쭉날쭉한 진행 경계를 재사용한다. 첫 화면에서는 먹을 숨기고, 400dp 스크롤 진행률을 목표로 왼쪽에서 오른쪽으로 칠한다. 빠른 스와이프·휠로 목표가 한 번에 바뀌어도 중간 붓질을 보여 주며, 드래그·자동 스냅의 연속 목표에는 기존 속도를 이어받는다. 임계 감쇠 spring(강성 200, 표시 임계값 0.001)으로 튕기지 않게 수렴한다. 위로 스크롤하면 현재 칠해진 위치에서 같은 경계가 되돌아가며 먹이 거둬진다. 완전히 펼친 뒤 추가 스크롤에서는 전체 표시를 유지한다. 포인터 위치·누름·포커스는 붓 진행률을 바꾸지 않으며 키보드 포커스 테두리는 유지한다.
- 버튼 중앙이 밝은 배경 경계를 지나면 흰 먹/검은 글씨에서 남색 먹/흰 글씨로 바뀐다. 글자도 먹과 같은 진행 경계로 반전해 가독성을 유지한다.
- 움직임 줄이기는 플랫폼의 Compose 애니메이션 배율을 따르고 화살표·자동 펼치기·색 전환 애니메이션을 멈춘다. 붓은 스크롤 중간점에서 숨김/전체 표시로 즉시 전환해 점진적인 칠하기를 생략한다.
- 카드 구역 제목은 두지 않고 AI 버튼 16dp 아래 가는 구분선, 그 16dp 아래 카드 격자를 둔다. 왼쪽 열은 학습(기초부터 배우기 · 운지법 보기 · 정간보 쉽게 읽기), 오른쪽 열은 연습·관리(연습곡 선택하기 · 연습 기록 보기 · 악보 추가·편집하기)로 휴대폰·태블릿·넓은 창 모두 2×3 격자다. 카드는 그림 80dp와 그 아래 가운데 정렬 제목만 두고(설명·↗ 없음) 카드 전체를 누른다. 한 줄의 카드 높이는 같게 맞추고, 좁은 화면에서 긴 제목은 두 줄로 내려 잘리지 않게 한다. 넓은 창의 그림·학습 카드 좌우 배치를 유지하면서 동일한 펼치기 동작을 제공한다. (2026-11-03 S15P31E102-428 가로 카드+2×2 → S15P31E102-437 2×3 → 2026-11-07 S15P31E102-549 제목·설명 제거, 학습 왼쪽 열)
- 기존 마이페이지·평가 시작·카드의 콜백과 인증·API 계약을 보존한다. '연습 기록 보기' 카드는 연습 기록 목록(`records`)으로, '악보 추가·편집하기' 카드는 연습곡 고르기의 내 악보 탭(`my-songs?sheets=true`)으로 이동한다.

## 검증

2026-11-03 변경 이력: 아티팩트의 터치 상시 표시를 기본 숨김·hover/포커스/누름 표시로 한 차례 보정했다. 이후 사용자가 스마트폰에서 붓이 움직이는 모습을 보여주려는 목적을 설명하고 스크롤 연동 제안에 동의했다. 현행 기준은 첫 화면 숨김 → 아래 스크롤로 칠하기 → 위 스크롤로 거두기이며, 기존 호버/누름 트리거를 대체한다. 자동 반복·홈 진입 자동 재생은 추가하지 않고 버튼의 기존 화면 이동은 지연하지 않는다.

같은 날 Android 후속 결함: 진행률을 직접 연결하자 빠른 입력에서 0→1로 뛰어 점등처럼 보였다. 스크롤 연동 목표는 보존하고 표시 진행률에 500ms 보간을 더한다. 느린 드래그의 정지 캡처만으로 빠른 입력의 연속 붓질을 검증하지 않는다.

실기기 후속 보정: SM-S936N(Android 16)의 짧은 드래그 후 자동 스냅에서, 목표는 약 27%→60%로 움직이나 표시 폭은 약 16.6%에 머무는 구간을 관찰했다. 기존 500ms tween은 새 목표에서 초기 속도를 다시 계산하므로 연속 입력 시 붓이 멈칫한다. 표시 진행률은 현재 속도를 이어받는 감쇠 애니메이션으로 보정한다. 스크롤 연동·빠른 입력의 중간 표시·역방향 거두기·기존 색/접근성/버튼 이동 계약은 유지한다. 양 끝을 넘는 바운스는 넣지 않으며, 고정 500ms 완료 시간 대신 속도 연속성과 부드러운 수렴을 기준으로 한다.

스크롤 상태의 양 끝·중간, 스냅 임계점 양쪽, 배경과 버튼 중앙의 교차, 낮은 화면의 추가 스크롤을 공통 테스트로 확인한다. 웹에서 실제 첫 화면·휠/화살표·키보드·카드 이동을 좁은/넓은 폭으로 확인하고 Android host test/debug APK를 빌드한다. Windows에서 iOS 컴파일·기기 확인은 미검증으로 남긴다.
