# HOME 전체 그림·스크롤·먹 버튼

- Task: S15P31E102-412 / 담당: 송가연
- Story: S15P31E102-109(UI/UX), 에픽: S15P31E102-1
- 기준: 사용자가 구현을 요청한 [최종 아티팩트](https://claude.ai/artifact/6g3t9TexDQZ4UDyHPddx6V), `ink-button-rough.html`(사용자 제공)

## 표시와 동작

- 첫 화면은 일러스트 너비 165%, 가로 위치 18%, 위로 200×너비/390 이동. 그림 끝은 남색 `#1B2233`으로 이어진다.
- 400dp 스크롤 동안 smoothstep 보간으로 원본 잘림(너비 100%, 세로 62%)과 밝은 바탕으로 전환한다. 폰의 끝 그림 띠는 376dp, 아래 60dp~위쪽 경계를 포함한 90dp 구간은 흰 그라데이션이다.
- AI 버튼은 첫 화면 하단 88dp 위, 펼친 화면에서 그림 띠 아래 12dp. 제목은 버튼 20dp 위에서 시작해 스크롤 앞 60% 동안 그림 띠 아래 20dp 위로 이동한다.
- 28dp 아래 화살표는 하단 44dp 위에서 2초마다 6dp 움직인다. 스크롤 초기에 사라지며 화살표·그림을 누르면 펼친다.
- 닫힌 상태에서 12% 초과 내리면 펼치고, 펼친 상태에서 15% 초과 올리면 접는다. 화면이 낮으면 펼친 상태 이후에도 카드 끝까지 스크롤할 수 있다.
- 버튼의 거친 SVG 붓 자국과 들쭉날쭉한 진행 경계를 재사용한다. hover·키보드 포커스·누름에 500ms 동안 왼쪽에서 오른쪽으로 칠한다. 터치에서는 완성된 먹을 표시한다.
- 버튼 중앙이 밝은 배경 경계를 지나면 흰 먹/검은 글씨에서 남색 먹/흰 글씨로 바뀐다. 글자도 먹과 같은 진행 경계로 반전해 가독성을 유지한다.
- 움직임 줄이기는 플랫폼의 Compose 애니메이션 배율을 따르고 화살표·자동 펼치기·붓 애니메이션을 멈춘다.
- 휴대폰 2×2 카드, 태블릿 세로 4열, 넓은 창의 그림·학습 카드 좌우 배치를 유지하면서 동일한 펼치기 동작을 제공한다. 큰 글꼴에서 버튼·카드 내용이 잘리지 않게 높이를 확보한다.
- 기존 악기 표시·마이페이지·평가 시작·4개 카드의 콜백과 인증·API 계약을 보존한다.

## 검증

스크롤 상태의 양 끝·중간, 스냅 임계점 양쪽, 배경과 버튼 중앙의 교차, 낮은 화면의 추가 스크롤을 공통 테스트로 확인한다. 웹에서 실제 첫 화면·휠/화살표·키보드·카드 이동을 좁은/넓은 폭으로 확인하고 Android host test/debug APK를 빌드한다. Windows에서 iOS 컴파일·기기 확인은 미검증으로 남긴다.
