# 마이페이지 학습 진도 카드

- 작업: S15P31E102-524 / Story S15P31E102-322
- 사용자 요청: 2026-11-06 이 대화의 카드 화면과 GIF 세 개.
- 1~9 숫자를 선택하면 카드에 표시된 악기의 해당 학습 단계로 이동한다. 완료 여부는 이동을 막지 않는다.
- 완료 단계에도 숫자를 유지하고 접근성 이름에 단계·완료 여부를 알린다.
- 오른쪽 위 장식 마스코트는 다음 미완료 단계 기준으로 1~3 악보 공부, 4~6 여기 보세요, 7~9 장단 타기다. 미시작·진도 조회 전은 악보 공부, 전체 완료는 장단 타기다. 이 기준은 구현 판단이며 단계별 완료 데이터는 바꾸지 않는다.
- 원본 GIF의 프레임·재생 간격을 보존하는 PNG 프레임 시트로 표시한다. 기존 네 타깃에서 새 라이브러리 없이 재생하기 위한 형식 변환이다. 밝은 배경은 카드 색과 곱셈 합성해 자연스럽게 연결한다.
- 좁은 화면에서 제목·숫자와 겹치지 않도록 제목 옆에 공간을 예약한다. 숫자는 폭이 부족하면 줄바꿈하며 터치 영역은 48dp 이상이다.
- 앱이 비활성화되거나 화면을 떠나면 재생을 멈추고 시스템 애니메이션 배율 0은 정지 프레임으로 표시한다.
- 진도 저장·계정·API 계약은 유지한다. Android·Web 검사와 실제 렌더링을 확인하며 iOS는 Windows에서 미검증이다.
