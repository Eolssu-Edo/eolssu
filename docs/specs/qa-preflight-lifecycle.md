# QA 사전 점검: 녹음 시작 요청의 화면 수명

- Task: S15P31E102-911. 제품 범위 추가나 권한 정책 변경 없이 기존 화면 이탈 동작의 결함을 점검한다.
- 근거: frontend/AGENTS.md의 녹음·재생 중단/재시작/이탈 자원 해제, PracticeRoute의 ON_STOP → onLeaveScreen 연결, PracticeViewModel.onLeaveScreen의 중단 계약, 기존 PracticeEvaluationMicPermissionTest의 허용 때만 평가 시작·중복 요청 차단 기준.

## 기대 결과

1. 화면에서 평가 시작을 요청하고 권한을 허용하면 기존 3초 카운트다운과 녹음을 한 번 시작한다.
2. 권한을 거부하면 대기 상태로 남고 녹음하지 않는다. 다시 요청할 수 있다.
3. 권한 응답을 기다리는 중 화면 이탈/중단 처리된 요청은, 나중에 허용 응답이 와도 카운트다운이나 녹음을 시작하지 않는다.
4. 화면 복귀 뒤 사용자가 다시 평가 시작을 누르면 현재 기기 권한에 따라 정상 진행한다. 단순 권한 창 표시 자체를 화면 이탈로 취급하지 않는다.

## 검증 경계

실제 PracticeViewModel의 공개 메서드와 지연 응답을 주는 MicPermission 경계 대역, 녹음 시작 횟수·화면 상태로 확인한다. Android OS 권한 창과 ON_STOP의 실제 순서는 별도 APK 실행 항목이며 이 테스트 통과로 대체하지 않는다.
