# 연습·평가 조작과 악보 공간

- Task: S15P31E102-518, Story: S15P31E102-32, Epic: S15P31E102-20
- 합의: 2026-11-05 이 작업 채팅의 요구사항과 사용자 답변.
- 모범 연주/장단 연습은 붙은 두 선택 칸으로 표시한다. 선택은 재생하지 않으며, 전환 시 현재 악보 위치를 유지하고 정지한다. 재생 버튼으로 이어 간다.
- 두 진입 경로의 연습에서 재생 중 악보는 평가와 같은 현재 위치를 따라간다. 수동 스크롤 후 현재 위치로 복귀하는 기존 기능은 보존한다.
- 평가 안내와 정상 장단 재생 안내를 삭제한다. 오류·지원 불가 안내는 유지한다.
- 평가 하단은 ‘처음부터’·‘연주 중단’의 높이와 빈 공간을 줄인다. 박자 표시 디자인은 후속 에셋 전달까지 유지한다.
- ‘지금 읽는 부분’·‘페이지’ 문구를 없애고 확보된 공간에 한 각을 온전히 표시한다. 글꼴 확대/낮은 창에서는 스크롤로 음에 접근할 수 있다.
- 평가 중에도 장단 소리를 즉시 켜고 끈다. 속도 변경 제한·녹음 중단/재시작·권한 처리·평가 계약은 보존한다.
- 모든 연습 설정은 즉시 저장한다. 적용·X 버튼을 제거하고 하위 화면의 뒤로가기는 상위 설정으로 이동한다. 배경 누르기는 설정 전체를 닫는다.
- 검증: 모드 선택 후 자동 재생 없음·위치 유지, 설정 저장 후 재진입, 평가 중 장단 on/off와 녹음 유지, 중단/화면 이탈 시 소리 종료, 작은 화면의 악보와 조작부 확인.

- 후속 합의: 일반 연습의 ‘점수 없이 악보를 보며…’ 안내 삭제. ‘연주 평가 시작’을 누르면 평가 준비 화면에서 버튼을 재차 누르지 않고 곡 로딩 후 권한 확인·카운트다운을 한 번만 시작한다. 취소 시 자동 재시작하지 않는다.

- 후속 합의: 운지 악보에서 현재 표시 중인 각의 마지막 이벤트 뒤 실제 발음 두 개를 운지·율명·가사로 미리 보여 준다. 이음·빈 자리·쉼은 건너뛰고 같은 높이의 반복 음은 별개 음으로 유지한다. 남은 음이 하나면 하나만, 없으면 마지막 음 안내를 표시한다. 한 각 표시와 함께 미리보기를 복원한다.

- 후속 UI 합의: 일반 연습·모범·장단 상태의 우측 문구는 ‘연습 준비’로 통일한다. 평가/카운트다운/중단 및 한 음씩 안내는 구분한다. 플레이어 내 모드 이름을 없애고 경과·전체 시간 → 타임라인 → 중앙의 −5초/재생/+5초 순서로 정돈한다. 모드 선택 스위치는 유지한다.
