# DB 백업 덤프의 정렬 메모리

S15P31E102-751 · [계획과 검증](../plans/S15P31E102-751.md)

큰 JSON 행을 가진 서비스 DB도 기존 기본 키 정렬·단일 트랜잭션·백업 형식으로 덤프한다. MySQL 8.4.13의 `mysqldump --init-command`로 덤프 연결에만 `sort_buffer_size=8388608`(8 MiB)을 설정한다. 운영 DB의 전역 설정·저장 데이터·권한은 바꾸지 않는다.

운영 덤프와 격리 복원의 데이터 대조 덤프는 같은 공통 옵션을 사용한다. 메모리 부족 등 덤프 오류는 계속 실패로 처리하며, 외부 백업이 성공하기 전에는 배포하지 않는다. 기존 백업 검사와 큰 JSON 고정 데이터의 덤프·복원 일치로 검증한다.
