# Android 평가 녹음의 장단 보정

- 작업: S15P31E102-695, Story S15P31E102-33. 사용자 요청: 스피커 장단·내장 마이크를 유지하고 잘못된 보정을 자동 차단해 앱에 적용한다.
- 근거: [실측과 실연](../knowledge/frontend/android-jangdan-recording-echo.md). 초기 소금 보정 오염이 없는 음을 만든 사례를 회귀 입력으로 삼는다.

## 동작

Android 평가 시작 시 장단이 켜져 있고 계획이 있으면, 실제 사용할 타격·굴림 클립을 먼저 준비한다. 화면의 **3 → 2 → 1**은 선택한 곡의 빠르기에 맞춘 **장단 한 바퀴**를 센다. 실제 패턴을 세 주기 재생하고 다음 주기의 첫 박에 연주 녹음을 시작한다. 화면은 아직 악기를 불지 말라는 안내·취소를 보여 주며, 숫자도 같은 재생 시계를 따른다. 별도 3초 대기나 보정 계산을 위한 박자 지연을 넣지 않는다. 준비 구간은 제출 녹음·실시간 음높이에서 제외하고, 준비와 본 연주 사이에 출력 시계를 재시작하지 않는다.

이 흐름은 2026-11-11 사용자가 확정한 ‘곡의 빠르기로 장단 한 바퀴마다 숫자 변경’ 요청을 반영한다. 기존 고정 간격의 클립 세 묶음은 이 요구를 충족하지 않으므로 대체한다. 산조대금 비행기의 기본값은 77 BPM·4박으로 한 주기 약 3.117초, 세 주기 약 9.351초다. 다른 플랫폼·장단 끔·보정 없이 연주·일시정지 후 재개는 기존 3초 준비 동작을 유지한다.

보정의 무재생 구간에 주기적인 음이 있거나, 반복 타격의 일치도가 낮거나, 입력·출력 시각/기기/볼륨이 불안정하면 보정을 만들지 않는다. 실제 패턴에서 이웃 타격의 응답이 겹치는 구간을 개별 타격 템플릿으로 학습하지 않는다. 필요한 클립마다 안전한 독립 관측을 세 번 이상 확보할 수 있어야 기존 판정 문턱을 적용한다. 보정이 불확실하거나 시작 시점까지 준비되지 않으면 보정만 끄고 정해진 박자에 원본 녹음을 시작한다. 녹음 입력·출력 준비 자체가 실패한 경우에는 실패 안내와 재시도·보정 없이 연주 선택을 제공한다. 조용한 보정이 확인되지 않은 파형을 재사용하지 않는다.

같은 화면의 recorder가 player를 명시적으로 전달받아 보정한다. 앱 전체 singleton으로 묶지 않는다. Android 장단은 정확한 프레임 번호를 제공하는 AudioTrack PCM 경로로 재생하며, 기존 음원·이득·겹침·굴림 길이·오디오 포커스를 보존한다.

유효한 보정에서만 원본 PCM과 예측 장단의 일치를 확인해 감산한다. 근거가 부족한 블록은 원본을 사용한다. 처리 샘플 수와 시각은 유지하며 같은 처리 PCM을 AAC 저장·음높이 분석으로 보낸다. 경로/시스템 볼륨 변경, 시각 손실, 재생 버퍼 이상은 보정을 차단한다. 일시정지에서는 기존처럼 마이크를 멈추고, 재개한 구간은 원본 녹음을 유지한다. 새 평가 시작 시 다시 보정한다.

장단의 녹음 중 켜기·끄기는 유지한다. 보정 없이 시작한 take에서 장단을 나중에 켜거나 재개 후에는 보정이 적용되지 않는 상태를 표시한다. 보정 차단은 녹음 삭제나 연주 중단을 뜻하지 않는다.

## 완료 조건

1. 기존 실연의 오염 보정은 차단되고 깨끗한 보정은 통과한다. 무음·정상 타격·연주가 섞인 타격·시각/볼륨/기기 변경을 격리 검사한다.
2. 취소·뒤로가기·백그라운드·권한 거부·중단·일시정지/재개에서 보정과 오디오 자원을 해제하고 늦은 비동기 완료를 무시한다.
3. 실제 Galaxy에서 올바른 보정의 적용을 관찰하고 AAC 저장에도 반영됨을 확인한다. 보정이 항상 우회되는 구현을 완료로 보지 않는다.
4. Android host 회귀 검사와 APK 빌드를 통과하고 기기에 설치한다. iOS 컴파일은 Windows에서 미검증으로 표시한다. 서버 계약·채점 기준·원격 배포는 변경하지 않는다.
5. 선택한 빠르기의 실제 장단 세 주기에 맞춰 3→2→1을 표시하고 다음 박에 연속으로 녹음한다. 본 연주의 startTick을 보존하고 준비 구간은 파일에서 제외한다. 안전한 타격 3회 이상도 기존 일치도·오염 판정 문턱을 통과해야 한다. 빠른 패턴의 겹침은 보정을 차단하며, 실제 기기에서 정상 적용·원본 녹음 전환·취소를 검증한다. 실패율이나 모든 환경의 품질이 기존 4회와 같다고 가정하지 않는다.
