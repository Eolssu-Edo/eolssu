# 휴대폰 연습 화면의 짧은 각 묶음

- 작업: S15P31E102-473 · Story: S15P31E102-32
- 상태: 사용자 요청에 따른 화면 시안 구현.
- 적용: 휴대폰 연습 화면의 기본 악보 보기만 변경한다.

## 동작

짧은 각은 오른쪽 세로 묶음에 1·2·3각, 왼쪽 묶음에 4·5·6각을 위에서 아래로 배치한다.
한 묶음에 최대 3각을 넣으며 실제 남은 높이에 들어가는 수를 선택한다.
3줄 이상의 소박 표시가 있는 정간은 기본 정간보다 1.5배 높게 표시한다.
음표 식별자·각 번호·연주 시간과 원본 데이터는 유지한다.
현재 연주 위치를 따라갈 때 같은 세로 묶음에서는 가로 이동하지 않는다.

## 경계와 확인

- 4정간 이하의 각으로 구성된 휴대폰 악보에서 남은 높이를 활용한다.
- 기본 정간 높이는 32~44dp로 맞추되 크게 보기는 기존 최소 크기를 유지한다.
- 높이가 부족하면 2각 또는 1각으로 배치하고, 한 각도 넘치면 스크롤로 접근할 수 있다.
- 큰 시스템 글꼴과 본문 높이가 560dp보다 작은 창에서는 페이지 스크롤을 유지한다.
- 긴 각·태블릿·운지법 함께 보기·곡 상세·평가 결과·기록 상세는 기존 배치를 유지한다.
- 자동 검사: 묶음 순서, 높이 경계, 3소박, 원본 좌표와 따라가기.
- 실행 확인: Android 에뮬레이터의 도라지타령 연습 화면. iOS 실기기 검증은 별도다.
