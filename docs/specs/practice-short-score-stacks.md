# 휴대폰 연습 화면의 짧은 각 묶음

- 작업: S15P31E102-473 · Story: S15P31E102-32
- 상태: 사용자 요청에 따른 화면 시안 구현.
- 적용: 휴대폰 연습 화면의 기본 악보 보기만 변경한다.

## 동작

각의 실제 길이·소박 표시·글꼴 배율과 화면의 남은 높이로 한 세로줄에 들어갈 각 수를 계산한다.
위에서 아래로 들어가는 만큼 표시한 뒤 다음 각은 왼쪽 세로줄로 자동 줄바꿈한다.
기존 4정간 이하·최대 3각 제한은 사용자의 범위 확장 요청으로 대체했다.
3각이 들어가면 오른쪽에 1·2·3각, 왼쪽에 4·5·6각이 놓이며 더 짧은 각은 4각 이상도 넣을 수 있다.
각 가로줄은 모든 묶음에서 가장 높은 각만큼의 공간을 공유한다.
같은 가로줄의 짧은 각은 정간 높이를 같은 비율로 늘려 머리글과 아래 테두리를 모두 맞춘다.
3소박 정간과 일반 정간의 1.5배 높이 비율은 늘린 뒤에도 유지한다.
3각 배치에서 1·4·7·10…각, 2·5·8·11…각, 3·6·9·12…각의 윗부분이 각각 같은 수평선에 놓인다.
마지막 묶음의 각이 부족해도 기존 가로줄의 시작 높이는 유지한다.
3줄 이상의 소박 표시가 있는 정간은 기본 정간보다 1.5배 높게 표시한다.
음표 식별자·각 번호·연주 시간과 원본 데이터는 유지한다.
현재 연주 위치를 따라갈 때 같은 세로 묶음에서는 가로 이동하지 않는다.
연주 중 입력 없음 안내는 표시 여부와 관계없이 동일한 공간을 확보한다.
안내가 나타나거나 사라져도 악보의 높이·위치·묶음 수는 바뀌지 않으며 숨긴 안내는 접근성 트리에 노출하지 않는다.

## 경계와 확인

- 각을 원본 표시상 한 세로줄로 그릴 수 있는 모든 휴대폰 연습 악보에서 적용한다.
- 첫 두 각만이 아니라 악보 전체의 가변 각 길이와 가로줄 최대 높이를 계산한다.
- 기본 정간 높이는 32~44dp로 맞추되 크게 보기는 기존 최소 크기를 유지한다.
- 높이가 부족하면 2각 또는 1각으로 배치하고, 한 각도 넘치면 스크롤로 접근할 수 있다.
- 큰 시스템 글꼴과 본문 높이가 560dp보다 작은 창에서는 페이지 스크롤을 유지한다.
- 한 각만 들어갈 때도 읽을 수 있는 최소 크기 안에서 높이를 맞춰 세로 스크롤을 줄인다.
- 렌더러가 한 각을 여러 줄로 나누는 악보·태블릿·운지법 함께 보기·곡 상세·평가 결과·기록 상세는 기존 배치를 유지한다.
- 자동 검사: 묶음 순서, 높이 경계, 3소박, 원본 좌표와 따라가기.
- 실행 확인: Android 에뮬레이터의 도라지타령 연습 화면. iOS 실기기 검증은 별도다.
