# 탈퇴 유예 만료와 삭제 경계

- 작업: [S15P31E102-306](https://ssafy.atlassian.net/browse/S15P31E102-306)
- 근거: 2026-10-30 사용자의 만료 후 취소 차단 및 코드 수정 요청. [209의 경합 수용 기록](../plans/S15P31E102-209.md)은 이 결정으로 대체한다.

## 동작

- 탈퇴 취소는 `withdrawal_requested_at + 30일` **미만**인 시각에만 가능하다. 정각부터는 일괄 삭제가 아직 실행되지 않았거나 실패했어도 취소할 수 없다.
- 이메일 로그인·연결된 소셜 로그인·소셜 계정 병합 모두 회원 행 잠금을 얻은 뒤의 최신 시각으로 판정한다. 만료 회원은 기존 `401 INVALID_CREDENTIALS`로 거절하며 ACTIVE 전환·로그인 기록·토큰 발급을 하지 않는다.
- 실제 삭제 예정 시각은 기존대로 요청 후 30일이 지난 뒤 처음 오는 04:00 Asia/Seoul이다.
- 일괄 삭제의 최초 대상 목록은 후보일 뿐이다. 녹음을 지우기 전에 회원 행을 잠그고 상태·삭제 예정 시각을 재확인한다. 먼저 진행 중이던 취소가 커밋되면 파일과 DB를 모두 보존한다.
- 확인을 마친 뒤에는 이미 취소 기한이 지났으므로 새 로그인은 거절된다. 녹음 저장소 호출은 회원 행 잠금 밖에서 실행해 DB 트랜잭션을 짧게 유지한다. 파일 삭제 실패·DB 삭제 실패의 재시도 정책은 유지한다.
- 추가 회원 상태나 DB 마이그레이션은 필요하지 않다. 기존 기한과 회원 행 잠금으로 경계를 맞춘다.

## 검증

유예 만료 직전·정각·직후, 삭제 예정 시각 전의 만료, 잠금 대기 중 만료를 검사한다. 취소가 먼저 잠금을 잡은 순서에서는 파일·DB 보존, 삭제가 먼저 확인한 순서에서는 로그인 거절을 MySQL 경합 검사로 확인한다. 파일 삭제 실패 후에도 만료 회원이 복구되지 않아야 한다. 기본 빌드와 격리 MySQL 통합 검사를 수행한다.
