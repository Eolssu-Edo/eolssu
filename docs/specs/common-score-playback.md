# 공통 악보 v1 재생 연결

- 작업: [S15P31E102-338](https://ssafy.atlassian.net/browse/S15P31E102-338), Story 30 모범 연주 재생.
- 요청: 기존 공통 악보와 재생기를 연결하고 한 곡의 화면 음·실제 생성 음원의 음높이, 길이, 쉼을 대조한다.
- 입력 계약: [score_data.schema.json](../../data/src/scores/score_data.schema.json). 새 서비스 스키마나 API는 만들지 않는다.

## 동작

기존 `python -m data.src.playback`이 서비스 JSON을 판별해 기존 reviewed-score IR → MIDI → CAT PCM → M4A/WAV 경로를 사용한다. `--common-bpm`은 `music.bpmUnit`의 분당 박 수이며 반드시 명시한다. QUARTER는 1, DOTTED_QUARTER는 3/2 quarter로 길이와 BPM을 함께 변환한다. JEONGGAN/JANGDAN_BEAT는 서양 음가를 추측하지 않고 MIDI 전송용 1 quarter를 1 입력 박에 대응시킨다. 어느 경우도 `tick/ticksPerBeat*60/bpm` 초를 보존한다.

원본 바이트, schemaVersion, scoreVersion, provenance, eventId/cellId 및 표시 자리와 초 대응표를 결과 묶음에 보관한다. 인접한 동음은 새로 발음하고 이미 합쳐진 지속 이벤트는 다시 나누지 않는다. `music.hwangHz`를 실제 음높이 기준으로 사용하며 악기 변경·옥타브 접기는 하지 않는다. 별도로 요청한 기존 transpose 옵션은 결과에 기록한다.

NOTE의 release를 원본 시간 안에 넣어 REST를 침범하지 않는다. 숨표는 기존 adaptive_breath 정책(목표 무음120ms, release와 합쳐 최대 음 길이 절반)을 사용하고 다음 음 시작을 유지한다. 음원의 후행 여백은 기존 MIDI 정책의 약550ms이며 악보 길이와 구분한다. 원본 reviewed는 악보 검수 상태이고 합성 음원의 전문가 검수 완료를 뜻하지 않는다.

스키마 위반, 표시와 음높이·시간의 불일치, 중복 ID, 미지원 악기/음역, rejected 원본, MIDI에서 정확히 표현할 수 없는 분할, 비어 있지 않은 sigimsae는 입력 위치를 포함한 오류로 중단한다. v1의 합쳐진 sigimsae만으로는 원래 장식의 배치·조를 복원할 수 없다. 기존 JGB/IR 입력의 동작은 유지한다.

## 완료 조건과 경계

- 작은 고정 입력으로 지속/반복음/앞·중간·끝쉼/숨표/조율/명시 BPM/미지원 오류 및 출력 묶음 보존을 검사한다.
- 검수된 p173 아리랑의 실제 FE mapper 출력(61 NOTE, 4 REST, 144ticks)을 원본 및 재생 대응표와 교차 검증한다. 기본 BPM96 근거는 `data/reference/jangdans.json`이다.
- 실제 CAT 샘플로 WAV와 AAC-LC M4A를 생성하고 실제 PCM 음높이·쉼·발음 구간·전체 시간을 측정한다. 합성 테스트는 실제 CAT 검사를 대신하지 않는다.
- 가능한 Android 검증 환경에서 실제 정간보 컴포넌트와 오디오 플레이어를 실행한다. 에뮬레이터 증거와 물리 기기 청취는 구분한다. 미실시 청감을 실시했다고 기록하지 않는다.
- 새 악보 렌더러(336), 인식(313), 서비스 업로드 연동(347), 곡 전수 검수는 제외한다.

## 후속: 모든 등록 시김새의 교육용 미리듣기

2026-11-01 사용자가 기존 Jira의 악기별 규칙을 연결하고, 미확정 기호에도 새 교육·미리듣기 근사값을 정해 즉시 재생하도록 요청했다. 아래 범위는 위의 시김새 거부 조건을 **명시적으로 선택한 미리듣기 모드에서만** 대체한다. 원본 판독 모드와 저장·채점용 공통 v1은 그대로 유지한다.

- `educational-preview/v1` 정책을 명시해 단소·소금·정악대금·산조대금의 기존 확정 음열을 우선 사용한다. 등록된 기호의 미확정 음열·표현에는 버전이 있는 기본 근사값과 근거를 기록한다. 오타·서로 모순되는 조합은 오류다. 전용 격음 샘플을 확보했다고 주장하지 않는다.
- 공통 v1의 병합된 `event.sigimsae`는 위치를 복원할 수 없다. 선택적인 원본 SHA256 결합 `common-score-expressions/v1` 파일의 `placements`에서 `(eventId,cellId,row,col,symbols)`를 받는다. 기호 목록을 바꾸거나 누락하지 않고 위치만 지정한다. 파일이 없으면 음의 첫 표시 자리에 적용하고 추정임을 기록한다.
- 표현 파일은 조·표현 정책과 기존 tempo/repeat 계획을 명시할 수 있다. 미지정 조는 교육용 황종계면 음계, 반복표/도돌이표는 해당 각 총2회, 길이표는 해당 자리의 재생 길이 배율로 선택한다. 빠르기 기호만 기존 정간 단위 계획에 따라 해당 정간 시작부터 적용하고 원래 위치와 적용 위치를 함께 기록한다. 기보 틱은 바꾸지 않는다. 구체 수치는 코드와 지식 문서에 함께 기록한다.
- 출력 `common-score-performance/v1`은 원본 SHA256·scoreVersion·sourceId·instrument·BPM·음원 SHA256에 결합한다. `segments`는 모든 표시 자리를 실행 순서로 담으며 고유 occurrenceId, eventId, cellId,row,col, 분수 허용 startTick/endTick, startMs/endMs, sigimsae를 갖는다. 늘임과 반복에서도 표시 위치를 따라갈 수 있어야 한다. durationMs는 후행 무음을 제외한 수행 악보 길이다.
- FE는 검증한 별도 시간표가 연결된 Model 모드에서만 이 수행 시간을 사용하고 해당 자리의 기호를 표시한다. 기존 녹음·채점 시간과 NOTE idx를 변경하지 않는다. 운영 API에 파일을 게시하는 작업은 포함하지 않는다.
- 회귀: 기존 무장식 아리랑, 원본 JGB 규칙, v1 저장·채점 투영을 유지한다. 4악기×등록 기호, 해시·위치 불일치, 이음 중간 표현, 분수 틱, 늘임 후 다음 음, 반복 후 원본 위치 복귀를 검사한다. 실제 CAT 파형과 Android 화면·재생에서 작은 고정 예를 교차 검증한다.

## 기존 재생용 JGB 가져오기와 지속음 복원

2026-11-02 사용자가 MR !203의 기존곡 전수 검사에서 드러난 차이를 기존 변환과 비교해 수정하도록 요청했다. 같은338의 후속 수정으로 아래를 수행한다.

- 검수된 채점 정답용 `score_data.convert()`와 기존 v1 파일·이벤트 ID는 유지한다. 별도 재생용 import 명령은 원본 JGB의 기존 parser를 사용하고 `inferred` 공통 v1, 해시 결합 표현 파일, 원문 자리 대응표를 함께 만든다. 서비스 게시·검수 승격은 하지 않는다.
- 독립 음열 기호는 기존 JGB와 같은 별도 시간 자리를 차지한다. 해당 슬롯만 실제 율명으로 펼치고 동일 row의 긴 음은 이음으로 채워 길이를 보존한다. 소비한 기호는 재생 표현에 다시 넣지 않고 원문 대응표에 남긴다. 부정확한 펼침이 필요한 조합은 위치와 함께 거부한다.
- 빈지속은 이음으로, 유효한 `gakBeats`는 각별 정간 수로 옮긴다. 원본 `staffUnit`에 따른 QUARTER 비율·명시 빠르기·황종·성부·조·표현 정책을 보존하며 추측한 조율이나 속도로 대체하지 않는다.
- 원문에 명시된 `playback.gak_continuations`만 각 경계 지속을 허용한다. 기본 각 시작 쉼은 그대로다. 공통 v1의 NOTE 각 경계 금지는 유지하고, 표현 파일의 `gakContinuations`에서 1-based 각 번호·근거를 받아 수행에만 적용한다. 미선택 성부를 포함해 원문 경계의 범위를 검사한다.
- 완료 조건: 기존107 JGB성부를 모두 가져와 공통 경로 실제 M4A 생성·디코드를 확인하고, 기존108성부(IR1 포함)와 음높이·발음 수·시작·길이를 대조한다. 오나라45.5~51초 지속을 MIDI와 실제 파형으로 확인한다. 실패나 의도된 수행 차이는 숨기지 않고 기록한다. 기존 검수 fixture와 회귀 검사도 유지한다.

## 시김새 연결 발음 보존

2026-11-02 전체 시김새 재점검에서 공통의 모든 음에 release를 포함하는 gate를 적용하면 시김새 내부 slur까지 끊기는 것을 실제 MIDI·CAT 파형으로 확인했다. 독립 음열 import도 구체 율명으로 펼칠 때 원래 slur 그룹이 소실됐다. 기존 명목 음높이·시간 일치 범위를 수행 연결까지 보강한다.

- 시김새 그룹 내부의 연결음은 기존 JGB의 slur/legato를 보존한다. 그룹 끝·쉼·숨표 경계에서는 기존 release가 악보 길이를 침범하지 않도록 한다. 명시된 끊는표/gate는 연결보다 우선한다.
- 원본 v1의 이벤트·표시 자리·채점 시간은 유지한다. 해시 결합 표현 입력의 선택적 `slurGroups`에 `{eventIds: [...], basis: "원문 근거"}`를 담아, importer가 구체음으로 펼친 독립 음열의 연결만 재생기로 전달한다. 각 그룹은 같은 정간에서 시작한 연속 NOTE 이벤트2개 이상, 중간 숨표 없음, 중복/겹침 없음이어야 한다. 구체음에 요성·곡선 같은 지속 효과는 허용하되 새 음열·강세가 겹쳐 연결 대상을 바꾸는 조합은 거부한다.
- 완료 조건은4악기의 직접 공통 시김새와 JGB import 시김새의 내부 legato·실제 MIDI 연결 및 CAT 파형 재대조다. 연속 동음·그룹 끝 쉼·숨표·명시 끊는표를 묶어 검사하고 기존 서비스 v1 검수 fixture와107곡 명목 음높이/시간은 유지한다.
