# 운영 Compose 교체

[S15P31E102-541](https://ssafy.atlassian.net/browse/S15P31E102-541)에서 edo1의 운영 `/opt/eolssu/config/compose.yml` 교체 경로를 관리한다.

- 운영자는 완성된 후보 파일을 설치 도구에 전달한다. 도구는 운영 배포와 같은 잠금을 사용한다.
- 후보는 대상 파일과 같은 디렉터리에서 준비한다. 운영 환경으로 구문을 검사하고 `root:jenkins 0640`을 적용한 뒤 Jenkins 계정과 CI 환경으로 검사한다. 두 검사를 통과하면 이전 파일을 root 전용으로 보관하고 원자적으로 교체한다.
- 검사에 실패하면 기존 파일과 권한을 유지한다. Compose 검사 출력에 환경변수 값이 포함될 수 있으므로 실패 단계만 출력한다.
- 설치 도구는 환경변수 파일을 쓰거나 컨테이너를 재생성하지 않는다. 운영자 권한으로 실행하며 Jenkins에 새 sudo 권한을 부여하지 않는다.
