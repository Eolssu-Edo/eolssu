# 휴대폰·태블릿 QA 경로 분리

- Task: S15P31E102-498 · 사용자 확정: 기존 QA 코드를 공유하고 기기별 URL·중계를 분리한다.
- 휴대폰 `/qa/` → Windows loopback17680 → EDO2 loopback27890.
- 태블릿 `/qa/tablet/` → Windows loopback17681 → EDO2 loopback27891.
- 동일 Windows PC에서 두 프로세스를 실행한다. ADB는 명시한 실제 기기 serial만 사용하며, 무선 복구는 각 기기의 고유 ID를 고정한다. 다른 기기로 대체 연결하지 않는다.
- 영상·화면 크기·입력 좌표·참여자·제어권·APK 설치 작업·설치 버전·밝기 유지·재접속 상태를 프로세스별로 관리한다. 한 기기의 업데이트/연결 해제가 다른 기기의 조작을 막지 않는다.
- 동일 출처의 중첩 URL에 휴대폰 쿠키가 함께 전송되므로 태블릿은 경로에서 파생한 별도 쿠키 이름과 Path를 사용한다. 부모 경로 쿠키를 태블릿 로그인으로 인정하지 않는다.
- QA 팀의 기존 접속 키를 사용하되 tablet-relay의 설정·상태·APK 보관·로그·종료 표시·감독 잠금은 phone relay 폴더와 분리한다. 도구 파일은 함께 사용한다.
- 헤더와 로그인 화면에 대상 기기를 표시한다. 공통 UI는 실제 영상 비율에 맞춰 가로/세로 화면을 담고, 회전으로 기하 정보가 바뀌면 이전 제어권·좌표 입력을 무효화한다.
- APK 이력 조회는 공통 동작이며 자동 설치는 추가하지 않는다. 센서·마이크·스피커는 각 실제 기기 것을 사용한다.
- 검증: 두 loopback 중계에서 쿠키 순서·교차 쿠키 거부·동시 소유자·입력 분리·태블릿 설치 중 휴대폰 조작 유지, PowerShell 설정 격리·기존 기본값 호환, 공개 Nginx 경로·실기기 영상/터치/회전 확인.
- 실기기 준비: Galaxy Tab S9 FE 무선 디버깅을 PC와 페어링하고 연결용 주소를 확인한다. 기기 Android 버전별 native 밝기/한글 도구 호환성은 실제로 확인하며 미검증을 성공으로 보고하지 않는다.

진행과 증거는 [Task498 계획](../plans/S15P31E102-498.md)에 기록한다.

## 확정한 공통 화면 동작

- 휴대폰과 태블릿 모두 실제 기기명을 헤더에 표시한다. 제어권 요청·반납·연결해제도 헤더 내부에 둔다. 디버깅 포트 라벨은 입력칸 세로 중앙에 정렬한다.
- APK 목록은 `MR 번호 - MR 작성자 이름 - MR 제목`으로 식별하고 같은 MR의 재빌드는 빌드 번호로 구별한다. 날짜를 주요 식별자로 쓰지 않는다.
- 설치 정보는 확인 중·설치 중·설치됨·미설치·조회 실패를 구분한다. 조회 오류를 미설치로 표시하지 않는다. 일반 얼쑤 앱과 자동 빌드 QA 패키지는 별개다.
- ‘자동 배포 대상: … 기존 앱 데이터 보존’과 클립보드 안내 문구는 제어 화면에서 제거한다. 보존 동작과 클립보드 부작용은 운영 문서에 남긴다.
- MR 상세 정보는 원본 목록의 검증된 데이터만 표시한다. 확보되지 않은 작성자/제목은 확인 중으로 표시한다. 현재 자동 수집 권한 제약은 운영 문서와 Task 계획에 명시한다.
