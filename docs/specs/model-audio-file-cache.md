# 모범 연주 음원 파일 재사용

- 작업: S15P31E102-859 · Story S15P31E102-30
- 근거: 2026-11-13 사용자 요청. 같은 곡에서 뒤로 갔다가 다시 재생할 때 음원을 캐시해 대기를 줄인다.

## 동작

공개 모범 연주의 메타데이터·현재 게시 여부·악보/음원 판본 검증은 유지한다. 검증된 SHA-256의 음원 파일이 기기 캐시에 있으면 원격 재생 대신 그 파일을 새 재생기에 전달한다. 음원 교체로 해시가 달라지면 다른 파일을 받는다. 내 악보의 기존 저장 음원과 장단 포함 여부는 바꾸지 않는다.

Android와 iOS의 시스템 캐시 영역에 공개 음원만 저장한다. 쿠키 없는 다운로드 클라이언트로 HTTPS와 검증된 리다이렉트만 사용한다. 기기의 캐시 삭제는 허용한다. 웹은 현재 모범 연주 플랫폼 지원을 유지한다.

최초 캐시 준비에는 다운로드와 SHA-256 확인이 필요하다. 파일 하나는 최대 32 MiB, 전체는 최대 4개/128 MiB로 제한한다. 캐시는 최선형 최적화이며 크기 제한·디스크/다운로드 오류·준비 시간 초과는 기존 원격 재생으로 돌아간다. 취소는 그대로 전파하고 부분 파일은 재사용하지 않는다. 저장 전 해시를 확인하고 재사용 시에도 손상을 검사한다. 메타데이터 조회 실패나 게시 해제는 기존대로 처리하며 캐시로 우회하지 않는다.

화면 이탈 시 재생기·오디오 포커스는 계속 해제한다. 파일은 화면 수명과 분리해 유지한다. 로컬 디코더 준비와 현재 메타데이터 조회는 남으므로 로딩 0초를 보장하지 않는다.

일시정지한 네이티브 재생기가 남아 있으면 바로 이어 듣는다. 화면 숨김 등으로 재생기를 해제한 뒤 캐시 음원을 다시 열 때는 Repository에서 파일을 재검증·복구한다. 같은 음원 해시이면 기존 미디어 위치를, 게시 음원이 교체됐으면 현재 악보 위치에 대응하는 새 음원 위치를 사용한다.

## 완료 조건

1. 같은 판본을 새 화면/저장소 객체에서 재생해도 음원 다운로드는 추가하지 않고 로컬 파일을 사용한다.
2. 해시 변경·파일 손상·파일 삭제·실패 후 재시도와 중복 요청을 작은 격리 테스트로 확인한다.
3. 취소·잘못된 다운로드·한도 초과가 완료 파일로 게시되지 않으며 원격 재생 경로는 유지된다.
4. Android 회귀 테스트·APK 빌드·웹 공통 코드 컴파일을 확인한다. 가능한 Android 실제 기기에서 재진입 재생과 요청 수를 관찰한다. iOS는 Mac 빌드·실기기 미확인 상태를 명시한다.
