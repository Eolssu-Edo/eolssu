# R2 공통 파일·폴더 업로드

- Task: S15P31E102-392. 기존 R2 연결로 개발 자료를 올리는 CLI와 팀원 실행 안내를 제공한다.
- `python infra/r2/upload.py <파일 또는 폴더> <객체 키 또는 접두사> [--env-file 경로] [--dry-run]`으로 실행한다. 폴더는 내용의 상대 경로를 목적지 아래에 보존하고 파일은 지정한 객체 키에 저장한다.
- 기존 `RECORDING_STORAGE_ENDPOINT/BUCKET/ACCESS_KEY_ID/SECRET_ACCESS_KEY/REGION`을 사용한다. 명시한 환경파일이 있으면 그 파일만 사용하며, 없으면 프로세스 환경변수를 사용한다. 셸 실행·변수 치환 없이 단일 행 dotenv 값을 읽는다. REGION 기본값은 auto다.
- 기본 조건부 PUT은 기존 객체를 덮어쓰지 않고 SKIP으로 표시한다. 기존 파일과 내용이 같다는 뜻은 아니다. `--overwrite`를 명시해야 교체한다. 폴더 업로드는 파일별 작업이므로 중간 실패 시 이전 성공은 남는다.
- `--dry-run`은 파일 목록과 키·바이트 수만 표시하고 SDK나 네트워크가 필요 없다. 비밀값·서명 URL·SDK 오류 본문을 출력하지 않는다.
- 사용자 녹음의 `recordings/` 목적지, 심볼릭 링크·특수 파일, `.git`·`.env`·`.env.*` 입력은 거절한다. 입력 트리를 먼저 검사하며 단일 PUT 한도 5GiB 초과 파일은 업로드 전에 거절한다. 빈 폴더 객체는 만들지 않는다.
- R2 공개 정책·키·권한 변경, 서버 설치·배포, 실제 운영 업로드, DB 적재·게시, 원본 변경·삭제는 범위 밖이다. 대시보드 권한이 없는 팀원도 API 키 또는 권한 있는 서버 접근은 필요하다.
- 완료 조건: 파일·중첩 폴더·환경파일·미리보기·충돌·실패·비밀값 비노출 검사를 실행하고, 실제 SDK와 로컬 HTTP 대역의 조건부 요청을 확인한다. 운영 R2 성공 여부는 별도 실행 전에는 미확인이다.
