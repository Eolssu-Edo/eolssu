## 운영 적용 (병합 뒤, 사용자 승인 필요)

S15P31E102-228의 V5 적용과 같은 절차로 한다. DB 비밀값은 에이전트가 다루지 않으므로 DB 조회·백업은 사용자가 실행한다.

1. **기존 행 확인(읽기):** 운영 `instruments`·`jangdans`·`songs` 행 수와 Flyway 최신 버전(V5)을 확인한다. 같은 id·code·name 행이 있으면 V6가 실패하므로 적용하지 않고 다시 정한다.
2. **백업:** `instruments`·`jangdans`·`songs`·`flyway_schema_history` 덤프를 root 전용 `/opt/backups/eolssu-S15P31E102-249-<시각>/`에 둔다.
3. **V6 적용:** Jenkins가 V6를 포함한 JAR을 배포한 뒤, 그 JAR로 일회용 컨테이너를 `db` 프로필·웹 서버 없이 운영 DB에 붙여 Flyway가 V6만 적용하게 하고 멈춘다. 비밀값은 `.env`에서 환경으로 넘기고 명령줄에 쓰지 않는다.
4. **확인:** Flyway 이력 V6 성공, `songs` 4행. 시험 계정으로 연습 세션 생성 201(S15P31E102-178 스크립트).
5. **되돌리기:** `songs` 1~4, `jangdans` 1~3, `instruments` 1 행과 이력 V6 행 삭제(insert만 하는 마이그레이션). 이미 이 곡으로 만든 연습 세션이 있으면 먼저 확인한다.
