# S15P31E102-105 정석 음원 제작 기반

담당 박찬형 · Story S15P31E102-30 · 진행 중 · 스프린트 3(59139) · [MR !41](https://lab.ssafy.com/s15-final/S15P31E102/-/merge_requests/41)

## 최종 범위

- `data/src/playback/`: 공통 악보 JSON → MIDI → CAT 단소 WAV. JGB 직접 입력 변환기는 후속 범위다.
- 꾸밈·요성·숨·이음·붙임을 수치로 해석하고 추가 떨림은 ±25cent로 고정한다. 샘플·입력·소스 해시와 원본 음표 ID 대응을 기록한다.
- 채점·AI 평가는 사지한 담당이다. 표현값은 재생 초기값이며 전문가 원보·연주 검수는 남아 있다.

## 검증

- Python 3.10.21·NumPy 2.2.6·SoundFile 0.14.0. 저장소 루트의 실행·검사 명령은 [도구 README](../../data/src/playback/README.md), 표현 수치와 근거는 [조사 기록](../knowledge/data/score-instrument-playback-pipeline.md)을 따른다.
- 격리 검사 22개 통과. 실제 CAT 생성: 입력 37음의 ID 보존, MIDI 44음, WAV 44.1kHz·mono·PCM16·612,255프레임·13.883333초.
- Data 이동 전후 WAV SHA-256 일치: `628020cb8d7b99b9fc5c688cf13d04ed6c778d593ed9f3e554b08001bb2e70c9`. 문서 링크·공백 검사 통과.
