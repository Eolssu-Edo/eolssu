# S15P31E102-1095 구간 빠르기 악보의 각 추가·삭제 허용과 빠르기 위치 재매핑

- Story: S15P31E102-319, 에픽 S15P31E102-16
- 규칙: [구조 편집 재매핑 스펙](../specs/tempo-plan-structure-edit.md#2단계-각-추가삭제)
- 결정: 2026-11-17 사용자 결정. 빠르기 구간이 있는 각은 지우지 않고, 각 추가는 뒤 위치를 밀기만 한다. 막는 범위는 "변경이 시작하는 각 + 끝이 있는 구간이 걸친 각 + 반복 범위"로 정했다.

## 변경

- FE 각 추가: 구간 빠르기·반복·`gakContinuations`의 각 번호를 민다(`tempoExpressionsAfterColumnInsert`).
- FE 각 삭제: 빠르기 구간이 걸친 각은 막고 안내한다(`tempoColumnDeletionBlocked`). 그 밖의 각은 지우고 뒤 번호를 당긴다(`tempoExpressionsAfterColumnDelete`). 안내 문구를 "빠르기가 바뀌거나 반복하는 각은 지울 수 없어요…"로 바꿨다.
- FE 저장:
  - companion의 칸·이벤트 ID(`placements`, `sourceSlots`, `slurGroups`)를 보낼 악보의 새 ID로 옮긴다(`companionIds`).
  - 결합 해시는 보낼 악보의 정규화 SHA다. `exportExpressions`가 직접 계산하므로 해시 인자를 없앴다.
- FE 한배 기호 추가: companion의 칸 ID(불러온 악보 기준)로 저장한다. 새로 넣은 각에는 저장 전까지 기호를 넣지 않는다.
- BE `SheetExpressions.prepare(requestScore)`: 요청 악보 해시에 결합한 계획은 격자 비교 대신 좌표 유효성을 검사한다. 확정본 해시 결합(옛 앱)은 그대로 격자를 비교한다.

## 남은 일

- 서버 계약 변경이라 BE 리뷰가 필요하다. 배포 때는 서버가 앱보다 먼저 나가야 한다.
