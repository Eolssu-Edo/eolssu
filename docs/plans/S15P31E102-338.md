## 결정

- BPM은 공통 JSON에 없으므로 명시 옵션으로 받는다. 장단 이름으로 추정하지 않는다.
- 원본 시김새 배열은 시각 정보를 잃을 수 있으므로 비어 있지 않으면 명시적 미지원 오류. 기존 JGB 표현 지원을 서비스 v1 지원으로 과장하지 않는다.
- gate_fraction=1로 release를 음표 길이 안에 포함해 쉼 시작을 보존한다. 숨표는 기존 정책 재사용.
- 기존 후행 약550ms는 유지하며 30초 악보 길이와 구분한다.
- 원본 fixture는 기존 추적 자료를 재사용한다. CAT 설치 파일·생성 대용량 음원은 Git에 넣지 않는다.

- 실패 재현: 공통 fixture를 기존 `run(... common_bpm=96)`에 전달하면 TypeError. 구현 후 MIDI61음·원본 바이트·65이벤트 대응표·30초 악보/30.55초 파일 확인.

- Python3.10.21 / NumPy2.2.6 / SoundFile0.14.0 / jsonschema4.26.0 / FFmpeg·ffprobe9.0.2. 독립 `data/.venv`에 저장소 requirements로 설치했다.
- playback 전체159개 통과(15.690초, 건너뜀0). FFmpeg/ffprobe 환경변수를 해당 설치 경로에 지정해 실제 AAC 테스트도 실행했다. 로그 `data/playback-tests-338.log`(로컬).
