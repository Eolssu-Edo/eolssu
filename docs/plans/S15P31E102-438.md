## 요청·결정

2026-11-03 사용자 요청에 따라 마이페이지를 개편한다.

- 프로필 카드 오른쪽 중앙에 연필 아이콘을 두고 기존 닉네임 수정 화면을 연다.
- 연습 악기 선택 UI를 제거하고 기초부터 배우기 진도 카드로 대체한다. 사용자의 '어느 레벨까지 했는지' 제안을 바탕으로 완료 수·다음 단계·9칸 진행 표시를 구성한다고 안내했으며, 사용자가 이어서 진행하도록 요청했다.
- 학습 화면이 실제로 사용하는 `LearnProgressRepository`의 악기별 완료 기록을 재사용한다. 현재 기기 저장이므로 서버에 동기화된 진도·경험치·연속 학습일로 표시하지 않는다. 건너뛰어 완료할 수 있으므로 '최고 완료 단계'를 현재 레벨로 확대 해석하지 않는다.
- OAuth는 공식 로고·제공자·연결/해제 버튼을 한 줄로 배치하고 연결됨/연결 안 됨 문구를 없앤다. 마지막 로그인 수단 보호·해제 확인은 유지한다.
- 서비스 안내 3종은 맨 아래 작은 링크 푸터로 옮긴다. 기존 테스터 의견 보내기 폼은 유지하고, 문의하기는 URL 확정 전 준비 안내를 표시한다.
- 사용자는 로그아웃 확인창 하단 버튼이 '회원 탈퇴'임을 확인했다. 작은 텍스트 버튼으로 옮기되 명확한 이름·48dp 터치 영역과 기존 탈퇴 확인·재인증 절차를 유지한다. 이 버튼 자체는 로그아웃·탈퇴 요청을 실행하지 않는다.
- HOME·네비게이션·테마·공용 컴포넌트·의존성 설정은 변경하지 않는다. HOME의 악기 선택 작업은 Claude 브랜치의 별도 업무다.
