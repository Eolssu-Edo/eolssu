- Android 17/API 37 `Medium_Phone` 에뮬레이터, 1080×2400·420dpi에서 정상 설정·저장, 장단 불일치, 여러 수정 정간, 잘못된 음역 사례를 통과했다. 실제 화면과 저장 요청·상태 기록을 대조했다.
- 초기 화면에 미리듣기 버튼·검토/오류 패널이 없고 빠르기·장단 및 오른쪽 편집 버튼을 확인했다. 편집 창에는 제목 입력이 없다. 취소 시 제목·BPM·장단과 저장 요청 수가 유지됐으며, 적용 후 `Changed736 / 120 BPM / 장단 1` 확정 저장에 성공했다.
