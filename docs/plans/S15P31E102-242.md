### U2 정답 기록

- 의도한 오류 종류: `PITCH`(음 바꿈), `OCTAVE`(옥타브), `TIMING`(지연·이름), `MISSED`(누락). 크기는 반음 수·ms.
- 실제 녹음 조건 칸: 연주자 ID(이름 대신 `P01`), 숙련도, 악기 ID, 녹음 기기·앱 버전, 마이크 거리, 장소·잡음, 날짜, 온도, 테이크 번호, 오류를 낸 방법. 합성 녹음은 대신 합성 방법·오류 위치·잡음·난수 시드.
- 완료: 칸이 빠지거나 `idx`가 곡의 음 수를 넘으면 Schema 또는 검사가 실패한다(테스트).

### U3 평가 실행

```text
검출률 = TP / (TP + FN)    오탐률 = FP / (FP + TN)
윌슨 구간: 중심 = (p̂ + z²/2n) / (1 + z²/n), 반폭 = z/(1 + z²/n) × √(p̂(1−p̂)/n + z²/4n²), z = 1.96
```

- 허용값 조합: 음정 30·40·50·60센트 × 시작 1/8·0.2박 × 길이 ±20·25%.
- 고르는 규칙은 둘 다 출력: 오탐률 5% 이하 중 검출률 최대, 유덴 지수(검출률 − 오탐률) 최대. 어느 쪽을 쓸지는 D1 회의 몫.
- 완료: 윌슨 구간이 알려진 값(9/10 → 0.596~0.982, 10/10 → 0.722~1.0)과 맞는 테스트, 합성 묶음에서 의도한 오류가 모두 검출되는 테스트.

### U4 전후 비교

```text
b = 전 CORRECT → 후 오류, c = 전 오류 → 후 CORRECT
b + c < 25이면 이항 정확 검정(p = 2 × P(X ≤ min(b, c)), X ~ B(b + c, 0.5)), 아니면 χ² = (b − c)² / (b + c)
```

- 완료: 선언하지 않은 묶음이 다르면 거절하는 테스트, 맥니마 값이 손계산과 맞는 테스트, 같은 결과끼리 비교하면 차이 0.
