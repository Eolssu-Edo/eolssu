# S15P31E102-701 Mattermost 점검 명령 통합과 보고서 표 구분

- Mattermost CI/CD 채널의 점검을 호스트별 `/edo1`, `/edo2`로 통합한다. 기존 상태·서버·컨테이너 검사의 판정과 측정값을 유지하고, 짧은 제목과 주제별 표로 표시한다. [Jira 작업](https://ssafy.atlassian.net/browse/S15P31E102-701) · [운영 모니터링 Story](https://ssafy.atlassian.net/browse/S15P31E102-41) · [메시지 스펙](../specs/mattermost-inspection-messages.md)
- 중계에서 기존 세 SSH 수집을 순차 실행한다. 한 모드의 실패를 해당 표의 미측정으로 표시하고 성공한 모드의 결과를 보존한다. 보고서가 여러 게시물로 나뉘면 같은 요청 ID를 사용한다.
- 실제 Mattermost 11.7.2에서 기존 건강 점검 명령의 트리거를 변경해 토큰을 유지한다. 새 트리거는 edo2의 비공개 설정에서 기존 토큰 키를 옮겨 연결한다. 두 명령이 동작하면 나머지 네 명령을 되돌릴 수 있게 비활성화한다. `/applog`의 접수와 조회는 기존 규칙을 따른다. [전환·복구 절차](../../infra/edo-check/README.md#통합-명령-전환과-복구) · [Mattermost 명령 수정 구현](https://github.com/mattermost/mattermost/blob/v11.7.2/server/channels/app/command.go#L703-L733)

## 검증 계획

- 자동 테스트로 세 수집의 부분 실패, 인증·다른 채널 차단·중복 요청, 긴 표의 분할과 머리글, 메시지 수와 길이 제한, `/applog` 회귀를 확인한다.
- 운영 수집 결과에서 각 표의 행·수치·판정 근거를 이전 보고와 대조한다. 운영 반영 뒤 CI/CD 채널에서 `/edo1`, `/edo2`를 각각 실행해 제목·표·요청 ID와 중계 전달 로그를 확인한다.
