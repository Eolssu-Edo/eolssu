- Jira: [S15P31E102-1035](https://ssafy.atlassian.net/browse/S15P31E102-1035), Story318 `Relates`, 오은서, 활성 스프린트5, 진행 중.
- 착수 기준: `origin/develop` `99a33b9e1`, 별도 worktree. 브랜치 `fix(ai)/S15P31E102-1035-장단을-정하지-못한-오선보-인식의-빠르기를-박자표-기본값으로-적용`.
- 범위·완료 조건: 숫자 빠르기도 장단도 없는 오선보가 60 대신 박자표의 장단 기본 빠르기와 알림으로 나온다. 숫자를 읽은 악보, 장단을 정했거나 요청한 악보는 바뀌지 않는다. 기준은 [인식 스펙](../specs/score-recognition.md)의 `bpm` 항목.

## 결정

- 위치: 인식 서비스. backend는 장단 이름으로만 기본값을 찾고 박자표를 모른다. 응답 `bpm`은 "인식한 숫자"에서 "인식한 숫자, 없으면 박자표 기본값"으로 넓어지고, 후자는 `TEMPO_DEFAULT_FROM_TIME_SIGNATURE` 알림으로 구분한다. backend 선택 순서(요청 → 응답 bpm → 장단 기본값)는 그대로다.
- 박자표가 여럿이거나 자동 장단 대응이 없는 박자표(예: 3/4)는 기존대로 생략한다. 낮은 신뢰도 박자표(`TIME_SIGNATURE_REVIEW_REQUIRED`)도 적힌 박자표로 본다. 60보다 나은 시작값이고 알림이 남는다.
- 장단은 계속 비워 둔다. 마디 길이가 맞지 않는 악보에 반주를 붙이지 않는다.

- 컨테이너(JGB 생성기 포함) 오선보 관련 회귀 182 통과·2 건너뜀(로컬 AuClair PDF 없음).
