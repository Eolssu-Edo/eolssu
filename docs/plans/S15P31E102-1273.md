# S15P31E102-1273 R2 파일과 DB를 대조하는 읽기 전용 점검 도구 추가

- [Task](https://ssafy.atlassian.net/browse/S15P31E102-1273)는 우동균 담당, Epic S15P31E102-21(인프라·운영), Story S15P31E102-1162(녹음·음원 R2 저장소 운영)와 relates로 연결했다(2026-11-24 생성, `진행 중`). 활성 스프린트가 없어 스프린트는 미배정이다(스프린트 6은 시작 전).
- 발표 뒤 개선 조사의 '데이터·비용 묶음' 중 첫 항목이다. 삭제 작업 수치·알림, R2 용량 감시, 마트 정리 등 나머지는 별도 Task로 한다.
- 브랜치 `feat(infra)/S15P31E102-1273-R2-파일과-DB를-대조하는-읽기-전용-점검-도구-추가`, 기준 `origin/develop` `9d8c7dfc4`.

## 배경

- 2026-11-03 `recordings/` 30일 수명 주기 규칙을 일부러 없앴다([녹음 보관 스펙](../specs/recording-retention.md)). 그 뒤에는 DB가 가리키지 않는 객체를 지우는 장치가 없고, 스펙의 '알려진 제약'에 그런 객체가 생기는 경우가 적혀 있다.
- 탈퇴 일괄 삭제(04:00)·미저장 녹음 정리(04:30)는 로그에 처리 수를 남기지만, 실제로 버킷에서 사라졌는지 대조하는 수단은 없었다.

## 결정

- 읽기 전용으로 만든다. 삭제는 결과를 보고 따로 승인받는다(사용자가 정할 일로 남김).
- 대조 기준은 백엔드가 키를 저장하는 DB 칸 전부다. 마이그레이션에서 `object_key`·`recording_url` 칸을 모두 찾아 [README 표](../../infra/storage/README.md#주인-없는-파일-점검-s15p31e102-1273)로 정리했다.
    - `practice_sessions.recording_url`은 REC-04 기록 삭제(`markDeleted`)와 미저장 녹음 정리가 NULL로 비우므로, NULL이 아닌 값 전체를 살아 있는 참조로 본다.
    - 모범 연주(`song_model_audios`)는 녹음 저장소 설정으로 읽으므로(`ModelAudioConfig`) 녹음 버킷과 대조한다.
    - `catalog/`·`notation-symbols/`는 백엔드 클래스패스 자원이라 R2 대상이 아니다.
- 회원 파일 접두사(`recordings/`·`sheet-sources/`·`sheet-audio/`)만 '주인 없는 파일'로 센다. 카탈로그 접두사에는 일부러 DB에 넣지 않는 게시 묶음 파일(`release.json` 등)이 있어 `other`로 보고만 한다.
- DB를 먼저 읽고 목록을 나중에 받는다. 업로드 직후 DB 갱신 전인 객체를 고아로 오판하지 않도록 24시간 유예를 둔다.
- 키에 회원·세션 ID가 들어 있어 콘솔에는 개수만 내고, 키는 `--keys-out` 새 파일(0600)에만 쓴다. 오류 원문(서명 URL 포함 가능)은 출력하지 않는다.

## 검증

- 2026-11-24 로컬(macOS, Python 3.9.6): `TMPDIR=<심볼릭 링크 아닌 폴더> python3 -B -m unittest discover -s infra/storage -p 'test_*.py'` 21개 통과(새 테스트 8개 포함).
    - 기본 `TMPDIR`(macOS `/var` 심볼릭 링크)에서는 기존 `test_migrate_r2` 2개가 `symlink destination rejected`로 실패한다. 이번 변경과 관계없는 기존 환경 제약이다.
- 새 테스트는 가짜 버킷(목록만 지원, 쓰기 메서드 없음)과 고정 DB 응답으로 분류·유예·누락·권한 실패 대체·출력에 키/비밀값 없음·키 파일 권한을 확인한다.
