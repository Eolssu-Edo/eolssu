## 확정 계약

- DB 큐에서 접수 순으로 단일 작업자가 하나씩 처리한다. 원격 호출 동안 DB 트랜잭션을 유지하지 않는다.
- 호출 제한 630초. 재시작 시 RUNNING은 SERVER_ERROR로 정리한다.
- 전체 재시도 최대 3회(attempt 4). TIMEOUT은 한 번만 재시도, ENGINE_ERROR는 재시도하지 않는다. 내부 실패 원인과 TIMEOUT 횟수를 별도 저장한다.
- 결과는 NEEDS_REVIEW. 빈 칸이 없으면 공통 악보 score_json, 있으면 draft_json. sourceId는 sheet-{id}, provenance.review는 inferred다.
- issues와 notices는 구분한다. 확인할 칸 수는 cellId(없으면 eventId) 중복을 제거한다. bbox는 쪽 크기로 정규화한다.
- 원본 PNG는 악보 전용 저장소에 보관하고 15분 서명 URL로 조회한다. 삭제·탈퇴 시 함께 정리한다.
