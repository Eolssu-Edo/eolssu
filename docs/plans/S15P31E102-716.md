# S15P31E102-716 연습 화면 계이름 표시·장단 안내 문구 삭제와 평가 화면 표기 스위치 이동

- Jira: S15P31E102-716, Story S15P31E102-32(연습 화면 흐름), Epic S15P31E102-20. 담당 오은서.
- 브랜치: `feat(fe)/S15P31E102-716-연습-화면-계이름-표시·장단-안내-문구-삭제와-평가-화면-표기-스위치-이동`, `origin/develop`(9715a7f5) 기준.

## 범위와 완료 조건

- 계이름 표시를 없앤다: 쉬운 표기 설정의 '계이름 표시' 스위치, 악보(정간보)의 계이름 글자, 설정 값(`showSolfege`), 곡 모델의 계이름 대응(`Song.solfege`, 서버는 늘 비어 있었다). 쉬운 표기는 '한글 읽는 법 표시'만 남는다.
- 장단 설정의 안내 문구를 없앤다: 구음 예시·속도 안내(구음이 없는 장단의 안내 포함), '연습 중 장단 소리'·'현재 박 시각 표시'의 설명 줄.
- 연주 평가(휴대폰)에서 곡 제목 옆에 '운지법 보기'·'쉬운 표기' 스위치를 두고, 톱니 연습 설정에서는 두 항목(쉬운 표기 메뉴, 운지법과 함께 보기)을 뺀다. '쉬운 표기' 스위치는 한글 읽는 법 표시를 바로 켜고 끈다.
- 완료 조건: 공유 테스트·JS 컴파일·Android 빌드 통과, 에뮬레이터에서 세 변경 확인.

## 결정

- 스위치 이동은 연주 평가(혼자 연습·내 악보 연습이 아닌 연습)에만 한다. 혼자 연습의 톱니는 그대로다.
- 휴대폰 화면만 제목 옆에 스위치를 둔다. 태블릿 세로는 제목 줄이 없고 가로는 오른쪽 상태 패널에 바로가기가 있어, 태블릿의 톱니·바로가기는 그대로 둔다.
- 곡 정보에서 여는 연주 평가 전 '연습 설정' 시트(705)는 제목 줄이 없어 두 항목을 그대로 둔다.
- 평가 녹음 중 장단 소리가 꺼진다는 안내(`practice_jangdan_mic_notice`)는 동작 안내라 남긴다.
- 제목 옆 스위치는 연주 중에도 누를 수 있다. 연주 평가는 들어오자마자 카운트다운·연주로 이어져 연주 중에 막으면 쓸 수 없고, 표시만 바뀌어 평가는 멈추지 않는다.
- 장단 설정의 '장단과 악보를 함께 따라가며 연습해요'·'재생 중이에요' 상태 안내도 주석 문구로 보고 뺐다. 장단 소리를 쓸 수 없거나 준비 중일 때의 이유만 남긴다.
