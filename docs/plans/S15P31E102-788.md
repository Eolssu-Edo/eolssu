## 계약과 완료 조건

OMR은 원래 실음 MIDI·옥타브를 전달하고 자동 5율 이조·옥타브 접기를 하지 않는다. 구조 변환의 중간 JGB 표기를 최종 음고로 삼지 않는다. 표기 범위 밖 음은 origin의 빈 표기와 원래 event 음고, 뒤의 연결 기호를 보존한다. RecognitionResultBuilder가 원본 score·음표 위치/MIDI·SHA를 `sheet-authoring/v1` source로 만든다.

SHT-04/08/11과 V42 `authoring_json`은 불변 source와 최신 adaptation을 공통 악보 밖에서 전달한다. 원본 교체는 거절하고 SHA 참조는 허용하며, 생략한 기존 클라이언트도 보존한다. 과거 판본 기준은 EXISTING_SCORE로 구분한다. 불완전한 과거 초안은 원본 snapshot을 억지로 만들지 않고 읽기를 유지한다. PDF 보관 정책은 바꾸지 않는다. source 변경 권한·본문1MiB·판본 충돌·소유자 검증은 기존 경계를 유지한다.

공통 서버·OMR 계약만 이 결과에 속한다. 변환 후보·사용자 확인·되돌리기는 FE771, 지원음 최종 검증은 BE787의 결과이며 별도 병합한다. V41은 그대로 유지하고 신규 V42만 추가한다.
