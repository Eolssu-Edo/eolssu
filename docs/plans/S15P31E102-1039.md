# S15P31E102-1039 내 악보 음원 생성 중 상태 표시

- 작업: `S15P31E102-1039` · Story `S15P31E102-319`
- 범위: 내 악보 연습(native) 화면의 음원 상태 표시. 서버 API·음원 생성 로직, 내 악보 목록 줄, Web 재생 UI는 제외.

## 원인

- 연습 화면은 열 때 기기 파일만 확인했다. 편집기 등에서 요청한 생성이 서버에서 QUEUED·RUNNING이어도 `음원 다운로드` 버튼을 띄워 준비되지 않은 것으로만 보였다. 화면을 떠났다 돌아와도 같았다.

## 변경

- `SheetPracticeRepository.generating`: 기기 파일이 없을 때 SHT-13으로 이 확정 판본의 생성이 진행 중인지 본다. 설정(악기·빠르기)은 보지 않는다.
- `download(resume = true)`: SHT-12를 다시 보내지 않고 진행 중인 생성만 기다린다. 끝난 음원이 연습 설정과 다르거나 기다릴 생성이 없으면 `NotStarted`로 다운로드 버튼에 돌아간다. 생성 실패는 기존처럼 `다시 시도`다.
- 표시: 버튼 자리 `음원 만드는 중`(기존 `음원 준비 중`), 막대 아래 `음원을 만들고 있어요 · 다 되면 바로 들을 수 있어요`.

## 검증

- `PracticePersonalAudioTest`: 열 때 생성 중 → 요청 없이 기다려 저장, 재진입 후 이어서 대기, 다른 설정으로 끝남 → 다운로드 버튼, 실패 → 다시 시도. 재진입 확인으로 SHT-13 조회가 1회 늘어난 기존 기대값을 고쳤다.
- 실기기·iOS·운영 API 확인은 하지 않았다.
