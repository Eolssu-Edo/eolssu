# S15P31E102-709 외부 의존성 운영 점검

- 운영 모니터링 Story 41, 스프린트 5, 진행 중. 최신 develop과 운영 점검 소스를 합친 브랜치에서 진행한다. [Jira 작업](https://ssafy.atlassian.net/browse/S15P31E102-709) · [판정 기준](../specs/mattermost-inspection-measurements.md)
- `/edo1`의 기존 상태 표에 학습 음원 R2 읽기, 녹음 R2 쓰기 최근 결과, 저장공간 측정 예약·최신성, 독립 HTTPS 최근 결과를 추가한다. 보고서 제목과 구분은 유지한다.
- 읽기 점검은 백엔드가 발급한 단기 서명으로 공개 학습 음원의 고정 범위를 검증한다. 쓰기 점검은 edo1에 주입된 운영 녹음 설정을 사용하고 전용 접두사의 합성 객체만 쓰고 읽고 지운다. 결과는 최근 시각과 고정 판정만 남긴다.
- 독립 HTTPS 검사는 edo1의 타이머가 edo2 중계와 공개 업무 API를 직접 호출하고 각각의 응답을 검증한다. 실행 결과는 edo1 상태 파일과 journal에 남긴다.
- 판정 회귀, 두 타이머의 운영 실행, 실제 Mattermost 결과를 확인한다. 내 악보 생성 음원용 R2 설정은 별도 세션의 [S15P31E102-710](https://ssafy.atlassian.net/browse/S15P31E102-710)에서 처리한다.
