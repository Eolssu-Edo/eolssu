# 구간 빠르기를 바뀌는 곳마다 바로·점점 기호 하나로 단순화하고 편집 창 재설계

- Jira: [S15P31E102-1089](https://ssafy.atlassian.net/browse/S15P31E102-1089). 1082(병합됨)의 후속.
- 규칙: [스펙](../specs/jeonggan-tempo-edit.md#바뀌는-곳마다-기호-하나-s15p31e102-1089).

## 결정 경과 (2026-11-17)

1. 처음에는 '구간 밖은 기본, 점점도 끝나면 기본으로 복귀'하는 일정·점점 구간 모델로 바꿨다.
2. 기본 160에서 80→160 구간이 기호 하나(`ㅈㅈㅅ`)로 표현되지 않는 문제가 나왔다. 저장소 조사 기록상 실제 정간보는 시작에 기호를 두고 다음 기호까지 유지하며, 한 자리에 기호 두 개를 쓴 사례는 찾지 못했다.
3. 사용자 결정: 바뀌는 곳마다 기호 하나, 시작 빠르기 입력 없음, 끝 빠르기 유지. '본래 속도로'는 따로 고르지 않고 기본으로 바로 돌아가면 화면이 붙인다. 화면에는 기호 대신 말로 보인다.
4. 편집 창의 그래프·긴 설명문은 빼고, 위치는 숫자 칸 입력으로, 기본 빠르기는 −/+ 한 줄로 바꿨다.
