## 진행 기록

### 2026-11-04 구현 (Windows)

- 1·2번 BE(커밋 `9824c13b`): `AppleOAuthGateway`(ES256 client_secret, 코드 교환, id_token 서명·iss·aud·nonce, 해지), `AesProviderTokenCipher`, `ProviderRoutingOAuthGateway`, V22, 토큰 저장·갱신(로그인·연결·가입/연결 제안 티켓·탈퇴 재인증)과 해지(연결 해제·비밀번호/소셜 탈퇴 커밋 뒤).
  - 새 테스트가 구현 전 컴파일 실패(타입 없음). 해지·갱신 코드를 일부러 빼면 `AppleTokenLifecycleTests` 3건이 실패하고 되돌리면 통과.
  - `./gradlew test` 590건 통과. 폐기용 MySQL 8.4(`databaseTest`) 224건 중 222건 통과. 실패 2건(`OpenApiDatabaseTests`·`OpenApiOpsDatabaseTests`의 경로 수 68≠69)은 417의 iOS 중계 GET 추가로 develop에 이미 있는 차이이며 이 Task는 API 경로를 추가하지 않았다.
- 3번 FE 공통: `SocialProvider.Apple`, `OAuthRoute.providers`(iOS만 Apple 맨 앞), `AppleNativeSignIn`(authorizationUrl의 state·nonce 읽기, 앱 복귀 주소 만들기), 로그인 Apple 버튼·마이페이지 Apple 줄(플랫폼 목록 + 연결된 제공자). `:shared:jsTest` 700건 통과. 새 3건은 일부러 목록·복귀 경로를 틀리면 실패.
- 4번 iOS: `IosExternalBrowser`가 Apple 주소면 `ASAuthorizationController`(email, nonce, state)를 띄우고 코드로 복귀 주소를 만든다. 취소는 아무것도 넘기지 않는다. `iosApp.entitlements`(applesignin Default)와 `CODE_SIGN_ENTITLEMENTS`(무료 팀은 로컬에서 비움). **Windows에서 iOS 컴파일 불가 — Mac 미검증.** Apple 로고 벡터도 기기 화면 확인 전이다.
- 미실행: `:shared:testAndroidHostTest`·`:androidApp:assembleDebug`(이 PC에 Android SDK 없음), Mac `:shared:iosSimulatorArm64Test`·Xcode 빌드, 실제 Apple 연동.
