# S15P31E102-768 기초 배우기·운지법 보기·정간보 읽기 화면을 마이페이지 스타일로 맞추고 홈·연습 기록·악보 추가 제목 정리

- Jira: S15P31E102-768, Story S15P31E102-109(UI/UX), Epic S15P31E102-1. 담당 오은서.
- 브랜치: `feat(fe)/S15P31E102-768-기초-배우기·운지법-보기·정간보-읽기-화면을-마이페이지-스타일로-맞추고-홈·연습-기록·악보-추가-제목-정리`, `origin/develop`(ccb751d6) 기준.

## 범위와 완료 조건

- 마이페이지(731·759)의 화면 스타일을 학습 화면에 맞추고, 홈·연습 기록·악보 추가의 제목 둘레를 정리한다. 마이페이지 진도 뱃지가 늦게 뜨는 문제를 고친다.
- 완료 조건: 공유 테스트·JS 컴파일·Android 빌드 통과, 에뮬레이터에서 각 화면 확인.

## 결정

- 마이페이지 스타일: 옅은 회색 바탕(`groupedBackground`)과 테두리 없는 흰 카드. 기초 배우기(휴대폰·태블릿 가로)·운지법 보기·정간보 읽기에 적용했다.
  - 운지법 카드는 모서리를 20dp로 맞췄다. 기초 배우기 단계 안에 들어가는 운지법 카드는 흰 바탕 위라 테두리를 남긴다.
  - 악기 선택·취법 탭·쪽 목차·단계 카드·달리기 지도·이전 버튼의 테두리를 없앴다.
  - 기본음·요성 버튼은 흰 카드 안에서 구분되도록 회색 바탕으로 칠했다.
  - 기초 배우기 제목은 다른 화면과 같은 크기로 줄였다(21sp 지정 삭제).
- 악기 그림: 기초 배우기의 대나무 악기 그림(749)을 `core/ui/component/InstrumentPicture.kt`로 옮겼다. 운지법 보기 악기 선택과 마이페이지 진도 뱃지가 같은 그림을 쓴다. 마이페이지에서 따로 그리던 악기 모양은 지웠다.
- 정간보 읽기: 화면 제목과 자료 출처 문구의 화면 이름을 '정간보 읽기'로 바꿨다.
- 홈: 기능 칸의 제목을 그림 상자 안 그림 아래로 옮겼다. 상자 전체가 누르는 영역이다.
- 연습 기록: '저장한 연주 N개'를 빼고 휴대폰 제목을 공용 상단 바(다른 화면과 같은 글꼴·크기)로 바꿨다. 태블릿은 원래 공용 상단 바다.
- 악보 추가: '정간보로 만들어 내 악보에 저장해요' 문구를 뺐다.
- 진도 뱃지 속도: 원인은 두 가지였다.
  - 다섯 트랙을 잠금 안에서 하나씩 받았다. 이제 기기에 올릴 완료 표시가 없으면 잠그지 않고 한꺼번에 받는다. 올릴 표시가 있는 트랙만 잠근다.
  - 내 정보(연습 악기)를 받은 뒤에야 진도를 받기 시작했다. 이제 바로 받고, 연습 악기는 완료 기록이 하나도 없을 때만 기다린다.
  - 같은 이유로 돌아왔을 때 보여 주는 마지막 뱃지를 연습 악기와 묶지 않는다.
  - 한계: 완료 기록이 없는 회원이 마이페이지에서 연습 악기를 바꿔도, 완료 표시가 바뀌기 전까지는 뱃지 악기가 바뀌지 않는다.
- 제목 글꼴: Song Myung(명조풍)으로 쓰던 제목(화면 제목·카드 제목·브랜드 문구)을 본문과 같은 IBM Plex Sans KR SemiBold로 바꿨다(사용자 요청, '시작하기' 버튼 글꼴 기준). `EolssuTheme`의 `heading`이 본문 글꼴을 가리킨다. 율명·곡 제목의 Noto Serif KR은 그대로이고, `song_myung_regular.ttf`와 라이선스는 지금은 쓰지 않지만 남겨 두었다.
- 바탕색: 연두빛이 돌던 바탕(#F9FAF9·#F2F3F1)을 차가운 회색 #F2F4F6으로 바꿔 본 뒤, 사용자 요청으로 옅은 회색 #F9FAF8을 거쳐 #F5F6F4로 정했다. 공통 `background`·선 색은 원래 값(#F9FAF9·#E3E9E3·#E5EAE5)으로 되돌리고, 회색은 `groupedBackground`(#F5F6F4)로 홈·마이페이지·학습 화면·연습 기록 목록·악보 추가(새 악보 만들기)·연습곡 고르기 화면에만 쓴다. 요청하지 않은 화면(연습·결과·기록 상세·성장·비교, 편집할 악보 고르기·사진 가져오기·가져오기 결과)은 바꾸지 않는다(사용자 요청). 흰 화면(연습 기록 등)은 그대로다. 홈 그림이 바탕으로 번지는 색(`HomeGround`)과 로그인 화면 바탕은 그림에 맞춘 색이라 그대로 둔다.
- 홈: 오른쪽 위 입구에 마이페이지와 같은 내 프로필 그림 원(40dp)을 둔다. 이를 위해 `ProfileImage`를 `core/model`로, 그림 대응·원 그리기를 `core/ui/component/ProfileImagePicture.kt`로 옮겼다. 기능 칸은 테두리 없는 흰 상자(모서리 20dp)이고 위 구분선을 뺐다.
- 연습 기록 목록: 회색 바탕 위 이번 주 카드·드롭다운·곡 묶음의 테두리를 뺐다.
- 기본음·요성 버튼: 마이페이지 '연결'과 같은 연한 연두 바탕(`accentTint`)·짙은 연두 글자.
- 기초 배우기 목록 단계 카드 그림: 카드 전용 자르기 값(`LearnCardArtCrops`)을 그림의 회색 바탕이 아닌 부분 전체가 들어가도록 정했다(둘레 약 6% 여백). 단계 상세 머리·과제 안내 그림은 원래 자르기 값을 그대로 쓴다. 7단계 꼬리처럼 원본 높이보다 넓게 잘라야 하는 그림은 원본 밖을 그림 바탕색(RGB 224)으로 채운다. 카드에서 그림을 86%로 줄이던 방식은 없앴다.
- 마이페이지 로그아웃 확인 창: 휴대폰 뒤로 가기를 눌러도 닫히지 않았다. 공용 확인 창(`EolssuDialog`)은 기본이 '뒤로 가기·바깥 눌러도 안 닫힘'인데 로그아웃 창이 닫기 동작을 넘기지 않았다. 로그아웃 창에만 '취소'와 같은 닫기를 넘겼다. 같은 화면의 간편 로그인 해제 창 등 다른 창은 바꾸지 않았다.
- 연습곡 고르기: 회색 바탕에 탭·검색칸·난이도 칩·정렬 단추·곡 줄·내 악보 줄·악보 추가 단추·악기 알약을 테두리 없는 흰 카드로 그린다. 평가할 곡 고르기·편집할 악보 고르기와 함께 쓰는 부품은 `bordered` 인자(기본 true)로 이 화면에서만 테두리를 끈다. 고른 줄·고른 난이도 칩의 색 테두리와 내 악보 줄의 '편집' 칩 테두리는 고른 표시·흰 카드 위 구분을 위해 남긴다. 고른 탭의 곡 수 숫자는 연두 바탕 위에서 회색이 탁해 보여 탭 이름과 같은 글자색으로 바꿨다.
- 연습곡 고르기 탭 모양: 고른 칸이 누르는 최소 높이(48dp)에 맞춰 보이는 높이 40dp보다 크게 자리를 잡아 위아래 간격이 양옆보다 넓었다. 고른 칸을 48dp로 올려 사방 4dp로 맞추고 모서리를 틀(14dp)에서 여백을 뺀 10dp로 했다.
- 연습 화면(제공 곡·내 악보 연습, 휴대폰·태블릿): 회색 바탕, 상단 바 구분선과 '한 음씩'·톱니 버튼 테두리 제거, 플레이어 카드 테두리 제거, '모범 연주·장단으로 연습'을 연습곡 고르기 탭과 같은 흰 틀 안 연두 알약으로 바꿨다. 공용 상단 바·원 버튼은 `divider`·`bordered` 인자(기본 그대로)로 연습 화면에서만 끈다. 정간보(악보 칸) 코드는 건드리지 않았다(사용자 요청).
- 연습 설정 시트: 회색 시트 위 흰 카드 세 묶음(연습 악기 / 쉬운 표기·장단·속도 / 운지법과 함께 보기), 줄 사이 선 없음, 아이콘 네모와 악기 고르기는 테두리 없는 회색 채움. 쉬운 표기·장단·속도 하위 화면은 바꾸지 않았다.
- 스크롤 끝 늘어남: 팀 코드가 정한 것이 아니라 Android 12 이상 Compose 기본 스크롤 끝 효과(늘어남)였다. 사용자 요청으로 테마(`EolssuTheme`)에서 `LocalOverscrollFactory`를 비워 앱 전체에서 껐다. 홈 그림이 당기면 커지는 동작은 홈 전용 스크롤 처리라 그대로다.
- 드롭다운 메뉴: 모양이 세 가지(연두 채움+구분선, 머티리얼 기본, 연한 연두 채움)로 달랐다. `core/ui/component/EolssuMenu.kt`(테두리·구분선 없는 흰 카드 16dp, 고른 줄은 `accentTint`·짙은 연두 글자·확인 표시)로 연습 악기(곡 고르기·연습 설정)·운지법·기초 배우기 악기·연습 기록 정렬·성장 곡 고르기 메뉴를 통일했다.
- 연습 설정 하위 화면(쉬운 표기·장단·속도·운지법): 회색 시트 위 흰 카드. 장단은 이름·칸·'장단 듣기'(회색 채움 단추)를 한 카드, 스위치 두 줄을 다른 카드에 둔다. 장단 칸과 미리보기 정간보 그림은 바꾸지 않았다.
- 연습 기록 상세: 회색 바탕, 점수 상자 흰 카드(`ScoreSummaryCard(filled = true)`), 오류 종류 칸은 그림자 없는 연두 알약(연습곡 고르기 탭과 같은 모양, 연주 결과 화면도 같은 부품이라 함께 바뀜). 재생 영역은 시간·막대를 흰 카드로 묶고 재생 묶음을 흰 알약으로, 아래 구분선은 없앴다. 태블릿 가로 기록 화면도 회색 바탕에 테두리 상자 없이 같은 카드를 놓는다.
- 이전 연주와 비교: 회색 바탕, 점수 비교 카드 흰 카드. '비교 기록 바꾸기'·'메모'·'지난 연주와 비교' 연두 알약(`TintPillButton`)은 마이페이지 '연결'과 같은 연한 연두 채움·테두리 없음(연주 결과 '다시 연습'도 같은 부품).
- 비교할 기록 고르기: 달력의 녹음한 날은 회색 채움, 이번 기록 날은 연한 연두 채움, 기록 칸은 회색 채움(비교 중이면 연한 연두)으로 테두리를 없앴다.
- 고르기·켜기 부품 통일: 성장 화면 주·월 탭, 악보 편집 칸 탭(테두리 제거, 큰 탭 사방 4dp), 구간 반복 횟수 버튼(회색 채움), 가입 악기 고르기(회색 채움), 스위치 손잡이 그림자 제거, '한 음씩' 작은 스위치 켬 색을 다른 스위치와 같은 연두(`primary`)로, 구간 반복 스위치 꺼짐 색을 기본값으로 맞췄다. 기본음·요성 버튼은 앞서 정한 연한 연두 그대로다.
- 자료 및 데이터 출처: 회색 바탕 위 흰 카드(20dp), 자료 종류는 연한 연두 꼬리표, 링크는 회색 채움 칸(주소 한 줄 말줄임)으로 바꿨다.
- 연습 '한 음씩' 두 칸(현재 정간·내 연주): 테두리 없는 흰 카드(16dp), 안쪽 여백을 사방 16dp로 같게 해 이름·내용·아이콘 위치를 맞췄다. 녹음 중은 옅은 빨강 채움.
- 연습 기록지: 회색 바탕, 요약 칸·그래프 카드를 테두리 없는 흰 카드로, 주·월 탭 틀은 흰색. 점수 변화의 악기 칩과 곡 고르기 칸은 같은 36dp 높이·테두리 없는 회색 채움 알약으로 맞췄다(`EolssuChip`에 고르지 않은 칩 바탕 `containerColor` 인자 추가).
- 정간보 읽기 '다음/이전' 버튼: 완전 둥근 알약 대신 작은 공용 버튼과 같은 모서리 12dp. 쪽 목차 펼침은 공용 메뉴(`EolssuMenuPanel`, 폭을 안 주면 칸을 채움)로 바꿔 고른 쪽이 연한 연두·확인 표시다.
- 평가할 곡 고르기(휴대폰·태블릿): 연습곡 고르기와 같은 회색 바탕·테두리 없는 검색칸·칩·정렬·곡 줄·악기 알약, 상단 구분선 제거. '46곡 · 단소' 같은 곡 수 안내는 지웠다. 태블릿 가로에서 고른 곡 줄은 테두리 없는 연한 연두.
- 난이도 배지(입문·초급·중급)와 난이도 칩: 앱 전체에서 테두리를 없앴다. 고른 난이도 칩도 바탕색으로만 구분한다.
- 곡 표지 '얼쑤' 도장: 긴 제목과 겹쳤다(표지 오른쪽 아래 고정). 도장을 세로 제목 바로 아래에 붙인 붉은 낙관(살짝 기울임)으로 바꿨다. 글자는 무료 공개 글꼴 나눔손글씨 붓(OFL 1.1)에서 '얼쑤' 2자만 남긴 서브셋 `seal_brush.ttf`(약 4.5KB)로 흰색으로 쓴다. 원본 3.5MB를 그대로 넣지 않아 앱 크기·웹 불러오기 부담이 없다. OFL 예약 글꼴 이름 때문에 서브셋의 글꼴 이름을 `Eolssu Seal Brush`로 바꾸고 라이선스 원문을 `files/licenses/nanum_brush_script_ofl.txt`에 넣었다.
- 연습 속도 하위 화면: '보통' 같은 속도 이름이 혼자 Regular였다. 다른 제목처럼 SemiBold(28sp)로 맞췄다.
- 비교할 기록 고르기 시트: 회색 시트 위에 달력을 흰 카드로 담고 기록 칸은 흰 칸(비교 중이면 연한 연두)이다. 공용 시트(`EolssuBottomSheet`)에 바탕색 인자를 더했다.
- 기록 상세 재생 묶음: 옆 '취약 구간 연습' 버튼과 같은 52dp·모서리 14dp 흰 사각 묶음, 재생 버튼은 모서리 10dp 연두 사각.
- 메모 창: 메모 글을 회색 칸에 넣고 '닫기'를 테두리 없는 회색 버튼으로 바꿨다.
- 마이페이지 '기초 N단계' 늦게 뜸: 화면에 처음 들어올 때마다 서버에서 다섯 트랙을 받은 뒤에야 그렸다. 마지막으로 받은 진도를 기기에 회원별로 남기고(`LearnProgressRepository.cachedRecent`) 들어오자마자 그것부터 보인 뒤 서버 응답으로 바꾼다.
- 프로필 그림 고르기: 고른 그림을 원 테두리 대신 누를 때와 같은 회색 칸으로 표시하고, 그림을 원으로 자르지 않는다. 동그란 얼굴 원은 마이페이지·홈 입구에만 둔다.
- 프로필 원이 타원으로 보임: 부모 칸이 좁거나 누르는 최소 크기(48dp)가 끼면 `size`가 한 축만 줄거나 늘어 타원이 될 수 있었다. 얼굴 원(`ProfileImageCircle`·마이페이지 84dp·홈 입구 40dp)을 `requiredSize`로 정사각형을 강제하고, 홈 입구는 누르는 영역(48dp)과 그리는 원(40dp)을 나눴다.

- 비밀번호 변경: 회색 바탕, 입력칸은 테두리 없는 흰 칸(`EolssuTextField`에 `bordered`·`containerColor` 인자 추가), 아래 구분선 제거.
- 회원 탈퇴 뒤: 로그인 화면 아래 짧은 알림을 놓치기 쉬워 '탈퇴 신청이 완료됐어요' 안내 창(30일 안 재로그인 시 취소)을 한 번 띄운다.
- 자료 및 데이터 출처 링크: Android에서 Chrome 별도 작업으로 열려 뒤로 가기가 앱으로 오지 않았다. 앱 작업 안에서 여는 Custom Tabs 의도로 열어 뒤로 가기로 앱에 돌아온다(iOS·웹은 기존 열기 그대로).
- 악보 추가·악보 올리기: 회색 바탕 위 흰 카드(20dp)로 묶고, 종류 카드 테두리 제거, 악기·장단 칩은 테두리 없는 회색 알약(고르면 연두), 파일 목록은 회색 칸, '파일 고르기'는 연한 연두 버튼.
- 연습 설정의 장단: 장단 연결이 검수 중인 악보는 긴 안내 문구가 줄바꿈되던 것을 '아직 사용할 수 없어요'로 줄이고, 장단 메뉴 줄(휴대폰 설정·태블릿 옆 칸)을 누를 수 없게 했다.
- 내 악보 연습의 정간보 배치: 플레이어 카드 높이가 모드마다 달라 악보 칸 높이와 정간보 배치가 바뀌었다. '음원 다운로드' 버튼을 재생 버튼 줄과 같은 높이 안의 작은 버튼으로 넣어 카드 높이를 같게 했다(정간보 그리기 코드는 건드리지 않음).
- 불러올 악보 고르기: 연습곡 고르기처럼 회색 바탕·흰 악기 알약·테두리 없는 검색칸, 정렬은 검색칸 아래 오른쪽 작은 버튼, 곡 줄은 테두리 없는 흰 칸(고르면 연한 연두). 고른 곡 안내 문구('…을(를) 내 악보로 복사해 편집해요' 등)는 지웠다.
- 악보 편집기: 입력판을 회색 바탕 위 테두리 없는 흰 자판으로, 고른 음은 연한 연두(옅은 연두 선), 음역 버튼은 고르면 연두. 칸 탭은 48dp 터치 최소 크기 때문에 알약이 틀보다 작아 보여 틀을 꽉 채우는 40dp 알약으로 바꿨다. 닫기 원 테두리 제거, '미리보기·편집' 등 상단 버튼은 모서리 12dp(편집은 회색 채움). 저장·편집 창 입력칸은 테두리 없는 회색 칸, '취소'는 테두리 없는 회색 버튼.
- 편집 저장 뒤: 저장이 끝나면 편집기와 악보 추가 화면을 닫고 연습곡 고르기 '내 악보' 탭을 연다.
- 내 악보 줄: '편집'을 연한 연두 채움·짙은 연두 글자로 눈에 띄게, 휴지통은 편집 옆 같은 높이 회색 네모 버튼으로 옮겼다. 모든 줄에 같던 '정간보 가져옴'은 지웠다('제공 곡에서 고침'은 유지).
