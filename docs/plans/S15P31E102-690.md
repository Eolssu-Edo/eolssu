# S15P31E102-690 내 악보 연습에서 음원 받기 화면으로 이동

- 기준은 `origin/develop`의 `8d958652`다. Story S15P31E102-319, Sprint 5.
- Android·iOS에서 내 악보 재생을 눌렀지만 현재 버전의 기기 M4A가 없으면 ‘음원 받으러 가기’를 표시한다. 탭하면 같은 확정 버전의 기존 미리보기와 음원 작업을 연다. 음원 만들기와 내려받기는 각각 버튼을 눌러 진행한다.
- 음원을 받는 화면에서 뒤로 가면 같은 연습으로 돌아온다. 재생을 다시 누르면 저장한 M4A를 조회한다. 기기 저장을 지원하지 않는 환경은 안내 문구를 유지한다.
- 음원 받기 화면은 연습 중인 확정 악보를 읽고 초안 저장과 확정 저장을 숨긴다. 서버에서 악보가 이미 갱신된 경우 연습을 다시 열도록 안내한다.

## 작업과 확인

- [x] 기기 저장 지원 여부와 재생 결과로 이동 버튼을 표시한다.
- [x] 편집 미리보기에서 기존 음원 작업을 재사용하고 연습 화면으로 돌아오게 한다.
- [ ] Android 호스트 테스트와 Wasm 컴파일을 확인하고, Android 기기에서 추가 확인할 흐름을 기록한다.

- 초기 Android 호스트 테스트에서 문서·음원·연습 관련 31개를 확인했다. 확정 버전 선택, 버전 불일치 차단, 내 악보 음원 없음 조건을 검증했다.
