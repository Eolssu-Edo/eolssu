# S15P31E102-585 성장 통계 날짜 범위 문서와 회귀 검사

- 관련 스토리: S15P31E102-23 연습 기록. 기준: `origin/develop`의 `892aa715`.
- [연습 시간 집계 명세](../specs/practice-time.md)의 요청 범위(1001~9998년, 양 끝 포함 366일)를 생성된 OpenAPI의 요약·달력 설명에 반영한다. 서버의 검증 로직과 DB 스키마는 유지한다.

## 검증

| 검사 | 기대 결과 |
| --- | --- |
| 인증한 `GET /api/v3/api-docs` | 요약·달력 설명 모두 1001~9998년과 양 끝 포함 최대 366일을 안내 |
| `from=1001-01-01&to=1002-01-01` (366일) | HTTP 200. 요약은 현재 60초, 직전 기간 30초. 달력은 366개, 첫날 60초·마지막 날 0초 |
| 종료일을 `1002-01-02`로 변경(367일) | 요약·달력 모두 HTTP 400 `INVALID_REQUEST` |

366일 요청에서 직전 기간 조회의 UTC 하한은 `0999-12-30 15:00:00`이다. 폐기용 MySQL에는 저장 가능한 1000년 이후 시각의 악보 열람 기록을 넣어, 조회 하한과 요청 연도의 경계가 달라도 현재·직전 기간 집계가 유지되는지 확인한다.
