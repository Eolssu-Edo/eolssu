## 후속 결함 조사: Android에서 붓질 대신 점등처럼 보임

- 사용자 관찰: 웹에서는 왼쪽에서 오른쪽으로 칠해지지만 Android Studio 에뮬레이터에서는 깜빡하고 켜져 보인다. 정지된 중간 캡처만으로 연속 입력의 가시성을 입증하지 못했다.
- 시작: `1c55aa40`, 작업 트리 변경 없음. 기존 Task 412와 동일 범위의 수정이다.
- 가설: (1) Android 휠 입력의 큰 위치 변화가 직접 연결된 붓 진행률을 뛰게 함, (2) 움직임 줄이기 경로의 이진 표시, (3) 렌더링 지연. OS 설정 조회에서 window/transition 배율은 1.0, animator 배율은 미지정이며 명시적 0 설정은 없다. 느린 스와이프의 gfxinfo에서 지연 프레임도 관찰했으나 원인으로 확정하지 않는다.
- 계획: 임시 `HOME_INK_PROBE_412` 로그로 입력별 실제 진행률·움직임 줄이기 값을 측정하고, 같은 에뮬레이터의 마우스 휠을 재현한다. 원인 확인 후 필요한 보간만 보정하고 임시 로그를 제거한다. 동일 입력의 전후 기록·기존 검사·Android/Web 빌드를 확인한다.
