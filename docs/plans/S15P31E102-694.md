# 내 악보 검수 화면에 악보 전체 알림 표시

- S15P31E102-694 · 스토리 319. 기준 develop 8d958652.
- SHT-08의 기존 전체 알림을 편집 화면에서 펼쳐 읽는다. 누락된 페이지의 번호와 사유, 추정 장단, 조 옮김을 안내하며 정간 확인 건수·저장에는 포함하지 않는다.
- 알림이 없는 기존 응답과 알 수 없는 알림 유형을 처리한다. 소스 파일·인식기·백엔드 계약은 기존과 같다.
- 기존 조회 테스트로 선택 필드 읽기, 편집 모델 테스트로 페이지와 사유를 검증한다. Android 호스트 및 공유 웹 컴파일을 실행한다.

## 검증

- Android 호스트 전체 테스트와 Wasm 컴파일이 통과했다. 실제 SHT-08 형식에서 페이지 알림을 정간 검수와 따로 읽으며, 알림이 없는 응답도 읽는 것을 확인했다.
