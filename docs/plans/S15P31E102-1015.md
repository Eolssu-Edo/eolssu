# S15P31E102-1015 홈 첫 화면 그림 4종 디자인 수정 요청 반영

- Jira: S15P31E102-1015 · Story S15P31E102-109 · 스프린트 59321 · 진행 중. 앞선 작업은 S15P31E102-983(그림 교체)이다.
- 범위: 홈 첫 화면 그림 네 장을 디자인으로 받은 그림으로 바꾸고, 제목이 먹 영역에 여유 있게 들어오게 하며, 펼친 화면의 그림 띠 아래를 흰 바탕으로 흐려 보낸다.

## 받은 요청(2026-11-16)

- 받은 그림 네 장(폰 세로·가로, 태블릿 세로·가로)을 앱에 적용한다.
- 첫 화면의 제목(얼쑤! 나도 이제 국악인)이 오른쪽 먹 영역에 안정적으로 들어오지 않으면 먹 영역을 넓힌다. 안정적이란 먹 경계와 글자가 너무 붙어 있지 않은 상태다.
- 스크롤해 펼쳤을 때 그림 아래쪽이 흰색으로 흐려져 아래 기능 카드와 어울리게 한다.

## 요청 수정(2026-11-16)

- 받은 그림 네 장은 고치지 않는다. 제목이 먹 영역에 들어오지 않으면 먹을 넓히는 대신 글자 크기를 줄인다.
- 가로 화면에서는 글자를 키우고 배치를 바꾼다.
- "얼쑤!"를 조금 더 크게 한다.

## 결정

- 받은 그림은 `frontend/tools/home-art/designer/`에 원본 그대로 두고, `build_home_art.py`는 오른쪽·아래 흰 여백만 잘라 앱 자산을 만든다. 같은 폴더의 `compose_home_art.py`와 입력 그림 두 장은 983에서 쓴 이전 합성 방식이다.
- "얼쑤!" 로고를 96×47에서 120×59로 키웠다. 붓글씨(171×42)와 4dp 간격은 그대로다(`HomeTitleLogoWidth`·`HomeTitleLogoHeight`).
- 첫 화면 제목의 크기·자리(`homeHeroTitle`): 제목 상자를 사방 16dp 넓힌 영역이 모두 먹 위에 있도록 그림마다 정했다.

| 그림 | 배율 | 자리 | 점검한 창 크기(dp) |
| --- | --- | --- | --- |
| 폰 세로 | 0.8 | 평가 시작 버튼 위 오른쪽(오른쪽 20dp) | 360×780, 360×800, 390×844, 412×915 |
| 태블릿 세로 | 1.3(이전과 같음) | 평가 시작 버튼 위 오른쪽 | 600×960, 768×1024, 800×1280, 834×1194 |
| 폰 가로 | 제목 너비 = 창 너비 29% | 오른쪽 5%, 제목 가운데 = 창 높이 38% | 780×360, 800×360, 844×390, 915×412 |
| 태블릿 가로 | 제목 너비 = 창 너비 23% | 오른쪽 5%, 제목 가운데 = 창 높이 50% | 1024×768, 1194×834, 1280×800, 1366×1024 |

- 가로 화면은 먹 영역이 화면 높이 전체에 걸쳐 넓어서, 제목을 버튼 위가 아니라 먹 영역 가운데 쪽에 크게 둔다(844×390에서 배율 약 1.43, 1280×800에서 약 1.72). 버튼과는 12dp 이상 떨어진다.
- 스크롤하면 제목은 첫 화면 자리에서 펼친 화면 자리(배율 1, 그림 띠 오른쪽 아래)로 옮겨 간다.
- 펼친 화면: 그림 띠를 띠 아래 끝에서 자르지 않고 56dp 더 그린 뒤, 띠 아래 끝 24dp 위부터 56dp 아래까지 바탕색으로 덮는다(`HomeArtFadeAbove`·`HomeArtFadeBelow`·`homeArtFade`). 위쪽 구간을 짧게 둔 이유는 펼친 화면의 제목이 띠 아래 끝 10dp 위에 놓이기 때문이다. 이전 코드는 띠 아래 끝에서 그림을 잘라 흐림 중간에 선이 생겼다.
- 펼친 화면 그림 띠의 초점: 폰 세로 (.5, .62), 폰 가로 (.75, .5), 태블릿 세로 (.5, .55), 태블릿 가로 (.45, .5).

## 변경

- 앱 자산: `home_art_*.webp` 네 장을 받은 그림(흰 여백만 자름)으로 교체했다. 폰 세로 580×1254, 폰 가로 1846×852, 태블릿 세로 644×1028, 태블릿 가로 1586×992.
- `feature/home/HomeScroll.kt`: 그림 비율·펼친 화면 초점 갱신, 제목 크기·자리(`homeHeroTitle`)와 흰 흐림 구간 추가, `HomeScrollFrame.headlineProgress` 추가.
- `feature/home/layout/HomeScrollLayout.kt`: 제목을 `homeHeroTitle` 자리에서 펼친 화면 자리로 옮기고, `HomeArt`가 띠 아래로 그림을 이어 그린 뒤 흰 흐림을 덮는다.
- `HomeScrollTest`: 새 그림 크기로 배치 기대값을 고치고, 흰 흐림 1개·제목 크기와 자리 1개·가로 제목과 버튼 겹침 1개를 추가했다.
- `frontend/tools/home-art/`: `designer/` 원본 네 장 추가, `build_home_art.py`를 받은 그림 기준으로 다시 쓰고 제목 여유 점검을 넣었다.
