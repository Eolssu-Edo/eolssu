## 빌드·업로드 (2026-11-08, Mac Xcode 27.2)

```sh
# frontend/에서
xcodebuild -project iosApp/iosApp.xcodeproj -scheme iosApp -configuration Release \
  -destination 'generic/platform=iOS' -archivePath <out>/eolssu.xcarchive \
  -allowProvisioningUpdates PRODUCT_BUNDLE_IDENTIFIER=com.ssafy.eolssu archive
xcodebuild -exportArchive -archivePath <out>/eolssu.xcarchive -exportPath <out>/upload \
  -exportOptionsPlist <export-options.plist> -allowProvisioningUpdates
```

- export 옵션: `method=app-store-connect`, `destination=upload`(로컬 확인 때는 `export`), `teamID=WDA26H33JA`, `signingStyle=automatic`, `manageAppVersionAndBuildNumber=false`.
- 결과: develop `de0e67e8`, `com.ssafy.eolssu` 1.0 (1), IPA 약 48MB. `Upload succeeded`, `Uploaded package is processing`.
- 다음 빌드는 빌드 번호 2 이상이어야 한다(`CURRENT_PROJECT_VERSION`).
