### 입력·오류 처리와 최초 검증

- 율명 입력·오선 높이 이동·수정 후보는 서버의 동일 selectable 목록을 사용한다. 목록 로딩/실패 중 최종 저장을 막고, 악기 코드 변경 시 재조회한다. 저장의 실제 거절 위치·사유를 표시하고 초안은 남긴다. 지속음 수정은 원래 이벤트 위치를 안내한다.
- 음원 악기 변경·최종 저장 후 지원음을 재검증하며 서버에서도 요청 악기로 재검증한다. 실제 연습 다운로드 경로도 지원음 거절을 구분해 악보 수정으로 안내한다. 현재 UI에는 별도의 편집기 음원 악기 선택 버튼이 없으므로 기존 호출 경로를 확장하거나 새 화면을 임의로 추가하지 않았다.
