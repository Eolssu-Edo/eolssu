# S15P31E102-1100 악보 편집의 신뢰도 낮은 인식 칸을 저장을 막지 않는 노란 표시와 지우기로 변경

- Story: S15P31E102-319, 에픽 S15P31E102-16
- 결정: 2026-11-17 사용자 결정. 신뢰도 낮음(`LOW_CONFIDENCE`) 검수는 저장을 막지 않는다. 표시를 지우지 않고 확정 저장해도 확인한 것으로 보내 평가 가능 악보(`EVALUABLE`)로 저장한다.

## 변경

- `SheetReviewIssue.advisory`: 종류가 `LOW_CONFIDENCE`인 칸·이벤트 검수. `TEMPO_PDF_TEXT` 같은 악보 전체 알림은 원래 저장을 막지 않으므로 그대로 둔다.
- 저장 검사(`validateCompletion`): 참고 항목을 `pendingReviewCount`·`correctionCellIndices`·`correctionUnitKeys`에서 빼고 `advisoryCellIndices`·`advisoryUnitKeys`로 따로 낸다. 같은 칸·소박에 고쳐야 할 문제가 있으면 빨간 표시가 우선한다.
- 악보판: 참고 칸·소박을 노란 점선 테두리와 `?`로 칠한다(`EolssuColors.caution`·`cautionSoft`).
- 노란 칸을 누르면 "잘못 읽었을 수 있는 칸이에요" 창에 이유·고치기 버튼·`표시 지우기`를 보인다. 지운 표시는 칸을 고쳐도 다시 뜨지 않으며 실행 취소 기록에 넣지 않는다.
- 다시 볼 곳 안내·이동, 저장 버튼의 첫 수정 칸 이동, `이대로 둘게요`는 저장을 막는 검수만 따라간다.
- 확정 저장의 `resolvedIssueIds`에 남은 참고 항목을 모두 넣는다(`confirmedResolvedIssueIds`). 초안 저장은 그대로 보내지 않는다. 서버 계약은 바꾸지 않았다.
