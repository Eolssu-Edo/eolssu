## 범위와 결정

원래 화면은 인식 후 장단 선택이나 서버 SHT-07은 정간보 업로드에 장단이 필수다. 사용자 2026-11-06 답변으로 **업로드 전에 장단 선택 추가**를 확정했다. 기본 장단을 몰래 전송하지 않는다. 활성 카탈로그에서 실제 악기·장단 ID를 선택한다.

실제 PDF 1개 또는 PNG/JPEG 1~10장을 고르고, 제목·악기·장단(정간보 필수)과 multipart `files`·`metadata`, `Idempotency-Key`를 보낸다. 합계 20MiB, 혼합 PDF·이미지 금지와 기본 형식을 전송 전에 검사한다. PDF 암호·쪽 수·실제 디코딩 검사는 서버 오류로 안내한다. 같은 제출의 불확실한 네트워크 실패 뒤에는 같은 키를 재사용한다. 입력 변경은 새 제출로 취급한다. 202를 확인한 뒤 접수 완료와 내 악보 목록 이동까지만 제공한다.

SHT-10 상태 조회, 인식 결과, SHT-14 재시도, 원본 미리보기는 제외한다. 가짜 진행률·예시 결과로 접수 성공을 대신하지 않는다. 기존 문서 조회·편집·저장 연동은 보존한다.

BE 534는 시작 시 진행 중이며 develop에 미병합이다. 이 작업은 SHT-07 요청·접수 계약만 사용하고 원본 보관·실패 재시도 계약은 구현하지 않는다. Notion MCP object_not_found, 이 채팅 in-app browser 미제공으로 최신 공개 명세 재조회 불가. develop의 Controller·검증·저장소 명세를 기준으로 구현하고 변경된 BE 계약은 병합 전 재대조한다.
