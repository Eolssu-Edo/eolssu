# 음원 재생과 OMR 로그 보존 연결

[S15P31E102-625](https://ssafy.atlassian.net/browse/S15P31E102-625) · [보존 정책과 운영 절차](../../infra/privacy/README.md)

edo1에서 기존 loopback syslog에 연결된 음원 재생·OMR 태그를 전용 저장소에 추가한다. OMR은 고정 경로의 HTTP 상태와 정형 처리 결과만 보존한다. 두 태그에 기존 파일 권한과 14일 상한을 적용한다. 구성 문법, 저장 허용·거부, 보존 경계, 실제 컨테이너 응답으로 생성한 로그를 확인한다. 설정과 정리 스크립트를 백업하고 rsyslog만 재시작한다.
