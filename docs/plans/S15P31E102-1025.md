# S15P31E102-1025 홈 휴대폰 가로 그림 제거와 웹 공통 테스트 컴파일 오류 수정

- Jira: S15P31E102-1025 · Story S15P31E102-109 · 스프린트 59321 · 진행 중.

## 결정

- 휴대폰은 회전을 막아 가로 화면을 지원하지 않는다(2026-11-16 사용자 결정). 홈 그림에서 휴대폰 가로(`PhoneLandscape`, `home_art_phone_landscape.webp`, 받은 원본)를 없앴다.
- 가로 창은 크기와 관계없이 태블릿 가로 그림과 그 제목 규칙(제목 너비 = 창 너비 23%, 가운데 = 창 높이 50%)을 쓴다. 웹의 낮은 가로 창도 여기에 해당한다. 세로 창은 너비 600dp를 기준으로 휴대폰·태블릿 세로를 가른다.
- `feature/song/edit/SheetBpmRangeTest.kt`(S15P31E102-1018)는 공통 테스트에서 JVM 전용 `assert`를 써서 웹 대상 테스트 컴파일을 막았다. 같은 조건을 `kotlin.test.assertTrue`로 바꿨다. 검사하는 조건은 그대로다.
- `build_home_art.py`의 태블릿 가로 제목 세로 위치가 앱(0.5)과 다르게 0.52로 남아 있던 것을 앱 값으로 맞췄다.

- `:shared:compileTestKotlinJs --offline`: 성공(2026-11-16, Windows).
- `python -I frontend/tools/home-art/build_home_art.py --check`: 남은 세 장이 앱 자산과 같고, 12개 창 크기 모두 제목 여유를 만족한다.
