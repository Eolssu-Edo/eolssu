## 목적

백엔드가 DB에 넣고 변환기(S15P31E102-156)가 읽을 단소 1차 기준 데이터를 만든다. 율명·장단·곡 세 표와 단소 음역이다.

## 기준

- 칸 이름과 허용 값은 백엔드 마이그레이션을 따른다: `backend/src/main/resources/db/migration/V1__initial_schema.sql`(`pitches`, `instruments`, `jangdans`, `songs`), `V2__auth_user_practice_extensions.sql`(`jangdans.bpm_unit`, `songs.description`).
- 기준음 황 = E♭4 = 311.13Hz, 목표 주파수 = 311.13 × 2^(semitone/12) (노션 1차 MVP 논의사항 1-1).
- 장단 기본 BPM과 기준 단위는 기획 S15P31E102-141 "장단별 빠르기 및 근거"(2026-10-27)를 따른다.

| 장단 | 기본 BPM | `bpm_unit` |
| --- | ---: | --- |
| 세마치 | 96 | `DOTTED_QUARTER` |
| 굿거리 | 66 | `DOTTED_QUARTER` |
| 중모리 | 88 | `QUARTER` |
| 타령 | 96 | `JEONGGAN` |

## 작업 단위

| ID | 내용 | 먼저 끝나야 하는 것 | 예상 |
| --- | --- | --- | --- |
| U1 | 율명 표 `pitches.json`과 단소 음역 `instruments.json`(DANSO 한 줄) | 없음 | 1시간 |
| U2 | 율 목표 주파수와 단소 측정값 ±50센트 검사(테스트) | U1 | 30분 |
| U3 | 장단 표 `jangdans.json`(BPM·단위·구음·대박 묶음·근거) | 없음 | 1~2시간(구음 근거 찾기) |
| U4 | 곡 표 `songs.json` 4곡 | U3 | 30분 |
| U5 | `data/README.md` 위치·형식 설명, 검사 명령 기록 | U1~U4 | 30분 |

U1과 U3은 서로 독립이라 순서를 바꿔도 된다.

### U1 율명 표와 음역

- 행: `yul`, `octave`(-1 배, 0 중, 1 청, 2 중청), `hanja`, `hangul`, `semitone`(황 0 기준).
- 범위: 단소 음역 전체와 4곡 정답에 나오는 율. 한자는 우물사이 옥타브 한자표(`data/src/scores/review_page.html`의 `HANJA`)와 같게 쓴다.
- 단소 음역 하한·상한은 `docs/knowledge/data/danso.md` 측정 음과 4곡 정답에서 정하고, 근거를 파일에 적는다. `pitch_tolerance_cent`는 노션 D1 시작값 50.
- 완료: 율마다 (yul, octave)와 semitone이 하나씩이고 한자·한글이 표와 맞는다. 4곡 정답의 모든 율명이 표에 있다.

### U2 주파수 검사

- `data/tests/`에 테스트를 둔다. 표의 semitone으로 목표 주파수를 계산해 `danso.md` 측정값(평취 중·임·무·청황·청태 등)과 센트 차이를 비교한다.
- 주의: `danso.md`의 평취 "황" 629.7Hz는 청황(E♭5)이다. 측정 표의 율 이름을 표의 (율, 옥타브)로 옮겨 비교한다.
- 완료: 비교한 율 모두 ±50센트 안. 벗어나면 고치지 않고 결과를 보고한다.

### U3 장단 표

- 행: `name`, `pattern`(`beats`: 소박별 구음, `group`: 대박 묶음), `default_bpm`, `bpm_unit`, `source`.
- 구음 근거는 국립국악원 자료를 먼저 찾는다. 늴리리야 입력본(`늴리리야_표준`)의 굿거리 장단 줄은 참고만 한다. 근거를 못 찾은 장단은 비워 두고 보고한다.
- 완료: 4개 장단의 소박 수가 장단 구조와 맞다(세마치 9, 굿거리 12, 중모리 12, 타령 12). BPM·단위가 위 기준 표와 같다.

### U4 곡 표

- 행: `title`, `instrument`(DANSO), `jangdan`(이름), `difficulty`(1~5), `default_bpm`, `bpm_unit`, `description`, `source`(원본 ID), `is_scorable`, `status`.
- 장단·출처는 [단소 4곡 채점 정답 검수](../knowledge/data/danso-scoring-answers.md)를 따른다. 곡 기본 BPM은 장단 기본 BPM으로 둔다.
- `is_scorable`은 4곡 모두 true. `status`는 `DRAFT`(공개는 서비스 연결 뒤).
- 난이도·곡 설명은 기획 자료가 있으면 그대로 쓰고, 없으면 비워 두고 확인을 요청한다(값을 지어내지 않는다).
