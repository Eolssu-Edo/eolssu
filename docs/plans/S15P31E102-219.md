## 결정(2026-10-28 사용자 확정, coco-clarify)

| 항목 | 선택 |
| --- | --- |
| 월 보기 지난 기간 | `from`이 1일이고 `to`가 같은 달 말일이면 지난 달력 월 전체. 그 밖에는 직전 같은 일수 |
| 성취도 기간 | `from`·`to`와 관계없이 회원 전체 기록 |
| 곡별 최고점 | 전체 곡 연주만. BPM·악보 버전·채점 모델은 구분하지 않음. 최근에 연주한 곡 먼저 |
| 항목별 성장 | 가장 최근 전체 곡 연주와 곡·악보 버전·채점 모델·BPM이 같은 연주 중 첫 번째와 최근. 2회 미만이면 점수 `null`. `songId`·`title`·`bpm` 추가 |

- 전체 곡 연주: `start_note_idx = 0`, `end_note_idx = songs.note_count - 1`, `DONE`, 평가 있음. 음표 번호가 0부터 양 끝 포함인 것은 Notion 연습 세션 API 명세로 확인했다.
- BPM은 단위(`bpm_unit`)까지 같아야 같은 조건으로 본다. 같은 숫자라도 단위가 다르면 빠르기가 다르다.
- 판정에 지금의 `note_count`를 쓴다. 악보를 고쳐 음표 수가 바뀌면 이전 버전의 전체 곡 연주는 빠질 수 있다.
