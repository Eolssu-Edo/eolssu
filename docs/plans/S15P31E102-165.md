## 결정

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| 마이크 허용 | 첫 실행 마이크 안내(AUTH-03)의 '허용'과 연습 화면 안내의 '계속'을 `PracticeSettingsStore`가 기기 저장소(`KeyValueStore`, 키 `mic_granted`)에 남긴다. 허용했으면 연습 화면에서 다시 묻지 않는다 | 권영민 결정. 실제 녹음을 붙일 때 플랫폼 권한(`platform/permission`)으로 바꾼다 |
| 허용하지 않음 | 연습 화면 안내에서 '나중에'를 누르면 이전 화면으로 돌아가며 '마이크를 허용해야 연주 평가를 할 수 있어요.'를 띄운다. 안내는 화면 이동 뒤에도 보이도록 `EolssuNavHost`가 모든 화면 위에 둔 알림 자리에 띄운다 | 권영민 결정. 돌아갈 화면(곡 상세·곡 목록·연습곡 고르기·배우기)마다 안내를 받는 코드를 넣지 않는다 |
| 기기 뒤로 가기 | `ui-backhandler`의 `BackHandler`로 화면의 뒤로 가기와 같게 처리: 연주·카운트다운 중이면 나가기 확인 창, 태블릿 가로처럼 화면 안에 열린 패널은 먼저 닫는다 | [결정 문서](../decisions/frontend-back-handler.md) |
| 홈 악기 | 목록은 대금·소금·단소(피리 제외), 처음 고른 악기는 단소 | 권영민 결정. 피리는 당분간 범위 밖 |
