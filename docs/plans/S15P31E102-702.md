# S15P31E102-702 내 악보 연습 화면에서 음원 다운로드 연결

- 기준은 `6cfd98ff`, Story 319, 스프린트 5. [음원 스펙](../specs/sheet-audio.md)을 따른다.
- 기기 저장을 지원하는 내 악보 연습에서는 계정과 악보 버전이 같은 로컬 파일을 먼저 확인한다.
- 파일이 없으면 재생 조작 대신 음원 다운로드를 제공한다. 탭하면 같은 화면에서 생성 요청, 상태 확인, 기기 저장을 진행한다. 저장이 끝나면 재생 버튼이 나타난다.
- 악보에 지정된 악기와 기본 빠르기를 사용한다. 연습 화면에서 장단을 별도로 제어하므로 기본 다운로드에는 장단을 섞지 않는다. 생성 및 저장 실패는 화면에서 다시 시도할 수 있다.
- 계정·악보 버전, 유효 기간, M4A 저장 검증과 675 연주 위치 정보는 기존 경계를 재사용한다. 제공 곡과 기기 저장 미지원 플랫폼의 기존 동작은 유지한다.
- Android 호스트 테스트와 디버그 APK, 가능하면 루프백 응답으로 다운로드와 기기 재생을 확인한다.


## 편집 화면

- 악보 등록 때 선택한 악기를 다운로드에도 사용한다. 연습 화면에서 악기를 다시 고르는 단계는 없다.
- 기기 저장을 지원하는 편집에서는 음원 생성·다운로드 조작을 빼고, 같은 저장 버전의 기기 음원이 있을 때 미리듣기를 제공한다.
- 앱 기기 저장을 지원하지 않는 브라우저의 기존 파일 내보내기는 유지한다.


## 검증 결과

- 최종 develop `1381bbf9` 동기화 후 Android 호스트 테스트 1,260개 중 1,256개 통과, 4개 건너뜀. 디버그 APK 빌드와 Wasm 컴파일 통과.
- 안내 문구 정리 전 통합 APK를 Android 17 API 37 에뮬레이터와 루프백 API로 검증했다. 파일이 없을 때 버튼이 바로 보였고 탭 전 음원 요청은 0회였다. 탭 후 등록 악기 ID와 기본 BPM으로 요청·조회·기기 다운로드가 각 1회였다.
- 다운로드가 끝난 연습 화면과 다시 연 연습 화면에서 추가 다운로드 없이 기기 파일을 재생했다. 편집의 생성·다운로드 버튼이 사라졌고 기기 음원 미리듣기는 추가 요청 없이 재생됐다.
- 698과 병합 가능한지 로컬 병합 트리로 확인했다. 실제 폰, iOS 및 브라우저 조작은 별도다.
