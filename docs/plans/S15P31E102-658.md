# S15P31E102-658 기초부터 배우기 단계 축소 화면 반영

- Jira: S15P31E102-658, Story S15P31E102-316, Epic S15P31E102-17. 담당 오은서.
- 브랜치: `feat(fe)/S15P31E102-658-기초부터-배우기-단계-축소-화면-반영`, `origin/develop`(1a6e28b4) 기준.
- 배경: 657(V37)이 8·9단계를 숨겨 공개 단계가 7개다. 앱의 9단계 가정과 8단계 '악보와 곡' 전용 연결을 정리한다. 할 일 박스식 진행·앞뒤 단계 이동·움직임은 688이다.

## 범위와 완료 조건

- 단계 수 7: `LearnProgressRepository.STAGE_COUNT`, 마이페이지 진도, 단계 그림(1~7장), 산길 지도(7단계가 꼭대기).
- 따라 배우기 2~7단계. 7단계는 혀치기 한 칸이고 박 나누기 그림·표기 묶음은 뺀다.
- 8단계 전용 연결 제거: 연주 결과의 8단계 자동 통과(611의 `LearnSongStage`), 단계 상세의 곡 목록·곡 받기, 8·9단계 화면 분기, 쓰지 않는 문구·그림.
- 마지막 7단계를 마치면 '완료했어요!'가 곡 연습으로 이어 준다. 문구는 "혀치기까지 기초를 모두 익혔어요. 이제 곡 연습에서 써 봐요.", 버튼은 '곡 연습하러 가기'(곡 목록, 뒤로 가면 단계 목록).
- 완료 조건: 공유 테스트·JS 컴파일·Android 빌드가 통과하고, 에뮬레이터에서 7단계 지도·상세·마지막 단계 안내를 확인한다.

## 결정

- 배포 순서와 무관하게 앱은 1~7단계만 보인다(`shownStages`). V37 배포 전 서버가 8·9단계를 줘도 그림·지도 자리가 없어 멈추지 않는다.
- 다른 화면이 완료를 남기면 학습 화면을 다시 받는 구독(`saves`)은 남긴다. 단계 연습 등이 같은 저장소를 쓴다.
- 연습 화면의 `learn` 모드(8단계 곡을 운지법과 함께 보기로 연습)는 진입점이 없어졌지만 연습 기능 쪽 변경이라 이번에 지우지 않았다. 후속 정리 대상이다.
