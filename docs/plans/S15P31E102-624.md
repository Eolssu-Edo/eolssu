# QA MR 동기화 조회 단위를 10개로 조정

[S15P31E102-624](https://ssafy.atlassian.net/browse/S15P31E102-624) · [기존 QA 동기화와 검증](S15P31E102-498.md)

GitLab MR 100개 일괄 조회의 HTTP 502를 피하도록 동기화 요청을 최대 10개로 나눈다. 기존 응답 검증·게시 잠금·원자적 인덱스 갱신을 유지한다. 23건을 10·10·3건으로 처리하는 회귀 검사와 edo1에서 미반영 MR 정보 복구 및 다음 타이머 성공을 확인한다. 운영 파일은 교체 전 백업하고 정상 실행을 확인할 수 없으면 복구한다.
