### Graphify 종료 및 COCO 새 배포 표시

사용자 실험에서 비슷한 코드 탐색 품질에 Graphify가 더 많은 토큰을 쓴 것으로 보고되어 기존 도입 결정을 철회했다. 서버에서 기존 앱의 발행 경로와 Jenkins 자동 실행을 종료하고 504의 미병합 생성기·AI 지침을 제거한다. 508 앱을 독립 패키징해 기존 프로젝트에서 Graphify 정리를 한 번 누르면 다운로드 폴더를 OS 휴지통으로 옮기고 즉시 숨긴다. 이전 설치에 덮어써 프로젝트·COCO 설정을 유지한다. 새 COCO 배포는 목록을 열지 않아도 버전 칸에서 바로 볼 수 있다.

- [x] 새 npm 배포를 선택 칸에 표시하고 변동 없는 재조회에서 수동 선택 유지 검증
