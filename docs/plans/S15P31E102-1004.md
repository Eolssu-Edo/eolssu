# 악보 추가·편집 화면 튜토리얼 기획

- Jira S15P31E102-1004 · Story S15P31E102-319
- 2026-11-16 사용자 결정. 기존 확인 카드를 포함한 화면 튜토리얼을 먼저 진행한다. 원본 대조, 확인 카드의 원본 미리보기, 축소 이미지 저장은 이번 범위에서 제외한다.

## 안내 순서

| 화면 | 처음 열었을 때 안내할 순서 |
| --- | --- |
| 악보 올리기 | ① 정간보·오선보 중 종류를 고른다. ② 악기와 정간보의 장단을 고른다. ③ 파일·갤러리에서 악보를 선택해 올린다. |
| 편집 입력판 | ① 바꿀 정간이나 소박을 고른다. ② 율명·기호 입력판을 사용한다. ③ 실행 취소와 저장 위치를 확인한다. |
| 기존 확인 카드 | ① 확인할 칸을 연다. ② 앱이 표시한 인식 결과를 확인하고 필요하면 수정한다. ③ 확인을 마치고 다음 칸으로 이동한다. |

각 안내는 해당 화면의 첫 진입 때 한 번 표시한다. 확인 카드 안내는 확인 항목이 있을 때 처음 표시한다. 어느 단계에서든 건너뛰거나 나중에 다시 볼 수 있다. 안내를 마쳤거나 건너뛴 기록은 화면별로 기기에 저장한다. 다른 기기나 앱을 새로 설치한 환경에서는 다시 표시될 수 있다. 시김새와 구간 빠르기 설명은 1001의 화면별 안내를 사용한다.

## 구현 작업과 검증

화면별 튜토리얼을 하나의 FE 구현 작업으로 진행한다. 첫 진입과 재진입, 건너뛰기, 다시 보기, 확인 항목이 없는 악보를 검증한다. 튜토리얼 표시와 종료가 업로드·편집·확인 결과나 선택 상태를 바꾸지 않는지 휴대폰과 태블릿 배치에서 확인한다.

## 구현 검증

- 공유 테스트 1,918개 중 1,913개 통과, 5개 건너뜀, 실패·오류 0건. Android 디버그 APK와 Wasm 컴파일 성공.
- 2026-11-16 Android 15 emulator-5558에 새 APK를 설치했다. 악보 올리기 첫 진입에서 1단계가 표시되고, 다음은 2단계로 이동했다. 건너뛴 뒤 재진입 시 안내가 자동으로 반복되지 않았고, 다시 보기는 1단계에서 열렸다.
- 편집에서 1단계부터 3단계 완료까지 확인했다. 확인 카드 대상이 없는 테스트 악보에서는 편집 안내만 보였고, 기존 확인 항목이 있는 오선보에서는 확인 카드 안내가 시작됐다. 화면 확인 중 악보를 저장하지 않았다.
- 909dp 태블릿 너비를 재현한 앱 재실행에서 악보 올리기 안내 다시 보기와 다음·건너뛰기 버튼을 확인했다. 에뮬레이터 밀도는 420dpi로 복구했다. 태블릿의 편집·확인 카드, 물리 기기와 iOS는 미검증이다.
