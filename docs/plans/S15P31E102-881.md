# S15P31E102-881 악보 추가 화면에 변환 진행 상황과 내 악보 목록 표시

- Jira: [S15P31E102-881](https://ssafy.atlassian.net/browse/S15P31E102-881) (Story S15P31E102-317 내 악보 업로드·관리, 에픽 S15P31E102-15)
- 브랜치: `feat(fe)/S15P31E102-881-악보-추가-화면에-변환-진행-상황과-내-악보-목록-표시` (develop `c259b89d`에서 시작)

## 배경

악보를 올리면 변환 진행 상황은 '연습하기 → 내 악보' 탭에서만 보였다.
홈 '악보 추가·편집하기'로 들어온 사용자는 업로드 뒤 연습곡 고르기 화면으로 옮겨져, 악보 추가 화면에서는 진행 상황도 내가 만든 악보도 볼 수 없었다.

## 범위와 완료 조건

- 악보 추가(EDIT-01) 화면 아래에 '내 악보' 묶음을 둔다.
  - 줄 모양·동작은 내 악보 탭과 같다(`MySheetRow`): 변환 대기·읽는 중(쪽 수)·만드는 중 배지, 실패 원인과 '다시 시도'·'다시 불러오기', 열기·편집·삭제(확인 창).
  - 화면이 보이는 동안만 변환 상태(SHT-10)를 서버 간격으로 다시 묻고, 끝나면 목록을 새로 받는다.
  - '다시 불러오기'는 이미 악보 추가 화면이므로 이동하지 않는다. 원인별 안내가 있으면 안내 창을, 없으면 바로 파일 선택을 띄운다.
  - 변환 중인 줄에는 배지 아래 진행 막대를 둔다(두 화면 공통). 숫자 %는 쓰지 않는다.
  - 내 악보가 없으면 묶음을 두지 않는다. 목록을 받지 못하면 '다시 시도' 안내를 둔다.
- 변환 상태 조회·다시 시도 로직을 내 악보 탭과 함께 쓰도록 한 곳(`MySheetConversionWatcher`)으로 옮긴다. 내 악보 탭의 동작은 바꾸지 않는다.
- 업로드 접수 뒤 이동: 연습곡 고르기에서 들어왔으면 지금처럼 그 화면으로, 홈에서 악보 추가로 바로 들어왔으면 악보 추가 화면으로 돌아온다.
- 완료 조건
  - 악보 추가 화면에서 변환 중인 악보의 진행 상태가 갱신되어 보인다(자동 테스트).
  - 악보 추가 화면에서 내 악보를 열고 편집·삭제할 수 있다.
  - 기존 내 악보 탭 테스트(`MySheetConversionTest` 등)가 그대로 통과한다.
  - 공유 테스트·JS 컴파일·Android 설치 빌드 통과, 에뮬레이터에서 악보 추가 화면 확인.

## 결정

- 별도 진행 화면을 새로 만들지 않고 기존 악보 추가 화면 아래에 목록을 붙였다. 화면 이동 없이 업로드 직후 같은 화면에서 진행을 보게 하기 위해서다.
- 내 악보 탭의 검색·두 열 배치는 악보 추가 화면에 넣지 않았다.
- 진행 막대(사용자 선택): SHT-10은 단계와 읽은 쪽 수만 주고 퍼센트를 주지 않는다. 서버 계약을 바꾸지 않고 앱에서 어림한다.
  - 대기 5% → 읽는 중 10~80%(읽은 쪽 수 비례) → 만드는 중 90%. 완료·실패는 막대를 없앤다. 값이 바뀌면 0.6초 동안 늘어난다.
  - 숫자 %는 정확하지 않아 표시하지 않는다. 1쪽 악보는 읽는 동안 10%에 머문다. 쪽 안의 진행률은 AI·BE 계약 변경이 있어야 한다.
