## 결과

2026-10-23, Windows / JDK 21 / Chrome Headless 155에서 `frontend/`의 `./gradlew :shared:testAndroidHostTest :shared:jsTest :shared:wasmJsTest :androidApp:assembleDebug :webApp:wasmJsBrowserDistribution --console=plain`을 실행했다.

| 검사 | 결과 |
| --- | --- |
| 대비 테스트 실패 확인 | 와이어프레임 원래 색으로 3개 테스트 모두 실패(`textMuted / background` 4.3, `playText / playSoft` 3.89, `onPrimary / rec` 4.29) |
| 전체 명령 | 통과, 1분 48초. Android 호스트·JS·Wasm에서 대비 테스트 3개와 기존 샘플 테스트 모두 성공 |
| 글꼴 생성 재현 | 같은 원본으로 두 번 만들어 5개 파일 SHA-256 일치 |
| Web 화면 | `wasmJsBrowserDevelopmentRun` + 앱 내장 브라우저. 임시 확인 문구(세리프 '얼쑤'·'아리랑', 율명 `黃 太 仲 林 南 無 潢 汰 淋`, Pretendard 본문 `똠얌꿍 뷁`, 상태 색)가 모두 표시됨. 글꼴 적용 전에는 한글·한자가 빈 상자였음 |
| Android 화면 | 에뮬레이터 Medium Phone API 37(Android 17)에 `installDebug` 후 같은 문구 확인. 실기기 아님 |
| Web 배포본 크기 | `webApp/build/dist/wasmJs/productionExecutable/` 19MB(글꼴 약 6.6MB 포함) |
| iOS | 미검증. Mac에서 `./gradlew :shared:iosSimulatorArm64Test`와 화면 확인 필요 |

임시 확인 문구는 커밋하지 않았다. 앱 화면은 아직 마법사 예제이며 테마 색만 적용된다.
