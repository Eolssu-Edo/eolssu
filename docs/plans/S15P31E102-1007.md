# S15P31E102-1007 연습 악보에서 쉼표를 눌러도 운지법 팝업 열기

- Jira: S15P31E102-1007 · Story S15P31E102-32(연습 화면 흐름) · 활성 스프린트 · 진행 중 · 담당 박찬형.
- MR: !874(draft).

## 결정

- 연습 악보에서 쉼표(△)를 눌러도 아무 반응이 없었다. 하지만 운지법 팝업에서 좌우로 넘기면 쉼 페이지가 떴다. 원인은 `PracticeUiState.selectUnit`이 율명이 있는 칸만 팝업을 열었기 때문이고, 악보의 누름 처리(`JeongganboView`)는 모든 칸에 똑같이 연결돼 있었다.
- 쉼표도 팝업을 쉼 페이지로 열게 했다. 좌우로 넘길 때 보이는 페이지(`fingeringNoteAt`)와 같다.
- 이음(ㅡ)과 빈 정간은 눌러도 지금처럼 팝업을 열지 않는다. 사용자가 요청한 범위는 쉼표뿐이다. 앞 음 운지로 열지는 MR 리뷰에서 의견을 받는다.

## 검증

- `PracticeStateTest.selectingRestOpensFingeringOnRestPage`를 추가했다. 쉼표를 고르면 팝업이 쉼 페이지로 열리고, 고른 자리가 그 쉼이며, 좌우 이동 규칙과 같은 음이 보이는지 확인한다.
- `:shared:testAndroidHostTest`: develop `09cfdc9a6` 병합 후 전체 통과. develop `2b539c8d7` 병합 후에는 `HomeScrollTest` 1건만 실패했고, develop 단독에서도 같은 실패라 이 작업과 관계없다(S15P31E102-1026에서 수정).
- `:shared:compileKotlinWasmJs`: 성공(Windows).
- 확인하지 못한 것: 실기기·에뮬레이터 화면.
