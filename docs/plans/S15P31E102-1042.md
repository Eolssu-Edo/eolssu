3. 확인 카드: 초록 상자에 `확인 필요: 단소로 낼 수 없는 음 N개` 한 줄과 흰 버튼 `N반음 올려서 모두 고치기`. 다시 볼 곳도 같은 모양.
4. 다시 볼 곳: '보러 가기'나 표시된 칸을 누르면 그 칸으로 가서 고칠 방법(율명 넣기·시김새 넣기·원본과 같아요)을 바로 보인다.
5. 운지 자료 미확인·꾸밈음 등 안내를 사용자가 할 일 중심 문장으로 바꾼다.
6. 저장 창: 제목과 예상 음원 길이만 둔다. 저장을 막는 문제와 오류만 있을 때 보인다.

8. (S15P31E102-1001에서 옮겨 온 11/16 피드백) 율명·기호 탭 윗줄·아랫줄에 `옥타브`·`음`을 적고, 정간·장단 탭 도구에 바뀌는 모양 그림과 한 줄 설명을 둔다. 반주 선택은 장단만 고른다.
9. 높이 맞추기 슬라이더의 추천 칸이 손잡이에 가리지 않고 보인다.
10. (4차 피드백) 확인 카드에 닫기(X)를 두지 않는다. 고칠 것을 다 고치면 줄이, 모두 고치면 카드가 저절로 사라진다. 칸을 편집했다가 실행 취소하면 처음과 같은 카드가 보인다.
11. 다시 볼 곳 창은 원본과 비교하라고 하지 않는다(앱은 원본을 보여 주지 않는다). 위치 줄을 빼고, 문제 종류마다 고치는 곳으로 보내는 버튼 하나와 `이대로 둘게요`를 둔다.

API·저장 형식은 바꾸지 않는다.

## 설계 결정과 원래 기대와의 차이

- 입력판 접힘은 화면 안 기억값이던 것을 `SheetEditUiState.inputPanelExpanded`로 올렸다. 다시 볼 곳의 '율명 바꾸기'·확인 카드의 높이 맞추기처럼 화면 밖 동작이 입력판을 펼쳐야 하기 때문이다. "처음 들어오면"은 변환된 악보를 열 때마다로 구현했다(다시 열어도 접혀 시작). 손으로 만든 악보·제공 곡 복사본은 지금처럼 펼친 채 연다.
- 탭 이름은 `높이 맞추기`로 했다. 흰 상자는 슬라이더에서 고른 값(`원조 유지`·`+1반음`)을 보이고, 같은 값을 보이던 슬라이더 위 가운데 글자는 뺐다.
- 확인 카드(11/16 2차 피드백 반영): 초록 큰 상자 대신 문제 종류마다 한 줄씩, 악보 칸 표시와 같은 바탕·점선·태그로 보인다. 낼 수 없는 음은 갈색 ↕ 줄 + 흰 버튼 `1반음 올려 고치기`(추천이 없으면 `높이 맞추기`), 다시 볼 곳은 빨간 ! 줄 + `첫 칸 보기`. 첫 칸으로 가면 줄이 `다시 볼 곳 1 / 11`과 이전·다음 버튼으로 바뀌고, 칸을 누르면 고칠 방법 창이 열린다. `확인 필요:` 글자는 색·태그로 대신해 뺐다.
- 다시 볼 곳 창: 칸 정보만 보이던 '선택한 위치 정보'를 '이 칸을 원본과 비교해 주세요'로 바꾸고 `율명 바꾸기`(꾸밈음이면 `시김새 넣기`)·`원본과 같아요`·`닫기`를 둔다. `원본과 같아요`를 누르면 다음 다시 볼 곳으로 바로 간다. 확인할 수 없는 항목(지원음 문제 등)에는 `원본과 같아요`를 보이지 않는다.
- 저장 창에서 변환 참고 알림(`SheetConversionNotes`)을 뺐다. 저장을 막는 문제·오류·빠르기 오류는 있을 때만 남긴다. 그 결과 '음높이 조정 ±N반음'·'성부 중 선율을 골랐어요' 같은 변환 참고는 앱에서 더 보이지 않는다. `SheetConversionNotes` 함수와 테스트는 다른 화면에서 다시 쓸지 정하기 전까지 남겨 두었다.
- 3차 피드백(11/16):
  - `안내 다시 보기` 링크는 뜻이 잘 안 읽히고 필요 없다는 의견에 따라 편집·악보 올리기 화면 모두에서 뺐다. 처음 한 번 뜨는 튜토리얼 창은 그대로 둔다.
  - 다시 볼 곳 이전·다음은 정간보가 오른쪽 각부터 읽히므로 왼쪽 버튼(◀)이 다음, 오른쪽 버튼(▶)이 이전이다. 오선보 보기에서는 반대다.
  - 높이 맞추기: 손잡이(북 그림)를 30dp에서 22dp로 줄이고, 추천 칸은 먹색 고리 점과 먹색 칩 `추천 +1반음`으로 표시한다.
  - 반주 선택 창에서 `기본 박 반주` 항목과 그 설정 창을 뺐다. 이미 기본 박 반주를 고른 악보는 그 상태를 선택된 줄로 보이고, `반주 없이`나 장단을 고르면 바뀐다. 기본 박 반주 계산·저장 코드와 테스트는 그대로 둔다.
- 4차 피드백(11/16):
  - 칸을 편집하면 높이 계산(`adaptation`)을 버려 카드가 표시된 칸 수(31개)와 악기 이름 없는 문장으로 바뀌었다. 이제 편집할 때 이미 받은 악기 음 목록으로 바뀐 악보의 높이 계산을 다시 해 둔다(`SheetEditViewModel.refreshedAdaptation`). 불러오는 중이거나 실패한 계산은 전처럼 버린다.
  - 정간·장단 탭: 도구 그림 속 칸 사이를 넓히고 설명 줄은 뺐다. 장단 줄은 다른 도구와 같은 44dp 한 줄(`굿거리장단 · 박 정보 ▾`)로 줄였고, 누르면 장단 선택 창이 열린다. 버튼·창 이름은 `반주 선택`에서 `장단 선택`으로 바꿨다.
  - 다시 볼 곳 창 버튼: 율명 문제 → `율명 바꾸기`, 꾸밈음 → `시김새 넣기`, 마디 길이(짧음·김·빈 마디) → `정간 고치기`(정간·장단 탭), 박자표 → `장단 선택`. `원본과 같아요`는 `이대로 둘게요`로 바꿨다.
  - 마디 길이 문제를 버튼 한 번에 자동으로 고치는 방법(빈 박을 쉼표로 채우기 등)은 어느 박이 빠졌는지 앱이 알 수 없어 넣지 않았다. 사용자에게 방향을 묻는다.
- 피치 확인 창의 버튼 '악기·음역 맞추기'는 탭을 여는 동작과 맞게 '곡 전체 높이 맞추기'로 바꿨다.

## '악기·음역 맞추기'를 눌러도 낼 수 없는 음이 남는 문제(강원도아리랑·단소 41개)

- FE 원인: 피치 확인 창의 버튼은 높이 탭을 열기만 하고 적용하지 않는다. 탭은 원조 유지 상태의 개수(41개)를 그대로 보여 '눌러도 안 고쳐진다'로 보였다. 이제 탭에 '추천'의 뜻을 적고, 어느 높이로도 다 못 고치면 `높이만 바꿔서는 N개가 남아요. 적용한 뒤 빨간 칸을 눌러 하나씩 바꿔 주세요.`를 보인다(`SheetAdaptationUi.unavoidableUnresolved`).
- 높이만으로 남는 이유: 높이 맞추기는 음마다 옥타브를 접어 악기 지원음 중 같은 율(12율 위치)을 찾는다. 단소 지원음(V18·V32 시드)은 황·태·협·고·중·임·남·무 8율이라 대·유·이·응만 없다. 5음 음계인 강원도아리랑이 바르게 인식됐다면 어느 한 높이에서 모두 맞는다.
- 확인 결과(2026-11-16 13:02, emulator-5556, gangwon998·단소): `원조 유지`는 옥타브 옮긴 음 13개 · 낼 수 없는 음 41개, `-1반음`은 옥타브 옮긴 음 54개 · 낼 수 없는 음 0개다. 확인 카드도 `1반음 내려 고치기`를 권한다.
- 결론: 인식 오류가 아니다. 인식된 음은 대·고·유·이·응 5음이라 단소에 없는 율(대·유·이·응)이 많았을 뿐이고, 한 반음 내리면 황·협·중·남·무로 모두 맞는다. 원인은 예전 버튼이 탭만 열고 적용하지 않은 FE 동작이었고, 이제 확인 카드 버튼 한 번으로 고쳐진다. S15P31E102-1043으로 넘길 일은 없다.
