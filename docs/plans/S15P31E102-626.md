# S15P31E102-626 기초부터 배우기 4~8단계 따라 배우기

- Jira: S15P31E102-626, Story S15P31E102-316, Epic S15P31E102-17. 담당 오은서.
- 브랜치: `feat(fe)/S15P31E102-626-기초부터-배우기-4-8단계-연습을-따라-배우기로-개편`. 611·619가 병합된 `origin/develop`(b5051db1) 기준이다.
    - 단계 연습 화면 듣기 판 위 안내는 develop(611 병합) 기준을 따른다: 음높이 판정 단계는 판정 안내, 그 밖은 스스로 확인 안내.
- 결정(사용자 확인 11-09)
    - 따라 배우기는 2·3단계처럼 단계 상세 화면에 둔다. '학습 시작' → 칸 넘기기 → 마지막 칸 '연습 시작'(4~7 단계 연습. 8단계는 아래 추가 결정대로 '다 익혔어요').
    - 칸: 4단계는 기존 할 일 3칸(첫 음 · 옮겨 가기 · 남은 음, 앞 두 칸은 운지 카드, 셋째 칸은 배우는 순서), 5단계는 패턴 5칸(음 줄), 6단계는 음역마다 '내기 · 음계 오르내리기' 2칸(운지 카드 · 단계 그림), 7단계는 서버 할 일 3칸(혀치기 '투' 넷 · 정간 2분 · 3분), 8단계는 서버 할 일 3칸(읽는 순서 보드 · 기본 5음 · 연습할 곡).
    - 따라 배우는 동안 단계 상세는 따라 배우기 판과 통과 기준만 보인다(칸 그림이 같은 내용을 보임).
    - '완료했어요!' 창: 4~6단계 음높이 자동 통과, 4~7단계 '스스로 확인했어요', 8단계 '다 익혔어요'와 곡 전체 결과 통과. '다음 단계로'는 완료 표시 뒤 다음 단계(8단계 결과 화면은 이미 완료를 남겼으므로 9단계 상세를 그 악기로 연다).
    - 창 모양은 결과 화면(`feature/result`)도 쓰도록 `core/ui/component/EolssuDoneDialog`로 옮기고, 619의 `LearnTourDoneDialog`는 이를 감싼다. 611의 결과 화면 스낵바 문구(`learn_song_stage_passed`)는 지웠다.
- 추가 결정(사용자 요청 11-09)
    - 8단계는 기초 과정이라 AI 연주 평가로 보내지 않는다. 곡 칩을 누르면 평가 버튼 없는 혼자 연습(`practice?learn=true`)을 '운지법과 함께 보기'를 켠 채로 연다. 이 켬은 그 화면에서만 쓰고 저장한 연습 설정은 바꾸지 않는다.
    - 8단계 따라 배우기 마지막 칸은 '연습 시작' 대신 '다 익혔어요'이고, '완료했어요!' → '다음 단계로'로 완료 표시 뒤 9단계로 간다.
    - 8단계 곡은 배우는 악기의 악보로 찾는다(곡의 악기 ID → 악기 목록 code → 트랙). 그 악기 악보가 없으면 '곡 데이터가 없어요'로 알리고 다른 악기 악보를 열지 않는다. 곡 연습은 연습 설정의 악기를 따르지 않고 악기 고르기도 숨긴다.
    - 글 줄이기(사용자 승인): 단계 상세에서 판정 표시·통과 기준·이전/다음 단계 버튼을 뺐다. 2~8단계는 시작 전 할 일 이름만, 따라 배우는 동안은 따라 배우기 판만 보이고 칸 설명의 'n / 전체'를 뺐다. 단계 연습 화면은 통과 기준 한 줄만 두고 판정 안내·허용 오차·연습할 음 설명·녹음 안내 문구를 뺐다(쓰지 않게 된 문자열 11개 삭제).
    - 611의 결과 화면 8단계 자동 통과(평가로 곡 전체를 통과하면 완료)는 그대로 두었다.
    - 단계 상세 머리에 단계 위치 줄(단계마다 점, 완료 연두 · 지금 단계 길쭉한 점, 'n / 전체')을 둔다.
    - 단계 목록은 카드 밖 내용 높이를 재어 남는 높이만큼만 단계 카드를 키운다(최소 160dp). 낮은 휴대폰에서도 '시작하기'까지 한 화면에 보인다.
- 611 판정 로직(`LearnPitchJudge.kt`, `LearnPracticeViewModel`)은 바꾸지 않았다. 3단계 연습 통과는 이전처럼 통과 판·'완료하고 다음 단계'만 보인다.
