## 확정 계약과 범위

사용자가 확정한 선택/최종 저장 기준은 등록 운지 ∩ 화면 표기 ∩ CAT 합성이다. 물리 음역은 문헌상 참고 범위로 제공하고 실물 검수 상태는 UNKNOWN으로 분리한다. 운지 자료가 없는 음은 연주 불가로 단정하지 않는다.

`GET /api/instruments/{id}/authoring-capabilities`는 기존 CAT-06과 별도 계약이다. 기존 카탈로그·DATA 악기 profile·authoring-policy·악보 schema를 읽어 판정하며 화면별 음 목록을 복제하지 않는다. 최종 저장과 음원 요청은 동일 검증기를 사용하고 음원 악기 생략은 저장된 악기를 선택한다. event 음고와 원점 표시, 황 기준 주파수도 검증한다. 오류에는 eventId/cellId와 이유가 있다. 기존 악보 조회와 임시저장은 이전 자료를 보존한다.

Gradle과 Docker에 정책·표기 schema를 함께 묶고 Jenkins/Compose 빌드 context를 저장소 루트로 맞춘다. DATA profile 검색은 정책 파일을 악기 profile로 읽지 않는다. 이 결과는 이조·원본 저장·장단·빠르기 정책 또는 FE 화면을 포함하지 않는다.
