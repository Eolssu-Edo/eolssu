### 실제 Android UI

다른 MR의 잠금 해제 뒤 FileMode.CreateNew로 공용 잠금을 획득했다. 전용 새 AVD `MR736_S10`은 Galaxy S10 화면 규격1440×3040·560dpi, Android17/API37·x86_64 이미지다. 고정 악보를 프로덕션 `SheetEditSettingsDialog`, `SheetEditUiState`, `JeongganboView`에 연결한 임시 Activity에서 adb 입력으로 다음을 확인했다. 저장 버튼은 로컬 파일을 쓰는 fixture이며 실제 API의 저장·재진입은 위 별도 통합 검증에서 확인했다.

- 다섯 한배 선택지·목표 미지정 안내 표시. 숫자 없이 좀 느리게를 추가하면 전체60을 유지하고 악보의 해당 위치에 세로 `ㅈㄴ`이 나타났다.
- 적용 후 실행 취소0구간→다시 실행1구간과 기호 복원을 확인했다.
- 수정으로 목표40 지정, 전체60→90 변경 시 화면 목표60 표시. 로컬 초안 저장/재진입 뒤에도90·목표60을 유지했다. 기기 파일 read-back은 저장 BPM90, 원래 기준 목표40, 반복2회, 음표4개였다.
- 삭제 후0구간·기호 제거, 실행 취소1구간·기호 복원, 다시 실행0구간을 확인했다.
- 점점 느리게 목표40·끝 위치 공란은 반영이 차단되고 오류를 표시했다. 긴 폼에서도 오류가 반영 버튼 위에 바로 보이도록 편집 중/목록 상태의 오류 위치를 나눴고, 수정 APK에서 추가 스크롤 없이 오류가 보이는 것을 재확인했다. 이 보완 뒤 FE 전체1680/제외5와 정상 APK를 다시 통과했다.
