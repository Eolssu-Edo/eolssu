# S15P31E102-999 내 악보 목록 악기 필터 추가

- Story S15P31E102-317 · 활성 스프린트 5 · 진행 중
- 기준 develop 65e26e717. 998의 변환 진행·실패 상태 표시가 병합됐다.

## 화면과 완료 조건

1. 연습곡 고르기의 내 악보 탭에 전체와 기존 지원 악기 필터를 보여 준다. 기본값은 전체다. 상단 연습 악기와 제공 곡 탭에는 이 필터를 적용하지 않는다.
2. 악기 코드와 제목 검색을 함께 적용하고 서버의 목록 순서를 유지한다. 악기 코드가 없거나 앱이 모르는 코드는 전체에서 찾을 수 있다. 변환 중·실패 행에도 같은 필터를 적용하며, 가려진 악보의 변환 감시는 계속된다.
3. 결과가 비면 검색 조건 초기화로 제목과 악기 조건을 함께 지울 수 있다. 탭 개수는 전체, 목록의 개수는 현재 조건의 결과를 표시한다.
4. 공유 테스트와 Android·Wasm 빌드, 휴대폰·태블릿 배치에서 확인한다.

## 검증

- 수정 전에는 단소 필터를 선택해도 소금과 악기 미지정 악보가 남아 추가한 회귀 테스트가 실패했다. 수정 후 검색과 단소 필터가 함께 적용되고 변환 중·실패 행의 순서가 유지됨을 확인했다.
- 공유 테스트 1,911개 중 1,906개 통과, 5개 건너뜀, 실패·오류 0건. Android 디버그 APK와 Wasm 컴파일 성공.
- Android 15 emulator-5556에 새 APK를 설치하고 갱신 시각을 확인했다. 앱 시작 후 화면 덤프가 실패했고 기기 연결이 끊겨 휴대폰·태블릿 화면 확인은 미완료다. 두 배치가 같은 필터 본문을 사용함을 코드에서 확인했다.
