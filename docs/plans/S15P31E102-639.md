# S15P31E102-639 평가 녹음 10분 한도와 채점 안내

- [Jira 작업](https://ssafy.atlassian.net/browse/S15P31E102-639) · Story S15P31E102-33 · Epic S15P31E102-20
- [녹음 파일 규격](../specs/recording-file.md#클라이언트-녹음) · 기준 `origin/develop` `77d26966`

- [x] 평가 녹음이 10분에 자동 종료되면 한도 안내를 띄우고 기존 평가 버튼으로 지금까지 녹음한 파일을 넘긴다.
- [x] 가짜 시계로 10분 직전에는 계속 녹음하고 한도에 닿으면 자동 종료되는지 확인한다. 곡 끝, 무입력, 저장 실패 상태도 공통 테스트로 확인했다.
- [ ] 실제 녹음이 가능한 Android·iOS에서 한도 안내의 문구와 평가 버튼을 확인한다.
- [x] 사용자 결정에 따라 악보 화면의 9분 30초 무활동 팝업을 제거했다. 무활동 10분 집계 상한과 입력 후 집계 재개를 확인했다.

기존 완료 창을 재사용하고 종료 이유에 따라 문구를 바꾼다. 연습 시간 집계와 업로드 규격을 유지한다.

## 검증

- `frontend`에서 `./gradlew :shared:jsBrowserTest --tests 'com.ssafy.eolssu.feature.practice.*'` 통과. 새 테스트는 구현 전 일반 완료 상태에서 실패했고, 구현 후 10분 한도 상태와 평가용 파일 전달을 확인했다.
- 9분 30초 팝업 제거 전에는 무활동 상태 테스트가 실패했고, 제거 후에는 9분 30초와 10분에 팝업 상태가 바뀌지 않았다. 연습 시간 상한·재개와 10분 녹음 한도 평가 경로 테스트도 통과했다.
- `./gradlew :shared:jsTest`는 1,140건 중 1,139건 통과. 변경 전후 모두 `MySheetConversionTest.pollsOnlyWhileWatchingAtServerIntervalAndRefreshesListWhenDone`에서 실패했다.
- Android SDK가 없어 Android 호스트 테스트를 실행하지 못했다. 모바일에서 10분 이상 걸리는 악보를 평가 녹음하고 한도 안내의 **평가하기**를 누르는 실기기 확인이 남았다.
