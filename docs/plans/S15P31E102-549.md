# 홈 카드 배치·상단 정리와 Android 뒤로 가기 두 번 종료

- Jira: S15P31E102-549 · Story: S15P31E102-109(UI/UX) · Epic: S15P31E102-1

- 현행 표시 기준: [HOME 전체 그림·스크롤·먹 버튼](../specs/home-scroll-ink.md)

## 확정 범위(사용자 요청)

1. 카드 구역 제목 '학습·연습하기'를 지우고 가는 구분선만 남긴다. AI 버튼 → 16dp → 구분선 → 16dp → 카드.
2. 2×3 격자: 왼쪽 열 학습(기초부터 배우기 · 운지법 보기 · 정간보 쉽게 읽기), 오른쪽 열 연습·관리(연습곡 선택하기 · 연습 기록 보기 · 악보 추가·편집하기). 카드의 그림·제목·화면 이동은 그대로다.
3. 카드의 ↗와 설명 문구를 지운다. 카드는 그림과 제목만, 카드 전체가 누르는 영역이다.
7. (폰 확인 뒤 추가 요청) 카드 제목을 같은 높이에서 카드 가운데로 정렬한다. 두 줄이 되면 줄마다 가운데다.
4. 홈 상단 '현재 악기' 드롭다운을 지우고, 평가할 곡 고르기(SONG-01)·연습곡 고르기(SONG-03) 상단 바 오른쪽으로 옮긴다(두 화면에는 악기 선택이 없었다).
5. 오른쪽 위 원형 아이콘은 이미 마이페이지(MY-01)로 연결돼 있어 그대로 둔다. 프로필 사진 변경 기능은 없고 새로 만들지 않는다.
6. Android 홈에서 시스템 뒤로 가기 두 번(2초 안)으로 앱을 닫는다. 다른 화면·iOS·Web 동작은 바꾸지 않는다.

## 분석 근거

- 홈 구성: `HomeRoute`(안내·콜백) → `HomeScreen`(Scaffold·스낵바) → `HomeScrollLayout`(400dp 스크롤 무대, 그림·제목·AI 버튼·카드, 스크롤 상자 밖 상단 판) → `FeatureSection`·`HomeHeader`·`HomeInkButton`.
- 악기 상태는 `InstrumentRepository.instrument` 하나를 홈·마이페이지·곡 목록·연습곡 목록·기초부터 배우기가 함께 구독한다. 홈 드롭다운은 `changePracticeInstrument`(마이페이지와 같은 절차)로 바꿨고, 두 곡 목록 ViewModel은 악기가 바뀌면 다시 불러온다. 그래서 드롭다운을 곡 화면으로 옮겨도 다른 화면의 선택은 그대로 이어진다.
- 홈 ViewModel은 악기 표시·변경만 맡아, 드롭다운을 옮긴 뒤 지웠다(빈 ViewModel을 남기지 않는다).
- 홈으로 가는 이동은 모두 `popUpTo(graph) { inclusive = true }`이거나 이미 있는 홈으로 `popBackStack`한다. 홈이 두 번 쌓이는 경로는 없다. 그래도 종료 처리는 홈 아래에 화면이 없을 때(`previousBackStackEntry == null`)만 켠다.
- 스크린숏 위쪽의 `P: 0 / 1 dX dY Xv Yv Prs Size` 줄은 Android 개발자 옵션 '포인터 위치' 표시다. 앱 코드에는 없어 기기 설정에서 끈다.
- 상단 판의 추가 스크롤 고정은 S15P31E102-437 결정이라 유지했다. 겹침은 같은 줄에 있던 악기 판이 빠지며 줄었다.

## 변경

- `feature/home`: 카드 순서(`HomeFeatureGrid`)·2열 고정(`HomeFeatureColumns`), 제목 줄 → 구분선, 카드 설명·↗ 제거와 한 줄 높이 맞춤(긴 제목 두 줄 허용), `HomeViewModel` 삭제. 태블릿 세로도 3×2 대신 2×3이다(학습 왼쪽 구분 유지).
- `HomeInkButton`: '→' 글자 대신 `EolssuIcons.ArrowRight`(24dp)로 붓글씨 글자와 가운데를 맞춘다.
- `home_score_art.xml`: 옅은 원을 악보 판 뒤로 옮겨 판의 왼쪽 테두리를 가리지 않게 했다(모양·색은 그대로).
- `core/ui/component/PracticeInstrumentDropdown.kt`: 홈 드롭다운을 상단 바용 알약으로 옮김. `feature/song/SongInstrumentSelection`·`component/SongInstrumentPicker`로 두 곡 화면이 같은 저장·실패 안내·세션 만료 처리를 쓴다. `SongTabletScaffold`에 `topBarRight` 자리 추가.
- 뒤로 가기: `HomeBackExit`(2초 판정) + `HomeRoute`의 `BackHandler`. 종료 동작은 `rememberHomeAppExit()` expect/actual로 Android만 `Activity.finish()`, iOS·Web은 null(가로채지 않음).
