# S15P31E102-717 한 음씩 연습 안내 문구 삭제·현재 정간 칸 정렬과 예시음 재생 수정

- Jira: S15P31E102-717, Story S15P31E102-32(연습 화면 흐름), Epic S15P31E102-20. 담당 오은서.
- 브랜치: `feat(fe)/S15P31E102-717-한-음씩-연습-안내-문구-삭제·현재-정간-칸-정렬과-예시음-재생-수정`, `origin/develop`(bef4f448) 기준.

## 범위와 완료 조건

- 혼자 연습에서 한 음씩을 켜면 악보 아래 안내('율명을 누르면 운지법을…')와 두 칸 아래 진행 안내('1 / 40음 · …')를 두지 않는다.
- '지금 음' 칸을 '현재 정간'으로 바꾼다. 두 칸의 이름·내용을 왼쪽 여백을 넓혀 조금 안쪽에 두고, 내용 줄 높이를 같게 해 두 칸의 이름이 같은 높이에 오게 한다.
- '현재 정간' 칸을 누르면 그 정간 음의 운지 예시음(운지 가이드의 기본 예시음)이 난다.
- 완료 조건: 공유 테스트·JS 컴파일·Android 빌드 통과, 에뮬레이터에서 문구·배치·예시음 재생 확인.

## 원인과 결정

- 예시음이 나지 않은 원인: 칸을 누르면 ViewModel이 아이콘 강조 상태만 1.2초 켜고, 실제 재생기는 연결돼 있지 않았다.
- 재생은 운지법 팝업과 같은 기본 예시음을 쓴다. 운지 가이드(`feature/guide`)의 재생기를 앱(`EolssuNavHost`)이 연습 화면에 넘긴다. 운지 팝업은 닫힐 때 음원 목록을 비우므로 한 음씩용 목록·재생기를 따로 둔다. 같은 음을 다시 누르면 멈춘다.
- 낼 음은 운지법 팝업과 같은 규칙(`fingeringFor`)으로 찾는다. 처음에 율명 기호로 찾았더니 서버 공통 악보의 율명·옥타브(청고선 등)를 찾지 못해 소리가 나지 않았다.
- 진행 수(`1 / 40음`)도 안내 문구 줄에 함께 있어 같이 뺐다. 판정기가 판정하지 못할 때 쓰는 임시 넘기기 버튼은 조작이라 남겼다.
