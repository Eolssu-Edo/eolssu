## 이번 단위(1차)

인증(S15P31E102-143)이 아직 없어 회원 ID를 받는 서비스·조회까지 구현했다. API(`GET /me/stats`)와 Spring Bean 연결은 같은 Task의 다음 단위다.

| 계층 | 내용 |
| --- | --- |
| domain | `StatsPeriod`: 주(KST 월~일, 요일별 막대 7개)·월(달력 월, 그 달 안의 월~일 주차별 막대 4~6개), 지난 기간. `DateRange`, `SessionTotals`, `PracticeStatsRepository` |
| application | `GetPracticeStats`: 오늘(KST)이 든 기간의 연습 시간(초)과 지난 기간 전체 대비 차이, `DONE` 세션 수, 평균 점수(반올림)와 지난 기간 평균 대비 차이(어느 쪽이든 점수 있는 세션이 없으면 없음), 막대별 연습 시간, 연속 일수(인정 합 1분 이상인 날, 오늘 연습 전이면 어제부터) |
| infrastructure | `PracticeStatsMapper`(KST 날짜별 인정 시간 합, `DONE` 세션 수·점수 합, 연습한 날 목록)와 `MyBatisPracticeStatsRepository`. 기간은 UTC 경계로 거르고 묶을 때만 `started_at + 9시간`의 날짜를 쓴다 |

## 결정

- (2단위에서 폐기) 평균 점수 변화는 반올림한 두 평균의 차이로 낸다. 지금은 앱이 `previousPeriod`로 계산한다.
- 평균은 평가 행이 있는 `DONE` 세션으로만 낸다. 연습 횟수는 평가 행과 상관없이 `DONE` 세션 수다.
- 연속 일수는 오늘부터 과거의 모든 연습한 날을 읽어 계산한다. 회원별 행 수가 커지면 기간을 제한하거나 저장하는 방식을 다시 본다.
- KST는 서머타임이 없어 9시간을 고정으로 더한다(MySQL 시간대 표 불필요).

## 2단위: Notion 명세에 맞춘 API (2026-10-28)

Notion API 명세 원문을 대조해 보니, GRO-01은 `GET /users/me/growth/summary`이고 GRO-02는 `GET /users/me/growth/calendar`였다. 두 API 모두 `from`·`to`(KST, 양 끝 포함, 최대 366일)를 받는다. 1단위의 `GET /me/stats`(서버가 주·월과 막대를 정함) 초안을 버리고 명세에 맞췄다(사용자 결정). 스펙 '성장 화면 통계'도 함께 고쳤다.

| 결정(사용자) | 내용 |
| --- | --- |
| API 형식 | Notion 명세대로. 주·월 기간·막대·변화 표시는 앱이 `summary`·`calendar`로 계산한다. 서버의 `StatsPeriod`(주·월·막대)는 지웠다 |
| 연습한 날·연속 일수 | 인정 시간 합 1분 이상인 날(우리 스펙). Notion 규칙 7('DONE 세션이 있는 날')은 빨간 글씨로 고쳐 표시했다 |
| summary 범위 | 연습 칸(`practiceCount`·`practiceSeconds`·`practiceDays`·`currentStreakDays`·`averageTotalScore`·`previousPeriod`)만 만든다. 미션 수는 `null`(명세 규칙 5). `bestBySong`·`metricGrowth`는 별도 Task에서 만들고, 그 전에는 응답에 넣지 않는다 |

| 계층 | 내용 |
| --- | --- |
| domain | `DateRange`(길이, 직전 같은 일수 구간), `SessionTotals` |
| application | `GetGrowthStats.summary`·`calendar`. 지난 기간은 `from` 바로 앞의 같은 일수(Notion 규칙 8) |
| api | `GrowthController`: access_token의 `sub`를 회원 ID로 쓴다. 범위 오류·형식 오류·누락은 400 `INVALID_REQUEST`. 인증 없음 401은 보안 필터가 처리한다 |
| config | `GrowthStatsConfig`(`db` 프로필). 체류 기록 저장 쪽 Bean과 겹치지 않게 파일을 나눴다. 공유 `Clock` Bean(`termClock`) 대신 `Clock.systemUTC()`를 직접 넘긴다 |
