## 동작

`POST /api/practice-sessions`, 로그인 필요(access_token 쿠키), `Idempotency-Key` 헤더 필수. 성공은 201과 공통 성공 형식, `result`에 `sessionId`·`songId`·`status`·`bpm`·`bpmUnit`·`startNoteIdx`·`endNoteIdx`·`startedAt`(UTC ISO8601). 세션은 `RECORDING`, `started_at`은 서버 시각(마이크로초), `score_version`은 곡의 현재 값이다.

판정 순서: 401(보안 필터) → 400(헤더·본문 형식·범위) → 같은 키 재전송 판정 → 404(곡·부모 세션·미션) → 400(부모 세션이 다른 곡, 구간이 곡 밖) → 409 `STATE_CONFLICT`(부모 세션이 `DONE` 아님).

## 결정

명세에 없거나 초안·논의 필요로 남은 항목이다. 사용자가 "알아서 진행"을 위임해 추천값으로 정했다(2026-10-28).

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| `missionId` | 형식이 맞아도 지금은 404 `RESOURCE_NOT_FOUND` | `missions` 테이블이 없다(V2에서 미도입). 미션 정의가 생기면 그 검증으로 바꾼다 |
| `jangdanSoundOn` | 받기만 하고 저장하지 않는다. 같은 키 비교에는 포함 | 명세가 "논의 필요", 저장 칸이 없다 |
| 구간(`startNoteIdx`·`endNoteIdx`) | 생략 시 0·`note_count - 1`. `0 ≤ start ≤ end ≤ note_count - 1`이 아니면 400 | 명세 기본값. 규칙 8의 보류 대상은 구간 **반복**이며 단일 구간은 받는다 |
| 대상 곡 | `PUBLISHED`·`is_scorable`·`deleted_at IS NULL`이 아니면 404 | 명세 비고 |
| 부모 세션 | 없음·타인 소유 404, 다른 곡 400, `DONE` 아님 409 `STATE_CONFLICT` | 명세 규칙 2. 타인 소유는 존재를 숨긴다 |
| `Idempotency-Key` | 1~100자 출력 가능 ASCII(`!`~`~`), 없거나 어기면 400 | DB 칸 `VARCHAR(100) ascii_bin` |
| 같은 키 재전송 | 본문 비교는 기본값(시작 0, 장단 소리 false)을 채운 정규화 본문의 SHA-256(`request_hash`). 같으면 기존 세션을 201로 그대로, 다르면 409 `IDEMPOTENCY_CONFLICT` | 명세 규칙 5·6. JSON 공백·키 순서 차이는 같은 요청으로 본다. 재전송 응답의 `status`는 현재 값 |
| 동시 같은 키 | 유일 제약(`uq_sessions_user_idempotency`) 위반이면 다시 읽어 위 규칙으로 응답 | 한 번만 저장되게 DB가 보장한다 |
| 오류 코드 | `STATE_CONFLICT`·`IDEMPOTENCY_CONFLICT`(409)를 공통 `ErrorCode`에 추가 | 명세 Exceptions 표 |

## 리뷰 반영(2026-10-28)

독립 리뷰 지적 1~3번을 고쳤다. 4번(회원 행 없음·부모 세션이 저장 직전 삭제되면 외래키 위반 500)과 5번(모르는 필드 무시)은 발생 가능성이 낮거나 명세에 규정이 없어 고치지 않았다.

- 타입 엄격 검사: Jackson 기본 변환으로 `"bpm":96.7`이 96으로 잘려 201이 되던 문제. `songId`·ID·`bpmUnit`은 JSON 문자열, `bpm`·구간은 int 범위의 JSON 정수, `jangdanSoundOn`은 JSON 불리언만 받는다(`StrictJsonDeserializers`). `bpmUnit`은 enum이면 숫자 `0`이 첫 값으로 바뀌어 문자열로 받고 이름을 확인한다. 컨트롤러 테스트에 10가지 입력을 추가했고, 수정 전 코드에서 이 테스트가 실패하는 것을 확인했다.
- README: 재전송 비교에서 기본값으로 채우는 것은 `startNoteIdx`(0)·`jangdanSoundOn`(false)뿐이고 `endNoteIdx`·`bpmUnit`은 생략과 명시를 다르게 본다고 고쳤다(결정은 그대로).
- 경합 단위 테스트를 둘로 나눠, 경합에 진 뒤 다시 읽은 결과가 다른 본문이면 409인 분기를 실제로 거치게 했다.
