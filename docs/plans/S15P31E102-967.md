# S15P31E102-967 구간 연습 구간 선택 화면 태블릿 가로 두 칸 배치

- Jira: S15P31E102-967 · Story S15P31E102-109 · 활성 스프린트 59321 · 진행 중.
- 근거: 태블릿 가로 화면 조사(960)의 1순위 항목. 1440×765 운영 화면의 `#weak/<recordId>/sections`가 560dp 휴대폰 폭 한 줄로 쌓여 정간보가 4각만, 낮은 높이로 보이고 양옆이 비었다.
- 범위: `feature/practice/SectionSelectScreen.kt`의 Expanded(840dp 이상) 배치만 바꾼다. Compact·Medium 배치, 상태·ViewModel, 구간 선택·추천 구간 동작은 그대로 둔다.

## 결과

- Expanded에서 상단 바와 본문을 `WindowBreakpoints.ContentMaxWidth`(1120dp)로 넓힌다.
- 왼쪽 380dp 칸에 틀린 종류 탭·안내 줄(‘취약 구간 보기’ 포함)을 두고, 같은 칸 아래에 ‘구간 연습 시작’·‘구간 재평가 시작’을 나란히 둔다. 버튼은 칸 너비를 넘지 않고 하단 고정 바는 쓰지 않는다.
- 오른쪽 칸은 정간보가 남은 너비와 전체 높이를 쓴다.
- 비교 화면(966)과 나눠 쓸 만큼 작은 공용 도우미가 없어 `core/ui`에 새 코드를 두지 않았다.
