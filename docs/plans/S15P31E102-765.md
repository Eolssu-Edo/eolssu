# S15P31E102-765 내 악보 목록의 악기 코드

- [Jira Task](https://ssafy.atlassian.net/browse/S15P31E102-765) · [Story](https://ssafy.atlassian.net/browse/S15P31E102-317) · 스프린트 5, 진행 중
- 기준 `origin/develop` `866d9064`. SHT-01에 편집기 필터가 사용하는 `instrumentCode`를 추가하고 기존 응답 필드와 회원별 조회 범위를 보존한다.
- 초안이 있으면 초안 공통 악보의 `score.instrument`를, 없으면 확정 문서의 값을 사용한다. 식별자가 없는 항목과 이전 서버의 응답은 기존 상세 조회로 처리한다.

## 작업과 검증

1. 기존 SHT-01 응답 검증에 확정·초안·빈 악보·다른 회원 사례를 추가한다.
2. 편집기 불러오기에서 악기 코드가 있는 항목과 호환 조회가 필요한 항목의 SHT-08 요청 수 및 필터 결과를 비교한다.
3. 백엔드 빌드 및 격리 DB 검사와 Android 에뮬레이터에서의 전후 비교 결과를 기록한다.

QA 보고서 `qa-user-flow-performance.html#api-sheet-list`와 실행 계획 `qa-improvement-work-plan.md`의 5번 항목을 참고했다. !564에서 이 경로의 요청 수·지연은 미측정이다. 후속 설치 빌드의 소스에서 악기 필터가 상세 조회를 하는 경로를 확인했다.

## 검증 결과 (2026-11-11)

- 변경 전 백엔드에서 `test --tests '*UserSheetControllerTests' --offline`을 실행했다. 새 회귀 검사 1건이 `instrumentCode` 경로가 없어 실패했다.
- 변경 후 `clean build databaseTest --tests '*UserSheetApiDatabaseTests' --offline --max-workers=2` 성공. 일반 테스트 724건 중 723건 통과, 기존 장단 스냅숏 검사 1건 스킵. SHT-01 MockMvc 검사는 3건 모두 통과했다.
- 임의 포트의 Spring Boot와 빈 MySQL 8.4.13에서 `UserSheetApiDatabaseTests` 16건 통과. 서로 다른 회원의 서명 쿠키로 각자의 목록만 반환되는지, 미인증 401, 기존 응답 필드·페이지 순서, 단소 확정 악보 코드와 빈 악보의 명시적 null을 확인했다.
- !564 및 후속 설치 빌드의 실제 요청 수와 지연, 실기기의 네트워크·화면 동작, 운영 API는 미측정이다.
- [Notion SHT-01](https://www.notion.so/405a0252aa45808a804dca25f1b3d1f3) 페이지 조회는 연결된 Notion에서 404, 브라우저 연결은 시간 초과였다. 명세 변경은 [저장소 계약](../specs/user-sheets.md#sht-01-get-apiusersmesheets)에 반영했고 Notion 반영은 미완료다.

## Android 에뮬레이터 검증 (2026-11-11)

- Android 15(API 35), x86_64, 1080×2400의 전용 AVD `Eolssu765_API35`에서 `866d9064`와 변경 후 디버그 APK를 비교했다. 두 APK를 `frontend`에서 `gradlew.bat :androidApp:assembleDebug '-Peolssu.debugApiBaseUrl=http://127.0.0.1:18765' --offline`으로 빌드했다.
- 앱 데이터를 초기화한 뒤 테스트 계정으로 로그인하고, 홈의 악보 추가·편집하기 → 내 악보·제공 곡 불러오기 → 단소 → 내 악보 → 소금 순서로 진행했다. `adb reverse`로 연결한 동일한 로컬 HTTP 서버에서 `GET /api/users/me/sheets/{sheetId}/score`를 셌다.
- 목록 픽스처는 단소 확정본 31(`DANSO`), 단소 확정본에 소금 초안이 있는 32(`SOGEUM`), 빈 악보 33(`null`), 코드 필드가 빠진 단소 악보 34로 구성했다. 상세 픽스처의 32는 단소 확정본과 소금 초안을 함께 반환했다.

| APK | 단소 첫 선택 | 소금 전환에서 추가 | SHT-08 합계 |
| --- | --- | --- | --- |
| 기준 `866d9064` | 4건 (31, 32, 33, 34) | 0건 | 4건 |

- Android 시스템 응답 지연으로 기준 APK 실행 전에 AVD를 4코어·4GiB 설정으로 재시작했다. 비교 지표는 요청 수다.
