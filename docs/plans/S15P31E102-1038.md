# S15P31E102-1038 완료 알림 선택 시 해당 화면 이동

- 작업: `S15P31E102-1038` · Story `S15P31E102-319`
- 범위: 음원 생성·악보 변환 완료 상단 알림의 `열기` 이동. OS 푸시·새 알림 종류는 제외.

## 확인 결과

- 홈 등 다른 화면에서 누르면 해당 악보(native: 내 악보 연습, Web: 편집기)로 이동한다(S15P31E102-905 Web 실행 기록과 같은 경로).
- 다른 내 악보의 연습·편집 화면에 있을 때 누르면 이동하지 않았다. `launchSingleTop`은 경로 패턴이 같으면 새 화면을 쌓지 않고 기존 항목을 같은 ID로 다시 만든다(navigation-runtime 2.10 `launchSingleTopInternal`). 연습 화면은 `savedStateHandle`의 `songId`, 편집기는 그 항목의 ViewModel을 그대로 써서 이전 악보가 남았다.

## 변경

- `SheetCompletionNavigation.kt`의 `openCompletedSheet`: 지금 화면이 이미 알림의 그 악보 화면일 때만 다시 쌓지 않고, 나머지는 `launchSingleTop` 없이 이동한다.
- 판정 회귀: `SheetCompletionNavigationTest` (다른 악보 위·같은 악보·같은 ID의 다른 화면).

## 검증

- 실제 앱에서 다른 악보 화면 위의 `열기`는 확인하지 않았다. native·iOS 실행 확인은 리뷰 단계에 남는다.
