## AI HTTP 통신 판정 후속

- AI 검사 범위를 기존 음원 처리·추론까지의 미검증 표시에서 HTTP 통신으로 좁힌다. 예상한 422와 필수 입력 오류 응답을 받으면 내부 판정을 정상으로 두고 상태 표에 `통신 정상`을 표시한다.
- 컨테이너 사실의 기존 `readiness` 배열을 유지하고 검사 유형을 별도 필드로 전달한다. 컨테이너 표시는 S15P31E102-667 범위다.
- 정상 422, 응답 오류, 확인 불가와 Docker 중지·비정상 회귀를 확인한다. 복제 프록시 판정과 운영 적용 범위는 기존 작업과 동일하다.
- 회귀 테스트 76건과 양쪽 SSH dispatch 문법 검사 통과. 기대한 422 외에는 통신 정상으로 표시하지 않았고, 기존 미검증에서 AI만 빠지는 것을 확인했다.
- 12:16:49 KST에 후보를 edo1에서 읽기 전용으로 실행했다. 상태 표에 `통신 정상 · POST /v1/analyses · HTTP 422 (입력 검증 응답)`이 표시됐고, 컨테이너 수집 사실의 판정·근거와 `readiness_kind: "http_communication"`을 확인했다. 전체는 장애 0 · 주의 0 · 미검증 1 · 미측정 0이었다. 운영 수집기는 적용 스냅샷 `17c5ab95`와 해시가 일치했다.
