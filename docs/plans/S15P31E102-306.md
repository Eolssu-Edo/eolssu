## 설계 판단

기존에는 파일 삭제 이후 취소되면 DB만 보존하는 위험을 수용했다. 사용자 요청에 따라 기한이 지나면 취소할 수 없도록 바꾼다. 단순 시각 검사만 추가하면 만료 직전 시작한 취소 트랜잭션이 아직 커밋되지 않은 후보를 삭제할 수 있으므로, 파일 삭제 전에도 같은 회원 행 잠금으로 기존 취소의 완료를 기다린다. 저장소 호출 내내 DB 잠금을 유지하거나 새 PURGING 상태를 추가하는 대신, 기한과 짧은 사전 잠금으로 순서를 결정한다.
