## 계획

1. 파일·폴더 CLI 계약의 실패 검사를 먼저 실행한다.
2. 기존 환경파일을 직접 읽는 Python CLI, 조건부 업로드와 미리보기·충돌 처리를 구현한다.
3. 로컬 HTTP 대역으로 SDK 요청을 확인하고 실행 문서를 추가한다.
4. 변경 전체를 자체 점검하고 Task 단위로 커밋한다. 실제 R2 업로드와 공식 리뷰는 미실행으로 구분한다.

## 결정

- API 키를 팀원에게 자동 복사하거나 접근 권한을 추가하지 않는다. 로컬 키 사용과 기존 서버 설정을 서버 안에서 사용하는 방법을 함께 안내한다.
- boto3를 사용해 OS별 셸 차이 없이 파일·폴더를 처리한다. AWS CLI 설치는 필요 없다. 선택적 SDK는 실제 업로드 때만 필요하며 테스트·미리보기는 표준 라이브러리로 실행한다.
- Python 단일 PUT 조건부 요청을 사용한다. 5GiB 초과는 분할 업로드가 필요한 별도 범위로 명확히 거절한다.

## 검증 및 결과

- 구현 완료 / 공식 리뷰 대기. 기대한 기존 설정 재사용·파일/폴더 공통 업로드를 그대로 구현했다. 구현 수단은 AWS CLI 대신 boto3이며 사용자 동작의 본질적 변경은 없다.
- `infra/r2/upload.py`, 실행 안내·설정 예시·requirements, 표준 라이브러리 검사와 SDK HTTP 통합 검사를 추가했다. 기존 마이그레이션·앱·운영 설정은 수정하지 않았다.
- 선행 파일·폴더 테스트를 미구현 inventory의 NotImplementedError로 실패 확인한 뒤 구현해 통과했다.
- Python 3.11 + boto3/botocore 1.43.123: `.venv/bin/python -m unittest discover -s infra/r2 -p 'test_*.py' -v` 10개 통과, 건너뜀 0. 실제 SDK의 로컬 HTTP PUT으로 바이트·Content-Type·MD5·SHA metadata·SigV4·조건부 충돌·교체를 검증했다.
- 기존 저장 도구: `TMPDIR=/private/tmp .venv/bin/python -m unittest discover -s infra/storage -p 'test_*.py' -v` 13개 통과. 최초 기본 TMPDIR에서는 기존 migrate_r2 검사 2개가 macOS `/var` 심볼릭 링크 때문에 거부되어, 코드 수정 없이 실제 경로를 지정해 재검증했다.
