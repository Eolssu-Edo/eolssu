## 배경

App Store의 얼쑤 1.0(빌드 4)이 '언어: 영어'로만 표시됐다. 프로젝트 `developmentRegion = en`이었고 번들에 `.lproj`가 없어 App Store가 개발 언어(영어)만 표시했다. 앱 화면 문자열은 Compose 리소스 `values`(한국어) 하나뿐이다.

## 변경

| 파일 | 내용 |
| --- | --- |
| `iosApp.xcodeproj/project.pbxproj` | `developmentRegion = ko`, `knownRegions = (ko, Base)` |
| `iosApp/Info.plist` | `CFBundleDevelopmentRegion = ko`, `CFBundleLocalizations = [ko]` |
| `iosApp/ko.lproj/InfoPlist.strings` | 마이크 권한 문구. 번들에 `ko.lproj`가 생겨 App Store가 한국어로 표시한다. 표시 이름은 넣지 않는다(Jenkins 개발 빌드가 Info.plist에서 '얼쑤 개발'로 바꾸므로). |
| `Configuration/Config.xcconfig` | `MARKETING_VERSION=1.0.1`, `CURRENT_PROJECT_VERSION=5`(1.0 업로드 빌드 4보다 크게) |

`iosApp` 폴더는 Xcode 동기화 그룹이라 `ko.lproj`가 프로젝트 파일 수정 없이 리소스로 들어간다.

## 검증

- Windows: `Info.plist`를 `plistlib`으로 읽어 키 확인, `git diff --check`. 버전 `1.0.1`이 `publish-ipa.py`의 버전 형식 검사와 맞는지 대조.
- 미실행: `infra/ios-qa` 단위 테스트(Windows에 `fcntl` 없음), Xcode 빌드·Archive(Mac 필요).
- 병합 뒤: Jenkins `eolssu-ios-qa` Ad Hoc 빌드 성공, 설치한 앱 번들의 `ko.lproj` 포함 확인.
- 출시: Mac에서 Release Archive → App Store Connect 업로드 → 1.0.1 버전 생성·빌드 선택 → 심사 제출(사용자). 스토어 '언어'가 한국어인지 확인.
