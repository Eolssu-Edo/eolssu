# S15P31E102-779 홈 기능 카드 그림을 서로 다른 모양으로 바꾸고 카드 제목 키우기

- Jira: S15P31E102-779, Story S15P31E102-109(UI/UX), Epic S15P31E102-1. 담당 오은서.
- 브랜치: `feat(fe)/S15P31E102-779-홈-기능-카드-그림을-서로-다른-모양으로-바꾸고-카드-제목-키우기`, `origin/develop`(2857c0d9) 기준.

## 범위와 완료 조건

- 홈 기능 카드 여섯 개 중 네 개가 모눈종이 그림이라 구별이 어려웠다. 카드마다 다른 그림으로 바꾸고 제목 글자를 키운다.
- 완료 조건: 공유 테스트·JS 컴파일·Android 설치 통과, 에뮬레이터 홈에서 여섯 카드 확인.

## 결정

- 그림은 시안을 여러 차례 거쳐 사용자와 정했다. 절쑤는 한 카드에만 쓰고, 네모 틀 그림이 겹쳐 보이지 않게 카드마다 겉모양을 다르게 했다.
  - 기초 배우기: 연두 세 단 계단 끝의 붉은 깃발(`home_learn_art`). 홈에서 쓰던 `home_tiger`는 완료 대화상자·기초 배우기 지도에서 계속 쓴다.
  - 연습하기: 단소 부는 절쑤(`tiger_play`, 기존 그림 재사용). 쓰지 않게 된 `home_song_art.xml`은 지웠다.
  - 운지법 보기: 악기 고르기와 같은 대나무색·붉은 띠 단소. 마디·취구·관 속을 넣었고, 위 두 지공은 막음(검정), 아래 두 지공은 열림(흰색), 다음에 짚을 곳은 연두 고리다.
  - 정간보 읽기: 정간 한 줄 위에 돋보기를 대고 율명(汰)을 크게 읽는 모양.
  - 연습 기록 보기: 틀 없이 오르는 막대와 선 그래프. 다른 카드의 연두와 겹치지 않게 앱의 파랑(박자 표시 색) 단계를 쓴다.
  - 악보 추가·편집하기: 종이 한 장과 노란 연필.
- 율명 글자는 기기마다 글꼴이 달라지지 않게 앱의 Noto Serif KR SemiBold(OFL) 외곽선을 벡터 경로로 넣었다.
- 그라데이션 대신 띠 여러 겹으로 단소의 둥근 면을 칠해 벡터 XML 기본 기능만 쓴다.
- 카드 제목: 휴대폰 15sp, 태블릿 17sp, 굵게(Bold). 시안의 17sp는 크다고 해서 15sp로 정했다.
