## 목적

1차 AI 평가 4곡(아리랑·도라지타령·밀양아리랑·늴리리야)의 단소 `.jgb.json`을 원본 PDF와 정간마다 대조해 채점 정답으로 승인한다. 아리랑을 먼저 끝내 S15P31E102-156 변환기와 1차 아리랑 연결 검증에 넘긴다.

기준은 노션 "1차 MVP 논의사항"(2026-10-27) 1-1·1-3·4-1·4-2다. 기준음 황=E♭4, 장단 기본 BPM은 원본 값과 따로 적고 jgb의 편집기 기본 BPM은 쓰지 않는다.

## 입력

| 곡 | jgb | 원본 PDF | 원본 ID(등록 예정) |
| --- | --- | --- | --- |
| 아리랑 | `아리랑_단소_최종확정본.jgb.json` | `아리랑_정간보_단소_표준악보집-PDF173.pdf` | `ngc-standard-2022-p173` |
| 도라지타령 | `도라지타령.jgb.json` | `도라지타령_정간보_단소_표준악보집-PDF171.pdf` | `ngc-standard-2022-p171` |
| 밀양아리랑 | `밀양아리랑.jgb.json` | `밀양아리랑_정간보_단소_표준악보집-PDF172.pdf` | `ngc-standard-2022-p172` |
| 늴리리야 | `늴리리야_표준.jgb.json`(D2 확인 후) | `닐리리야_정간보_단소_표준악보집-PDF174.pdf` | `ngc-standard-2022-p174` |

- jgb: `Downloads/정간보_모음 (.jgb.json)/단소/` (노션 DATA 첨부 사본, `_manifest.json`에 SHA-256)
- PDF: `Downloads/단소/`
- 같은 곡의 다른 판본 PDF(학교교과서·단소교실·기존참고악보)는 이번 정답 기준이 아니다. 섞지 않는다.

## 도구

소금 검수(S15P31E102-130)에서 만든 검토 화면을 그대로 쓴다. 새 도구는 만들지 않는다.

```bash
python data/src/scores/review_page.py <폴더>/*.jgb.json --umulsai C:/Users/SSAFY/omr114/jeongganbo-generator --out data/processed/scores/danso-154/review
```

- jgb와 이름 앞부분이 맞는 PDF를 같은 폴더에 둔다. 작업 폴더는 `data/processed/scores/danso-154/`(Git 제외).
- 검토 화면 HTML에는 원본 그림이 들어가므로 공유 위치에 올리지 않는다.
- 끝난 뒤 `python data/src/scores/review_stats.py <검토 기록 폴더> --json <결과.json>`으로 고친 정간 수를 센다.

### 곡마다 하는 일 (U1~U4 공통)

1. 원본 PDF를 `data/raw/scores/<원본 ID>/`에 원래 이름으로 복사하고, [원본 목록](../../data/catalog/collected-scores/sources.json)에 기존 표준악보집 항목(`ngc-standard-2022-p166` 등)과 같은 형식으로 추가한다. 이용 조건은 공공누리 제4유형, `sourceVerified=false`.
2. 검토 화면을 만들고 정간 상자 수가 문서 정간 수와 같은지 확인한다.
3. 사용자가 정간마다 율명·옥타브·위치·이음·쉼·반복·시김새를 원본과 대조해 확인 표시한다. 모르는 기호는 임의로 고치지 않고 확인 항목으로 남긴다.
4. 고친 `.jgb.json`과 검토 기록 `.review.json`을 저장한다.
5. 원본 값(악보에 적힌 장단·빠르기)과 서비스 설정(황=E♭4, 장단 기본 BPM)을 나눠 적는다.

### 완료 조건 (곡마다)

- 검토 기록의 모든 정간에 확인 표시가 있다.
- 정간 상자 수 = 문서 정간 수 = 장단 정간 수 × 각 수.
- 정답 파일 `곡_단소_최종확정본.jgb.json`과 검토 기록을 D3에서 정한 위치에 둔다. `method: manual`, `review: reviewed`, 원본 ID·SHA-256을 함께 적는다.
- 편집 입력본 승인과 채점 정답 승인을 따로 기록한다.
