## 목적·범위·완료 조건

Blue Valentine 최근 변환본의 구간 빠르기가 실제 음원에 반영되지 않는 제보를 조사한다. 저장·재조회 companion → 생성 snapshot → 수행 시간표 → 실제 음원 경계와 길이를 대조한다. 사용자 원본·초안·기존 음원은 읽기 전용으로만 확인한다. 예상 길이는903, 완료 알림은905이며 이번 Task에 편입하지 않는다.

두 구간 이상의 다른 빠르기가 실제 생성 시간과 일치하고 기본 빠르기만 있는 입력도 유지해야 한다. 앱/서버/생성기 버전·고정 입력·명령·관측과 운영 반영 여부를 구분한다. 실기기·iOS·청취 미검증은 통과로 쓰지 않는다. Push·MR·병합·배포·운영 데이터 수정은 범위 밖이다.
