## 선택

- `blacklist_rc`(완전 무시)가 아니라 `override_rc = 0`을 쓴다. 재시작 필요 여부가 로그와 `needrestart -b`에 계속 남아 사람이 나중에 적용할 수 있다.
- 정규식은 `^eolssu-jenkins-(?:[a-z]+-)?agent\.service$`다. 에이전트 4개만 맞고 실패 알림 oneshot(`eolssu-jenkins-notify`)과 다른 서비스는 그대로 둔다.
- 자동 보안 업데이트와 다른 서비스의 자동 재시작은 바꾸지 않는다.
