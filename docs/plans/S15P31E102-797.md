# S15P31E102-797 홈 기능 카드 그림을 단소 그림 느낌으로 통일

- Jira: [S15P31E102-797](https://ssafy.atlassian.net/browse/S15P31E102-797) (Story S15P31E102-109 UI/UX, 에픽 S15P31E102-1)
- 브랜치: `feat(fe)/S15P31E102-797-홈-기능-카드-그림을-단소-그림-느낌으로-통일` (develop `c0ad3802`에서 시작)

## 범위와 완료 조건

- 홈 기능 카드 6개(기초 배우기·연습하기·운지법 보기·연습 기록 보기·정간보 읽기·악보 추가·편집하기) 그림을 사용자가 고른 단소 그림의 느낌으로 맞춘다.
  - 기준: 짙은 갈색 외곽선, 반질한 하이라이트, 아래로 갈수록 진해지는 색, 연한 바닥 그림자.
- 한지 느낌(종이 얼룩 질감·누런 기)은 넣지 않는다.
- 외곽선 굵기는 연습하기 호랑이 다리 선(화면에서 약 0.7dp)에 맞춘다.
- 강조 표시(연두 반짝 선·고리)는 운지법 보기에만 둔다.
- 완료 조건: 여섯 그림의 외곽선 굵기·색감이 맞음, 공유 테스트·JS 컴파일·Android 설치 빌드 통과, 에뮬레이터 홈 화면 확인.

## 결정

- 벡터(XML) 그림 5개를 투명 배경 webp(480px 높이)로 바꿨다. 물감 결이 있는 사용자 제공 그림을 함께 쓰기 위해서다.
- 그림별 출처:
  - 기초 배우기(`home_learn_art`): 기초 배우기 지도의 돌다리처럼 호수 위 징검돌 4개(건넌 돌 연두·아직인 돌 흰 돌빛)와 마지막 돌의 빨간 깃발을 새로 그렸다(SVG → 브라우저 렌더링 → webp).
  - 연습 기록 보기(`home_records_art`): 크림에서 짙은 초록으로 오르는 막대 4개와 남색 꺾은선. 막대 안 흰 선은 없애고 막대 간격을 좁혔다(같은 방법).
  - 운지법 보기(`home_fingering_art`): 사용자 제공 단소 그림.
    - 왼쪽 두 구멍은 막음(검정)·오른쪽 두 구멍은 엶(흰색)으로 고치고, 왼쪽 둘째 구멍에만 초록 고리와 그 위 반짝 표시를 둔다.
    - 셋째 구멍의 고리는 단소 길이 방향의 대나무 색으로 메우고 윗 외곽선을 이어 그었다.
    - 가로로 긴 그림이라 1.15 : 1 판에 둬 다른 그림보다 조금 크게 보이게 했다.
  - 정간보 읽기(`home_score_art`): 사용자 제공 그림(정간 칸 안 黃·太·仲, 돋보기 안 太).
  - 악보 추가·편집하기(`home_edit_art`): 사용자 제공 두루마리·붓 그림. 직접 다시 그린 얇은 종이안은 사용자가 되돌려 쓰지 않는다.
  - 연습하기(`home_practice_tiger`, 새 파일): 사용자 제공의 앉아서 단소 부는 호랑이.
    - 크림색 털·옷은 프로필 호랑이(`profile_tiger_*`) 밝은 면의 채널별 중앙값에 맞춰 따뜻한 흰색으로 바꿨다.
    - 기존 `tiger_play`는 결과·악보 가져오기 화면도 쓰므로 그대로 두고 홈 카드만 새 그림을 쓴다.
- 사용자 제공 그림 처리:
  - 종이 면(밝고 채도 낮은 곳)의 얼룩 질감과 누런 기는 걷어 냈다.
  - 바깥 먹선은 안쪽 면에 붙은 6px(원본 기준, 단소는 5px)만 남기고 바깥쪽을 깎았다.
  - 굵은 검은 면(붓 쇠테·먹 자국·글자)과 가는 붓 고리는 건드리지 않았다.
- 모든 그림은 알파 기준으로 내용 테두리를 잘라 여백 4%만 남겼고, 카드 안 그림 칸 높이를 96dp에서 112dp로 키웠다(`FeatureSection`).
- Jira 본문의 '카드 상자 옅은 그림자'는 이번 변경에 넣지 않았다.
