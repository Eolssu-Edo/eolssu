## 3차: 1단계 '악기 알기' 따라 배우기 (11-09, 미커밋)

- 결정: 1단계 주 버튼을 '학습 시작'으로 바꾸고, 누르면 악기 그림에서 취구 → (청공) → 손가락 구멍 → (칠성공)을 차례로 동그라미로 짚으며 한 줄 설명을 보인다. 아래 버튼은 '이전 · 다음', 마지막 곳에서 '다 익혔어요'. 끝나면 호랑이가 튀어 오르는 '완료했어요!' 창을 띄우고 '다음 단계로'는 기존 '확인하고 다음 단계'와 같이 1단계 완료 표시 뒤 2단계로 간다.
- 짚는 곳의 이름·손 위치·좌표는 운지 그림 구멍 좌표와 같은 앱 쪽 안내라 `LearnFirstTour.kt`에 둔다. 서버의 1단계 부분 이름(`parts`)은 화면에서 쓰지 않는다. 서버 진도·API 계약은 그대로다.
- 손 위치: 단소는 뒷구멍 왼손 엄지, 1·2공 왼손, 3·4공 오른손. 소금·대금은 1·2·3공 왼손, 4·5·6공 오른손.
- 진행 단계는 `rememberSaveable`로 회전 뒤에도 이어지고, 가로 배치에서 다른 단계를 고르면 처음부터 다시 한다.
- `home_tiger.webp`는 좌우 투명 여백을 잘라 384×313 → 289×313으로 줄였다. 높이가 같아 홈 카드·산길 지도·완료 창의 호랑이 크기는 그대로다(모두 `Fit`).
- 짚는 곳 좌표는 네 악기 그림 위에 겹쳐 그려 취구·청공·칠성공·구멍 위치와 맞는지 확인했다. `LearnFirstTourTest`는 좌표가 그림 안에 있고 손가락 구멍을 순서대로 한 번씩 짚는지, 이전·다음이 범위를 벗어나지 않는지 검사한다.

Pixel 7 Android 15 에뮬레이터에서 임시 고정 데이터 화면(검증 뒤 되돌림)으로 단소·정악대금 1단계의 시작 전 부분 이름, 학습 시작·다음·다 익혔어요, 짚는 곳 동그라미, '완료했어요!' 창과 '다음 단계로'의 완료 콜백(`onConfirm(1)`)을 확인했다. `git diff --check` 통과.
