# S15P31E102-619 기초부터 배우기 2·3단계 할 일별 따라 배우기

- Jira: S15P31E102-619, Story S15P31E102-316, Epic S15P31E102-17. 1단계 따라 배우기(S15P31E102-565)를 이어 쓴다.
- 결정(사용자 확인 11-09): 2·3단계도 '학습 시작' 뒤 서버 할 일을 한 칸씩 넘기며 그림과 한 줄 설명을 보인다. 할 일 문구는 서버 그대로이고 서버 진도·API 계약은 바꾸지 않는다.
    - 2단계: 앉은 자세(단계 그림) → 악기 잡기(왼손 빨강·오른손 연두 구멍 동그라미) → 복식호흡(4초 들이쉬기·4초 내쉬기 동그라미). '다 익혔어요' → '완료했어요!'(바른 자세와 숨쉬기를 익혔어요) → 완료 표시 뒤 3단계.
    - 3단계: 취구에 입술 대기(취구 동그라미) → 입김 방향·세기 찾기(단계 그림) → 한 소리 길게 내기(첫 음 운지 카드). 마지막 칸의 주 버튼은 '연습 시작'. 시작 전 아래 버튼은 '완료로 표시 · 학습 시작'이다.
    - 그림은 서버 할 일 순서와 짝 짓고(`taskVisual`), 할 일이 더 오면 단계 그림을 보인다. 손 구분은 1단계 짚는 곳의 손 안내를 그대로 쓴다(`leftHandHoles`·`rightHandHoles`).
    - 3단계 따라 배우는 동안은 마지막 칸과 겹치는 '소리가 나면' 첫 음 카드 구획을 숨긴다.
- 611(4~8단계 자동 통과)의 `LearnPractice*`는 고치지 않았다.
- 검증(11-09, Windows): `gradlew.bat :shared:testAndroidHostTest :shared:compileKotlinJs :androidApp:assembleDebug` 성공(호스트 테스트 1125개 실패 0, `LearnTaskTourTest` 5개·`LearnFirstTourTest` 3개 포함).
    - Pixel 7 Android 15 에뮬레이터, 로그인 계정·실제 서버(단소): 2단계 학습 시작 → 세 칸 → 다 익혔어요 → '다음 단계로'로 3단계 이동, 목록이 1/8 → 2/8 완료로 바뀌어 완료 저장 확인. 3단계 세 칸과 마지막 칸 '연습 시작' 표시 확인('연습 시작'은 누르지 않음).
    - 같은 에뮬레이터에서 임시 고정 데이터 화면(검증 뒤 되돌림)으로 소금·정악대금 2단계 손 위치 동그라미가 겹치지 않음을 확인했다.
- 남은 일: 태블릿 가로 배치·화면 회전 뒤 진행 유지, Android 실기기, iOS(Mac) 확인.
