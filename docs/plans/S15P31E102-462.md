# S15P31E102-462 내 악보 빈 악보·복사 생성 API 제거

- 이전 작업 S15P31E102-390(SHT-03 구현), S15P31E102-413(편집 저장·자동 저장·삭제).
- 기준 origin/develop af36906f(OpenAPI 경로 등록은 S15P31E102-463에서 먼저 병합됨), 브랜치 `refac(be)/S15P31E102-462-내-악보-빈-악보·복사-생성-API-제거`.

## 목적

- 2026-11-03 결정으로 내 악보는 정간보·오선보 PDF·이미지 불러오기(SHT-07, 미구현)로만 만든다. 작업 취소된 SHT-03 `POST /api/users/me/sheets`(`startType` BLANK·COPY)와 그것만 쓰던 코드를 지워 죽은 코드를 남기지 않는다.

## 범위

- 지움: `CreateUserSheet`(`SheetStartType`·명령·결과), 컨트롤러 POST와 요청·응답 DTO(`CreateUserSheetRequest`·`CreatedSheet`), `createUserSheet` Bean, OpenAPI `post /api/users/me/sheets` 계약.
- 생성에만 쓰던 저장소·매퍼: `findByIdempotencyKey`, `findSongSource`, `insert`(+ `NewUserSheet`·`SongCopySource`·`SongCopySourceRow`·`UserSheetInsert`, XML 문장 3개), `SHEET_KIND_JEONGGANBO`·`SHEET_SOURCE_MANUAL`, 재전송 비교에만 쓰던 `UserSheet.requestHash`(조회 열에서도 뺌), `SheetScores.copy`·`CopiedScore`.
- 유지: SHT-01·08·04·11·02, 본문 상한 필터, 탈퇴 삭제. `findJangdan`은 SHT-04가 쓴다. 제목 상한 50은 `EditUserSheet.MAX_TITLE_LENGTH`로 옮겼다.
- 범위 밖: DB 스키마. V16 `idempotency_key`·`request_hash` 칸과 유일 제약, V20은 그대로 두며 기존 MANUAL 행은 읽기·편집·삭제할 수 있다.

## 결정 (2026-11-04)

- 같은 경로 POST는 처리기가 없어 405 `METHOD_NOT_ALLOWED`다.
- DB 테스트는 만들기 API 대신 그 API가 만들던 행(빈 악보, 게시 곡 악보를 `score.scoreVersion` 1로 옮긴 사본)을 `JdbcTemplate`으로 바로 넣는다.
- 생성 규칙만 보던 테스트(멱등 재전송·동시 요청, 복사 버전 초기화·숨김 곡·장단 불일치·음표 수 불일치)는 지웠다.
- `idempotency_key`·`request_hash`가 NOT NULL이라 SHT-07이 행을 만들 때 값을 정해야 한다. 칸을 지울지는 SHT-07에서 정한다.
