## 계약과 검증 순서

1. Android QA 패키지에서만 typed 이벤트 sink 활성화. 입력 원문·길이·오류 원문·URL·본문을 받지 않는 이벤트 계약.
2. Activity는 전달을 변경하지 않고 DOWN/UP/CANCEL·포인터·키 동작을 관측한다. MOVE는 종료 요약만 저장한다. 콜백 실행과 기능 성공은 분리한다.
3. 공통 컨트롤·화면 이동, 로그인 분기, 기초 콘텐츠 및 실제 재생/녹음 상태를 연결한다. 확정되지 않은 인과관계는 estimated로 표시한다.
4. 기존 비동기 SQLite와 읽기 전용 사본 수집을 유지한다. 원본 ACK·삭제 명령으로 수집하지 않는다. 보존 한도는 별도 versioned retention floor로 전달한다.
5. 웹 조작별 묶음·원본·필터·누락/미지원/수집대기 표시를 검증한다.
6. Android 공통/앱 테스트와 빌드, 기존 중계 전체 테스트. S10 USB 우선 및 태블릿 TLS identity/설치 버전·서명·데이터 보존 확인.
7. 기존 Chrome 문서를 유지한 신규 로그·영상, 성공/실패/민감 입력·단절 복구 실측. 직접 손 조작·가청 소리·마이크는 사용자 실측이 필요한 부분을 별도로 기록한다.
