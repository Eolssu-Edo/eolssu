# S15P31E102-698 내 악보 검토 전 열람과 저장 안내 개선

- 상태는 진행 중. Story 319, 스프린트 5, 기준 커밋 `1bcbc86d`.
- [내 악보 스펙](../specs/user-sheets.md#내-악보-검토-전-열람)에서 열람과 연습의 진입 조건을 구분한다.
- 목록의 상태 표시와 선택 동작을 맞추고, SHT-08 응답의 저장 악보 또는 변환 초안을 기존 정간보 렌더러로 읽는다.
- 편집 저장 안내는 실제 저장 응답을 따른다.

## 검증 계획

- 저장 악보가 있는 검토 대기 곡과 변환 초안만 있는 곡 모두 열람되는지 확인한다.
- 검토 완료 악보는 기존 연습 화면을 열고, 변환 중·실패 악보는 기존 상태 동작을 유지하는지 확인한다.
- Android 호스트 테스트와 디버그 APK 빌드를 실행한다.


## 검증 결과

- Android 호스트 테스트 1,242개 중 1,238개 통과, 4개 건너뜀. Android 디버그 APK 빌드 성공.
- 독립 Android 에뮬레이터와 루프백 응답으로 검토 대기 악보 두 종류(저장 문서, 미입력 정간이 있는 변환 초안)가 목록에서 열리고 율명이 보이는 것을 확인했다.
- 열람에서 ‘검토 및 편집’으로 진입하고 ‘편집 내용 확인’에서 저장 동작을 찾을 수 있었다. 검토 완료 행은 기존 연습 화면을 열었다. 검증 과정의 악보 요청은 조회만 발생했다.
- 목록 상태가 오래된 경우 최신 조회 응답에서 연습 가능 상태를 확인한다. 검토 상태별 저장 안내와 변환 미완료 응답은 호스트 테스트에서 확인했다.
- 운영 데이터와 실기기 QA 앱은 로컬 검증 대상에서 제외했다.
