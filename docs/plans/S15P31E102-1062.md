# S15P31E102-1062 정간보 스캔의 시김새 인식 범위 확대

- Jira: S15P31E102-1062 · 스프린트 59321 · 진행 중(메인 세션이 배정·전환).
- 기준: `origin/develop` `9ca7e29a0`. 1058(!923)은 이미 develop에 병합돼 그 위에서 시작했다. 1059·1060·1061 MR도 `jeongganbo_scan.py`를 고친다(`ENGINE_VERSION` 충돌 예상).

## 범위

- 공통 악보 의미를 바꾸지 않는 부분만 구현한다: 이음에 붙은 시김새 보존, 율명 오른쪽 시김새 획(물결선·`)`·`^`·`И`) 보정.
- 쪽 그림 전처리(1059), 칸·각·`cellId` 조립(1060), 신뢰도 기준(1061)은 건드리지 않는다.

## 결정

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| 재학습 | 하지 않는다 | 놓친 시김새가 모두 모델 어휘에 있고, 물결선 18개 중 11개는 자리를 맞혔다. 모양 규칙으로 대부분 고칠 수 있었다 |
| 보정 위치 | DATA 리더 `jeongganbo_omr.py --side-marks`(`side_marks.py`) | 칸 그림과 모델 원문이 함께 있는 곳이다. `octave_check`의 물수변 복원과 같은 자리에서 돈다 |
| 붙이는 자리 | 한 줄에 율명 하나만 있는 자리 | 반칸 줄은 기호가 어느 음 것인지 모양으로 정하기 어렵다. 잘못 붙은 시김새는 그 음의 음높이 채점을 없앤다 |
| 짧은 물결선 이름 | 같은 쪽에서 모델이 물결선에 붙인 이름을 따르고, 없으면 풀어내림표 | 실기교재 정답은 풀어내림표, 진도아리랑 교재 정답은 농음표로 같은 모양을 다르게 적었다 |
| `И` 이름 | `니나*` 토큰(우물사이 `{니나}`) | 정답 표기와 앱 그림(`И`)이 같다. 모델의 붙임 니나는 `{니라}`(`ㅅ`)가 된다 |
| 율명 없는 독립 기호 | 결정 대기, 구현하지 않음 | 공통 악보 의미 변경이다. 선택지(버림·이음+앞 음 시김새·실제 음으로 펼침)와 영향을 메인 세션에 보냈다(2026-11-17) |
| 시김새 평가 도구 | `data/src/scores/sigimsae_eval.py` 추가 | 저장소 정답(`data/annotations/scores`)으로 누구나 다시 잴 수 있게 한다 |

## 검증

- 실제 모델(실기교재 10곡 45개): 맞음 13 → 39, 정답에 없는 시김새 15 → 3(남은 3개는 모델 출력), 놓침 32 → 6. 진도아리랑 교재 16개: 5 → 16. 곡별 값·조건은 [OMR 대조 기록](../knowledge/data/jeongganbo-omr-accuracy.md#시김새-획-보정-1062).
- 서비스 API 경로(고사리꺾자 PNG): 공통 악보 시김새 풀어내림표 5·흘림표 1로 정답과 같다. 정악풍 대금교실 15는 보정 전후 시김새가 같다.
- 자동 테스트: `ai/tests/unit/test_omr_scan_engine.py` 26개(Node 변환기 포함), `data/tests/test_side_marks.py` 11개, `test_sigimsae_eval.py` 3개, `test_scan_register_cli.py`·`test_scan_register.py`·`test_grid_boxes.py`를 합친 DATA 스캔 테스트 60개 통과. `test_score_data.py` 51개 통과(변환기 무변경 확인).
- 하지 않은 것: 국악원 정악보 스캔(이 PC에 없음), 서비스 컨테이너 안 실행, 앱 화면 확인.
