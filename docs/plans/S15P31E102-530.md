## 확정 범위와 완료 조건

1. 연습 기록 선택은 해당 sessionId의 단독 평가·오류 위치 화면으로 이동한다. 휴대폰·태블릿 모두 동일하다.
2. EVA-01 평가의 id·songId·악보 판본을 대조하여 다른 결과를 표시하지 않는다. 로딩·누락·실패·재시도를 제공한다.
3. 곡에 연결된 instrumentId로 기존 악기 카탈로그의 이름을 조회한다. 현재 회원의 선택 악기나 고정 단소를 사용하지 않는다. 악기 조회 실패는 평가 표시를 막지 않는다.
4. 기존 오류 위치 화면과 점수 항목 부품을 재사용한다. 녹음 재생·비교는 명시적인 별도 진입으로 보존한다.
5. 비교 화면 구현, 정간보 크기·오류 표시 디자인, 서버 API 계약은 변경하지 않는다.
