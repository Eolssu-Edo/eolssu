## 판단 근거

2026-11-05 운영 Android QA #107에서 `:shared:testAndroidHostTest`의 JUnit 905개, 실패 0개와 공통 `LearnViewModelTest` 실행을 확인했다. 브라우저 대상의 JS·Wasm 테스트는 수동 웹 잡에 둔다. 백엔드 배포 도구, 인증서와 Nginx 공통 검사는 웹 배포 여부와 무관하게 유지한다.

운영 백엔드 정의에는 저장소 공통 파일과 별도로 Android QA·iOS 예약 단계가 있다. 운영 반영 후보는 실제 정의에 같은 범위의 변경을 적용해 두 모바일 단계가 보존되는지 확인한다. 운영 상태와 설정은 적용 단계에서 별도로 확인한다.

## 검증

- 수정 전 검사는 웹 자동 예약, 백엔드 사전 검사 경로, 수동 SHA 이력 확인의 세 조건에서 실패했다. 수정 후 검사 9개가 통과했다. 임시 Git 이력에서 develop tip과 이전 develop SHA를 허용했고 미병합 SHA를 거부했다.
- 배포 도구 전체 58개, 인증서 초기화 8개, Nginx health 경로 6개, HTTPS 리다이렉트 7개가 통과했다. 세 Nginx 검사에는 `RUN_NGINX_TESTS=1`을 적용했다.
- 실제 Jenkins 컨트롤러에서 저장소 백엔드·프론트 정의와 운영 백엔드 후보가 선언형 문법을 통과했다. 운영 후보의 develop polling, Android 예약, iOS 변경 감지와 백엔드 배포 단계를 기존 정의와 대조했다. 운영 프론트와 저장소 기준의 차이는 빈 줄뿐이었고, 수동 웹 후보의 웹 배포 도구·브라우저 테스트·배포 단계는 기존 운영 정의와 일치했다.
