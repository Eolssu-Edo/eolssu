## 계획

1. 남은 높이에 맞춘 짧은 각 묶음·3소박 정간 높이를 작은 함수와 자동 검사로 구현한다.

## 설계

고정 3각이 화면을 넘치는 경우 글자를 과도하게 줄이지 않고 들어가는 묶음 수를 선택한다.

## 후속 수정: 가로줄 시작 높이 정렬

사용자 확인에서 묶음별 자연 높이 누적으로 2·5·8각, 3·6·9각의 윗부분이 어긋난 점을 지적했다.
기존 묶음별 쌓기를 가로줄별 최대 높이 공유로 대체한다.
1·4·7·10…각 / 2·5·8·11…각 / 3·6·9·12…각의 시작 높이를 맞추고, 공유 높이를 포함해 화면에 들어가는지 계산한다.
일부 각만 남은 마지막 묶음과 도라지타령의 3각 배치를 자동 검사하고 실제 화면을 다시 확인한다.

- 새 회귀 검사 2개가 기존 구현에서 assertion 실패하는 것을 확인한 뒤 수정했다.

  줄 사이 간격은 6dp로 맞추고 줄마다 픽셀 반올림 여유 2dp를 포함해 3각 배치를 유지한다.

  준비 화면의 2줄과 연주 화면의 3줄에서 각 머리글 시작점이 같은 수평선에 놓이는 것을 확인했다.

## 후속 수정: 입력 없음 안내와 각 하단 정렬

- 사용자 요청: 입력 없음 안내가 나타나도 악보 위치를 유지하고, 같은 가로줄의 각은 가장 긴 각에 맞춰 정간을 늘려 하단도 정렬한다.
- 원인: 하단 안내를 조건부로 추가해 본문 높이가 바뀌며, 공유 가로줄 높이는 각 바깥 공간만 예약하고 실제 정간 높이는 원래 값으로 그렸다.
- 구현: 안내의 실제 크기를 항상 확보하고 숨길 때 접근성 정보도 숨긴다. 각의 정간 높이를 가로줄 최대 높이에 비례해 늘리며 소박 높이 비율·원본 좌표·기존 분할 악보는 유지한다.
- 검증 예정: 서로 다른 소박·정간 수와 마지막 묶음·1각 배치의 실제 각 높이 회귀 검사, 전체 Android 호스트 검사·APK 빌드, 가능한 에뮬레이터 화면 확인.
- 새 회귀 검사 2개가 이전 구현에서 각 하단 높이 불일치·일반 정간 높이 미지정으로 실패하는 것을 확인했다.

  정간 수가 다른 각·3소박 비율·마지막 불완전 묶음·한 각 배치의 하단 정렬을 포함한다.
