# Android 런처 아이콘 크기·잘림 보정

- Task: S15P31E102-522 · Story: S15P31E102-109 · Epic: S15P31E102-1.
- 범위: Android 적응형 아이콘 전경. 로고 전체를 보이게 하고 사용자가 제공한 참고 아이콘에 가깝게 여백을 줄인다.
- 기준: 최신 작업 시작 시 `origin/develop`의 `e62970d0`. 작업 브랜치에서만 반영했으며 develop 반영과 구분한다.

## 선택과 근거

- 2026-11-06 사용자 사진에서 최초 수정은 잘림이 남았고, 108dp 투명 캔버스를 추가한 46×43dp 배치는 전체 로고가 보이지만 너무 작다고 확인됐다.
- 캔버스는 108×108dp를 유지하고 로고를 60×55.375dp로 키운다. 원본 480×443 비율을 유지한다.
- Android 8 이상은 기존 adaptive-icon의 배경·전경 구성을 유지해 런처가 크기와 마스크를 적용한다. S25+ 전용 분기는 추가하지 않는다. 런처별 바깥 모양·사용자 아이콘 설정은 다를 수 있다.
- [Android 적응형 아이콘 공식 가이드](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)의 중앙 66dp 안전 영역을 기준으로 검사한다. iOS 아이콘과 Android 7 레거시 리소스는 이번 변경 대상이 아니다.

## 검증

- 2026-11-06: Pillow로 원본의 알파 >32, RGB 최솟값 <245인 픽셀 중심을 실제 XML의 배치 크기로 변환했다. 중앙에서 가장 먼 로고 픽셀은 32.3671dp로 안전 영역 반지름 33dp 이내였다. 흰 배경 픽셀을 로고로 세지 않는다.
- `:androidApp:assembleDebug --offline`: 성공. XML 리소스 컴파일과 APK 생성 확인.
- 46×43dp 버전의 S25+ 전체 표시 여부는 사용자가 제공한 사진에서 확인했다. 60×55.375dp 버전의 S25+ 최종 시각 판정과 다른 기기 실기기 검증은 미확인이다. 수치 검사·빌드 성공을 실기기 시각 검증으로 취급하지 않는다.

## 남은 일

- S25+에 확대 버전을 설치한 뒤 최종 크기 확인.
- 다른 Android 런처에서 원형·둥근 사각형 표시 확인. Push·MR은 별도 요청 시 진행.
