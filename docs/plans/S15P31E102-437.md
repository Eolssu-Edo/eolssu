## 요청

- 스크롤 전: 상단 로고·현재 악기·프로필 판을 숨긴다. 다 펼치면 현재 악기·프로필 판만 더 투명한 바탕으로 보이고, 왼쪽 위 로고는 없앤다.
- 현재 악기 기본은 단소. 누르면 단소·소금·산조대금·정악대금 드롭다운.
- 히어로 '얼쑤!'를 흰 로고로, '우리 소리와 가까워지는 시간'은 지우고 글자 위치를 조금 내린다.
- '악보 추가·편집하기'를 연습곡 선택하기 안에서 HOME 카드로 뺀다.
- 카드 순서를 정해 2×3으로 둔다. 기억나지 않던 다섯 번째 카드는 428 브랜치의 '연습 기록 보기'였다.

## 결정

- 카드 순서(2열): 기초부터 배우기·연습곡 선택하기 / 운지법 보기·정간보 쉽게 읽기 / 악보 추가·편집하기·연습 기록 보기. 배우기 → 곡 고르기 → 운지·악보 읽기 → 내 악보 만들기·기록 보기의 흐름으로 정했다. 태블릿 세로는 같은 순서를 3열(3×2)로 둔다. 428의 가로 카드와 `HomeFeatureHighlight`는 없앴다.
- 구역 제목은 428에서 바꾼 '학습·연습하기'를 유지했다. 이번 요청 본문은 '연습·학습하기'로 적었지만 명시적 변경 요청이 아니라 보았다.
- 상단 판은 `HomeScrollFrame.headerAlpha`(진행률 50%→90% 동안 0→1)로 나타나며 0이면 그리지 않아 첫 화면에서 눌리지 않는다. 판 바탕 불투명도는 0.93 → 0.62.
- 상단 판은 스크롤 상자(`verticalScroll` Column) 밖의 오버레이로 두어 위 12dp(`HomeHeaderTop`)에 붙고, 낮은 화면에서 카드 끝까지 더 스크롤해도 그 자리에 남는다. 처음 구현은 무대 안 56dp에 두어 추가 스크롤 때 함께 올라갔는데, 2026-11-03 첫 Push 전 사용자 요청으로 바꿨다.
- 악기 드롭다운은 운지법 화면의 드롭다운과 같은 모양(Popup, 48dp 줄, 고른 줄 연두 바탕)으로 홈 컴포넌트에 두었다. feature 간 참조가 금지라 guide의 구현을 가져오지 않았다. 선택 절차는 마이페이지와 같아야 해서 `UserRepository.changePracticeInstrument`(data/user)로 뽑아 `MyPageViewModel`·`HomeViewModel`이 함께 쓴다. 서버가 반영한 뒤에만 로컬 악기를 바꾸고, 401이면 로그아웃 후 로그인 화면으로 간다.
- 악기를 아직 확인하지 못한 상태(`instrument == null`)는 요청대로 단소로 표시한다. 이때 단소를 고르면 서버에 저장 요청을 보낸다.
- 히어로는 `EolssuLogo(tint = Color.White)`(96×50dp) + '나도 이제 국악인' 한 줄. 제목 기준선은 버튼·그림 띠에서 20dp → 10dp 위로 내렸다. `home_hero_body` 문자열은 삭제했다.
- '악보 추가·편집하기' 카드는 `my-songs?sheets=true`로 가서 내 악보 탭을 먼저 보인다(추가 버튼과 편집이 모두 그 탭에 있다). 시트를 자동으로 열지는 않는다. `MySongsViewModel.showSheetsFirst`는 사용자가 탭을 고른 뒤에는 되돌리지 않는다.
- 새 카드 그림 `home_edit_art.xml`(악보 + 연필 + 더하기 배지)은 기존 카드 그림 스타일로 임의로 그렸다. 설명 문구 '내 악보를 만들고 고쳐요'도 임의다.
