# S15P31E102-641 악보 변환 완료 상태 조회 테스트 실패 수정

- [Jira 작업](https://ssafy.atlassian.net/browse/S15P31E102-641) · Story S15P31E102-318 · Epic S15P31E102-15
- [SHT-10 계약](../specs/user-sheets.md#불러오기-접수변환-상태-s15p31e102-471) · 기준 `32788549`

변환 상태 조회 테스트는 단독 실행에서 통과했다. 전체 실행에서는 조회 간격이 3,000ms로 계산됐지만 테스트 시계를 30초 더 진행해도 다시 조회하지 않았다. 당시 조회 코루틴은 실제 브라우저의 `Dispatchers.Main.immediate`에서 대기했다.

- [x] 결과 저장 테스트 4개가 `runTest`의 `TestResult`를 반환하도록 했다. 이전에는 브라우저 테스트 러너가 완료를 기다리지 않아 뒤늦은 `resetMain()`이 다음 테스트의 가짜 메인 디스패처를 해제했다.
- [x] 기존 악보 변환 테스트와 결과 저장 테스트를 포함한 JavaScript·Wasm 전체 검사에서 각각 1,143건이 통과했다. `frontend`에서 `./gradlew :shared:jsTest :shared:wasmJsTest`를 실행했다.
