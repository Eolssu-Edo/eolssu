# S15P31E102-661 연주 평가 결과 표시와 완료 감지 대기 단축

- [Jira](https://ssafy.atlassian.net/browse/S15P31E102-661) · [평가 결과 화면 Story](https://ssafy.atlassian.net/browse/S15P31E102-37)
- 기준 `origin/develop f2bf0a2b`. 별도 피처 worktree에서 구현한다.
- 범위는 평가 흐름의 곡 재사용과 점수 우선 표시, 분석 완료 폴링이다. 실기기 성능 계측은 후속 범위다.

## 구현 순서와 완료 조건

1. 분석 대기 초기 8초에는 성공한 PENDING 응답 뒤 1초 간격, 이후 2초 간격으로 조회한다. 응답 실패, 앱 복귀 및 70초 무응답 판정은 기존 계약을 유지한다.
2. 연습에서 표시한 곡을 분석과 결과에 전달한다. 결과의 회원 소유권은 기존 API가 확인하고, 곡 ID와 악보 버전이 일치할 때만 사용한다. 복구·직접 진입·버전 불일치에는 정상 조회 경로를 사용한다.
3. 평가 API의 총점과 항목별 점수를 상세 악보보다 먼저 표시한다. 상세 조회 실패는 점수와 함께 재시도할 수 있고, 상세 기능은 검증한 곡이 준비되면 활성화한다.
4. 기존 폴링·결과 테스트와 실제 평가 저장소 HTTP 대역으로 간격, 선표시, 악보 버전·재시도 경계를 확인한다.

## 검증 기록

- 기존 코드에 새 폴링 테스트를 적용했을 때 초반 간격이 2초로 관측되어 테스트가 실패했다.
- 변경 후 `./gradlew :shared:jsTest :webApp:jsBrowserDevelopmentWebpack` 통과. ChromeHeadless 공통 테스트 1,170개, 실패 0개.
- 로컬 웹 앱의 `#result/41`에서 평가 API는 총점 81·항목 90/70/77, 곡 API는 보류 후 503으로 응답하게 했다. 390px 화면에서 곡 응답 전 점수가 보였고, 1024px 화면에서 503 뒤에도 점수가 남았다. 재시도 버튼을 눌러 평가와 곡 요청이 다시 발생했으며 브라우저 실행 예외는 없었다.
- `./gradlew :shared:wasmJsTest` 통과. ChromeHeadless 공통 테스트 1,170개, 실패 0개.
- Android 호스트 테스트는 이 Mac에 Android SDK가 없어 실행하지 못했다. 실기기 녹음 업로드부터 첫 점수까지의 전후 시간은 측정하지 않았다.

구현 및 로컬 검증 완료. 독립 리뷰와 실기기 검증 대기.

## Android 리뷰 후속과 빌드

- 곡 조회가 실패하면 현재 평가 화면이 인증된 평가 응답을 보관한다. '곡 정보 다시 불러오기'는 같은 평가의 곡 조회와 매핑만 반복한다. 로그인 세대가 바뀌면 보관 상태를 비우고 이전 평가의 상세 로딩도 거절한다.
- '같은 곡 다시 연습'은 스택의 직전 화면이 해당 곡의 연습일 때 그 화면으로 돌아간다. 홈의 남은 녹음 보내기에서 결과로 온 경우에는 결과를 닫고 해당 곡 연습 화면을 연다. Android 진입점과 두 화면 스택을 코드에서 대조했다.
- Android 호스트 회귀 테스트는 수정 전 평가 요청이 두 번 발생해 실패했고, 수정 후 평가 요청 1회·곡 요청 2회와 점수 복구를 확인했다. 동일 회원의 재로그인 뒤 이전 상세 조회가 취소되는 검사도 통과했다.
- 임시 Android SDK API 37을 사용해 `ANDROID_HOME=/tmp/eolssu-661-android-sdk ./gradlew :shared:testAndroidHostTest :androidApp:assembleDebug`를 실행했다. Android 호스트 테스트 1,192개 통과, 실패 0개. 선택 카탈로그 검사 4개는 실행 조건이 없어 건너뛰었다.
- 디버그 APK는 `frontend/androidApp/build/outputs/apk/debug/androidApp-debug.apk`에 생성됐다. `apksigner verify`에서 APK 서명 v2를 확인했다. SHA-256은 `9d8c9982e305e3712bc9c677ab207216639282f6499ffe5866720ba6727ac2f6`이다.
- 변경 범위의 코드 리뷰에서 추가 수정 항목은 발견하지 않았다. 연결된 기기가 없어 APK 실행과 실기기 타이밍은 미확인이다.
