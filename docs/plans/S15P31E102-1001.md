# S15P31E102-1001 악보 편집 시김새·장단·구간 빠르기 사용 안내

- Story S15P31E102-319 · 스프린트 5 · 진행 중
- 기준 develop 4941bb2b1. 1000의 빠르기 입력 수정이 병합된 상태다.

## 범위와 완료 조건

1. 시김새 탭에서 율명과 옥타브의 차이를 예로 안내한다. 율명 선택·입력 방식과 붙일 수 있는 위치는 기존 동작을 따른다.
2. 장단 변경이 지원되지 않는 편집 상태에서 장단 버튼을 누르면 해당 악보에서는 변경할 수 없음을 알린다. 기존 장단 선택 창은 지원되는 악보에서 그대로 연다.
3. 빠르기 창에서 전체 빠르기와 구간 빠르기의 차이, ‘바로’와 ‘점점’의 적용 시점을 설명한다. 구간 빠르기가 있는 악보의 정간·각 도구에는 배치를 바꾸려면 구간 변경을 먼저 삭제해야 한다는 안내를 보인다.

공유 테스트·Android 빌드·Wasm 컴파일을 실행하고 Android에서 해당 탭, 빠르기 창과 조건별 안내를 확인한다.

## 검증

- 2026-11-16 공유 테스트 1,896개 중 1,891개 통과, 5개 건너뜀, 실패·오류 0건. Android 디버그 빌드와 Wasm 컴파일 성공.
- Android 15 `emulator-5554`에 새 디버그 APK를 설치하고 패키지 갱신 시각을 확인했다. UI 덤프가 재시도 후에도 종료되어 안내 문구 노출은 현 APK에서 미확인이다.
- 장단을 바꿀 수 없는 편집 상태에는 버튼을 유지하고, 눌렀을 때 해당 악보에서 장단을 바꿀 수 없다는 안내를 보이도록 선택했다.
