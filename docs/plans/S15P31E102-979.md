## 범위와 완료 조건

1. 첫 진입 안내 카드 `확인할 게 N가지 있어요`: 할 일마다 흰 칸 하나를 둔다. 음역 칸은 `소금으로 낼 수 없는 음 N개`와 결과까지 말하는 버튼(`6반음 올려서 모두 고치기`, 일부만 풀리면 `…올려서 K개 고치기`), 인식 칸은 `다시 볼 곳 N곳 · 악보를 잘못 읽었을 수 있어요`와 `보러 가기`다. 반음 수는 지금 적용된 높이에서 추천까지의 차이다. 닫으면 이번 화면에서는 다시 띄우지 않는다.
2. `추천 적용`: 편집 전이면 확인 창 없이 바로 적용하고 되돌리기로 원래 악보로 돌아간다. 편집 뒤에는 기존 덮어쓰기 확인을 거친다. 적용한 추천은 다시 권하지 않는다.
3. 표시 구분: 음역·운지만 문제인 칸은 갈색 점선 테두리와 `↕`, 인식·구조 문제는 기존 빨간 `!`를 유지한다. 한 칸에 둘 다 있으면 `!`가 우선한다.
4. AI 변환: 마디 길이 검수(`OVERFULL_MEASURE` 등)는 성부마다 마디 첫 음에만 남긴다. 사라진 꾸밈음(`ORNAMENT_DROPPED`)은 전용 문구로 안내한다.
5. 이조 슬라이더의 추천 표식: 4dp 검은 마름모와 아래 범례 대신, 칸 위에 앱 초록 `추천` 칩 하나를 두고 아래 꼭짓점이 해당 칸을 가리킨다. `최소`(이조 폭 최소) 표식은 초보자가 뜻을 알기 어렵다는 사용자 의견으로 빼고, 양끝 칸 점은 둥근 막대 밖으로 삐져나와 그리지 않는다. −·+는 막대와 같은 줄에 둔다.
6. 편집의 음역 맞추기에서 악기 선택을 뺀다. 악기는 악보를 만들 때 고르므로 이름만 보여 준다.
7. 같은 화면 반주 선택 창의 `장단 선택` 제목·안내 글자를 창 본문과 같은 크기·색으로 맞추고, `반주 없이` 등 장단 버튼 글자를 위아래 버튼처럼 가운데에 둔다.

저장 형식·API·원본 음고 계약은 바꾸지 않는다.
