## 1. 목표와 완료 조건

웹은 `SheetAudioDeviceStore`가 `UnavailableSheetAudioDeviceStore`라서 내 악보 연습의 재생 자리에 '재생을 지원하지 않아요'만 보였다. 음원 생성 완료 배너도 웹에서는 편집기로 갔다.

Jira 완료 조건:

1. 웹에서 내 악보 연습 화면의 반주 음원이 재생된다.
2. 음원 생성 완료 배너가 웹에서도 내 악보 연습으로 이동한다.
3. `:shared:compileKotlinWasmJs` 통과, 관련 commonTest 통과.

## 2. 결정 (사용자, 2026-11-24)

| 항목 | 선택 | 근거·영향 |
| --- | --- | --- |
| D1 듣는 방식 | SHT-13 서명 URL을 `<audio>`로 바로 재생 | R2 설정을 바꾸지 않는다. 구현 중 서버가 완료 10분 뒤 링크 발급을 멈추고 파일을 지운다는 사실(`docs/specs/sheet-audio.md` 684 절, 백엔드 `SheetAudios.DOWNLOAD_WINDOW`)을 확인해 다시 물었고, 10분 제한을 감수하기로 했다. 웹은 완료 뒤 10분 안에서만 듣고, 그 뒤에는 다시 만든다. |
| D2 버튼 문구 | 웹은 '음원 만들기' | 실제 앱 문구는 '음원 다운로드'·'다시 시도'였다. 웹은 없음일 때만 '음원 만들기'로 바꾸고, 실패의 '다시 시도'는 내려받기 뜻이 없어 그대로 둔다. |
| D3 판정 방법 | 웹 플랫폼 모듈의 명시 값 `SheetAudioPlayback.Stream` | '저장소 없음'과 '바로 재생'을 섞지 않는다. 등록이 없으면 `Device`다. |
| D4 편집기 진입 조회 | 유지 | 웹 편집기의 음원 내보내기(파일 내려받기)와 생성 완료 추적을 그대로 둔다. `SheetEditViewModel.kt`를 고치지 않아 1265와 겹치지 않는다. |

브라우저 저장(IndexedDB) 방식은 악보 음원 버킷 `eolssu-sheet-audio`에 CORS 정책이 없어(`docs/plans/S15P31E102-710.md`, R2 CORS는 `eolssu-recordings`에만 있음) 대시보드 변경이 먼저 필요하다. 이번 범위에서 뺐다.

## 3. 한 일

경로 접두어 `frontend/shared/src/`.

- `commonMain/.../core/audio/SheetAudioDeviceStore.kt`: `enum class SheetAudioPlayback { Device, Stream }`.
- `webMain/.../platform/PlatformModule.kt`: `single { SheetAudioPlayback.Stream }`.
- `commonMain/.../app/di/AppModule.kt`: `SheetPracticeRepository(..., streamsAudio = getOrNull<SheetAudioPlayback>() == Stream)`.
- `commonMain/.../data/song/SheetPracticeRepository.kt`
  - `deviceAudioAvailable`를 `personalAudioPlayable`(기기 저장 또는 스트리밍)로 바꿨다. `streamsAudio`를 공개한다.
  - `get(song)`: 스트리밍이면 SHT-13에서 `DONE`·`outdated` 아님·`scoreVersion`과 `currentScoreVersion`이 연습 판본과 같음·`audio/mp4`·링크가 30초(`STREAM_START_MARGIN_MS`) 넘게 남음을 확인하고 서명 URL `ModelAudio`를 만든다. 생성 설정(악기·빠르기·장단)은 기기 저장본처럼 따지지 않는다. 응답 없음은 `CatalogUnavailable`, 404·만료(`AUDIO_EXPIRED`)는 null이다. 수행표(`performance`)는 기기 저장과 같은 검사(`matchesFile`)를 통과할 때만 붙인다.
  - `download`: 스트리밍이면 SHT-12·13으로 완료를 확인한 뒤 저장 없이 `Saved`로 끝낸다. `generationStatus`도 스트리밍에서 진행 중 생성을 확인한다.
- `commonMain/.../data/song/ModelAudioRepository.kt`: `SheetPlayback.localFile`을 nullable로(null = 서명 URL). `ModelAudio.streamsSheetAudio`.
- `commonMain/.../feature/practice/ModelAudioSession.kt`: 스트리밍 음원은 제자리 이어 듣기가 아니면 새로 열 때마다 저장소(SHT-13)를 다시 거친다. 파일이 지워졌으면 `Unavailable`이 되고, 연습 화면은 기존 규칙대로 '음원 만들기'(Missing)로 돌아간다.
- `commonMain/.../feature/practice/PracticeViewModel.kt`·`PracticeUiState.kt`·`component/PracticePlayer.kt`: `supportsPersonalAudio`가 `personalAudioPlayable`을 본다. `personalAudioStreams`이면 없음 버튼이 '음원 만들기'(`practice_sheet_audio_create`)다. 문구 선택을 `personalAudioLabel`로 뺐다.
- `commonMain/.../app/navigation/SheetCompletionNavigation.kt`·`EolssuNavHost.kt`: 완료 배너 대상은 `sheetAudioCompletionTarget(personalAudioPlayable)`. 웹도 연습으로 간다.
- 문서: `docs/specs/sheet-audio.md` '웹 연습 재생 (S15P31E102-1261)' 절, `docs/specs/sheet-audio-app-flow.md` 완료 알림 이동 대상, `frontend/README.md` '웹에서 아직 지원하지 않는 기능' 표에서 이 기능 줄 삭제.
