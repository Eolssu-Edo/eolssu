### 플레이어 동작

- **제스처 해제:** 연습 화면의 플레이어가 붙어 있는 동안 `window` 캡처 단계 리스너(pointerdown·pointerup·mousedown·touchend·keydown·click)가 제스처마다 `AudioContext`를 만들거나 `resume()`한다. Safari처럼 제스처 안의 시작만 인정하는 브라우저에서도 '장단 듣기' 누름 자체가 해제 시점이 된다.
- **놓았다가 다시 쓰기:** `PracticeViewModel.onScreenHidden()`(탭 숨김·화면 이탈)과 `JangdanSession`의 실패 처리가 `release()`를 부른 뒤 같은 플레이어를 다시 쓴다. 그래서 `release()`는 소리를 끊고 출력에서 떨어지기만 하고, 출력 문맥은 닫지 않고 멈춘다(`suspend`). Safari의 해제는 문맥에 남으므로 돌아와 다시 틀 때 제스처 없이 이어진다. 다시 쓸 때 `prepare()`가 문맥이 돌 때까지 최대 300ms 기다려 첫 타격을 버리지 않는다.
- **예약 시각:** `at = max(audibleNow + lead + delayMs/1000, currentTime)`. `audibleNow`는 `getOutputTimestamp()`를 `performance.now()`로 보간한 값이고, 쓸 수 없거나 `currentTime`보다 50ms 넘게 앞서면(멈췄다 깨어난 직후의 낡은 값) `currentTime - (baseLatency + outputLatency)`다. `lead = 출력 지연 + 20ms`(20~250ms).
- **막힌 동안:** `state == "suspended"`이면 타격을 버리고 true를 돌려준다(쌓았다가 몰아 울리지 않음). `"interrupted"`·`"closed"`이면 `interrupted = true`로 두어 세션이 Interrupted로 끝낸다.
- **타격:** 타격마다 `AudioBufferSourceNode → GainNode(gain × 0.65) → destination`. 끝난 음은 다음 예약 때 정리하고 `silence()`는 모두 `stop()`·`disconnect()`한다.
- **굴림 길이:** `targetFrames < 원본`이면 박자 길이에서 자르고 끝 5ms(220 frame)를 줄인다. `targetFrames > 원본`이면 원본 길이만 틀고 남는 부분은 비운다.
- **가려진 탭:** `visibilitychange`에서 `document.hidden`이면 `interrupted`로 멈춘다.
