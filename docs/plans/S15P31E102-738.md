# S15P31E102-738 마이페이지 프로필 그림을 절쑤 12종에서 골라 서버에 저장

- Jira: S15P31E102-738, Story S15P31E102-322(내 정보·계정 관리), Epic S15P31E102-14. 담당 오은서.
- 브랜치: `feat(fe)/S15P31E102-738-마이페이지-프로필-그림을-절쑤-12종에서-골라-서버에-저장`. 731 브랜치(b959af72) 위에서 만들었다. 731이 develop에 병합되면 develop 기준으로 다시 맞춘다.

## 범위와 완료 조건

- 마이페이지 얼굴 원 오른쪽 아래에 작은 연필 뱃지를 두고, 원을 누르면 절쑤 그림 12종에서 골라 저장한다. 고른 그림은 서버에 저장해 다른 기기·재설치 뒤에도 유지한다.
- 완료 조건: 서버 단위 테스트·실제 MySQL 검사, 앱 공유 테스트·JS 컴파일·Android 빌드 통과, 에뮬레이터에서 원·뱃지·고르기 화면 확인.

## 결정

- 그림은 앱에 담고 서버에는 키만 저장한다: `users.profile_image VARCHAR(20) NOT NULL DEFAULT 'HELLO'`, 12개 키 CHECK(V38). 사진 업로드·저장소는 쓰지 않는다.
- 키(표시 이름): HELLO(반가워요)·DANSO(단소 연주)·STUDY(악보 공부)·LOOK(여기 보세요)·GREAT(잘했어요)·JANGDAN(장단 타기)·AGAIN(다시 해봐요)·SURPRISE(깜짝이야)·PROUD(쑥스러워요)·OKAY(괜찮아요)·REST(잠깐 쉬어요)·DONE(연습 완료).
- API: `GET /api/users/me` 응답에 `profileImage`를 더하고, `PATCH /api/users/me/profile-image` `{profileImage}`로 바꾼다. 목록 밖·빈 값·소문자는 400 `INVALID_REQUEST`, ACTIVE가 아닌 회원은 401. 성공 응답은 `{userId, profileImage}`.
- 탈퇴 익명화는 그대로 둔다. 그림 키는 개인 정보가 아니다.
- 앱은 키가 없거나(이전 서버) 모르는 키면 '반가워요'로 보여 준다. 저장은 서버가 받아들인 키만 화면에 반영한다.
- 고르기는 별도 화면(`my/profile-image`)으로 둔다. 닉네임 수정과 같은 흐름이다: 저장하면 마이페이지로 돌아가 '프로필 그림을 바꿨어요.'를 띄우고, 고르지 않고 저장하면 요청 없이 돌아간다. 실패하면 고른 그림을 유지하고 화면 아래에 안내를 둔다.
- 그림은 12종 그림 시트에서 얼굴과 갓이 원 가운데 오도록 256px 정사각형으로 잘라 webp로 넣었다(`profile_tiger_*.webp`, 합계 약 304KB).
- 옷 색깔 바꾸기는 녹색 부분 색상 이동 시험에서 빨강·보라·갈색이 탁해 보여 이번 범위에서 뺐다.
