## 요청과 완료 조건

2026-11-03 사용자 요청에 따라 홈의 '연습곡 선택하기'로 들어가는 SONG-03 '연습곡 고르기' 제공 곡 목록 위에 단계별 알약 필터를 둔다.

- `전체 · 입문 · 초급 · 중급`을 가로 한 줄로 배치한다. 기본은 전체이며 한 번에 한 단계만 선택한다.
- 좁은 창·확대 글꼴에서 줄바꿈 대신 가로 스크롤을 제공한다.
- 현재 악기의 곡을 기존 모델의 난이도 대응(1=입문, 2=초급, 3=중급)으로 앱 안에서 거른다.
- AI 평가가 불가능한 연습 전용 곡도 포함한다. 단계 미확인 곡은 전체에서 원래 숫자 난이도로 보인다.
- 선택한 단계에 곡이 없으면 안내와 '전체 곡 보기'를 제공한다. 통신 실패·서버의 빈 목록은 기존 안내를 유지한다.
- 악기 변경·재시도·내 악보 탭 왕복·연습 화면 복귀 때 선택한 필터를 유지한다.
