# S15P31E102-616 Mattermost 점검 메시지 재구성

- [작업](https://ssafy.atlassian.net/browse/S15P31E102-616) · [스펙](../specs/mattermost-inspection-messages.md)
- 시작 기준은 develop의 `187cdd69`다. 상태·서버·컨테이너 여섯 명령을 대상으로 한다.
- `infra/edo-check/collector.py`에서 필수 슬롯 선택에 사용한 라우팅 설정을 상태 응답에 담는다. `relay.py`에서 기존 수집 결과로 모드별 요약과 우선 조치를 만들고 상세 표를 뒤에 둔다.
- 회귀 검사는 두 서버의 세 모드, 슬롯 선택·누락·미측정, 우선순위와 상세 보존, 빈 목록·잘린 메시지를 포함한다. 기존 테스트와 실제 수집 응답 렌더링을 확인한다.

## 검증

- 점검 도구 테스트 58건과 전용 SSH dispatch 두 파일의 셸 문법 검사를 통과했다.
- edo2 중계가 사용하는 전용 SSH와 HTTPS 검사로 두 서버의 세 모드를 각각 수집했다. edo1 상태는 후보 수집기를 읽기 전용으로 실행해 블루 슬롯 정보와 컨테이너 상태를 확인했다.
- 실제 수집 데이터 여섯 건을 후보 메시지로 렌더링했다. edo1 블루·API·지표, edo2 MySQL 복제본·대기 API의 Docker 검사 결과가 요약에 나타났고, 서버·컨테이너 상세 표를 유지했다.
- 운영 반영과 Mattermost 게시 검증은 후속 단계다.
