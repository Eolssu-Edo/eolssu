## 결과

2026-10-27, Windows / JDK 21에서 `frontend/`에서 `./gradlew :shared:testAndroidHostTest :shared:wasmJsTest :androidApp:assembleDebug --console=plain` 통과. Android 호스트·Wasm 브라우저 테스트 각 71개(새 테스트 29개: `YulNotationTest` 5·`FingeringTest` 7·`FingeringViewModelTest` 5·`LearnUiStateTest` 7·`LearnCurriculumTest` 5), 실패 0.

글꼴 확인(fontTools 4.60.1): 운지표·설명에 쓰는 한자 중 세리프 부분 글꼴에 없는 글자는 `㑣㑥㑲㒇㒣汏浹㴌㳞㶋洟湳潕㶐㶂㶃㶄㴩㶌㶍㶝` 21자다. Windows의 `NotoSerifKR-VF.ttf`에는 `汏浹洟湳`만 있고 나머지 17자는 없다(SimSun에만 있음). 빌드 원본 `NotoSerifKR-*.otf`는 내려받지 않아 직접 확인하지 않았다. 4자만 글꼴에 넣으면 같은 표에서 두 가지 그리기가 섞여 모두 나눠 그리기로 통일했다.
