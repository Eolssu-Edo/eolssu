## 계획과 판단

1. 완료된 847의 표시 매핑과 편집 목록을 대조한다. 혀치기·반음올림표·꺾는음·원문점 네 항목이 map 밖 분기로만 표시되어 입력 목록에서 누락됐다.
2. 네 항목의 선택·원본 변형 문자열·소박·JSON 저장/복원을 회귀 검사로 재현한다.
3. 공통 registry로 누락을 해소하고 반음올림표를 첨부 원본의 두 가로획과 오른쪽 연결획으로 교체한다.
4. 집중 검사·전체 Android host 회귀와 Android/JS/Wasm 컴파일, 가능한 실제 화면 확인 후 변경을 자체 검토하고 작업 단위로 커밋한다.

원래 요청은 #를 원본 모양으로 재현하는 것이었고, 후속 요청으로 편집기 선택과 다른 누락 항목 점검을 추가했다. 표시 가능한 기호와 입력 목록을 일치시키며 음향 의미는 새로 정의하지 않는다.

## 검증

2026-11-15 구현·자체 검토 완료, 정식 리뷰와 배포 전이다. 제품 변경은 이 기록과 함께 작업 단위로 커밋한다. 원본 첨부는 세션의 `codex-clipboard-b251bcbc-8ffa-4036-b97a-6af6a4bc8e37.png`이며 저장소에 복사하지 않는다.

- 수정 전 새 회귀 검사가 `혀치기 입력 누락`으로 실패했다. 수정 후 `ScoreSigimsaeTest`·`SheetDraftTest`·`SheetDocumentEditingTest` 25개가 통과했다. 음이 있는 두 번째 소박에 추가하여 기존 첫 소박의 `@변형`, 음표 ID·음고·tick·길이, JSON 저장/복원·삭제·재선택을 검사했다.
- `frontend/`에서 `./gradlew.bat :shared:testAndroidHostTest :androidApp:assembleDebug :shared:compileKotlinJs :shared:compileKotlinWasmJs --console=plain --max-workers=2` 성공(1분 28초). Android host 검사 1,750개 중 1,745개 통과, 실패·오류 0, 외부 서버·카탈로그 캡처 환경 변수 미지정 검사 5개 생략이다.
- `:webApp:jsBrowserDevelopmentRun`으로 현재 변경을 실행했다. 앱 초기 로그인 화면 표시 후 기존 샘플 편집 경로 `#sheet-edit/edit?from=jg&pending=0&hwang=Eb4`로 이동했다. 계정 로그인·운영 문서 변경 없이 로컬 샘플의 南을 선택하여 시김새 목록 끝의 혀치기·반음올림표·꺾는음·원문점을 각각 추가·삭제했다. 악보 셀과 선택 표시가 일치하고 3개 제한이 유지된다. 반음올림표 단독으로 `南 · 반음올림표`가 표시되는 최종 화면을 확인했다.
- 새 벡터를 읽어 만든 대조 화면에서 원본의 두 가로획·오른쪽 연결획과 비교했고, 실제 Compose 편집기의 목록·선택 알약·南 옆 기호에도 같은 모양이 표시되는 것을 확인했다.
- 표시 registry 51개와 기존 전성 1개로 편집 선택지는 총 52개다. 기존 공개 카탈로그 기록과의 누락 4종이 모두 입력 목록에 포함된다. 원문점의 의미와 꺾는음의 원본 이름을 보존하고 이전 `sig_sharp` 참조가 남지 않음을 확인했다.
