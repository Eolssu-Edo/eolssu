## 발표 전 사람이 할 일 (점검표)

1. **QA 원격 중계 끄기:** 11-17 저녁부터 발표가 끝날 때까지 끈다. Windows QA PC의 `relay`, `tablet-relay`에 `supervisor.disabled`를 만들거나 Ctrl+C를 누른다(`infra/qa-phone/OPERATIONS.md`). 끈 뒤 `/qa/`가 502인지 확인한다. 끄는 동안에는 `/applog` 수집도 멈춘다.
2. **시연 계정 정리:** 발표 1~2일 전 앱에서 비밀번호를 바꾼다. 이 계정의 기존 세션 57개가 모두 끊긴다. 곧바로 마이페이지에서 팀이 의도하지 않은 소셜 연결(GOOGLE·KAKAO)을 해제한다. 새 비밀번호는 시연 담당자에게만 알리고, 시연 기기에서만 다시 로그인한다.
3. **로그인 잠금 대비:** 시연 기기는 미리 로그인해 두고 현장에서 새로 로그인하지 않는다. '이메일 기억'은 끈다.
4. **화면 공유 수칙:** 발표 PC에서는 Eolssu Updates를 종료하고 SSH 터널을 닫는다. phpMyAdmin은 로그아웃한다. 개발자 도구, Swagger, `/ipas/`는 띄우지 않는다. 주소는 도메인(`https://k15e102.p.ssafy.io`)만 쓴다.

## 이번에 하지 않은 것

- **테스트 계정 이메일을 문서에서 지우기:** `infra/qa-phone/test/adb.test.mjs`도 함께 바꿔야 하고, git 이력에는 그대로 남는다.
- **QA 웹 차단, Swagger·phpMyAdmin 닫기:** 서버 변경과 팀 합의가 필요해 진행하지 않았다.
- **phpMyAdmin 열 단위 권한, Grafana `memo` 열 제외, 소셜 연결 시 비밀번호 재확인, `/ipas/` 접근 제한:** 복제를 멈출 위험이 있거나 코드 변경이 필요하다. 발표 뒤에 다룬다.
