## 이번 단위

- `data/mart/alter_add_total_practice_seconds.sql`: 칸을 추가하기 전에 만든 마트에 한 번 실행하는 변경. `CREATE TABLE IF NOT EXISTS`는 기존 테이블에 칸을 더하지 않기 때문이다.

## 결정

- `BIGINT NOT NULL DEFAULT 0`: 하루·악기 합계라 `INT`로도 충분하지만 합계 칸이라 넘침 걱정이 없게 했다. 기본값 0은 기존 행을 채우고, 체류 구간이 없는 날은 0이라는 뜻이다.
- 녹음 세션 없이 체류 구간만 있는 날·악기도 행을 만든다고 주석에 적었다. 이 경우 `session_count`·`user_count`·`failed_count`는 0, `avg_total_score`는 NULL이 된다(배치가 따를 기준).
- 변경 파일은 MySQL 8.4에 `ADD COLUMN IF NOT EXISTS`가 없어 두 번 실행하면 1060으로 멈춘다. 데이터는 바뀌지 않는다.
