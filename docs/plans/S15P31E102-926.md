# S15P31E102-926 운영 Nginx TLS 설정의 블로그 편집·IPA 블록을 저장소 템플릿에 반영

- Jira: [S15P31E102-926](https://ssafy.atlassian.net/browse/S15P31E102-926). Story 40 배포 환경·CI, Epic 21 인프라·운영. 담당 우동균. 활성 스프린트 5.
- 기준: develop `489c90f9`. 브랜치 `chore(infra)/S15P31E102-926-운영-Nginx-TLS-설정의-블로그-편집·IPA-블록을-저장소-템플릿에-반영`.
- 계기: [917](S15P31E102-917.md) 운영 반영 중 서버 TLS 설정에 저장소에 없는 블록이 있음을 확인했다. 템플릿으로 서버 파일을 덮으면 블로그 편집과 iOS QA IPA 설치가 사라진다.

## 변경

- `infra/runtime/nginx.tls.conf.template`에 서버 `/opt/eolssu/config/nginx.tls.conf`에만 있던 블록을 서버와 같은 위치·내용으로 옮겼다.
  - 맨 위 `limit_req_zone` 2개(`blog_editor_per_ip` 10r/m, `blog_views` 30r/m).
  - `/blog-editor/config·session·post·views` → `172.18.0.1:18121` 프록시([713](S15P31E102-713.md)의 편집용 컨테이너)와 그 밖의 `/blog-editor` 경로 404. `/api/internal/` 앞에 둔다.
  - `/ipas/`([444](S15P31E102-444.md)) → `/usr/share/nginx/ipas/` 정적 제공. `no-store`·`nosniff`·`noindex`, 목록 비공개. `location /` 앞에 둔다.
- `infra/runtime/compose.yml` frontend에 서버와 같은 `/opt/eolssu/ipas:/usr/share/nginx/ipas:ro` 마운트를 넣었다. frontend 서비스 블록(1~30행)은 서버와 같아졌다. `compose.tls.yml`은 이미 서버와 같았다.
- `infra/scripts/tests/test_nginx_blog_ipa.py`를 추가했다. 운영처럼 `nginx.conf`·TLS 설정을 한 컨테이너에 싣고 IPA 폴더를 붙여 HTTPS로 확인한다. `test_nginx_redirect.py`는 917이 같은 setUp을 고치므로 충돌을 피해 파일을 나눴다.

## `nginx.conf`·TLS 설정의 주석 한 줄

- 차이: 저장소 두 파일의 `location ^~ /api/internal/` 위 주석 `# Uploaded originals are available only to the internal recognition worker.`가 서버 두 파일에는 없다.
- 결정: 저장소에 남기고 서버 파일은 고치지 않는다.
- 근거: 이 주석은 534(2026-11-06, `939aa8de`)가 차단 이유를 설명하려고 넣었다. 서버 백업 `nginx.conf.bak-486-*`(11-04)·`*.bak-917-*`(11-15) 모두 이 주석이 없다. 486 이후 서버 파일은 통째로 덮지 않고 필요한 블록만 고쳐 왔기 때문이다. Nginx는 주석을 해석하지 않으므로 동작 차이가 없다. 서버에 맞춰 지우면 차단 이유 설명만 사라진다. 다음에 서버 파일을 저장소 기준으로 설치할 때 함께 들어간다.

## 남은 일

- Jenkins backend 잡은 Nginx 테스트를 파일 이름으로 하나씩 실행하므로 새 테스트는 아직 CI에서 돌지 않는다. `infra/jenkins/backend.Jenkinsfile`도 서버 사본(`/opt/eolssu/config/backend.Jenkinsfile`, Android·iOS QA 큐 단계)과 달라 이번 범위에서 고치지 않았다.
- 범위 밖으로 확인한 Compose 차이: 저장소와 서버 `compose.yml`의 backend·omr 환경 변수 위치(`SHEET_*`·`RECORDING_STORAGE_*`), 저장소에만 있는 `SHEET_IMPORT_READ_BASE_URL`, 주석 두 곳이 다르다([563](S15P31E102-563.md)에서도 기록). 이번 작업은 frontend IPA 마운트만 맞췄다.
