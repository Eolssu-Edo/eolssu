- `SheetEditScreen`은 `hasTempoPlan`이면 예상값을 무조건 숨기고, `SheetEditRoute`는 같은 조건으로 상세/저장 창의 계산 콜백을 제거한다. 마지막 구간 삭제 후에도 빈 `performancePlan`이 유지되어 표시가 돌아오지 않는다.
- 기존 `SheetSaveDuration`은 일정 BPM과 원본 tick 비율만 계산한다. 기존 `tempoChanges`의 표시 BPM·위치를 사용해 즉시 변경 및 기보 위치에 선형인 BPM의 역수 적분을 계산한다. 목표 미지정 기호는 기존 계약대로 속도를 바꾸지 않는다.
- 반복·특수 음가처럼 이번 계산기가 다루지 않는 경우의 표시 제한을 보존한다. 저장·생성 계약의 의미를 바꾸지 않는다.
- 먼저 3정간/60 BPM 고정 입력에서 구간 적용 회귀를 실패시키고 수정한다. 다음으로 점진 변화·명시 시작값·점4분음표 비율·전역 비율·변경/해제·undo/redo·export/reopen을 검증한다.
