## 범위와 완료 조건

- 기초 배우기 단계 목록 위 호숫가 돌다리 그림(`LearnTrailMap.kt`)을 그림체는 유지하고 사실감 있게 고친다.
  - 징검돌: 단추 모양 → 실제 돌 모양.
  - 왼쪽 물가 부들, 오른쪽 정자: 실제 모양에 가깝게.
- 이후 기초 배우기 화면 UI 개선도 같은 Task에서 사용자 요청 단위로 이어 간다.
- 완료 조건: 사용자가 미리보기로 확인한 안을 반영하고, 돌 누르기·호랑이 건너기·완료 축하·완료/보는 중 표시가 그대로 동작한다.

## 결정 (돌다리 그림)

- 반영 전 미리보기를 브라우저에서 앱과 같은 좌표·색 섞기(Oklab)로 그려 사용자에게 네 번 확인받았다. 사용자 피드백으로 바꾼 점:
  - 돌이 윗면·옆면 두 겹으로 보임 → 윤곽 하나인 바위로 그리고, 아래 절반쯤이 물에 잠기게 했다(물 아래는 물빛으로 덮고, 물이 닿는 선에 물결).
  - 정자가 언덕 밖 물 위로 나옴 → 언덕 위를 평평하게 넓히고, 정자를 카드 오른쪽 끝에서 늘 22dp 떨어진 곳에 둬 화면 너비와 관계없이 땅 위에 서게 했다. 정자는 조금 줄였다.
  - 숫자가 돌 위쪽에 붙음 → 물 밖으로 나온 바위의 세로 가운데(윤곽 최고점과 물이 닿는 선의 중간)에 둔다.
  - 먼 산과 호수 사이 가로선 → 없애고, 호수 빛이 물가 조금 위에서 투명하게 시작해 서서히 짙어지게 했다.
- 바위 윤곽은 타원 둘레 9점의 반지름을 단계 번호로 흔들어 돌마다 조금씩 다르다. 마친 돌은 이끼 연두와 얼룩, 아직인 돌은 점·금 결, 보는 돌은 짙은 녹색(`play`) 테두리, 선택 단계는 점선 테두리다.
- 그림은 누르는 칸(31×26dp)보다 조금 커서 칸 밖까지 그리고, 누를 때 번지는 표시만 칸 모양으로 자른다. 누르는 범위·돌 위치는 바꾸지 않았다.
- 장면 그림은 dp 좌표로 그리도록 Canvas에 화면 밀도만큼 확대를 걸었다. 호랑이 발 깊이는 바위 꼭대기에 맞춰 7dp → 6.5dp.
- '버들'은 기존 그림의 부들(물가 풀)로 해석했다.
