## 원인 (2026-11-14)

- 홈을 맨 아래까지 내린 뒤 기능 카드로 들어갔다가 돌아오면 아래 카드 줄이 잘린 채 멈췄다.
- 스크롤 위치(`rememberScrollState`)는 화면 복귀 때 복원되지만, 카드 묶음·버튼·문구의 잰 높이는 `remember`라 기본값(카드 묶음 480)으로 돌아갔다.
- 첫 배치에서 기본값으로 계산한 콘텐츠가 실제보다 짧아 복원된 위치가 짧은 바닥으로 잘렸다. 그 뒤 실제 높이를 다시 재도 잘린 위치는 그대로 남았다.

## 수정

- `HomeScrollLayout`의 잰 높이 세 개를 `rememberSaveable`로 바꿔 복귀 첫 배치부터 실제 높이로 바닥을 계산한다. 카드 묶음 높이는 지금처럼 창 너비 구간이 바뀌면 다시 잰다.

- `:shared:testAndroidHostTest :shared:compileKotlinJs :androidApp:assembleDebug` 통과, 테스트 1709개 실패 0.
- 에뮬레이터(emulator-5554, 1080x2400): 맨 아래까지 내림 → '정간보 읽기' → 뒤로, 맨 아래 → '운지법 보기' → 뒤로. 두 경우 모두 맨 아래 위치로 돌아오고 아랫줄 카드 글자(세로 2157~2216)까지 보였다. 수정 전에는 같은 절차에서 아랫줄이 잘렸다.
- 자동 테스트 없음: 화면 복원은 Compose UI 테스트 도구가 필요한데 프로젝트에 없다.
