## 결정 (2026-11-04)

- 별도 Task: 351(편집·저장·음원 전체 연결, 미배정)은 범위가 넓고 저장 API 연결이 선행이라, 음원 계약 반영만 484로 나눴다.
- POST 설정: `withJangdan`은 EDIT-04 체크박스, `bpm`은 악보 bpm, `instrumentId`는 회원이 고른 악기(없으면 생략해 서버 기본 단소). 화면에 악기 선택은 두지 않는다.
- 저장(내려받기)은 서명 URL을 기기 브라우저로 연다. 앱 안 파일 저장소·sha256 대조는 하지 않는다.
- 예시 악보(서버 ID 없음)는 '준비 중' 안내. 가짜 생성 흐름을 흉내 내지 않는다.
- 폴링 기본 간격 3초, 연속 5회 응답 없음이면 멈추고 '다시 확인'. URL은 만료 30초 전부터 새로 받는다.
- 만료 시각은 `urlExpiresAt`(UTC ISO8601)을 epoch ms로 바꿔 둔다. 기기 시계 기준이라 실제 서명 만료와 조금 다를 수 있으나 서버가 '실제 만료보다 늦지 않다'고 보장한다.
