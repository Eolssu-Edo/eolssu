- 조사: `SheetImportViewModel` 업로드 후 내 악보 목록으로 돌아가 `MySongsViewModel`이 변환을 폴링한다. 편집기의 `loadCompletionCatalog`·`openAdaptation`·음원 목록이 각자 카탈로그를 읽는다. 일반 저장소와 DI에는 응답 캐시가 없다.

- 추가 요청: 적용 뒤 율명·기호 탭으로 넘어가는 동작을 고쳐 음역 도구를 유지한다. 탭 이름은 사용자가 선택한 `음역·이조`로 바꾼다. 같은 Task의 UI 회귀와 실제 악보 검증에 포함한다.
