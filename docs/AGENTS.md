# 문서 작업 지침

- [README](README.md)의 위치와 기록 기준을 따른다. 관련 영역을 조사할 때는 해당 파트의 `AGENTS.md`도 읽는다.
- 조사 기록에는 핵심 결론·출처·프로젝트 적용점·미확인 사항을 남긴다. 실험이 있으면 입력·버전·조건·재현 방법·결과를 함께 기록한다.
- 결정 기록에는 상태·선택·근거·영향 범위를 적는다. 확정됐다고 쓸 때는 확인 가능한 합의 근거를 연결하고, 변경된 결정은 대체 문서와 연결한다.
- 기획·실행 방법·설계 근거·도메인 설명은 일반 문서에 둔다. `AGENTS.md`에는 해당 범위의 실행 지침만 적고 루트 규칙을 반복하지 않는다. COCO 스킬과 겹치는 규칙은 적지 않고 COCO보다 좁은 규칙만 적는다.
- `CLAUDE.md`는 같은 폴더의 `@AGENTS.md` 참조만 유지한다. 두 파일에 규칙을 따로 작성하지 않는다.
- `docs/plans/`의 작업 계획·결정·검증 기록은 해당 작업의 Git 커밋과 MR에 포함한다. 로컬 제외 설정에도 이 경로를 추가하지 않는다.
- 새 문서를 [README](README.md)의 목록에 연결한다. 외부 원문·대용량 결과·비밀값을 복사하지 않는다.
