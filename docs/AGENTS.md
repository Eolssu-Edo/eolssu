# 문서 작업 지침

- [README](README.md)의 위치와 기록 기준을 따른다. 관련 영역을 조사할 때는 해당 파트의 `AGENTS.md`도 읽는다.
- 기존 주제 문서를 먼저 갱신한다. 코드 변경이 없어도 팀이 재사용할 도메인 지식·실험 결과·결정은 남기되 단순 질의응답과 전체 대화를 자동 저장하지 않는다.
- 조사 기록에는 핵심 결론·출처·프로젝트 적용점·미확인 사항을 남긴다. 실험이 있으면 입력·버전·조건·재현 방법·결과를 함께 기록한다.
- 출처의 사실, 직접 관찰한 결과, 가설, 제안, 확정된 결정을 구분한다. 제안을 임의로 팀 합의로 바꾸지 않는다.
- 결정 기록에는 상태·선택·근거·영향 범위를 적는다. 확정됐다고 쓸 때는 확인 가능한 합의 근거를 연결하고, 변경된 결정은 대체 문서와 연결한다.
- 여러 파트가 공유하는 정의·단위·계약은 한 문서를 기준으로 삼고 관련 문서에서 링크한다. 같은 설명을 파트마다 복사하지 않는다.
- 기획·실행 방법·설계 근거·도메인 설명은 일반 문서에 둔다. `AGENTS.md`에는 해당 범위의 실행 지침만 적고 루트 규칙을 반복하지 않는다.
- `CLAUDE.md`는 같은 폴더의 `@AGENTS.md` 참조만 유지한다. 두 파일에 규칙을 따로 작성하지 않는다.
- 경로·실행 명령·수치·인용·확정 상태를 확인한다. 실행해 보지 않은 명령은 검증됐다고 기록하지 않는다.
- 새 문서를 [README](README.md)의 목록에 연결한다. 외부 원문·대용량 결과·비밀값을 복사하지 않는다. 문서 본문을 요청 없이 Notion·Jira 본문·댓글·메신저에 게시하지 않는다.
