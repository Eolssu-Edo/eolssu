## 사용자 선택과 검증용 악기

사용자는 검증용 악기를 **피리사대금 특산조(검정)**으로 알려 주었다. [제조사 제품 65](https://m.kukaksa.co.kr/product/detail.html?product_no=65)는 `피리사산조대금(특검정)`, 상품코드 `P00000CN`으로 등록되어 있다. 제품 상세 이미지에는 `p(특)산조`, ABS 재질, 약 70cm라고 적혀 있다. 사용자가 말한 모델과 대응하는 후보이나, 소유 실물·제조 시기·개체 음정은 직접 검사하지 않았다. 제품명만으로 청이나 특정 Hz를 확정하지 않는다.

**이 정보는 조사·검증 입력이며 서비스 사용자의 제품명·제조사·청 입력을 필수로 하자는 요구사항이 아니다.** 산조/정악 선택을 기본으로 검토하되, 채점에 영향을 주는 실음 차이는 실제 검증에서 확인한다. 필요 시 짧은 기준음 녹음으로 확인하는 방법은 검토안이며 구현·채택되지 않았다. 초보자의 잘못된 발음을 자동 조율 기준으로 삼거나, 한 음의 차이를 모든 운지에 같은 비율로 보정해도 된다고 가정하지 않는다.

## 지공 번호와 손가락부터

취구에서 가까운 순서가 1~6공이다. 여섯 지공을 사용하는 기본 파지에서의 담당은 다음과 같다. [국립국악원 『창작을 위한 국악기 이해와 활용』 4장 대금](https://www.gugak.go.kr/site/program/board/basicboard/list?boardtypeid=116&menuid=001003003006002&lang=ko) PDF 11쪽(인쇄 151쪽)의 본문·양손 사진을 렌더해 확인했다. [공통 원본 명세](../score-manifest.json)의 `ngc-daegeum-practical-guide`와 연결한다.

| 지공 | 기본 파지의 담당 |
| --- | --- |
| 1공 | 왼손 검지 |
| 2공 | 왼손 중지 |
| 3공 | 왼손 약지 |
| 4공 | 오른손 검지 |
| 5공 | 오른손 중지 |
| 6공 | 오른손 약지 |

위 표는 기본 파지의 지공 순서다. 다른 파지법·좌우 반전 도식에 무조건 적용하지 않는다. 앱 도식은 화면의 왼쪽/오른쪽과 연주자의 손을 명시해야 한다. PDF 10쪽(인쇄 150쪽)은 저취·평취·역취가 입김의 속도·압력과 관련된 취법임을 설명한다. 따라서 손가락의 열림·닫힘만으로 실제 음높이를 결정할 수 없다.

[국립국악원 박물관의 산조대금 설명](https://archive.gugak.go.kr/portal/vr/selectVrDetail?seq=32)도 제작 규격에 따라 음정 차이가 있음을 안내한다. 기종 선택만으로 모든 실연의 절대 Hz가 같다고 가정하지 않는 이유다. 이 사실을 제품명 필수 입력이나 미검증 자동 보정 기능으로 곧바로 연결하지 않는다.

## 제조사 운지표 실물

[한양국악사·피리사 자료실: 산조대금운지표, 게시물 417](https://m.kukaksa.co.kr/board/free/read.html?board_no=7&no=417), 게시일 2015-06-17. [원본 그림](https://kukaksa.co.kr/web/myimg/daekum%20use.jpg)은 545×701 이미지이며 브라우저에서 전체를 육안 확인했다.

표제에 **가요·창작곡 등 오선악보 연주 시의 산조대금 안공표**라고 명시하고, 저취·평취·역취별 율명과 여섯 지공을 구분한다. 일부 음에는 두 가지 운지가 있으며 가락에 따라 쓴다고 적혀 있다. 남궁연 대금교본을 참고했다고 표시한다. 이 자료를 모든 산조 유파·파지법의 단일 표준으로 확대하지 않는다. 해당 이미지에 검증용 특검정 모델의 전용 버전·청·Hz는 명시되지 않았다.

아래는 표를 읽는 데 필요한 사실 확인용 예시다. 왼쪽부터 1~6공, `1=막음`, `0=열림`으로 적었다. 제조사 원본의 도안·사진을 앱 자산으로 복제하지 않았다.

| 원본의 취법·율명 | 여섯 지공 상태 | 확인한 의미 |
| --- | --- | --- |
| 저취 임 | `111111` | 여섯 지공을 모두 막은 예 |
| 저취 남 | `111110` | 6공을 연 예 |
| 평취 임 | `011111` | 같은 임이라는 이름에도 취법·음역에 따라 다른 운지가 표시됨 |

이 예시는 원본 그림의 판독 결과다. 실제 손 모양·기종별 적합성·율명 표기·해당 실음은 교사 검수 전이며 서비스 정답표로 확정하지 않는다. 반공과 모든 유파의 운지를 망라한 데이터셋은 아니다.

후속 대조를 위해 [운지 참조 명세](fingering-reference.json)에 24행·27패턴을 출처 ID와 함께 기록했다. 저취 중·평취 중·역취 임은 복수 운지를 함께 전사했다. 같은 지공 패턴이 여러 취법·율명에서 나타나므로, 지공 패턴만으로 음 이름을 역산하지 않는다. 이 명세는 출처 판독 단계이며 교사 검수·해당 녹음과의 연결을 뜻하지 않는다.

제조사 운지표와 사진의 원본 재배포·가공 이미지 재배포는 **현재 불가(개별 허가 미확인)**로 관리한다. 공개 열람과 앱에서의 이미지 제공 권한을 구분하며, 사실 검수 후 자체 도식 제작과 필요한 권리 확인을 별도로 진행한다. 공통 국립국악원 교재의 원문·가공본 재배포도 기존 허가 미확인 상태를 유지한다.

## 기본음과 실제로 연결된 것은 어디까지인가

| 연결 | 현재 확인 | 미확인 |
| --- | --- | --- |
| 원본 ↔ 악기 분류 | 국립국악원 UI가 산조대금으로 분류. 공식 메타데이터에 `본청 = C` 명시 | 제작처 음별 라벨·조율 Hz·제조사·실물 |
| 원본 ↔ 구간·F0 | 같은 SHA-256 원본에서 13후보의 시각·주파수 자동 추정 | 청취에 의한 경계·음 변화·정답 F0 검수 |
| 운지표 ↔ 율명·취법 | 제조사 표에 명시된 사실 판독 | 검증용 특검정 실물에서의 음별 적합성 |
| 운지표 ↔ 원본의 13음 | 공개 실음 기준·옥타브 관계와 같은 국립국악원 요성 녹음의 18음군 배열 가설로 율명 추정 13개. 참고 운지 연결 | 독립 정답 및 녹음 당시 실제 사용한 지공 |

13구간을 각각 대조한 [연결 확인 결과](basic-tone-analysis.md#13구간의-율명운지-연결-확인)와 [연결 명세](note-fingering-map.json)를 추가했다. 현재 13개 모두 율명 추정이며, 한글로 저취 임·남·황·태·중 / 평취 임·남·황·태·중 / 역취 임·남·무를 표시한다. 참고표의 운지는 `referenceFingeringCandidates`로 연결하고 실제 녹음 운지와 구분한다. 원본의 음별 라벨이 없다는 이유로 추정까지 막았던 앞선 판단을 수정했다.

국립국악원 기본음에는 음별 운지 라벨이 없지만, **실측 음높이·공개 실음 기준·음정 관계를 결합한 율명 추정은 가능**하다. 첫 음이 표의 첫 행이라는 가정이나 오름차순만을 근거로 삼지 않는다. 검증용 피리사 악기에서 같은 소리가 날 것이라고 단정하지도 않는다.

같은 국립국악원 요성 녹음과의 음높이 대응은 [대응 명세](basic-note-correspondence.json)에 기록했다. 18음군의 율명은 교육용 7율명 반복 가설을 포함하므로 독립 검수가 필요하다. 다음에는 특히 5·10번 중과 12·13번 역취 음을 우선 대조한다. 실물·교사와의 대조나 제작 기록은 추정을 독립 검증하는 방법이며, 제작 라벨 확보만을 유일한 선행 조건으로 삼지 않는다.

## 두 표와 원음의 수가 다른 이유

사용자가 보낸 교재 음역표는 30개 기보 위치(괄호 3개 제외 시 27개), 제조사 안공표는 24행·27운지 패턴, 국립국악원 기본음 녹음은 13개 지속음 후보다. 서로 세는 대상과 목적이 다르다. [음역표와 녹음의 상세 비교](basic-tone-analysis.md#13음음역표운지표의-수가-다른-이유)에 근거를 남겼다. 참고 운지의 이름을 연결하는 데 녹음 악기가 피리사 제품이어야 할 필요는 없다. 다만 특정 참고 운지의 실제 음높이·적합성 검수는 남아 있다.
