## 바로 활용할 수 있는 결과

국립국악원의 산조대금 9개 원본을 모두 확보하고 해시·형식·실제 길이를 검사했다. 총 **898.379초(14분 58.379초), 325,272,316 bytes**다. 8개는 48kHz float32 스테레오, 연주 「태평가」는 44.1kHz PCM16 스테레오다. 모두 공식 선택 다운로드 ZIP에서 원본 그대로 추출했다. 기존 기본음 파일과 재다운로드한 파일의 바이트도 일치했다.

전체에서 **44,885개 F0 분석 프레임, 145개 발음 구간, 191개 짧은 발음 후보**를 얻었다. 실제 분석은 Python 3.12.14·NumPy 2.3.5, 약 **7.288초**, 입력 9개·성공 9개·실패 0개였다. 이 로컬 입력과 환경의 단일 실행 관찰이다. ‘145구간’은 음표 145개라는 뜻이 아니다. 탐색 분석은 시각·원본 ID·해시를 연결하며, 후속 준비 단계에서 아래의 검토 결과에 따라 개별 WAV를 생성한다.

- 각 항목의 `frames.csv`: 20ms 간격의 시각·RMS·F0·주기성·요약 채택 여부.
- `envelope.csv`와 `articulations.csv`: 10ms 간격의 강약과 짧은 발음 후보.
- `regions.csv`와 `analysis.json`: 구간별 시각, F0 중앙값·변동 폭, 주기적 변화 후보, 강약 변화, 참고 기본음 연결, 검수 상태.

결과 폴더는 `data/processed/instruments/daegeum/sanjo/collection-v1/<원본ID>/`다. 원음과 대용량 결과는 Git에서 제외하고, 재실행 가능한 코드·원본 명세·요약만 공유한다. **지금 가능한 활용은 출처를 표시한 주법 예시 재생, F0·강약 시각화, 정제·정렬 실험이다. 독립 검수된 음표별 정답이나 채점 기준은 아직 아니다.**

## 항목별 관측과 용도

‘F0 범위’는 발음 구간 각각의 p10~p90을 모은 최솟값~최댓값이다. 산조대금 전체 음역이나 정답 Hz 범위가 아니다. ‘변동 폭’은 각 구간의 F0 p10~p90 폭을 cent로 계산한 뒤 구간 간 중앙값을 구한 값이다. 연주 구간에는 여러 음이 들어가므로 다른 주법과 같은 의미로 비교하지 않는다.

- **기본음:** 기존 13구간의 F0와 일치한다. 기존 [율명·운지 추정](basic-tone-analysis.md#13구간의-율명운지-연결-확인)을 참조한다. 같은 기본음끼리의 13개 참조 일치는 자체 비교이며 독립 정확도 검증이 아니다.
- **요성·깊은요성:** 요성 20구간 중 15개에서 약 3.319~3.917Hz, 깊은요성 16구간 중 14개에서 약 3.333~4.191Hz의 주기적 음높이 변화 후보를 찾았다. 구간 변동 폭 중앙값은 각각 약 46.0·138.4cent다. 파일의 음별 구성과 구간 길이가 다르므로 동일 음의 통제 실험이나 주법 판별 정확도로 해석하지 않는다.
- **노니로·니라:** 제목은 원출처 표기를 보존했다. 구간별 F0·RMS를 확보했지만 소리만으로 혀·입술 동작이나 모든 장식음 이름을 확정하지 않았다. 예를 들어 노니로 16.78~20.59초의 F0 중앙값은 356.5Hz로 기본음 3번 372.3Hz와 다르다. 같은 순번이라는 이유로 같은 율명을 복사하지 않는다.
- **스타카토:** 20ms RMS 창을 사용한 별도 검출에서는 17개 발음 후보가 약 0.21~0.34초 길이로 분리됐다. 85ms F0 창 기반의 긴 구간은 16개로 집계된다. 작은 발음을 긴 구간 검출에서 누락할 수 있어 두 결과를 보존한다. 이 차이를 실제 음 개수의 정답으로 단정하지 않는다.
- **크레센도:** 공격·감쇠 경계를 일부 제외한 각 구간의 첫·마지막 20% RMS 중앙값을 비교했다. 16구간 모두 후반이 약 +2.50~+7.01dB 커졌다. 이 녹음의 상대 강약이며 지각 음량·녹음 입력 게인이나 앱 마이크 허용치를 뜻하지 않는다.
- **다루치기:** 긴 구간 10개, 짧은 발음 후보 11개다. 구간 변동 폭 중앙값이 약 370.6cent여서 한 구간을 단일 지속음으로 축약하면 주법의 음높이 이동을 잃는다. 프레임 궤적과 발음 시각을 사용한다.
- **태평가:** 95.68초, 긴 구간 22개·짧은 발음 후보 29개다. 각 긴 구간에는 여러 음이 들어 있어 구간 F0 중앙값으로 율명을 붙이지 않았다. 예를 들어 0.64~5.71초는 약 953cent 폭으로 움직인다. 악보와 음표 단위로 연결하는 작업은 별도다.

기본음 13개와 달리 다른 파일은 14~20개 등 구간 수가 다르고, 요성·깊은요성·스타카토에는 약 1.5kHz 이상의 관측도 있다. **기본음 13개가 산조대금의 모든 음 또는 모든 파일의 공통 음 순서라고 가정하면 안 된다.**

## 한글 율명 연결

기본음 13개에 **저취 임·남·황·태·중 / 평취 임·남·황·태·중 / 역취 임·남·무**를 추정으로 연결했다. 요성 녹음의 20구간을 18음군으로 묶고 교육용 주요 7율명 배열을 반복 적용한 가설과 음높이 대응을 사용했다. 기본음과 대응 음군의 차이는 최대 43.43cent다. 이는 율명의 독립 정답 검증은 아니며 [가설·근거·행별 대응](basic-tone-analysis.md#13구간의-율명운지-연결-확인)을 함께 확인한다. 연결 명세에 한글 율명과 원음 구간·Hz·참고 운지를 기록한다. 태평가 전곡의 음표별 채보는 아직 수행하지 않았다. 재생용 개별 파일의 최신 대응은 아래 준비 결과와 catalog.json을 따른다.

## 추정 방법과 재현

[전체 분석 도구](../../../../../../data/src/analyze_digital_collection.py)는 기존 [YIN 계열 추정기](../../../../../../data/src/analyze_basic_tones.py)의 F0 계산과 WAV 읽기를 재사용한다. 입력 해시를 명세와 대조하고 원래 샘플레이트를 유지한다. 채널 평균만 수행하며 리샘플링·정규화·음높이 보정은 하지 않는다. 44.1kHz 파일의 창·hop은 같은 시간 길이에 가장 가까운 정수 샘플 수로 정한다.

| 측정 | 설정·해석 |
| --- | --- |
| F0 | 약 85.33ms 창·20ms hop, 100~2500Hz, CMND 기반 주기성 `≥0.85`인 추정만 요약 |
| 긴 발음 구간 | RMS 게이트 `max(0.0001, p95 RMS×0.025)`, 0.20초 이내 간격 병합, 0.30초 미만 제외 |
| 짧은 발음 | 별도 20ms RMS 창·10ms hop, 0.05초 간격 병합, 0.03초 미만 제외. 혀 동작을 검출한 결과가 아님 |
| 구간 내부 | 양끝 최대 0.20초 제외. 짧은 구간은 길이의 1/5씩 제외 |
| 주기적 변화 | 끊김 없는 2초 이상 F0를 cent로 바꾸고 선형 추세를 제거, Hann FFT의 2~10Hz 대역 에너지 비중 ≥0.5·변동 폭 ≥10cent일 때 주기 후보 반환 |
| 기본음 참조 | 변동 폭 ≤100cent·유효 F0 비율 ≥0.8인 구간에서 같은 악기의 실측 기본음과 가장 가까운 후보가 80cent 이내일 때 연결. 탐색용 휴리스틱이며 정답 허용 오차가 아님 |
| 강약 | RMS에 대해 구간 내부 첫·마지막 20% 중앙값의 dB 비율. 마이크 게인·감쇠·반주 영향의 분리 검증 전 |

기본음 참조는 **13개 실측 음에 대한 음향 후보 검색**이다. 목록에 없는 중간 음·다른 옥타브는 놓칠 수 있고, 가까운 후보끼리 혼동할 수도 있다. 기존 율명 추정의 불확실성도 그대로 전파된다. 연결이 없다고 발음이 틀렸다는 뜻이 아니며 `eligible_for_scoring=false`로 둔다. 실제 녹음 운지는 오디오에서 확정하지 않는다.

저장소 루트에서 실행한다. 원본 9개는 공식 페이지의 산조대금 전체 선택 다운로드로 받아 명세의 `rawPath`에 원형대로 둔다. `python`이 PATH에 없으면 준비된 Python 실행 파일을 사용한다. 산조 9개에는 Python·NumPy만 필요하며 MP3 디코더는 사용하지 않는다.

```powershell
python data/src/analyze_basic_tones.py --manifest docs/knowledge/data/instruments/daegeum/sanjo/sample-manifest.json --output-dir data/processed/instruments/daegeum/sanjo/basic-tone-v1
python data/src/analyze_digital_collection.py --manifest docs/knowledge/data/instruments/daegeum/sanjo/collection-manifest.json --output-dir data/processed/instruments/daegeum/sanjo/probe --only ngc-sanjo-2625
python data/src/analyze_digital_collection.py --manifest docs/knowledge/data/instruments/daegeum/sanjo/collection-manifest.json --output-dir data/processed/instruments/daegeum/sanjo/collection-v1
python -m unittest discover -s data/tests -p 'test_*.py' -v
```

자동 검사 26개를 통과했다. 합성음 추정, 음군 병합·가설 대응, PCM16 변환, 라벨·분할 수정 및 기존 생성 파일 보호 검사가 포함된다. 44.1/48kHz의 음높이, 알려진 5Hz 음높이 진동과 단순 글리산도 구분, 짧은 발음, 역상 스테레오, 다중 음 구간을 단일 음으로 잘못 연결하지 않는 조건을 검사했다. 실제 음악적 정답 정확도를 검증한 시험은 아니다.

## 태평가 정간보·오선보 확보

[국립국악원 『2022 개정교과서 표준악보집』 공식 게시물](https://www.gugak.go.kr/site/program/board/basicboard/view?boardid=44199&boardtypeid=102&menuid=001003002011&pagesize=10)에서 제공하는 PDF를 실제 다운로드했다. 25,875,334 bytes·PDF 250쪽이며 SHA-256은 `c8bf7a6e113c76d3f2a9154f1605ad36a9b5ad81ac3307f0c4e6f5bed17b7c19`다. 한 PDF 쪽에 두 인쇄 면이 배치되어 있으므로 쪽수 체계를 구분한다. 원본은 `data/raw/instruments/daegeum/ngc-textbook-standard-score-2022.pdf`, [공통 악보 명세](../score-manifest.json)에 보존했다.

| 확보 자료 | 실제 확인 범위 | 녹음과의 대응 |
| --- | --- | --- |
| 태평가 오선보 | PDF 127쪽, 인쇄 252~253쪽. 경기민요, 굿거리장단, 성악용 본절·후렴 악보. 렌더·육안 확인 | 민요 태평가의 선율 비교용. 녹음의 전곡 장식음·반복·속도·옥타브 대응 미검수 |
| 태평가 정간보 | PDF 176쪽, 인쇄 350~351쪽. 단소용 본절 일부, 문서 자체에 일부라고 명시. 렌더·육안 확인 | 산조대금 전용 정간보나 해당 녹음 전체를 채보한 판본으로 취급하지 않음 |

녹음 제목만으로 동명 가곡과 구분하지 않았다. 초기 지속음 약 0.9~1.7초는 G5 부근이며, 확보한 민요 성악 오선보 첫 음은 G4다. 이조·옥타브·장식음·편곡의 확인이 필요하며 첫 음 하나를 맞춘 것만으로 동일 판본이라고 확정하지 않는다. **현재 확보된 것은 비교용 악보 원본이며, 이 연주의 완전한 정간보·오선보 정답 쌍은 아니다.**

산조대금 전용 후보도 조회했다. [산조대금 태평가 정간보 게시물](https://www.mycom.kr/566)은 본문에서 중(仲) 글자의 인쇄 누락을 명시한다. 이미지 요청은 403이었고 [사이트 저작권 안내](https://mycom.kr/notice/2659)는 링크만 허용한다고 적혀 있어 원본을 복제하지 않았다. 여민락 카페의 산조6관 정간보·산조5관 오선율명보 후보도 원글 열람에 실패했다. 경로·실패·재배포 미확인은 [악보 연결 명세](performance-scores.json)에 남겼다. 정간보의 누락 글자를 임의 복원하거나 단소 율명을 그대로 산조대금 운지로 옮기지 않았다.
