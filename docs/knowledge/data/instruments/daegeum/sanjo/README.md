# 산조대금 데이터

작업: [S15P31E102-52](https://ssafy.atlassian.net/browse/S15P31E102-52), 관련 Story S15P31E102-43. 2026-10-22 준비.

## 사용할 자료

[생성·검증 명령](../../../../../../data/README.md#산조대금-사용-자료-준비)에 따라 로컬에서 자료를 생성한다. 생성 후 `ready-v1/README.md`와 `ready-v1/catalog.json`으로 파일·음 이름을 확인한다. 원음과 생성물은 Git에 포함되지 않는다.

| 분류 | 준비한 파일 |
| --- | --- |
| 기본음계 | 기본음 13개·요성 18개·깊은요성 15개를 분리한 WAV 46개 |
| 시김새 | 노니로 18·니라 14·스타카토 17·크레센도 16·다루치기 10구간을 분리한 WAV 75개 |
| 연주 | 태평가 WAV 1개와 오선보·정간보를 포함한 원본 악보집 PDF 1개 |

예: `기본음계/기본음/저취_황.wav`, 검색 키 `sanjo.jeochwi.hwang`.
사용 폴더는 `data/processed/instruments/daegeum/sanjo/ready-v1/`이며 원본을 보존하고 재생용 mono PCM16 WAV로 준비했다. 원래 샘플레이트를 유지했다. 생성 명령은 [data 실행 안내](../../../../../../data/README.md#산조대금-사용-자료-준비)를 따른다. 폴더는 Git 제외 경로다.

**개별 음원 121개 모두 취법·율명으로 연결했다.** 기본음13개만 비교하던 방식을 요성18음 기준으로 넓혔고, 깊은요성의 중심음과 시김새의 음렬·도착음을 분석했다. 다루치기는 `001_저취_임-저취_남.wav`처럼 아래 안정음→도착 안정음을 함께 표기한다. 이 복합 이름은 실측 음고의 대응이며 주법상 의도된 율명과 다를 수 있다.

**중복 검토 결과:** 깊은요성 저취 임은 원본상 연속된 한 연주를 잘못 분할한 것이었다. 두 조각과 누락된 끝음을 복구해 원본0.6–7.1초의 하나로 합쳤다. 노니로015·016 역취 임은3.795초 간격을 둔 별도 발음 두 개로 유지한다. 따라서 이전122개에서121개로 수정했다. 태평가를 포함하면122WAV다.

율명은 분석 추정이다. 추정 근거·실측 Hz·인접 후보·원본 ID·해시·구간·변환 정보는 `catalog.json`에 보존했다. 노니로007·스타카토013은 순서와 옥타브 대응까지 판단했고, 반복되는 음은 별도 구간으로 유지했다. 실제 녹음 운지·채점 정답 검수는 별개다.

**태평가 악보:** 원본 PDF 127쪽은 성악 오선보 본절·후렴, 176쪽은 단소용 정간보 일부다. 이 산조대금 녹음의 전곡과 맞는 두 악보는 아직 확보하지 못했다. 원본 PDF 한 개를 두 쪽으로 연결하며 임의로 채보·이조·수정하지 않았다.

원음은 국립국악원 공공누리 제1유형(출처표시), 악보는 제4유형(출처표시·비상업·무변경)이다. 재생용 음원의 가공·출처는 연결 정보에 기록했다. 악보는 상업 앱 배포용으로 승인된 자료가 아니다.
