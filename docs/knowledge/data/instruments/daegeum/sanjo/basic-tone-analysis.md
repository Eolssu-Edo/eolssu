## 방법과 재현

기존 [공통 분석 도구](../../../../../../data/src/analyze_basic_tones.py)를 수정 없이 사용했다. 양 채널의 평균, 원본 48kHz 유지, 4096샘플 창(약 85.33ms)·20ms 간격, RMS 게이트 `max(0.0001, p95×0.025)`로 구간을 찾는다. 이번 게이트는 약 `0.00718415`다. 활성 프레임 간 거리 0.20초 이하를 연결하고 0.30초 미만 후보는 버린다.

YIN 계열 자체 추정기는 100~2500Hz, CMND 임계값 0.15·지연 포물선 보간을 사용한다. 각 구간 양끝 0.20초를 뺀 내부에서 주기성 지표 `1−CMND ≥ 0.85`인 프레임을 요약한다. 중앙 1초 Hann 창·262144점 FFT의 최대 피크를 100~5000Hz에서 별도로 대조한다. 정규화·음높이 보정·리샘플링은 하지 않는다. 방법의 참고는 [de Cheveigné·Kawahara의 YIN 논문](https://pubmed.ncbi.nlm.nih.gov/12002874/)이다. 이번 코드는 차분 함수와 누적 평균 정규화(CMND)를 직접 구현한 탐색용 추정기이며 논문 전체 구현을 동일하게 재현했다는 뜻은 아니다. FFT 제로 패딩은 피크 위치를 세밀하게 읽기 위한 것이며 원래 창의 주파수 분해능을 높이지 않는다. 최대 스펙트럼 피크가 강한 배음일 수 있어 기본주파수의 독립 정답으로 취급하지 않는다.

저장소 루트에서 실행한다. `python`이 PATH에 없으면 준비된 Python 실행 파일의 절대 경로로 바꾼다.

```powershell
python data/src/analyze_basic_tones.py --manifest docs/knowledge/data/instruments/daegeum/sanjo/sample-manifest.json --output-dir data/processed/instruments/daegeum/sanjo/basic-tone-v1
```

## 13구간의 율명·운지 연결 확인

**13개 모두 한글 율명·취법의 분석 추정과 참고 운지를 연결했다.** 같은 국립국악원 「기본음+요성」 녹음과 실측 음높이를 대조해 앞선 9개 추정·2개 후보·2개 미확인 판정을 갱신했다. 아래 율명에는 음 순서에 관한 가설이 포함되며, 제작처가 제공한 정답 라벨은 아니다. 실제 녹음 악기가 피리사 제품이라는 가정은 사용하지 않았다.

### 판별 근거

1. **공식 기준 정보:** 국립국악원 공개 조회 응답의 악기 코드 19915, `본청 = C`, 기본음 항목 2550·파일명이 원본과 일치한다. 음별 율명·운지는 해당 응답에서 찾지 못했다. WAV XMP의 `key=C`만으로 정하지 않았다.
2. **산조대금 실음의 기준점:** [이용구의 기존 전통 산조대금 설명](https://patents.google.com/patent/KR200282888Y1/ko)은 전폐음 C, 5공까지 막은 음 E♭, 3공까지 막은 음 G♭, 2공까지 막은 음 A♭ 부근을 설명한다. 제조사 참고표의 임·남·황·태 명칭과 대조하되, 해당 특허의 개량악기 7음계는 적용하지 않았다. 평균율과의 정확한 일치를 가정하지 않는다.
3. **같은 출처의 다른 녹음:** 「기본음+요성」 2551의 20개 RMS 구간 중 인접한 같은 음의 반복 두 쌍을 합치면 18개 오름차순 음군이 된다. 병합 조건은 간격 0.4초 이하·음높이 차이 20cent 이하이며 대표값은 가장 긴 구성 구간의 실제 F0 중앙값이다. 제작처가 18개 음이라고 명시한 것은 아니다.
4. **율명 배열 가설:** 교육용 주요 7율명 `임·남·무·황·태·고·중`을 위 음군에 `7+7+4`로 배치했다. [부산대학교 강좌 안내](https://d-sce.pusan.ac.kr/kor/CMS/Lecture/stuView.do?cource_gbn=A&lect_no=A20240323&mCode=)의 검색 색인에서 이 7개 율명을 확인했으나 원문 재요청은 HTTP 503이었다. 교육용 배열이 이 녹음의 실제 연주 순서라는 직접 증거는 없으며, 출발 율명과 음군의 누락 여부에 관한 가설을 포함한다.
5. **두 녹음의 음향 대응:** 기본음 13개가 18음군 중 서로 다른 음군과 오름차순으로 대응하며, F0 차이는 절댓값 최대 43.43cent다. 이는 음높이 대응을 지지한다. 비교 대상에도 율명이 없으므로 이 수치 자체가 율명 정답을 독립 검증하지는 않는다. 저취·평취에서 같은 율명들의 근사 옥타브 반복도 함께 대조했다.

13개는 산조대금 전체 음 수나 모든 음원에 공통으로 붙는 번호표가 아니다. 이번 검색에서는 모든 산조대금 기본음 13개를 같은 순서로 정의한 공식 표준을 확인하지 못했다. 율명과 그에 대응하는 음역을 사용해 연결한다. 제조사명은 필수 사용자 입력으로 만들지 않는다.

### 기록과 검증 상태

[연결 명세](note-fingering-map.json)는 `inferred=13`, `confirmed=0`이다. 화면은 `저취 임 (추정)`처럼 한글을 우선 표시한다. `referenceFingeringCandidates`에는 모든 행의 참고 운지를 연결했고, 실제 녹음 운지인 `holes`는 null로 남겼다. 제작처 정답 라벨·독립 실연 검수는 미확인이며 `eligibleForNoteScoring=false`를 유지한다.

이번에 5·10번을 중, 12번을 역취 남, 13번을 역취 무로 추정한 추가 근거는 **18음군에 대한 배열 가설과 같은 출처 녹음 간 대응**이다. 같은 출처라는 이유만으로 동일 연주자·동일 악기라고 단정하지 않는다. 독립 검수에서는 특히 이 네 음과 배열 가설을 대조한다.
