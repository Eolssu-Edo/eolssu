## 분할·율명 판단의 근거

기존 분석은 원래 샘플레이트를 유지하고 채널 평균 후 YIN 계열 추정기(약 85.33ms 창·20ms 간격, 100–2500Hz)를 사용했다. RMS 문턱은 `max(0.0001, p95 × 0.025)`였다. 요성의 짧은 끊김은 음군으로 묶고, 스타카토는 별도 20ms RMS 창·10ms 간격에서 검출한 발음 구간을 사용했다. 측정 당시 원음 9개의 총 길이는 898.379초, 크기는 325,272,316 bytes였다.

| 사례 | 보존한 판단 |
| --- | --- |
| 깊은요성 첫 저취 임 | 약한 요성 때문에 두 조각으로 잘못 나뉜 연속 발음. 틈 3.465292–3.740초에도 28/28 프레임에서 주기음이 유지되고, 6.225292–7.03초의 끝음도 81/81 프레임에서 유지됐다. 원본 0.6–7.1초, 프레임 `[28800, 340800)`로 복구 |
| 노니로 역취 임 015·016 | 110.220–114.045292초와 117.840–121.305292초의 별도 발음. 사이 약 3.795초의 낮은 소음, F0 중앙값 1087.853/1088.970Hz. 두 구간 유지 |
| 노니로 007 | 529.801Hz의 최근접 평취 임 대신 음렬·옥타브 대조로 저취 중을 선택. 대안과 판단을 `evidence.sequenceDecision`에 보존 |
| 스타카토 013 | 1050.862Hz의 최근접 역취 임 대신 음렬·옥타브 대조로 평취 중을 선택. 대안을 보존 |
| 다루치기 10개 | 한 구간의 두 상승 동작을 유지. `gesture.lowerAnchor`와 `destination`, 복합 `displayLabel`을 보존. 상위 취법·율명은 도착 안정음의 대응 |

두 반복음 사례는 원본 WAV에 40ms 창·10ms 간격의 YIN을 RMS 게이트 없이 다시 적용하고 Hann FFT로 대조했다. 깊은요성 복구 구간의 269.8Hz는 양끝 0.2초씩을 제외하고 주기성 0.9 초과의 610프레임에서 구한 중앙값이다(p10 261.14Hz, p90 275.916Hz). 다루치기는 선택한 안정창의 RMS 제곱 가중 중앙값을 사용했다. 004의 첫 아래음은 부분음 혼재 때문에 제외하고 두 번째 반복에서 측정했다. 005의 실측 대응은 저취 태→평취 임이다. 이름은 실측 안정음의 대응이며 주법상 의도된 율명과 다를 수 있다. 대안·선택창은 그룹의 `evidence[행 ID].gesture`에 보존했다. 행의 도착음 이름·F0와 같은 정보는 중복 저장하지 않는다.

라벨 작성 후에는 이 결과를 명시적 구간으로 관리한다. 시작 포함·끝 제외이며 `round(초 × 샘플레이트)`로 원본 프레임을 정한다. 같은 율명의 별도 발음은 ID와 파일명으로 구분하고 자동 중복 제거하지 않는다.

## 태평가 묶음

연주는 95.68초 원음 WAV를 바이트 그대로 복사한다. 기존 준비본의 모노 변환본과 구분한다. 오선보·정간보는 한 원본 PDF를 한 번만 복사하고 각 쪽을 연결한다.

| 연결 | 확보 범위 | 해당 산조 녹음과의 대응 |
| --- | --- | --- |
| 오선보 | PDF 127쪽, 인쇄 252–253쪽. 경기민요 태평가의 성악용 본절·후렴 | 전곡의 장식음·반복·옥타브 대응 미검수 |
| 정간보 | PDF 176쪽, 인쇄 350–351쪽. 단소용 본절 일부 | 산조대금 전곡 악보로 확정하지 않음 |

`samePerformanceEditionVerified=false`와 실제 커버리지를 유지한다. 이 산조대금 녹음 전곡과 일치하는 두 악보는 아직 미확보다. [산조대금 정간보 후보](https://www.mycom.kr/566)는 본문에 중(仲) 인쇄 누락이 명시돼 있고, 원그림 요청 실패·링크만 허용 조건 때문에 복제하지 않았다.

## 열·행 구조 검증 — 2026-10-23

- 사용자가 승인한 토큰 절약 목적의 내부 입력 변경이다. labels v2는 열 이름과 상태를 한 번, 원본·주법·방법을 그룹마다 한 번 기록하고 음마다 한 행을 둔다. sources·performances v1은 변경하지 않았다.
- labels는 3,927줄·118,163 bytes에서 249줄·24,885 bytes로 축소됐다(바이트 78.94% 감소). 토큰 수는 측정하지 않았으므로 같은 토큰 감소율을 주장하지 않는다.
- 합성 입력 단위·CLI 검사 18개 통과. 열 순서·행 길이·자료형·예외 근거·자동 파일명·선택 후 번호 보존을 검사했다. 소금·단소·정악대금 ID도 실행했으며 실제 세 악기의 자료를 수집·라벨 검수했다는 뜻은 아니다.
- 기존 `e860c6e`와 121개 전부의 ID·순서·취법·율명·대표 주파수·대응 방법·표시 이름·파일명·구간이 일치한다. 실제 전체 내보내기의 121개 WAV SHA-256·프레임도 기존 준비본과 일치했다. 기본음계 46개·시김새 75개를 보존했다.
- 예외 근거 24개를 보존했다. 읽기 전용 별도 검토에서 병합 계보 3개, 복구 경계 근거 1개, 반복 발음 2개, 음렬 판단 2개, 일반 애매 후보 9개, 다루치기 10개의 선택창·대안·고유 검토 기록에 불일치가 없었다. 항목 간 중복 집계가 있다.
- 태평가 원음과 원본 PDF의 복사 결과가 각 입력 SHA-256과 일치한다. 두 악보 참조의 커버리지·대응 미검수 상태를 유지했다.
- 실제 노니로 두 번째 역취 임·깊은요성 저취 임·태평가 묶음의 선택 내보내기 통과. 두 번째 역취 임의 파일번호 `016`을 유지하고 선택 후에도 전체 출력은 바이트가 같았다. 깊은요성 선택 실행 중 Windows rename 접근 거부가 한 번 발생했으며, 실패한 출력이 없는 상태에서 재실행해 성공했다.
- 로컬 결과는 `data/processed/instruments/daegeum/sanjo/prepared-v3/`, 전수 대조 기록은 같은 상위 폴더의 `compact-validation.json`이다. 위 검증은 구조 변경의 정보·출력 보존 검사이며 율명의 음악적 정답을 새로 검증한 결과는 아니다.
