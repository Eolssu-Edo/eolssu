## 이용 조건과 악보

음원 페이지의 단소 자료는 **공공누리 제1유형(출처표시)**이다. 원음과 가공 클립 모두 출처를 표시하고, 가공 클립에는 구간 절단·채널 평균·PCM16 변환 내용을 표시한다.

[2022 국립국악원 개정교과서 표준악보집 게시물](https://www.gugak.go.kr/site/program/board/basicboard/view?menuid=001003002011&boardtypeid=102&boardid=44199&lang=ko)은 **제4유형(출처표시·비상업·무변경)**이다. 기존에 확보한 PDF를 단소 원본 폴더로 복사하고, SHA-256 `c8bf7a6e113c76d3f2a9154f1605ad36a9b5ad81ac3307f0c4e6f5bed17b7c19`와 25,875,334바이트를 다시 확인했다. PDF 231쪽(인쇄 460~461쪽)을 렌더링하여 왼쪽 위의 단소 「청성곡」 오선보 2단과 출처 설명을 확인했다. 같은 쪽 아래의 대금 악보를 단소 악보로 취급하지 않는다.

이 단소 악보는 김기수의 『단소율보』(1979)를 기준으로 만든 표준악보다. 90.699초 녹음과 전곡·시김새·반복·판본이 일치하는지는 검증하지 않았다. `comparisonScores`에만 넣고 PDF 전체를 변경 없이 복사한다. 상업 서비스 데이터셋 승인은 `false`다. PDF의 태평가·다른 단소 악보를 제목이 비슷하다는 이유로 「청성곡」에 연결하지 않았다.

정간보는 국악사전·표준악보집·e국악 자료와 공식 검색 결과를 확인했으나, 이번 원음과 연결할 수 있고 이용 조건까지 확인한 단소 「청성곡」 정간보 원본은 확보하지 못했다. 『단소율보』 등 서지의 존재와 실제 파일 확보를 구분한다. 정간보 항목을 빈 파일이나 다른 곡으로 채우지 않았다.

## 취법·율명 대응

[e국악아카데미 단소 발음법](https://academy.gugak.go.kr/dp/pds/HTML5-1-2-2/HTML5-1-2-2-3/index.htm)은 평취의 기본 5음을 `仲·林·無·潢·汰`로 설명하고 역취·옥타브 연습을 구분한다. 이번 녹음의 평취 3종은 이 순서에 대응하며, 역취 녹음은 같은 다섯 율명의 높은 음이다. 「음계+요성」은 평취 5음 뒤 역취 5음이다. 교육자료의 더 넓은 음역을 녹음에 없는 발음으로 추가하지 않았다.

## 재현과 검증

분석 환경은 Python 3.12.14·NumPy 2.3.5·SoundFile 0.13.1이다. 분석은 원본 샘플레이트를 유지한 채 채널 평균, 4,096샘플 YIN 창, 약 10ms 이동, 250~3,000Hz 범위로 수행했다. RMS 문턱은 `max(0.0001, p95 × 0.02)`, 무음 연결 한계는 0.18초다. 기본음 대표값은 구간 양끝 0.2초를 제외하고 주기성 0.85 이상인 프레임의 중앙값이다. 경계는 분석창 길이만큼 불확실할 수 있으며 초의 소수 자릿수는 정확도를 뜻하지 않는다.

`method`는 `tool:prepare_danso_assets@ac0e383e5335`다. 뒤 문자열은 로컬 준비 스크립트 SHA-256의 앞 12자리다. `research-v1/`의 `analyze_danso.py`, `prepare_danso_assets.py`, `prepared-evidence.json`에 실제 분석 코드·버전·모든 선택창을 보존했다. 분석 스크립트 SHA-256은 `2c313b6fd0ddba2b40cc9cecb90adf1c1886e6243612638a39299a77bc4272fb`다. Git에서 받은 라벨을 내보낼 때는 이 로컬 조사 스크립트를 실행할 필요가 없다.

원본을 `sources.json`의 `rawPath`에 준비하고 저장소 루트에서 실행한다. 출력은 아직 없는 폴더를 사용한다.

```powershell
python data/src/audio/export_dataset.py --dataset data/catalog/danso --output-dir data/processed/instruments/danso/prepared-v3
python data/src/audio/export_dataset.py --dataset data/catalog/danso --technique '음계+요성' --register 역취 --yulmyeong 무 --output-dir data/processed/instruments/danso/selected-yeok-mu-v3
python data/src/audio/export_dataset.py --dataset data/catalog/danso --performance ngc-danso-2369 --output-dir data/processed/instruments/danso/selected-cheongseong-v3
```

실제 결과는 전체 **56클립·연주 1묶음**, 조건 선택 **1클립**, 연주 선택 **원음 1개·원본 PDF 1개**였다. 별도 로컬 `research-v1/verify_danso.py`로 원본 33개 해시·크기, 56구간의 경계·중복, 106개 안정음 창의 범위·순서·행 연결, 클립 56개의 실제 PCM 값과 예상 절단 결과, 복사 자산 2개 해시를 검사해 통과했다. 조건 선택의 `ngc-danso-2342.tone-008`은 원래 번호 `008`을 유지하고 전체 내보내기의 같은 클립과 바이트가 같다. 선택창의 YIN 중앙값과 인접 FFT 피크 차이는 최대 37.405센트였다.

공통 exporter는 annotation에 남긴 복합음 76개 창의 유한수·라벨 내부 범위·원래 순서·비겹침·실제 프레임과 선택 안정음의 행 일치를 검사한다. 기본음 상세 근거 30개를 포함한 전체 106개 창은 별도 로컬 검사 대상이다. 소비자는 내부 음 순서를 단일음 채점 정답으로 사용하지 않아야 하며, 기존 두 기준음 `gesture`로 세 단계 이상 이동을 축약하지 않는다. 잘못된 창·행 불일치 36조건이 이전 exporter를 통과함을 먼저 재현한 뒤, 보완한 공통 테스트 43개가 통과했다. 출력 폴더의 `v3`를 `v4`로 바꿔 실제 전체·조건·연주 내보내기도 재실행했으며 56클립의 PCM·라벨·복사 자산은 기존 결과와 같았다. 전체 106개 창을 포함한 재검증 상세는 `research-v1/verification-v4.json`에 있다. 독립 연주자 검수, 「청성곡」 전곡 악보 대응, 정간보 확보는 남아 있다.

sourceProfiles 도입에서는 exporter의 v3 거부와 원본 검증 CLI의 누락된 프로필 참조 묵인을 먼저 재현했다. 공통 로더 연결 후 총 51개 테스트가 통과했다. v2·v3의 펼친 출처·라벨·출력 바이트 동등성, 개별 값과 `null`의 우선 적용, 중첩 객체의 독립성, 프로필·버전 오류, 원본 검증 CLI의 기존 목록 및 크기·해시·누락 오류 처리를 확인했다.
