# 산조대금 JGB·MIDI·CAT·M4A 변환

[S15P31E102-107](https://ssafy.atlassian.net/browse/S15P31E102-107) · Story30 · Epic18 · 2026-10-29. 단소 !87·소금 !44가 병합된 공통 엔진에 산조 프로필을 연결한다. 악기 종류·황종 기준·빠르기·필요한 상대음 음급과 표현 정책을 명시한 단선율 JGB를 처리한다. 관종·유파별 모범 연주나 실제 운지 가능성을 검증한 결과는 아니다.

[MR !43](https://lab.ssafy.com/s15-final/S15P31E102/-/merge_requests/43)은 정악대금 [MR !42](https://lab.ssafy.com/s15-final/S15P31E102/-/merge_requests/42)를 선행 변경으로 사용한다. 정악의 공통 악기 선택·표현 registry·샘플 경고를 먼저 반영한 뒤 산조표와 검증을 추가한다. 두 registry는 분리되어 있고 산조에 정악 복합음열을 자동 적용하지 않는다. 검토 기준 커밋은 정악 `22d8a601f0bcddfb7135b40cf5bc01e77e33538e`이며 병합 순서는 !42 → !43이다.

## CAT에서 구분되는 것

[공식 라이브러리](https://www.catseoul.com/gugak-library/)는 대금(통합)·산조 대금·정악 대금을 각각 배포한다. 확보한 Live Sampler v1.3 ZIP의 이름만 비교하지 않고, 내부 WAV 67개와 simple·modal 프리셋을 직접 대조했다.

| 확인 대상 | 정악대금 | 산조대금 |
| --- | --- | --- |
| simple 키존 | 32개, MIDI58~89 | 32개, MIDI60~91 |
| modal 키존 | 18개, MIDI58~89 | 18개, MIDI60~91 |
| ZIP 내부 WAV | 67개 | 정악의 67개와 파일명·SHA-256 모두 동일 |
| 공통 MIDI60~89 | sample·root·detune·volume·trim·loop | simple와 modal 각각 정악과 동일 |
| 전역 설정 | attack0.1ms, release50ms, gain−12dB | 정악과 동일 |

샘플 맵과 파일 경로 메타데이터를 제외한 전역 leaf 값도 표시 이름 외에는 같았다. 두 프리셋이 존재하지만 공통 음역의 서로 다른 산조·정악 음색을 확보한 것은 아니다. 이 결론은 조사한 포맷·버전에 한정한다. CAT 키존을 특정 관종의 전통적 실연 음역으로 쓰지 않는다.

- 산조 ZIP SHA-256: `b27d2247543a019a45f8aba593e3aece425d66a59cbb14d156eca294d36d65b4`
- 산조 simple XML SHA-256: `c226c32df09d470cc74ef5ae9b5b9d7c8f1c354a40982fd400f2180d97756d33`

## 산조에서 필요한 입력과 보류 조건

[국립국악원 단음 자료](https://www.gugak.go.kr/digitaleum/front/monotone/list.do)의 산조대금에는 기본음·요성·깊은요성·노니로·니라·스타카토·크레센도·다루치기가 별도 자료로 있다. 이 목록이 각 주법의 고정 cents·Hz·초 수치를 정하지는 않는다. 기존 [산조 원음 조사](sanjo-daegeum.md)의 발음 수·F0도 해당 녹음의 관측값이며 관종 전체의 음역·조율 정답이 아니다.

- 악기는 `sanjo-daegeum`으로 명시한다. `all`·일반 `daegeum`은 산조임을 확인한 근거 없이 선택하지 않는다. 정악/산조가 명시된 곡만 생성한다는 사용자 조건을 유지한다.
- 황종 MIDI와 정간/분·기준 음가를 입력한다. 빠르기는 `tempoBpmUserSet=true` 또는 명시적 `--bpm`이 필요하며 편집기 기본값을 확정값으로 사용하지 않는다. 악기 이름만 보고 전체 음높이를 이동하거나 조율을 선택하지 않는다. 원본에 저장된 수치라도 실제 판본 근거가 확인됐는지는 별도로 기록한다.
- 상대음 시김새에는 `joPreset` 또는 근거가 붙은 `playback.relative_scale`이 필요하다. 등장한 음 몇 개만으로 산조의 음계·조를 자동 판정하지 않는다.
- 농음·흘림은 `playback.expression_policy`로 mode·속도·폭·시점을 명시한다. 정악단소의 amplitude 농음이나 단소용 흘림 수치를 산조 기본값으로 복제하지 않는다. 표기가 없는 음에는 단소 실험의 추가 ±25cent 떨림을 적용하지 않는다.
- 프로필의 `technical_range`·`style_range`와 기본 `yoseong_mode`는 미확정 상태를 유지한다. 실제 렌더링에서는 CAT 키존·샘플 길이를 검사한다. 긴 음은 상관도·음높이·음량 검사를 통과한 안정 구간만 연장하고 실패하면 중단한다. 범위 밖 음을 임의로 옥타브 이동하지 않는다.

## 산조 기호의 지원 범위

[국립국악원 『창작을 위한 국악기 이해와 활용』](https://www.gugak.go.kr/site/program/board/basicboard/list?boardtypeid=116&menuid=001003003006002&lang=ko) 대금 장의 p162–164 도표를 기준으로 한다. p165는 정악·산조 예시를 함께 안내한다. 확보 PDF SHA-256은 `11957f76378c94c96d5e2f51a977d3bd4a5465cbebe76b833367398a8b4fcc32`다. `expressions.py`의 산조표는 확인한 일반 대금 기호만 명시적으로 등록하며, 단소나 소금 전체 표를 자동 선택하지 않는다.

아래 단계0은 본음이고 ±1은 작성자가 명시한 음계의 이웃음이다. 앞꾸밈은 뒤에 본음0이 이어진다. 같은 도형의 한글 이름·상류 ID 연결과 시김새의 실제 유파별 표현을 구분한다.

| 종류 | 입력과 음열 |
| --- | --- |
| 독립 음열 | 노[-1], 로[-2], 니[1], 리[2], 니나[1,0], 느나[-1,0], 느니[1,2], 노라[-1,-2], 니레나[2,1,0], 니로나[1,0,-1] |
| 붙임 음열 | 나니나[0,1,0], 나느나[0,-1,0] |
| 혀치기 | 명시한 본음에 붙여 음높이·길이를 유지하고 새 attack으로 발음. 자출은 별칭으로 쓰지 않음 |
| 반음올림표 | 명시한 본음과 이어지는 지속만+1반음. 다음에 적힌 본음에는 전파하지 않으며 s02는 별칭으로 쓰지 않음 |
| 앞꾸밈 | 니레[1], 니라[2], 노네[-1], 너녜/너네[-2], 노니로[0,1], 네로네[0,-1], 나니로/나니르[-1,1], 느로니르[0,-1,1] |
| 공통 같은음 반복 | 같은음표/repeat는 앞 음높이를 새 음으로 다시 발음. 지속으로 합치지 않음 |
| 자동 적용 제외 | 네로나·니느라니·느나르나니·떠이어표·느니르·니루니 등 위 도표로 산조 대응을 확인하지 않은 기호. 정악·소금의 복합음열을 복제하지 않음 |

나느나는 [국립국어원 『한국 음악 점자 규정 해설서』(2019)](https://www.korean.go.kr/common/download.do?c_file_name=korean_music_finger_alphabet.pdf&file_path=about&o_file_name=%ED%95%9C%EA%B5%AD+%EC%9D%8C%EC%95%85+%EC%A0%90%EC%9E%90+%EA%B7%9C%EC%A0%95+%ED%95%B4%EC%84%A4%EC%84%9C.pdf) 제18항 관악기 공통 장식음, 인쇄33쪽/PDF41쪽에 본음·한 음 아래·본음을 같은 길이로 내는 뜻으로 명시돼 있다. PDF SHA-256은 `b450b0f80502d03bd4968c29c63b171db7e976eaccd679a3d1c22e56041d639a`다. 세 음을 균등 분할하며 앞꾸밈 시간으로 줄이지 않는다. 이 이름의 의미 확인은 개별 스캔의 글리프가 정확히 전사됐다는 검증과 구분한다.

혀치기는 국립국악원 대금 교재 p161·164의 혀로 같은 음을 구분해 발음하는 설명을 따른다. `임{혀치기}`는 새 음 하나의 길이·음높이를 유지하며 샘플 attack을 다시 시작한다. 혀치기 전용 녹음의 음색 재현은 아니며, `sample-attack-approximation-not-tonguing-specific-recording`을 정책에 남긴다. 단독 혀치기·지속 뒤 부착·복합 꾸밈과 동시 지정은 모호한 범위를 숨기지 않고 거부한다. 원본의 `자출`을 자동으로 같은 이름으로 바꾸지 않는다.

교재 p158은 같은 닫는 괄호형 기호가 정악에서는 퇴성, 민속악에서는 음 시작에 반음 아래로 꺾는 의미로 쓰임을 설명한다. 원본 글리프만으로 끝부분 하행 곡선에 대응시키지 않는다. JGB의 명시적 `흘림표`·`퇴성`·`풀어내림표`는 작성자가 선택한 의미와 수치를 합성하는 경로다. 특히 풀어내림의 농음+하행 결합을 산조 원보의 특정 글리프와 검증된 일대일 대응이라고 보고하지 않는다. 시작 부분의 꺾음 같은 실제 곡선은 근거가 붙은 표현 프로필의 `pitch_curve.points`로 직접 지정할 수 있다.

반음올림표와 꺾는음의 판본 근거는 김희영의 [「산조대금을 활용한 민요 지도방안」(한양대 석사,2013)](https://dl.nanet.go.kr/SearchDetailView.do?cn=KDMT1201331912) 진도아리랑 범례(PDF84/인쇄76쪽)와 원보(PDF88/인쇄80쪽)다. 공개 뷰어로 범례·원보를 대조했으며 전체 PDF를 확보한 것으로 기록하지 않는다. 반음올림은 해당 본음과 지속만+1반음으로 바꾸며, 확인한 `남{니레}{반음올림표}`는 명시 음급[2,7,9,10]과 황종63에서 앞꾸밈77→본음73이다. 그 밖의 반음올림+복합 음열/꾸밈 조합은 미확정으로 거부한다.

같은 논문의 한오백년(PDF79/인쇄71쪽)은 닫는 괄호형을 짧고 부드러운 흘림으로, 진도아리랑은 굵고 짧은 꺾기로 설명한다. 따라서 `흘림표` 전체를 꺾는음으로 치환하지 않는다. 산조의 canonical `꺾는음`에는 `expression_policy.kkeok`의 명시 points가 필요하며 기본 수치는 없다.

기보음 기준 꺾기는 `reference: "written-pitch"`와 예시 points `[[0,100],[0.15,0],[1,0]]`를 선택할 수 있다. 반음올림이 있는 남73은 MIDI 기준0→-100cent, 없는 남72는+100→0cent로 변환해 모두73→72로 내려간다. 이 수치와 시점은 청취용 선택이며 원전의 고정 수치가 아니다. 올림표를 누락된 것으로 덧붙이지 않으며 source-map에 실제 반음올림량을 기록한다.

지속 중 미올림 음에 꺾기가 붙으면 그 기호 앞은0cent를 유지하고 기호 시작에+100cent로 진입한다. 이 경우에만 IR `pitch_curve.step_at_delay=true`를 명시 생성한다. 기본값은false이며 기존 지연 곡선의 비영점 시작 거부는 유지한다. 플래그는 bool·points·양수 delay만 허용하고, MIDI에는 기호 직전tick과 시작tick을 넣어 늦거나 미리 적용하지 않는다. 남의 풀어내림3곳은 이미+1반음인 본음73에0→-100cent 초기 하강과 잔농음을 따로 지정하며+100cent를 중복 가산하지 않는다.

## 실행과 확인

[검사용 JGB](../../../data/src/playback/examples/sanjo-authored.jgb.json)는 직접 작성한 4정간이다. 60정간/분, 황종 MIDI63, 상대음 음급, pitch 농음과 흘림 수치는 모두 작성자가 선택한 검사값이다. 실제 산조 악보·관종·유파의 정답을 나타내지 않는다. 검사용 명시 정책을 실제 곡의 검증된 주법으로 복사하지 않는다.

```powershell
python -X utf8 -m data.src.playback --score data/src/playback/examples/sanjo-authored.jgb.json --assets C:/local-gugak/assets.json --instrument sanjo-daegeum --out data/processed/playback/sanjo-authored
```

`assets.json`에 `sanjo-daegeum`의 로컬 v1.3 ZIP 경로가 필요하며 M4A는 FFmpeg·ffprobe 경로도 필요하다. 공통 [실행 안내](../../../data/src/playback/README.md)를 따른다. 입력 하나의 변환에 필요한 원본 JGB·정규화 score·source-map·MIDI·M4A·프리셋 및 샘플 해시를 출력한다. 배치 처리와 HTML 생성은 포함하지 않는다. WAV가 필요하면 별도 출력 폴더와 `--audio-format wav`를 사용한다.

실제 목록은 원본을 보존한 준비 JGB에 기종 근거·빠르기 선택·상대음 음급·표현 정책을 따로 기록해 생성한다. 사용자가 이번 산조 작업에서 승인한60정간/분은 숫자 빠르기를 확인하지 못한 곡의 연습용 선택값이며, 원전 수치나 모범 연주로 표시하지 않는다. 원전에 장단이 있는 곡에는 기존 장단표의 선택 경로를 기록한다.

CAT 원본 ZIP·WAV와 생성 음원은 Git에 넣지 않는다. 출처 표시는 생성 결과에 보존한다. 실제 샘플 생성 성공은 전문가 청감·원보 검수를 뜻하지 않는다.

빠르기·반복 계획은 `sanjo-daegeum-performance/v1`, 별도 표현 프로필은 `sanjo-daegeum-expression-profile/v1`이다. 원본 바이트 해시가 다르거나 다른 악기의 schema이면 거부한다. 단소 전용100ms 연결 시작점과 추가25cent 떨림은 산조에 적용하지 않는다.
