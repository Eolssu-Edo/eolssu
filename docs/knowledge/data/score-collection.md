## 분류 근거와 제한

- 대금 교실은 원문에 명시된 대금으로 분류했다. 정악대금·산조대금 규격을 확인하지 않은 자료를 임의로 세분하지 않았다. [공식 강좌](https://academy.gugak.go.kr/course/active/detail.do?courseActiveSeq=914)
- 산조대금 논문은 김희영, 「산조대금을 활용한 민요 지도방안」, 한양대학교 교육대학원, 2013의 실제 악보 페이지를 확인했다. 기초 연습 3묶음, 두꺼비, 닐리리야, 몽금포타령, 한오백년, 진도아리랑을 분리했다. 진도아리랑은 목차의 인쇄79가 아니라 PDF88(인쇄80)에 있다.
- 2026-10-24 사용자 요청으로 대금 28개·산조대금 8개를 `대금` 폴더에 모으고, 단소 50개·소금 21개도 각 폴더 바로 아래로 옮겼다. 파일명과 원래 악기 분류는 보존했다. 목록·manifest 경로를 갱신하고 PDF 107개의 이동 전후 SHA-256 일치, 세 폴더의 하위 폴더·비PDF 파일 0개를 확인했다. 근거는 출력 폴더의 `폴더정리검증.json`이다.
- 교과서 표준악보집의 단소 25항목·소금 17항목은 악기별 목차와 실제 페이지를 연결했다. PDF 한 페이지가 인쇄본 두 쪽의 펼침면이다. 아리랑은 단소 PDF173(인쇄344–345), 소금 PDF194(인쇄386–387)이다. PDF169·191은 구아리랑이다.

- JG-like 텍스트는 우물사이 `.jgb.json`과 다른 형식이다. 공개 페이지도 OMR·규칙 기반 변환 결과가 완전히 검수되지 않았다고 설명한다. [데이터셋 설명](https://www.danbinaerin.com/Jeongganbo_dataset/)
