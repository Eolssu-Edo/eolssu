## 운영 연결의 미완료 조건

현재 DB/reference는 단소와 공개4곡이며 Notion 전체 자료가 운영 적재된 상태가 아니다. 현재 모범 음원 경로는 보안 허용 목록에만 있고 Controller·저장URL·버전 연결 계약이 없다. Notion 첨부를 임의 DB ID나 만료 URL로 앱에 하드코딩하지 않는다. 다른 악기/곡의 범위·난이도·채점가능 여부·공통악보 변환과 기종별 데이터 의미는 해당 담당과 연결해야 한다.

표준악보집은 현재 catalog에 KOGL-4·`serviceDatasetApproved:false`·별도 변경 허락 미확보로 기록돼 있다. CAT 공식 웹 조회는 timeout이고 ZIP에 이용허락 문서를 찾지 못했다. 파일을 보유하거나 합성이 성공했다는 사실을 공개 서비스 사용권 승인으로 보지 않는다. 기존 DATA 위치에 올리는 연결 검증 후보와 Play 운영 배포 준비를 구별한다. 사용권 담당은 미정이며 원자료/샘플 권리와 서비스 제공 조건 확인이 필요하다.

청감·전문가 승인·Android 실제 재생/오디오 포커스·실기기 검사는 미검증이다. 생성된 M4A는 사용자 마이크 녹음 대역이나 녹음→업로드→분석 성공 증거가 아니다. 기존 Android release3·제출 준비 미완료 판정과 실기기 인계표는 그대로 유효하다.
