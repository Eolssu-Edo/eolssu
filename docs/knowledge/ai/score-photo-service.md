## 현재 동작

사진 업로드 → PNG 정규화/원본 해시 보존 → 표기법별 로컬 인식 → 오선보 실음 또는 정간보 율명 초안 저장 → 기존 해석 엔진/MIDI → CAT WAV → 미검수 미리듣기 재생·다운로드. 원본 대조·수정 후 사용자 확인 렌더도 지원한다.

후속 요청으로 Ollama와 Audiveris를 로컬에 설치하고 실제 사진 자동 인식을 시험했다. 오선보는 Audiveris MusicXML 기반, 정간보는 직사각형 격자·기호 분할 → Qwen3-VL 4B 기호 분류 → 명시적 음높이/시간 규칙으로 처리한다. 범용 VLM에 전체 악보를 바로 JSON으로 요청한 결과보다 범위를 나눈 경로가 유효했다. 모델 출력은 계속 `machine-transcribed-unverified`이며, 자동 출력은 `review_mode=automatic-preview`로 구분한다. 실제 확인 요청만 `user-confirmed`와 `reviewed_revision`을 남기고 **기계 전사를 수동 전사로 바꾸지 않는다**. 형식·음원 생성 성공은 음악적 정확성의 증거가 아니다.

새 서비스의 추가 흔들림 기본값은 ±25cent, 선택값은 ±100/3cent·없음이다. 이전 `build_vibrato_depth_comparison.py`의 1/4·1/3은 시간 분할이 아니라 반음 대비 피치 폭이었다. 긴 음 0.65초 이상, 4.5Hz, 지연 0.22초, fade-in/out 0.18/0.16초를 재사용한다. 원보의 pitch/mixed 요성은 중복 적용하지 않고 음량 요성의 CC11은 유지한다. 기존 CLI 기본값은 추가 흔들림 없음으로 보존한다.

## 로컬 API

기준 주소 `http://127.0.0.1:8765`. 쓰기에는 `X-Playback-Client: local` 헤더가 필요하며 브라우저는 같은 origin만 허용한다. 이 헤더는 사용자 인증이 아니다. 서버의 `--assets`, `--storage`, `--model`, `--ollama-url`은 실행자가 설정하며 요청 본문에서 파일 경로나 외부 주소를 받지 않는다.

| 요청 | 입력 / 결과 |
| --- | --- |
| `GET /api/config` | 단소·기본 quarter·인식 설정 유무 |
| `POST /api/scores?notation=staff 또는 jeonggan` | 이미지 바이트 직접 전송, multipart 아님. 201: id, image_url, revision=0, score, regions, state=needs_review |
| `GET /api/scores/{id}` | 저장한 작업. 브라우저 주소 `/#id`로 열기 |
| `PUT /api/scores/{id}/draft` | `{revision, score, regions}`. 검증 성공 시 revision 증가, needs_review. regions는 `{note_id,bbox:[x,y,width,height]}`이고 0~1 상대 좌표 |
| `POST /api/scores/{id}/recognize` | `{revision,context}`. 실행자의 로컬 모델로 초안 생성. context에 선택적 quarter_bpm/reading_direction 힌트 가능. 모든 결과는 needs_review |
| `POST /api/scores/{id}/automatic` | `{revision,vibrato,context?}`. 사진 인식부터 CAT까지 실행, 성공 시 작업 전체와 state=preview_ready. 사람 확인을 꾸며내지 않음. 렌더 실패 시 인식 초안·오류 보존 |
| `POST /api/scores/{id}/render` | `{revision,approved:true,vibrato:quarter 또는 third 또는 none}`. audio_url, midi_url, score_url, timeline, regions, seconds, credit 반환 |
| `GET /api/scores/{id}/renders/{render_id}/danso.wav` | WAV, 바이트 범위 재생 지원. MIDI/score.json도 허용 목록으로 제공 |

timeline은 `{note_ids,start,end,pitch}` 배열이며 시간 단위는 초다. 원본 ID와 장식 확장 parent ID를 그대로 유지한다. 이 API는 새 로컬 API이며 기존 `SongRow.scoreJson`이나 평가 API 계약을 바꾸지 않는다. `playback`은 현재 AI wheel에 포함되지 않으므로 안내한 소스 checkout의 `ai/`에서 실행한다.

같은 revision·표현·review_mode의 바로 이전 성공 요청은 같은 결과 URL을 반환한다. 악보 수정 중 생성이 끝나면 최신 revision을 다시 확인하고 오래된 결과를 게시하지 않는다. 동시 인식/생성은 409, 오래된 revision은 409, 입력 오류는 422, 크기 초과는 413, 모델/자산 사용 불가는 503이다. 모델·CAT 실패 시 가짜 음표나 무음 파일로 대체하지 않는다. 새 렌더는 임시 폴더에서 완성한 뒤 이동하며 이전 결과 URL은 유지한다. OS/디스크 고장 전체에 대한 트랜잭션은 보장하지 않는다.

### 환경과 판독 경로

RTX 4060 Ti 8GB, RAM 32GB, Windows, 위 Python 환경에서 실행했다. Ollama `0.40.10`, `qwen3-vl:4b-instruct-q4_K_M`(digest `84f7ed8042fa7cdbd902f7dcb7d0370e032095047cc3244179f263b77b5bc318`), Audiveris `5.11.0`과 동봉 JRE, Tesseract `eng.traineddata`를 사용했다. 설치 경로는 `%LOCALAPPDATA%/score-playback/`이며 저장소에 모델을 넣지 않았다. 로컬 HTTP만 사용하고 클라우드 추론·비밀 키는 사용하지 않았다. Qwen 추론은 seed 42, temperature 0.2, repeat_penalty 1.1, num_ctx 8192, num_batch 128, num_predict 6000을 기준으로 한다. 기호·메타데이터의 더 작은 응답 제한은 각 trace에 보존한다. 시간은 한 번의 준비된 모델 실행값으로, 반복 측정 평균이나 최초 로딩 시간이 아니다.

- **오선보**: Audiveris → MusicXML 단선율 파서 → Qwen이 실제 오선 위치 기반 crop에서 조표·8va·빠르기 보조 판독 → 실음 초안. 원본 MXL/OMR와 보정 XML을 모두 보존한다. 조표·옥타브를 명시적 음높이에 한 번만 반영하며 임시표는 보존한다. 조표를 음표로 오인한 선행 음 삭제는 5개 플랫 모양·위치·헤더 위치·낮은 신뢰도·XML/OMR 음표 대응이 함께 맞는 제한된 경우만 수행한다. 이 부분은 평가 교재에 맞춘 적응이며 일반 조표 전체를 검증한 결과가 아니다.
- **정간보**: 짧은 직사각형 격자 탐지 → 칸의 세로 1~3분할 → 글자별 로컬 Qwen 분류 → 명시적 율명·청성·지속선·`h` 해석. `h`는 교재의 黃太仲林無 5음 문맥에서 한 음 아래·두 음 아래로 나눈다. 중성 黃=MIDI63, 한 칸=3/2 quarter, 위→아래·오른쪽→왼쪽은 입력 문맥/미리듣기 가정이다. 사진에 없는 조율·빠르기를 읽었다고 기록하지 않는다. 원문 글자와 분류의 차이도 경고에 남긴다.

### 입력과 평가 기준

국립국악원 단소 교재의 세령산 도판을 사용했다. 오선보 4음과 정간보 2칸은 `eng_danso.pdf`의 PDF 14쪽/인쇄 38쪽을 600dpi로 래스터화한 원문 crop이며 새로 그린 합성 악보가 아니다. 각각 `[1280,670,710,360]`, `[2760,2344,188,404]`의 x/y/width/height를 사용했다. 긴 오선보는 앞선 작업의 같은 곡 첫 장단 `first-jangdan.png`(2600×410)다. **서로 독립된 곡 3개가 아니며, 카메라로 촬영한 새 사진도 아니다.** 짧은 두 정답은 다른 에이전트가 원보를 읽어 작성했고 긴 오선보는 기존 원보 대조 예제다. 전문가 검수는 받지 않았다. `independent-*-first-*.json`에 판독 근거·좌표·출처를 남겼다.

`playback.evaluate`는 정답 JSON을 **추론 후에만** 읽어 비교한다. 그러나 같은 교재를 구현 조정에도 사용했으므로 홀드아웃·일반화 정확도로 부르지 않는다. 본음 이벤트의 음높이와 음높이+유리수 길이를 각각 삽입·누락이 가능한 편집 거리로 정렬한다. 장식 객체 수·템포·전체 박 길이는 별도 항목이다. 원문을 청성 율명으로 정확히 전사했는지와 최종 MIDI 음높이 일치는 구분한다.

| --- | ---: | ---: | --- | ---: |
| 오선보 첫 4음, 조표·8va·빠르기 포함 | 4/4 | 4/4 | 67.5, 정답과 같음 | 5.422초 |

긴 오선보의 틀린 14개 길이는 3연음·5연음의 축소 비율을 놓친 결과다. 전체 길이가 정답 15quarter에서 127/8(15.875)quarter로 늘었고, 정답 장식 객체 4개도 자동 결과에는 0개다. 따라서 **37/37 음높이를 모범 연주 완전 일치로 해석할 수 없다.** 정간보는 해당 두 칸에서 음높이·상대 길이가 같았지만 사진에 없는 템포는 맞히지 않았다. 전체 정간보 격자는 불규칙한 칸·복잡한 분할 때문에 지원하지 않으며 실제 HTTP에서 503과 한국어 안내를 반환했다. 가짜 초안이나 성공 음원은 생성하지 않았다.

비교 실험도 보존했다. 전체 이미지를 범용 Qwen4B에 바로 요청하면 빈 음표/반복 경고와 출력 잘림이 발생했고, 8B는 4음 crop에서 8음을 만들어 약 133.6초가 걸려 채택하지 않았다. Audiveris 단독은 긴 구간에서 조표·8va 누락과 선행 가짜 음으로 38음을 출력했다. 공개 `MALerLab/jeongganbo-omr` 체크포인트를 별도 CPU 환경에서 시험한 두 본음은 0/2로, 이번 사진 판독 경로에는 채택하지 않았다. 모델의 공개 데이터셋 수치를 이 교재의 정확도로 전용하지 않는다.

### 범례 판독과 기존 페이지 회귀

복합 정간보는 격자 검출 뒤 원본의 연결 요소를 분리하고 국립국악원 단소 교재의 일반 범례41개와 획을 대조한다. 율명 본체·삼수변·주음과 장식의 간격, 짧은 점·긴 선, ∧/λ의 교차점, I의 가운데 직선과 양끝 획, w의 꺾임을 근거로 분류한다. 곡별 정답 음열이나 대상 페이지 glyph를 atlas에 넣지 않는다. 외부 atlas 경로는 `-JeongganAtlas` 또는 `PLAYBACK_JEONGGAN_ATLAS`로 지정하며 trace에 manifest·이미지 해시를 남긴다. 범례 재생성 스크립트와 원본 판본/렌더러 조건은 `ai/playback/README.md`에 기록했다.

복합기호용 경로를 켠 뒤 새야새야에서 가사 열을 바깥 기호로 읽는 회귀가 발견됐다. 격자 단계가 이미 비리듬 머리글/꼬리글로 판정한 영역과 다른 음악 칸 내부의 연결 요소는 제외하고, 빈 여백 열의 실제 장식은 계속 읽도록 수정했다. 세령산의 바깥 긴 선1개·五2개는 그대로 남았다. 수정 후 새야새야 전체/수동 crop은 각각32/32발음+8/8쉼표의 음높이·길이, 기존 세령산2칸은4/4를 유지했다. 두 새야새야 입력은 같은 원보이므로 독립 표본2개로 계산하지 않는다. 실제 실행·trace·분모는 로컬 `jeonggan-margin-regression/`에 보존했다.

### API와 화면 동작

사진 업로드 시 악기를 지정하고 `/automatic`으로 새로 인식·합성한다. 이후 `/preview`는 저장된 같은 음표를 선택 악기로 다시 합성하며 OCR을 호출하지 않는다. 악기 선택은 IR 밖의 재생 옵션이며 원본 음높이·황종·기보 옥타브·박자를 변경하지 않는다. 음역 이탈·샘플 소진·키존 누락은 오류로 남기고 임의 음표 삭제나 자동 옥타브 접기를 하지 않는다. 미검수 미리듣기와 원보를 확인한 `/render`는 분리하고 기존 단소 작업·다운로드 주소는 호환한다.

캐시는 revision·악기·흔들림·검수 모드를 구분한다. 새 악기 생성 실패는 `error_instrument`와 오류를 저장하며 이전 성공 result와 파일을 보존한다. 화면에서도 이전 악기와 현재 선택을 구분한다. 음표를 수정하지 않고 악기만 바꿀 때는 draft를 다시 저장하지 않아 revision·이전 결과를 보존한다. 손상 ZIP·압축 프리셋·샘플 이름 누락은503으로 처리하고 로컬 진단을 남긴다. 다른 악기의 재생은 계속 가능하다.

## 남은 통합·품질 범위

모델 설치·제한된 실제 악보 평가·네 악기의 로컬 자동 미리듣기와 개발용 세령산 전체 페이지를 처리했다. 실제 촬영 오선보는 두 장의 수동 선택 구간에서1장 성공·1장 실패였고, 읽을 수 있는 실촬영 정간보의 출처·사용조건은 확보하지 못했다. 일반 카메라 사진의 안정적인 전체 페이지 인식, 모든 국악 장식·연음, 전문가 청감 검수는 미완료다. MusicXML은 Audiveris가 생성한 단선율의 지원 부분만 읽으며 범용 MusicXML 업로드 기능은 아니다. Compose 앱/백엔드의 업로드·플레이어와 운영 인증·테넌트 격리·보관/삭제 정책·배포는 별도로 통합해야 한다. 단소 이외 프로필은 기존 106~108 브랜치에서 가져와 로컬 사진 서비스에 통합했으며, 게시 브랜치의 통합·Push는 하지 않았다. 긴 음의 CAT 샘플 소진은 계속 오류이며 임의 반복하지 않는다. 이 구현만으로 제품 모범 연주 품질이나 운영 준비 완료를 주장하지 않는다.
