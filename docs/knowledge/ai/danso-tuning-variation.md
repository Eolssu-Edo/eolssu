# 단소 단음 녹음의 조율 흔들림: 김 세기·취법별 보정량

- 작업: [S15P31E102-242](https://ssafy.atlassian.net/browse/S15P31E102-242)
- 상태: 측정 완료(2026-10-28). 연주자 한 명·악기 하나의 녹음이라 조율 보정 상한을 바꾸는 근거로 쓰지 않는다.
- 입력: 국립국악원 국악기 디지털 음원 단소 기본음계 5개(ngc-danso-2338~2342, 공공누리 제1유형), 음 구간은 [단소 라벨](../../../data/annotations/audio/danso/). 원본 확인은 `python data/src/catalog/verify_sources.py --dataset danso`.
- 재현: `ai/`에서 `uv run python -m evaluation.danso_tuning --raw-root <data/raw가 있는 저장소 루트>`
- 코드: [측정](../../../ai/evaluation/danso_tuning.py), [채점](../../../ai/src/ai_service/pipelines/scoring.py)

## 방법

채점과 같은 pYIN 설정(`pyin_f0`, 16kHz, 10ms 간격)으로 f0를 구하고, 라벨 구간마다 소리 있는 가운데 60% 프레임을 기준음 황 = 311.13Hz의 목표 음에서 몇 센트 떨어졌는지 잰다. 녹음 보정량은 모든 음의 가운데 프레임을 합친 중앙값(채점의 조율 보정과 같은 식), 잔차는 음별 중앙값 − 보정량이다.

데이터 조사의 대표 주파수([단소 조사](../data/danso.md), YIN 4096표본)로 구한 보정량은 평취 강 +10.9, 중 0.0, 약 −3.7, 역취 −26.9센트다. 이번 값과의 차이는 −1.3~+5.0센트로, pYIN 기본 해상도(10센트 칸)에서 생기는 반올림 범위 안이다.

## 해석

- **김 세기만으로 곡 전체가 약 20센트 움직인다**(강 +15 ~ 약 −5). 조율 보정이 흡수하는 대상이며, 단소 4곡의 상한 100은 물론 반음 이웃 곡의 상한 40 안에도 든다.
- **역취는 음마다 따로 어긋난다.** 역취 녹음 안에서 중·임과 무·황의 차이가 40센트다. 곡 전체에 같은 값을 빼는 보정은 이 차이를 줄이지 못한다. 평취와 역취를 섞어 분 녹음(음계+요성)에서 가장 큰 잔차는 역취 무 −30으로, 음정 허용 범위 50센트의 60%를 쓴다.
- **pYIN은 실제 단소 단음에서 옥타브를 잘못 잡지 않았다**(가운데뿐 아니라 소리 있는 모든 프레임 기준 0%).
- 측정 값이 5·10센트 단위로만 나온다. pYIN의 음높이 칸이 10센트(`resolution=0.1`반음)라서다. 허용 범위를 30·40센트로 좁혀 비교할 때는 이 해상도가 판정 경계를 흔들 수 있다.

## 한계와 후속

- 연주자·악기·녹음 환경이 하나다. 다른 연주자·악기의 보정량 분포는 실제 4곡 녹음(S15P31E102-158)에서 본다.
- 아리랑에서 역취로 부는 음은 청중 하나라(이 녹음에서 역취 중 잔차 +30, 보정 전 +5) 4곡 채점에는 영향이 작다. 역취 무·황을 쓰는 곡이 들어오면 취법별 보정을 검토한다.
- pYIN 해상도를 1센트로 올리는 것은 채점 결과를 바꾸므로 `modelVersion`을 올리고 평가 도구로 전후를 비교한 뒤 정한다.
