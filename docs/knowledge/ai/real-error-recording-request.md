# 일부러 틀린 실제 녹음 요청서 (아리랑, 단소·소금)

- 작업: [S15P31E102-353](https://ssafy.atlassian.net/browse/S15P31E102-353)
- 목적: 채점(pyin-4)이 실제 연주의 틀린 음을 얼마나 잡는지 잰다. 정상 연주를 틀렸다고 하지 않는지도 함께 본다.
- 결과: 녹음은 `data/raw/recordings/`에만 두고 커밋하지 않는다. 정답 기록은 `data/annotations/recordings/`.

## 녹음 방법

- 곡: 아리랑. 단소는 표준악보집 판본(`ngc-standard-2022-p173`, 61음), 소금은 표준악보집 판본(국립국악원 2022 표준악보집 소금 아리랑, PDF194, 61음).
- 빠르기: 메트로놈 **72**(점4분음표, 정간 하나 = 한 박). 메트로놈 소리는 **이어폰으로만** 듣는다. 딸깍 소리가 녹음에 들어가면 음 시작 측정이 흔들린다.
- 시작: 메트로놈 네 번을 듣고 다섯 번째 박에 첫 음을 분다. 녹음은 첫 음 바로 전에 시작하고 마지막 음이 끝나면 바로 멈춘다.
- 기기·조건: 갤럭시 S24+ 기본 녹음 앱, 마이크와 약 20~30cm, 조용한 방. 158 녹음과 같게 맞춘다.
- 테이크: 악기마다 아래 6개. 한 번 틀리면 그 테이크를 처음부터 다시 분다. 정해진 곳 말고는 평소처럼 맞게 분다.
- 파일 이름: `<악기>_<테이크>.m4a`, 예: `단소_정상A.m4a`, `소금_빼먹기.m4a`.

| 테이크 | 하는 일 |
| --- | --- |
| 정상A, 정상B | 틀리지 않게 두 번 |
| 음바꿈 | 표의 음을 다른 율로 분다 |
| 옥타브 | 표의 음을 한 옥타브 위(역취)로 분다 |
| 박자 | 표의 음을 반 박 늦게(앞 음을 반 박 더 끌고) 또는 반 박 일찍(앞 음을 반 박 줄이고) 시작한다. 그 음의 끝은 원래대로 맞춘다 |
| 빼먹기 | 표의 음 길이만큼 소리를 내지 않고 쉰다 |

음 번호는 악보 처음부터 센 음 순서(쉼 제외)다. 줄·칸은 정간보에서 몇 번째 줄의 몇 번째 정간인지다.

## 고른 기준

- 오류마다 서로 이웃하지 않게 다섯 곳을 고르고 곡 전체에 퍼뜨렸다.
- 음바꿈은 바꾼 음이 앞뒤 음과 같아지지 않는 곳만 골랐다. 같아지면 정렬이 이웃 음으로 붙여 음바꿈인지 가릴 수 없다.
- 옥타브는 입문자가 역취로 낼 수 있는 낮은 음(단소 중, 소금 임)을 골랐고, 짧은 음(1/3박)을 하나 넣어 짧게 분 옥타브 위 음([S15P31E102-251](short-octave-error.md))을 실제로 확인한다.
- 박자·빼먹기는 1박 넘는 음 위주로 골라, 사람이 일부러 내기 쉽고 측정이 분명하게 했다. 앞뒤 음과 높이가 같은 곳은 빼먹기에서 뺐다(소리가 이어져 빈 곳을 찾기 어렵다).

## 시김새

서비스 곡 정답 악보 6개(단소 4곡, 소금 2곡)에는 시김새 표시가 하나도 없다(2026-11-02 변환 결과 확인). 그래서 이번 녹음으로는 시김새 판정을 검증할 대상이 없고, 시김새가 있는 곡을 정답에 넣을 때 다시 본다.
