# 관악기 '기초부터 배우기' 단계와 지도 근거

작업: [S15P31E102-118](https://ssafy.atlassian.net/browse/S15P31E102-118). 조사일 2026-10-26. 앱이 지원하는 대금·소금·단소·피리의 입문 지도 순서를 국립국악원 자료와 학술 자료로 확인하고, 네 악기에 공통으로 쓸 단계 초안을 정리했다. 현악기·타악기는 범위에서 제외했다. 아래 단계는 **제안**이며 팀 확정 사항이 아니다.

## 핵심 결론

- 네 악기의 공식 자료는 모두 `악기 알기·감상 → 자세·호흡 → 첫 소리 → 기본음 → 음역 확장 → 혀치기·박 나누기 → 곡 → 장식음·시김새` 순서를 따른다.
- 기본음은 **소리 내기 쉬운 음부터** 가르친다. 단소·소금·대금은 지공을 모두 연 음에서 시작해 지공을 하나씩 막으며 내려가고, 피리는 낮은 음역부터 시작한다.
- 요성·퇴성 같은 시김새는 모든 자료에서 마지막 단계다. 단소 지도서는 정규 학습에서 잘 되지 않으면 "무리하게 지도할 필요는 없다"고 보고 감상으로 소개하는 선에서 끝내도 된다고 쓴다.
- 처음에는 모범 연주를 듣고 따라 하고, 악보는 점차 도입한다(단소 지도서 기본원칙 ①·④). 다만 e국악아카데미 강좌는 정간보·율명을 1~4차시에 넣는 경우가 많아 시기가 자료마다 다르다.

## 자료 간 차이

- **단소 첫 음**: 단소 지도서는 汰 하행을 쓴다. 정일영 2014는 이 방식이 입김의 성질을 고려하지 않았다고 보고, 汰와 같은 입김으로 나는 '가운데 소리'를 먼저 익힌 뒤 낮은 소리 → 높은 소리로 가자고 제안한다. 단소 교실은 낮은 소리(4차시) → 높은 소리(5차시) 순이다.
- **정간보 시기**: 단소 지도서는 악보 읽기를 발전단계에 두고 범주를 먼저 하라고 한다. 반면 강좌들은 1~4차시에 정간보·율명을 넣는다(대금 교실 1차시, 단소 교실 3차시, 소금 교실 4차시, 대금 기초편 9차시).
- **시김새 시점**: 모두 후반이지만 소금 교실은 퇴성을 14/15차시, 대금 교실은 장식음을 12·13/15차시에 둔다. 단소 지도서는 특별활동 수준의 선택 단계로 본다.

## 프로젝트 적용점

- 1~2단계는 설명·영상 중심이고 앱이 판정하기 어렵다. 3~8단계는 음높이·지속 시간·박으로 판정할 수 있는 구간이다.
- 현재 데이터의 단소·소금 라벨은 모두 `inferred`, `eligibleForNoteScoring=false`다([단소](../data/danso.md), [소금](../data/sogeum.md)). 기본음·시김새 모두 검수 전에는 채점 정답으로 쓸 수 없다. 9단계는 처음에는 듣고 따라 하기로 두는 것이 자료의 '선택 단계' 성격과도 맞는다.
- 8단계 곡은 단소 지도서 통합단계 목록(비행기, 아리랑, 천안삼거리, 도라지타령, 풍년가, 새야새야 등)에서 고를 수 있다. 앱에 쓸 악보·음원의 이용 조건은 곡마다 따로 확인해야 한다.
- 악기마다 시작 음과 음역 확장 방향이 다르므로 단계 이름은 공통으로 두고 4·6단계의 내용만 악기별로 바꾸는 구조가 맞다.

## 정간보 쉽게 읽기·운지법 보기와의 역할 분담

권영민 채택(2026-10-26), 팀 합의 전. 정간보·운지 설명은 각 페이지에 한 번만 두고, 기초부터 배우기는 단계에 필요한 부분만 가져와 연습과 통과 확인을 맡는다. 근거 자료가 모두 배울 차례가 된 음·기호만 그 자리에서 가르치므로(단소 지도서 발음법 3항, 소금 교실 5~7차시), 링크만 걸어 전체 표를 보게 하지 않는다.

| 페이지 | 역할 |
| --- | --- |
| 정간보 쉽게 읽기 | 정간보 읽는 법·율명·기호 설명. 찾아보는 사전 |
| 운지법 보기 | 율명별 운지 전체 표. 찾아보는 사전 |
| 기초부터 배우기 | 정해진 순서로 연습하고 통과를 확인. 설명은 아래 범위만 가져온다 |

| 단계 | 가져올 범위 | 원래 페이지 |
| --- | --- | --- |
| 4. 기본음 | 이번 단계에서 배우는 1~2음의 운지 | 운지법 보기 |
| 6. 음역 넓히기 | 역취·저취 운지 | 운지법 보기 |
| 7. 혀치기·박 나누기 | 정간 안 박 나누기 표기 | 정간보 쉽게 읽기 |

- 운지 데이터와 정간보 설명 문구는 한 곳에 두고 두 페이지가 같은 화면 조각을 쓴다. 한쪽만 고쳐지는 일을 막기 위해서다.
- 기초부터 배우기에서 가져온 부분에는 원래 페이지로 가는 '더 보기'를 둔다.
- 설명 내용 제작은 Jira 에픽 '쉬운 정간보'(S15P31E102-16)·'운지법 안내'(S15P31E102-17)에서 하고, 기초부터 배우기 Task는 단계 흐름과 통과 확인만 맡는다.

| 입김 | 단소 발음법 '김넣기': 약하게 '휘' 하는 기분으로, 반은 밖·반은 취구 안('후'·'투'로 넣지 않는다). 소금 교육자료도 소리가 안 나는 원인으로 '투'·'튀' 발음을 든다. 둘 다 첫 소리를 내는 법이고 혀치기 이야기는 아니다. 대금 자료에는 '휘'가 없고, 블로그는 '프'·'읍'·'임' 입모양 등으로 갈린다('포'는 찾지 못했다) | 3단계 입김: 단소·소금만 '휘', 대금은 발음 없이 |
| 역취·저취 | 국악사전 취법(대금): 역취는 입술을 좁게 모으고 숨의 속도·압력을 높임, 저취는 입술을 느슨하게. 단소 발음법: 역취는 입술을 더 오므려 가늘고 강하게 | 6단계 앱 문구(서버 음역 설명은 화면에 쓰이지 않아 그대로 둠) |

- 공식 자료에 없는 것: 대금 취구를 아랫입술로 덮는 비율(블로그는 1/4~1/5와 2/3~3/4로 갈린다), 소금·대금의 첫 음과 익힐 순서.
- 화면 한 줄 기준: 360dp 폰에서 할 일 설명 칸 글자 폭은 약 260dp(화면 여백 20·상자 14·글 배경 14씩)다. IBM Plex Sans KR 15sp로 잰 문구를 250dp 안에 두었다.

## 미확인 사항

- 단소 지도서의 정식 서명·발간 기관·연도.
- 단소 역취 음 6개의 정확한 율명. 원문에서 이미지 글자라 淋 외에는 추출하지 못했다.
- 정일영 2014의 단계별 음 구성(검색 요약에만 있음), 한영숙 2012·김혜진 2011의 본문.
- 대금 취구 덮는 비율, 소금·대금 첫 음은 공식 자료에서 찾지 못했다(위 절).
- 대금·피리를 다룬 국립국악원 발간 교재나 지도 순서 논문은 찾지 못했다. 두 악기는 e국악아카데미 강좌 차시 구성만 근거로 했다.
- 피리를 낮은 음역부터 가르치는 이유.
- 이 초안을 국악 전공자나 교사가 검토하지 않았다.
