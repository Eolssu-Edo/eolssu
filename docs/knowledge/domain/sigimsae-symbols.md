# 정간보 시김새 기호의 뜻과 출처

작업: [S15P31E102-224](https://ssafy.atlassian.net/browse/S15P31E102-224). 조사일 2026-10-28. 정간보 쉽게 읽기의 '더 많은 시김새' 35개 기호에 붙일 한 줄 설명을 공식 자료로 확인했다. 아래 설명 문구는 화면 시안에 쓴 쉬운 말이며, 원문은 각 출처에서 확인한다.

## 핵심 결론

- 35개 중 34개는 공식 자료로 뜻을 확인했다. 국립국악원 『대금 정악보』의 '대금 악상기호' 표가 가장 넓게 맞고, 국립국어원 점자 해설이 나머지를 채운다.
- 노라느니 하나만 두 공식 자료 어디에도 없다. 우물사이 기호 사전의 값(사전 스스로 '추정'이라 적음)을 임시로 쓴다.
- 우물사이 사전 값 중 느네느·네로나·느나르나니 3개는 정악보와 달라 정악보를 따랐다.
- 겹요성표는 정악보 악상기호 표에 있지만 공개 악보 데이터셋의 대금 성부에는 한 번도 나오지 않는다. 느네느도 해금에만 1번 나온다.

## 악보 데이터셋에서 쓰이는 정도

정악보를 OMR로 읽은 공개 데이터셋 `jeongganbo-dataset`([조건](../data/jeongganbo-omr.md), CC BY-NC-SA 4.0)의 `jg_dataset` 텍스트 91곡에서 기호 이름이 나온 횟수를 성부별로 셌다. 파일 이름의 `_` 뒤 악기 순서대로 빈 줄로 나뉜 성부를 대응시키고, 성부 글자 안의 기호 이름을 부분 문자열로 셌다. 성부 수가 파일 이름의 악기 수와 다른 파일은 없었다.

```js
// node count.mjs <jg_dataset 폴더> <기호 이름...>
import { readdirSync, readFileSync } from 'node:fs';
const dir = process.argv[2], names = process.argv.slice(3), out = {};
for (const f of readdirSync(dir).filter(f => f.endsWith('.txt'))) {
  const insts = f.replace(/\.txt$/, '').split('_').slice(1);
  const parts = readFileSync(`${dir}/${f}`, 'utf8').split(/\r?\n\s*\r?\n/);
  if (parts.length !== insts.length) continue;
  parts.forEach((p, i) => names.forEach(n => { const c = p.split(n).length - 1; if (c) { out[n] ??= {}; out[n][insts[i]] = (out[n][insts[i]] || 0) + c; } }));
}
console.log(out);
```

## 앱에 적용할 점

- 대금·단소·소금 화면에서 겹요성표·느네느를 보일지는 정해야 한다. 정악보 표에는 있지만 대금 성부 실사용은 없다.
- 노라느니는 대금 성부에 15번 나오는데 공식 정의가 없다. 화면에 보일 때는 추정 값이라는 점을 감안한다.
- 같은음표·떠이어표는 대금 성부에서 가장 많이 나오는 기호라 설명 우선순위가 높다.

## 미확인 사항

- 노라느니의 공식 정의.
- ㉰를 읽은 jeongganbo-generator 커밋.
- 설명 문구를 국악 전공자가 검토하지 않았다.
