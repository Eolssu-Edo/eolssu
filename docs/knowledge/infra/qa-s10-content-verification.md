## 후속 범위

연습 기록 비교에 필요한 두 전곡 기록을 만들려고 테스트 입력을 준비했으나 새 녹음은 시작하지 않았다. 사용자의 범위 확인 후 추가 앱 조작을 멈추고 입력을 기기 마이크로 복원했다. 이번 확인으로 5번 연습 기록, 7번 악보 추가·편집을 통과 처리하지 않는다. 해당 항목은 요청된 후속 확인으로 남기고, 기존 QA 배치를 보존하는 다기기 HTML 시안을 먼저 제공한다.

사용자가 필요한 확인의 진행을 다시 승인한 뒤, 추가 기기 녹음을 반복하지 않도록 기존 전곡 fixture를 같은 격리 계정에 API로 제출했다. 실제 AI가 각각 61음표·100점으로 평가한 세션 1·2를 별도 기록 저장 요청의 200 응답까지 준비했다. [입력 구분과 준비 결과](qa-s10-history-fixture.json). 이는 기록 조회·비교용 준비 데이터이며 기기 마이크나 S10 기록 UI 검증 결과가 아니다.

관측 재시작 후 QA 웹에서 기기 화면 재연결과 제어권 요청 비활성 상태가 나타나 5·7번 실제 조작은 완료하지 못했다. USB ADB에는 S10·태블릿 모두 인식됐으므로 USB 미연결로 단정하지 않는다. 이 상태의 원인은 아직 조사하지 않았다. 시안 변경 요청을 우선하고 추가 로그 수집을 종료했다.

수집 종료 후 페이지를 새로고침한 최종 상태에서 S10 영상 약 30.6 FPS와 제어권 요청 활성 상태가 돌아온 것을 확인했다. 로그 수집은 종료, 조작자는 없는 상태로 두었다. 새로고침 없이 복구했다고 판정하지 않으며, 복구 확인만으로 5·7번을 통과 처리하지 않는다.
