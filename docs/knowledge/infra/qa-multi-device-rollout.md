# 통합 QA 화면의 실제 적용

- Task: S15P31E102-936 · Story S15P31E102-328 · 진행 중.
- 수행일: 2026-11-16, 한국시간.
- 진입점: https://15.165.144.7/qa/ . 기존 /qa/tablet/도 같은 화면을 제공한다.
- 기준: 승인된2열 HTML 시안과 EDO1 develop 자동 빌드 APK. 시안의 가짜 영상·점수·검사 결과는 운영 코드에 넣지 않았다.

## 적용과 보존

- 연결 기기는 자동 표시하고 카드 수에 맞춰 축소한다. 기기명·연결 점·영상 정보·포트 설정은 각 카드로 옮겼다. 메뉴·선택 내용·앱 바깥 카드의 너비를 맞추고 좌우 구분선을 추가했다.
- 앱 처리 기록은 서버 검사 위로 옮겼다. 출처는 한 줄 버튼, 통과는 기기색/번호로 표시한다. 부하는7번에 두고 버튼 안에 로딩·완료를 표시한다.
- 경로별 세션/소유권/epoch/입력 순번·영상·설치 상태를 분리했다. APK는 미적용 기기만 갱신하고 앱 실행은 연결 기기를 대상으로 한다. 다른 조작자의 제어권을 가져오거나 데이터 삭제로 설치 오류를 우회하지 않는다.
- 이름 입장·10분 무활동+1분 확인·한글 입력·승인/거절·APK 이력·페어링·밝기 기능을 유지했다. 실행은 기존 Windows 감독 프로세스가 유지하므로 ChatGPT 종료와 무관하다.
- 등록 중계는 최대6개다. 현재 실제 등록/검증 대상은 Galaxy S10과 Galaxy Tab S9 FE 두 대다. 추가 기기는 고유 ID·전용 중계/원격 경로를 등록해야 한다. 실제6대의 동시 영상/제어를 확인한 결과는 아니다.

## 최신 APK와 로그 범위

- 최초 확인 시 두 기기는 qa-20261115.235702-ec8f88d1이었다. QA 웹의 최신 적용으로 두 기기를 MR !850/05e2adae로 갱신한 뒤, 작업 중 추가된 최신 빌드도 같은 버튼으로 적용했다. 최종 버전은 아래 실행 근거에 기록한다.
- 최신 APK는 설치된 QA 앱 컴포넌트를 실행한다. 임시 관측 APK로 교체하지 않는다. 앱 실행 명령 성공은 로그인/업로드/AI/DB/첫 점수의 통과가 아니다. 실제 앱 로그가 없는 경우 기록 없음으로 표시한다.
- 관측용 APK의 기존 격리 경로도 호환한다. 수집기는 기기별 프록시18280~18285와 요청/timing/시도로 분리하고, 서버 검사·부하와 중앙 예약으로 배타 처리한다. 두 관측 APK의 동시 실제 녹음은 이번 적용에서 수행하지 않았다.

## 발견하고 수정한 경계

- 종료 재요청/늦은 관측 worker가 서버 실행 상태를 덮지 않도록 했다. 시작 중 취소는 worker 정리까지 배타를 유지한다. 새 부하는 요청 수락 시 직전 결과와 감사 로그를 비운다.
- 미확인 설치 버전은 최신이 아니다. 일괄 적용 중 조회 실패도 보류로 남긴다. 늦은 상태 응답은 기기별 순번으로 통과 배지를 되돌리지 못한다.
- 기존 격리 스택의 소유권을 확인해 재채택하며, 재채택 실패 후 재시도로 DB·계정·녹음을 지우지 않는다. 제어 서비스 교체 전후 세 컨테이너 ID가 같은 것을 확인했다.
- USB를 연결했는데 저장된 무선 endpoint로 되돌아가던 경로를 수정했다. USB 전송을 우선하면서 TLS 포트 검색과 이력은 유지한다.
- 연결 초기화의 online=false만으로 인증된 영상을 중단하지 않는다. 이전 세대 응답·프레임은 새 연결에 적용하지 않는다. 파서 오류 시 미종료 스트림이2개 쌓여429로 굳는 경로를 재현하고, 연결별 reader/controller를 항상 정리하도록 했다.
- 영상 소켓의 drain을 기다려 큰 정상 프레임을 순서대로 전송한다. 기존256KiB 대기 한도와 느린 접속 종료는 유지한다. 부하 중 ADB probe가 지연돼도 최근3초 내 실제 영상이 계속 도착한다면 그 증거를 유지하고, 무응답 전송은 종료한다.

## 확인 결과와 제한

- 실제 두 기기의 영상과 최신 APK 일괄 적용·실행을 확인했다. 수집되지 않은 앱 로그를 합성하지 않았다.
- 실제 첫6건 동시 제출은4/6 저장 확인·2실패·5초 이내0/6이었다. UI도 실패2개를 표시하고 제출 완료로 바꾸지 않았다. 태블릿 문맥의 실행 ID는 473475c8-327e-4b0d-b68a-b907596bb28e다. 이 결과를 서버 성능 기준 통과로 확대하지 않는다.
- [실제 제출 중 화면](qa-multi-device-load-running.jpg). 최종 PC/작은 화면·APK·검사 결과와 코드 해시는 [실행 근거](qa-multi-device-rollout.json)에 둔다.
- 임시 UI 서버/스크립트/롤백 사본은 검증 뒤 정리하고, 사용 중인 실제 QA·APK 저장소·컨테이너·앱 데이터·기록은 보존한다.

운영 설정과 API 계약은 [LIVE.md](../../../infra/qa-phone/LIVE.md), 발표자가 읽을 대본은 [guide.html](../../../infra/qa-phone/public/guide.html), 후속 작업은 [계획](../../plans/S15P31E102-936.md)을 따른다. 전수 앱 QA·실제 마이크 재검증·대규모 부하는 이번 UI 적용의 완료 근거로 삼지 않는다.
