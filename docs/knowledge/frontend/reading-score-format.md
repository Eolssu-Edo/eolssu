# 연습 화면 외 정간보 공통 형식 (591)

상태: 2026-11-09 사용자 요청으로 적용(S15P31E102-591, 미병합 브랜치). 화면마다 정간보 크기·칸 규칙을 따로 고치던 것을 하나로 묶었다.

## 선택

자동으로 넘어가는 연습 화면(`PracticeScoreArea`)을 뺀 모든 화면은 `core/ui/score/ReadingScoreFormat.kt`의 `readingScoreFormat(song)` 하나로 크기·모양·칸 높이를 받는다.

| 규칙 | 값 |
| --- | --- |
| 각·정간·율명 | 연습 악보 크기. 각 78dp, 정간 44dp, 율명 21sp. 11정간 이상인 각은 정간 32dp, 율명 18sp. |
| 위아래로 나뉜 소박 | 한 줄 26dp 이상. 율명은 두 음 16sp, 셋 이상 15sp. |
| 가로로 나뉜 음 | 높이를 늘리지 않는다. |
| 각 끝 맞춤 | 정간 수가 같은 세로 줄끼리 가장 긴 줄에 맞춰 정간을 고르게 늘린다. |
| 곁줄(가사 칸) | 곡에 가사가 있을 때만 25dp. |
| 모양 | `JeongganboLook.Reading`: 연습과 같은 보드, 회갈색 대강 선, ‘← 다음’ 강조 없음. |

## 근거

- 나뉜 소박 26dp·16/15sp는 553에서 구간 반복 화면에 맞춰 사용자가 확인한 값이다. 535(기록 화면 크기)와 548(각 끝 맞춤)의 규칙을 함께 묶었다.
- 이전에는 결과 카드가 카드 폭을 각 수로 나눈 별도 크기(정간 40dp, 소박 22dp, 빈 곁줄)를 써서 소박 글자가 작고 답답했다. 비교·구간 고르기는 각 끝 맞춤이 없었고, 편집기는 모든 정간을 똑같이 늘렸다.

## 적용 범위

- 평가 결과 카드, 틀린 부분, 이전 연주 결과(곁줄 없음), 이전 연주와 비교, 구간 고르기, 악보 편집 큰 악보.
- 구간 반복은 크기·칸 높이만 공통 형식을 쓰고, 연주 중 표시가 있는 연습 모양은 유지한다.
- 결과 카드는 카드 폭에 들어가는 각만 보여 주고(`previewColumns`), 보이는 폭만큼 가운데에 둔다.
- 이전 연주 결과는 535의 사용자 결정대로 곁줄을 두지 않는다(`lyrics = false`).

## 제외

- 연습 화면 악보: 화면 높이에 맞춰 정간을 줄이는 별도 규칙(542·560)을 유지한다.
- 장식·예시용 작은 악보: 곡 표지(`SongScoreCover`), 연습 설정의 표기 예시(`NotationPanel`), 오선보 아래 같은 위치 참고 악보(`CompactEditScoreMetrics`).

## 바꿀 때

새 화면이나 표시 조정은 화면 파일에서 크기를 만들지 않고 `ReadingScoreFormat.kt`를 고친다. 규칙은 `ReadingScoreFormatTest`가 검사한다.

## 미확인

- 실기기(Galaxy S25+)·태블릿·iOS와 글자 크기를 키운 휴대폰에서의 표시는 확인하지 않았다. 에뮬레이터(Medium_Phone_API_37.0)에서 결과 카드·틀린 부분·구간 고르기·이전 연주 결과·비교·편집 화면을 확인했다.
