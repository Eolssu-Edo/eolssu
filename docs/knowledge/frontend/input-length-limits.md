# 입력칸 글자 수 상한과 메모 입력 방식 (S15P31E102-996)

QA 피드백 "모든 입력창에 글자 수 제한 없음"과 "메모 500자를 넘기면 400자대로 되돌아감, 엔터를 치면 칸이 끝없이 늘어남"을 고치며 정한 기준이다.

## 상한 기준

상한 값은 `core/model/InputLimit.kt` 한곳에 둔다. 글자 수는 서버와 같이 코드 포인트로 센다.

| 칸 | 앱 상한 | 서버 | 판단 |
| --- | --- | --- | --- |
| 이메일 (가입·로그인·인증) | 100 | 320 | 서버 값은 RFC 상한이라 실제 주소로는 비정상적인 길이다. 앱 형식 검사(`EmailRule`)도 100자로 맞췄다. |
| 비밀번호 (가입·재설정·변경·로그인·탈퇴·현재 비밀번호·계정 연결) | 64 | 8~128 | 모든 비밀번호 칸을 64자로 통일했다. 앱 규칙(`PasswordRule.MaxLength`)과 안내 문구도 8~64자다. 서버를 64자로 맞추고 64자보다 긴 기존 계정의 처리 방식을 정하는 일은 S15P31E102-1014(백로그)에서 한다. |
| 닉네임 | 10 (수정 화면은 넘침 표시용으로 20까지 받음) | 10 | 기존 `NicknameRule` 유지 |
| 내 악보 제목 | 50 | 50 | |
| 메모 | 500 | 500 | |
| 곡 검색어 | 50 | 서버로 보내지 않음 | |
| 숫자 칸 (악보 편집) | 빠르기 3자리. 각·정간 번호는 편집 중인 악보 기준: 각은 '악보 끝'(마지막 각 + 1)의 자릿수, 정간은 가장 긴 각의 정간 수 자릿수, 기본 반주 첫 강박 정간은 전체 정간 수 자릿수 | Int | 자릿수는 창을 열 때 메모리의 악보로 한 번 계산한다(서버 요청 없음). 값의 범위 검사는 기존대로 둔다. |

서버 계약은 바꾸지 않았다. 앱 상한이 서버보다 엄격한 칸은 이메일과 비밀번호뿐이다.

상한을 넘겨 치려다 막히면 입력이 조용히 멈추지 않도록 칸 아래에 'n자까지 입력할 수 있어요'를 보인다(오류가 있으면 오류가 먼저). 딱 맞게 채운 값(빠르기 120 등)에는 띄우지 않는다. 가려진 비밀번호는 막혔는지 알 수 없으므로 모든 비밀번호 칸에 보기/숨기기 눈 버튼을 둔다.

## 메모는 `TextFieldState`로 받는다

- 기존 메모 칸은 값(`TextFieldValue`)을 받아 500자를 넘는 변경을 거절했다. 이 방식은 한글을 조합하는 중에 칸 내용과 키보드가 가진 내용이 어긋날 수 있다. Compose 문서도 입력을 걸러야 하면 상태 기반 입력칸의 `InputTransformation`을 쓰라고 안내한다.
- 공용 `EolssuMemoField`는 `TextFieldState`와 코드 포인트 상한 변환(`MaxCodePoints`)을 쓴다. 이미 가득 찬 칸에서는 입력을 되돌리고, 붙여넣기로 넘치면 새로 들어온 글의 앞부분만 남긴다.
- 칸은 `maxHeight`까지만 커진다. 넘치는 줄은 칸 안에서 스크롤하고 오른쪽에 스크롤 막대(`verticalScrollIndicator`)를 보인다. 읽기 상자에도 같은 막대를 붙였다.
- 연주 결과 저장 시트도 같은 칸을 쓴다. 전에는 한 줄 칸에 상한이 없어서 500자를 넘기면 서버가 400으로 거절했다.

## 검증 (2026-11-16)

- 로컬 MySQL 8.4와 `db` 프로필 백엔드(:18080)에 Android 에뮬레이터(Medium_Phone, `adb reverse`)를 연결했다.
- 로그인 이메일 칸에 130자를 입력하면 100자만 남았다. 검색칸에 70자를 입력하면 50자만 남았다.
- 기록 상세 메모(446자, 여러 줄)는 읽기 상자 안에서 스크롤 막대와 함께 보였다. 고치기에서 줄바꿈 30번과 120자를 더 입력해도 칸 높이는 그대로였고, 500/500에서 멈췄다. 저장하자 DB에 500자가 저장됐다.
- 로그인 비밀번호 칸에 140자를 입력하면 64자에서 멈추고 '64자까지 입력할 수 있어요'가 보였다. 눈 버튼을 누르면 입력한 글자가 보였다.
- 미검증: 한글 키보드로 500자 경계에서 조합하는 경우(adb로는 한글을 입력할 수 없음), 실기기, 태블릿, iOS.
