## 첫 검증의 오류와 검증 경계

1. **이미지 중청 인식 오류(후속 수정됨)**: 첫 검증은 대조표 7·11·15·19·22칸을 각각 청 음으로 읽었다. PNG·JPEG에서 동일하다. 후속 수정은 실제 두 물수변을 확인해 중청을 복원하며 같은 자료 24/24가 일치했다. 기존 저장본은 자동 변경되지 않으므로 새 인식 또는 원본 대조 후 수동 수정이 필요하다.
2. 보허자는 PDF 463음·PNG 묶음 464음으로 차이가 있다. 바흐도 이전 784 기록의 4044음과 이번 4038음이 다르다. 전곡 정답이 없으므로 정확도를 통과로 보고하지 않는다. 인식 엔진 출력 차이·누락·추가 여부의 원본 전수 대조가 남아 있다.
3. 임의 추정된 장단이 악보 길이와 맞지 않으면 확정 저장을 거절한다. Blue Valentine에서 이 안내·수정 경로를 실행했다. 장단을 해제해 저장한 것은 테스트 선택이며 원곡 장단 확정이나 자동 변환 정책 변경이 아니다.
4. 실제 Android·iOS, 음원 합성·다운로드·청음, 모든 제공 이미지의 개별·조합 입력, 전곡 전문가 채보 검수는 이번 회차의 통과 범위에 포함하지 않는다. 브라우저 파일 선택 취소는 제공 드라이버가 빈 파일 목록을 받지 않아 미검증이다.
5. Compose 대화상자가 닫힌 뒤 자동화 도구의 접근성 트리가 이전 창을 유지하는 현상이 있었다. 이후 동작은 새 실제 화면 캡처와 좌표, 필요시 정상 새로고침으로 실행하고 서버 재조회로 확인했다. 접근성 트리 잔존만으로 제품 저장 실패를 판정하지 않았다.
