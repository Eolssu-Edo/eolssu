## 확인된 원인

1. **2·6각 2정간의 大 위 세로 두 점은 우물사이가 중청대에 쓰는 대체 표기다.** 중청대 글자 `𣴘`는 존재하지만 우물사이의 글자 매핑에 빠져 기본자와 옥타브 점으로 그린다. 후속 제공 JGB에도 해당 칸이 `중청대`로 저장돼 있다. 이 점 해석은 일반 정간보 규칙이 아니며, 사용자의 요청으로 MR !588에서 제외했다. 현재 리더는 해당 두 음의 글자 `大`만 읽어 기본 대로 남긴다. 전체 악보에는 실제 점 없는 기본 대 16개도 있으므로 모든 대를 일괄 올리면 안 된다. 원본 오선보의 해당 음은 E6이며 우물사이 표제의 황종은 E♭4다.
2. **4·8각의 네 칸 지속은 정상이다.** 원본에서 앞 각의 마지막 청유와 연결돼 총 5정간 길이다. 기존 PDF 변환은 검수 JGB의 각 경계 규칙을 그대로 써서 다음 각의 지속을 쉼 이벤트에 연결했다. 신규 PDF 경로만 명시적 `-`를 앞 NOTE에 연결한다. 앞 음이 없는 이음·새 각 첫 빈칸에 새 소리를 만들지는 않는다.
3. **삼각 쉼표도 도형이다.** 기존 리더는 이를 놓쳐 쉼표만 있는 9·49·85각까지 누락했다. 벡터 도형과 격자를 함께 읽어 115각/460정간에서 원본의 118각/472정간으로 복구했다.
4. **악기 음역과 앱 등록 음은 별개다.** V17 카탈로그는 단소의 지원 범위를 황종 대비 반음 3…29로 두지만, 중청대(25)는 전역 등록 목록에 없다. 중청황(24)·중청태(26)와 청대(13)는 등록돼 있다. 중청대가 입력된 문서에는 미등록 음의 대체음 안내를 제공한다. 기본 대(1)는 범위 아래다. 서버 카탈로그를 임의 확장하지 않았다.
5. **중모리는 원본 4/4에 맞는 선택이 아니다.** 원본은 한 각 4정간·한 정간 4분음표 1박이다. 중모리로 가져오면 12박÷4정간=3박/정간으로 저장되고 호환 조건을 벗어난다. 장단 이름만 바꾸거나 해제해도 이 시간값은 자동 교정되지 않는다. 장단 해제는 현재 음 길이와 BPM을 보존한다.

## 편집기의 수정 방식

- 음역 버튼 5개를 직접 고른다. 최초와 율명 입력 직후에는 기본이다. 기본의 한자는 빈칸으로 남긴다. 부수의 실제 글자 폭과 한글 중심을 맞추고, 배탁 `彳`는 기존 공식 Noto 원본에서 subset에 추가했다.
- 오류 음 또는 그 지속 칸을 누르면 등록 여부/악기 범위의 구체적 이유와 후보를 보여 준다. 후보는 전역 등록 음과 악기 음역의 교집합에서 반음 거리순 3개, 같은 율명의 가장 가까운 옥타브 후보를 중복 없이 제공한다. 원곡 음높이가 달라진다고 안내하고 선택 전에는 변경하지 않는다.
- 지속에서 후보를 골라도 시작 NOTE의 음높이만 바꾸므로 이벤트 ID·길이·시김새·이음 참조를 유지한다. 한 번 실행 취소로 되돌릴 수 있고, 이미 바뀐 음에 오래된 후보나 미지원 음을 적용하지 않는다.
- 독립 검토에서 일반 편집 재구성(시김새 변경 등)이 복원된 각 경계 지속을 다시 끊는 문제를 발견했다. 명시적 `-`와 원본의 같은 이벤트를 참조하는 지속을 각 경계에서도 보존하고, 새 미입력 빈칸을 소리로 만들지 않도록 수정했다. 시김새 변경→지속 칸 대체음 선택→재직렬화→실행 취소를 회귀로 검사한다.
- 기존 JGB에서 각 첫 `-`가 별도 REST로 확정된 경우는 쉼을 먼저 보존한다. 표시 기호만 보고 NOTE에 붙이지 않는다. 신규 지속 입력과 원본 이벤트의 NOTE/REST 의미를 구별하는 회귀를 추가했다.
- 수정 후에도 인식 검수 항목의 사용자 확인은 유지한다. 지원 음으로 고친 항목에는 과거 미지원 메시지 대신 현재 음은 지원되며 원본 대조 후 확인하라는 안내를 표시한다.
- 장단 창에는 실제 `정간 수 × 정간당 박 = 각의 박수`와 후보의 박수를 표시한다. 기존 호환 정책을 완화하지 않는다.

## 한계와 적용

- 기존 저장된 초안·완성 악보는 자동 교체하지 않는다. 인식 서비스 엔진 3 배포 후 다시 변환해야 누락된 쉼·각·지속이 복구된다. 우물사이 전용 점 인식은 이번 MR에 포함하지 않는다. 앱 APK 변경만으로 서버 변환기가 교체되지는 않는다.
- 이 작업은 PDF의 템포 맵(26·58마디 80, 가속 후 30·62마디 160)을 구현하지 않는다. 현재 앱의 단일 BPM 정책은 유지한다.
- 회귀는 합성 PDF/짧은 악보로 고정하고 실제 제공 PDF는 로컬 대조용으로만 사용한다. 전체 범용 PDF 인식 정확도나 실물 단소 연주 검증으로 일반화하지 않는다.
- 지속 칸의 붉은 표시는 연결된 시작 음의 지원 여부에도 영향을 받는다. 지속 네 개 자체를 금지하는 개수 제한은 없다. 사용자 기기의 저장된 초안 전체 상태를 읽은 것은 아니므로, PDF의 재현된 변환 손실과 개별 초안의 오류 표시 원인을 구분한다.
