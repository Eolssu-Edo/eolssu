827의 추가 화면 정리에서는 적용 확인창의 유지 항목 나열을 제거하고 덮어쓰기 경고를 굵게 표시한다. 네 도구 탭은 여유 폭에서 가운데 정렬하며 좁으면 가로로 넘긴다. 빠르기 편집은 상단 편집 창, 장단은 정간 도구, 음역은 음역 맞추기 탭에서 조정한다. 편집 화면·빠르기 창의 예상 음원 길이는 기존 정간/tick 비율 계산을 사용하며 구간 빠르기·반복 등 계산할 수 없는 경우 길이를 추정하지 않는다.

추천은 지원하지 않는 음 수, 옥타브를 옮기는 음 수, 옮기는 옥타브 거리 합, 이조 폭 절댓값, 이조 값 순서로 비교한다. 미해결 음 수가 같을 때 이조 폭을 우선하는 대안도 함께 표시하며 같은 이조이면 하나로 합친다. 예를 들어 원본 MIDI60·64, 지원음64·68·71·75이면 +4는 옥타브 이동0개, -1은2개다. +4를 기본 추천하고 -1을 이조 폭 최소 대안으로 제시한다. FE 추천 순서만 바꾸며 DATA·서버의 지원음 계약은 유지한다.

편집기에 들어오면 입력판 첫 탭인 음역 맞추기를 선택해 연다. 악기를 선택하고 -6~+6 정수 슬라이더로 이조를 고른다. 추천 위치는 채운 마름모, 이조 폭 최소 대안은 빈 마름모로 표시한다. 동일 위치이면 하나만 표시하고, 색 외에 모양과 접근성 설명으로 구별한다. 사용자의 미리보기 후 요청에 따라 별도 추천 버튼·추천 기준 설명창·음별 변경 내역은 제거했다. 미해결 음 수는 사용자가 이미 편집한 음 수가 아니므로 `수정 필요 N개`로 표시한다. S15P31E102-850에서는 200dp 고정 높이를 제거하고 내용에 맞춰 줄였다. 여유 폭에서는 악기·이조 조절·보정 수·적용을 한 줄에 두며, 좁은 화면이나 큰 글자에서는 이조 조절을 다음 줄에 둔다. 내용은 최대160dp 안에서 세로로 넘기고, 조작 영역은 최소48dp를 유지한다.

음높이 복원은 정간 전체 배치의 일치 여부로 결정하지 않는다. 현재 정간과 `sourceCellIds`로 연결된 판본의 시작 음표를 소박 순서로 대조하고, 원본 메타데이터의 이벤트·정간과 정간 단위로 환산한 시작·길이가 같을 때 원본 MIDI를 사용한다. 분할로 새로 생긴 자리, 이음·쉼표에 새로 입력한 음, 새 각에는 현재 음고를 쓴다. 각을 지운 뒤 재사용된 위치 ID만으로 원본 음을 연결하지 않는다. 같은 편집 세션에서 다시 적용하거나 오류 음을 직접 교정해도 복원 기준을 유지한다. 저장 후 다시 연 판본에 원본 연결 정보가 충분하지 않으면 그 판본의 음고가 기준이다. 새로운 서버 필드나 저장 형식은 추가하지 않았다.

적용 전 확인창에서 직접 바꾼 음높이·옥타브를 덮어쓴다고 알린다. 취소하면 선택한 악기·이조와 편집본을 유지하고, 적용은 되돌리기 한 번으로 복구한다. 제목·빠르기·장단·시김새·가사·정간 분할·쉼표·음표 시각은 유지한다. 추천을 연 뒤 다른 편집이 발생하면 이전 제안을 닫아 오래된 결과를 적용하지 못하게 한다. 맞추지 못한 음도 한글 표기를 유지해 후속 편집에서 음표가 사라지지 않게 한다.
