# 서비스 장단 카탈로그의 추가 근거와 남은 자료

2026-11-03 KST, S15P31E102-411. [카탈로그 계약](../../specs/catalog-read-apis.md)과 [확장 스펙](../../specs/jangdan-catalog-extension.md)을 따른다. 기본형 두 종류를 로컬 V19에 추가한다. 기존 세마치·굿거리·중모리의 ID 1~3과 모든 값은 유지한다. 새 ID는 자진모리4·중중모리5다. 운영 DB 적용·배포 여부와 구분한다.

## 서비스 악보와 카탈로그의 차이

운영 `GET https://k15e102.p.ssafy.io/api/songs`를 읽기 전용으로 조회해 111곡의 원본 `score.music`을 집계했다. 이름이 있는 누락 후보는 아래 7종이며 모두 원본 BPM 단위가 QUARTER다. 자진모리4곡·중중모리3곡·엇모리1곡·단모리1곡·타령6곡·계면가락도드리3곡·세령산2곡이다. 이름이 빈 45곡은 추정하지 않는다. 기존 세마치20곡·굿거리18곡도 QUARTER여서 기존 카탈로그의 DOTTED_QUARTER와 다르다. 새 두 장단도 이름만으로 곡에 연결하지 않으며 곡 FK·BPM·tick·음원 메타데이터를 변경하지 않는다.

## 추가한 기본형

| ID·이름 | 출처에서 확인한 값 | 저장과 적용 |

| 4 자진모리 | [e-국악아카데미 자진모리](https://academy.gugak.go.kr/dp/pds/HTML5-1-7-3/HTML5-1-7-3-4/index.htm)의 첫 기본 악보 `img1.gif`: 12/8, 점4분음표 96~108. 네 소박 위치에 떵·덕·쿵·덕을 배치한 반주기6칸을 두 번 반복한다. | `[떵,"",덕,쿵,덕,""]`를 두 번, group `[3,3,3,3]`, DOTTED_QUARTER, 시작 BPM96. |

두 시작 BPM은 선택한 자료 범위의 하한이다. 기획141의 기존3종 기본값을 새 장단의 확정값으로 확대하지 않으며, 곡별 빠르기·모든 유파의 정답·채점 기준으로 사용하지 않는다. 구음의 떵/덩·쿵/궁·덕/따는 출처별 표기를 보존한다. 빈 문자열은 앞 소리를 잇는 칸이며 별도 쉼 이벤트가 아니다. 목록의 beatCount12는 구음 칸 수, groupCount4는 묶음 수다. 장단 소리나 타격 샘플은 확보·연결하지 않았고 soundUrl은 null이다.

공식 자료의 작은 기본형을 구조화한 사실과 출처만 기록한다. 원본 도판·음원은 제품에 포함하지 않았다. 국악사전은 원고에 공공누리2유형, 복합매체에4유형을 안내한다. 제품에서 원문·도판·음원을 재사용할 때는 해당 조건을 별도로 따른다. 이번 확인은 전문가의 청음·판본 승인이나 매체 재배포 승인을 뜻하지 않는다.
