## 공개 제공 및 DB 등록 준비

검토할 공개 문서는 접근권한 안내, 개인정보 처리방침, 이용약관, 앱 외 계정 삭제 요청 안내다. 앱 외 삭제 안내에는 앱명·운영자, 연락처, 본인 확인 절차, 삭제 범위, 30일 유예·취소 조건·삭제 일정 및 보존 예외를 표시한다. 이메일 요청 접수 절차를 실제 운영하고 앱을 다시 설치해야만 요청할 수 있게 만들지 않는다. 아직 공개 URL이나 요청 처리 기능이 생긴 상태는 아니다.

공개 경로는 `/legal/<version>/privacy.html`, `/legal/<version>/terms.html`, `/legal/<version>/permissions.html`, `/legal/account-deletion.html`을 후보로 검토한다. 운영자 승인된 완성본을 HTML로 제공하고 로그인 없이 HTTPS 200·본문 일치·한국어 가독성을 확인한다. Nginx SPA fallback의 200을 문서 제공 성공으로 오인하지 않는다. 경로와 배포 방식은 구현 시 확정한다.

실제 terms 컬럼은 `code`, `version`, `title`, `content_url`, `is_required`, `seq`, `effective_at`이다. `required` 컬럼이나 활성화 플래그를 만들지 않는다. 같은 code에서 시행 시각이 현재 이하인 최신 effective_at, 동률이면 큰 id가 선택된다. 문자열 version 정렬이 아니다.

1. 기존 terms와 사용자 동의 참조를 조회해 보존한다.
2. 동의 항목·필수 여부·최종 HTML·시행 시각(UTC 저장)을 확정한다. AGE_OVER_14도 누락하지 않는다. 선택 권한을 가입 필수 동의로 등록하지 않는다.
3. HTTPS 원문을 검증한 후 승인된 등록 SQL을 준비한다. 본문·필수 여부 변경은 기존 행 UPDATE 대신 새 버전 INSERT로 처리한다. 동의된 과거 버전을 지우지 않는다.
4. 운영 반영 전 변경 행과 롤백 범위를 검토한다. 공개 문서 없이 빈칸을 채운 임시 URL이나 허위 동의 행으로 가입 차단을 우회하지 않는다.
5. 반영 후 GET /api/terms의 result.items와 문서 URL·버전·필수 여부, 앱의 다시 시도 및 필수·선택 동의를 확인한다. 운영 DB 쓰기·앱 실행 검증은 아직 수행하지 않았다.
