# 소리 나는 버튼의 눌림 효과(elastic squash)

- 작업: [S15P31E102-891](https://ssafy.atlassian.net/browse/S15P31E102-891)
- 상태: **확정** — 2026-11-13 프론트 담당 권영민 결정. 시안 비교 뒤 '소리 나는 버튼만 적용' 범위를 고르고 지침 확정을 밝혔다(S15P31E102-891 작업 세션).
- 시안: [재생 버튼 elastic squash 시안](https://claude.ai/artifact/RBn1dQVj8apR3qou6txwk1) (비공개 페이지, 팀에 공유해야 열린다)
- 코드: `frontend/shared/src/commonMain/kotlin/com/ssafy/eolssu/core/ui/component/ElasticSquash.kt`

## 선택

누르면 바로 소리가 나는 버튼만 누르는 동안 세로로 납작하게 눌렸다가, 떼면 스프링으로 살짝 튕기며 돌아온다.

| 구분 | 버튼 | 쓰는 방법 |
| --- | --- | --- |
| 적용 | 연습 화면·연주 기록 상세 재생(`PlaybackSkipGroup`, 44dp 먹색 원) | `Modifier.elasticSquash` |
| 적용 | 악보 가져오기 '들어보며 확인' | `Modifier.elasticSquash` |
| 적용 | 장단 설정 '장단 듣기' | `EolssuButton(squash = true)` |
| 적용 | 운지법 '기본음·요성', 기초 배우기·연습 화면 '음 듣기'(`ReferenceAudioControls`) | `ElasticSquashSoftAmount`(기본의 60%), 글자 버튼 가로 늘림 |
| 제외 | ▶ 아이콘이어도 화면만 넘어가는 버튼('시작하기'·'구간 연습 시작') | 기본 눌림 |
| 제외 | 5초 이동, 녹음 시작('연주 평가 시작'), 중단·삭제 | 기본 눌림 |

값: 세로 10% 눌림, 아이콘 버튼 가로 늘림은 세로의 0.8배, 글자 버튼은 그 절반. 누를 때 스프링 감쇠 0.6·강성 1500, 뗄 때 감쇠 0.4·강성 400. 빠른 탭도 보이도록 최소 70ms 눌린 모양을 유지한다.

## 근거

- 효과를 '누르면 소리가 난다'는 신호로 읽히게 하려고 소리 나는 버튼에만 쓴다. 한 화면에 출렁이는 버튼이 하나 정도라 과하지 않다.
- 5초 이동은 연달아 누르는 버튼이라 출렁임이 겹쳐 묶음이 떨려 보인다. 녹음 시작은 바로 연주를 준비해야 하는 순간이고, 중단·삭제는 무거운 행동이라 튕기는 느낌이 맞지 않는다.
- 운지법 소리 버튼은 한 화면에 많고 음을 빠르게 차례로 비교하므로 약하게 둔다. 글자 버튼은 가로로 많이 늘면 글자가 퍼져 보여 늘림을 줄인다.
- 대안: 모든 재생 표시(▶) 버튼에 적용 — 화면 이동 버튼까지 출렁여 신호가 흐려져 기각.

## 영향과 남은 일

- 새로 소리 나는 버튼을 만들면 같은 효과를 쓴다. 지침은 [frontend/AGENTS.md](../../frontend/AGENTS.md)의 '도메인 표시와 오디오'에 있다.
- 크기는 바꾸지 않고 그릴 때만 바꾸므로 옆 요소가 밀리지 않는다.
- 시스템 '애니메이션 끄기' 설정에서의 동작은 확인하지 않았다.
