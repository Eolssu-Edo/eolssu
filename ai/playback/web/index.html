1. 악기와 악보 사진

악기별 음원 설정을 확인하는 중입니다.

악기를 바꿔도 음높이·옥타브를 자동으로 옮기지 않습니다. 선택 악기의 음역을 벗어나면 원보와 음표를 확인해 주세요.

PNG·JPEG·WebP, 8 MiB / 1600만 화소 이내. 사진은 이 컴퓨터에 저장됩니다.

오선보는 단선율을 사용하세요. 정간보는 페이지에서 격자를 자동으로 찾으므로 테두리와 글자가 선명해야 합니다. 복잡한 장식은 인식되지 않을 수 있으며, 읽지 못한 음·기호가 있으면 확인이 필요합니다.

    2. 음표 확인

    음표 행의 ‘위치’를 누른 뒤 사진에서 사각형을 드래그하면 재생 위치를 연결할 수 있어요. 위치 연결 없이도 재생할 수 있습니다.

    입력한 음표 0개
    위치음높이길이 (4분음표=1)쉼표삭제

    장식음·이음줄·숨표 등 상세 데이터

    기존 스키마의 ornament / slur / tie / breath_seconds / yoseong을 보존합니다. 수정 후 ‘상세 데이터 적용’을 누르세요.

    3. 선택 악기로 연주 듣기

    현재 음표를 사용해 다시 합성합니다. 사진을 다시 읽지 않으며, 검수가 끝난 악보로 표시하지 않습니다.

    추가 흔들림은 긴 음에 적용합니다. 악보에 명시된 음높이 요성은 그대로 유지합니다.

    합성 참고 연주입니다. 국악 전문가가 검수한 모범 연주로 인증된 결과는 아닙니다.
