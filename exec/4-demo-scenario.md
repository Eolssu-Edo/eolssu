- 화면 문구는 앱에 표시되는 문구를 그대로 적었다. 버튼 위치는 레이아웃 코드에서 확인했으며, 시연 기기에서 리허설하며 최종 확인한다.
- 학습 흐름 **보기 → 듣기 → 연주 → 평가 → 반복 연습 → 기록**을 따라가고, 마지막에 내 악보 기능을 보여 준다.

## 0. 시연 환경과 사전 준비

### 시연 환경

| 항목 | 내용 |
| --- | --- |
| 기기 | Android 휴대폰(또는 태블릿) 실기기, 화면 미러링으로 발표 화면에 표시 |
| 앱 | 운영 서버(`https://k15e102.p.ssafy.io`)에 연결된 릴리스 빌드 |
| 악기 | 단소 (실제 연주자 1명) |
| 시연 곡 | **아리랑 · 단소** (세마치, 96 BPM, 약 30초, QA·실제 마이크 검증에 사용한 곡) |
| 예비 곡 | **비행기** (25음, 네 악기 판본 모두 채점 가능) |
| 계정 | 운영 시연 계정(만료 없는 세션). 비밀번호는 시연 담당자만 보관하며 이 문서에 적지 않는다 |
| 내 악보 자료 | 글자 층이 있는 정간보 PDF 1쪽(변환 약 1초) |

웹은 녹음·평가와 내 악보 음원 저장을 지원하지 않으므로 시연은 **모바일 앱**으로 한다.

### 발표 전날·당일 점검

1. 시연 계정 비밀번호를 바꾸고 의도하지 않은 소셜 연결을 해제한다.
2. 시연 기기에서 **미리 로그인**해 둔다. 현장에서 새로 로그인하지 않는다(5회 실패 시 15분 잠김).
3. 시연 곡이 공개 상태인지 `GET /api/songs` 목록으로 확인한다.
4. AI 분석 컨테이너를 예열한다. 예열하지 않으면 첫 분석이 약 16초 더 걸린다.

   ```sh
   ssh edo1 'sudo docker exec eolssu-runtime-ai-1 python -m ai_service.warmup'
   ```

5. 시연 계정으로 아리랑을 한 번 평가하고 **연습 기록에 저장**해 둔다. 6장의 "지난 연주와 비교"에 쓸 이전 기록이 필요하다.
6. 기기 마이크 권한을 미리 허용하고, 방해 금지 모드를 켜고, 화면 밝기·볼륨을 맞춘다.
7. 발표 PC에는 Swagger·개발자 도구를 띄우지 않는다.

| 7-8 | 내 악보 | '연습 가능' 상태의 "시연 악보" 줄을 누른다 | 내 악보 연습 화면 |
| 7-9 | 내 악보 연습 | 플레이어 자리의 **"음원 다운로드"**를 누른다 | "음원 생성 대기 중" → "음원 생성 중" → "음원 다운받는 중". 짧은 악보는 수 초, 10분 곡도 약 21~25초. 완료 배너 "음원이 준비됐어요." + "열기"를 눌러 확인한다(재생 방식은 리허설에서 확인) |

> 스캔 PDF는 쪽당 약 13.5초, 오선보는 쪽당 19~30초가 걸리므로 시연에는 글자 층이 있는 정간보 PDF를 쓴다. 변환 중 다른 화면으로 나가도 계속되며, 완료 시 상단 배너 "악보 변환이 완료됐어요." + "열기"가 뜬다.
