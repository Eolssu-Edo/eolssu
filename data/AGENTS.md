# Data 작업 지침

- [README](README.md)의 담당 범위를 따른다. 데이터 수집·정제·메타데이터·평가 데이터셋 구축과 이를 위한 악보 변환·오디오 전처리를 구현한다.
- 연주 요청별 전처리·추론·채점은 `ai/`에 둔다. 공통 변환이 필요하면 입출력과 재사용 위치를 맞추고 중복 구현하지 않는다.
- 데이터마다 출처·사용 조건·버전·접근 방법을 기록한다. 사용·재배포 가능 여부가 불명확한 자료를 공유 데이터셋이나 검증 샘플에 넣지 않는다.
- 원본과 가공 결과를 구분한다. 원본의 식별자와 변환 이력을 연결하고, 샘플레이트·채널·시간·음높이 단위와 악보·음표 식별자를 소비하는 파트와 맞춘다.
- 정제·변환 시 누락·중복·손상·길이·라벨 불일치를 검사한다. 원본을 덮어쓰지 않고 입력 버전·변환 설정·생성 절차·결과 버전을 재현할 수 있게 남긴다.
- 학습·튜닝을 수행하면 평가 데이터와 원본·파생 샘플의 중복을 확인하고 분할 기준을 기록한다.
- 원본·대용량 결과는 `data/raw/`, `data/processed/`에 두고 커밋하지 않는다. 코드와 사용 가능한 작은 고정 샘플은 `src/`, `tests/fixtures/` 등 Git에서 추적되는 경로에 둔다.
- 변환·품질 검사는 작은 샘플로 먼저 실행한다. 전체 처리 전에는 데이터 범위·실행 비용을 확인하고, 처리 후 입력·처리량·소요 시간·실패 내역을 남긴다.
- 수집처·악보 표현·정제 방법을 조사한 결과는 `docs/knowledge/data/`에 기록한다. 데이터가 없어도 조사 결론·출처·미확인 사항을 남기고 실제 확보 여부를 구분한다.
- 실행 도구를 구성하면 이 폴더의 README에 데이터 획득·생성·검증 명령을 기록한다.
