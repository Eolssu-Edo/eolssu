얼쑤 QA 시연 대본

QA 화면

“지금 보이는 화면은 실제 기기에서 실행 중인 앱입니다. PC에서는 화면을 함께 보고 조작하며, 소리와 마이크는 기기를 사용합니다. 앱에 설정된 실제 서버를 그대로 사용합니다.”

1. 앱 실행

“기기별로 화면을 함께 볼 수 있고 한 사람이 조작합니다. 제어권을 요청하면 현재 조작자가 승인하거나 거절할 수 있습니다. QA 앱 실행을 누르면 연결된 기기에서 현재 설치된 앱을 엽니다.”
  • 기기 이름 옆 점과 현재 조작자를 보여 줍니다. 카드 이름을 누르면 해당 기기의 제어·로그 문맥을 선택합니다.
  • 최신 APK 적용은 새 버전이 있는 기기에만 설치합니다. 현재 버전을 유지하는 시연에서는 누르지 않습니다. 새로 빌드됐다고 자동 설치되지 않습니다. 앱 로그를 읽는 중이면 “앱 로그를 읽고 있습니다. 잠시 후 설치됩니다.”를 표시하고 읽기가 끝나면 다시 누르지 않아도 설치합니다.

2. 로그인

“이제 실제 앱의 로그인과 입력 검증을 확인하겠습니다. 성공하면 본인 데이터가 보이고, 잘못 입력하면 앱의 오류 안내를 확인합니다.”
  • 앱의 이메일 칸에 이메일을 입력합니다. 비밀번호 칸을 별도로 클릭하고 포커스를 확인한 뒤 비밀번호를 입력합니다.
  • 테스트 계정 자동 입력은 사용하지 않습니다. 비밀번호는 로그에 표시하지 않습니다.

3. 기초 콘텐츠

“기초부터 배우기·운지법 보기·정간보 읽기는 학습 콘텐츠입니다. 항목을 열어 내용과 이동을 보여 드리고, 들어보기는 기기 스피커의 실제 소리를 확인합니다.”

4. 연습 기록 보기

“실제 계정의 기록을 날짜나 조건으로 찾고 상세 점수와 녹음 재생을 확인합니다. 이전 연주와 비교하고 메모를 수정할 수 있습니다.”
  • 목록·필터→상세·재생→비교 순서로 보여 줍니다. 삭제 시연은 삭제해도 되는 기록을 선택합니다.

5. 연습·평가

“곡과 악보를 선택하고 모범 연주·구간 연습을 확인한 뒤, 기기 마이크로 녹음해 평가를 요청합니다. 실제 서버의 처리 결과가 앱에 표시되는 흐름을 보겠습니다.”
  • 곡·악보 선택→모범 연주·구간 연습→실제 마이크 녹음→평가 결과→틀린 부분 순서로 보여 줍니다.
  • 화면 점수와 실제 로그의 대상·응답·표시 단계를 맞춰 보여 줍니다. 합성 녹음이나 별도 QA 서버를 사용하지 않습니다.

6. 악보 추가·편집

“사진이나 PDF로 악보를 등록하고, 인식된 음·빠르기·장단을 검수·편집할 수 있습니다. 저장한 악보를 다시 열고 연습 화면에서도 확인하겠습니다.”

앱 처리 기록 설명

“오른쪽에는 현재 APK가 실제로 남긴 로그를 보여 줍니다. 기기 번호와 색으로 구분하고 동작을 선택하면 그 동작의 실제 처리 단계를 볼 수 있습니다.”
  • 기기 로그 범위를 선택하고 전체·HTTP·오류 필터를 사용합니다. 이전 기록·최신 기록으로150건씩 이동합니다.
  • 초록 체크는 해당 기록이 관측됐다는 뜻입니다. 앱 기능 전체의 통과 판정은 아닙니다. 기록 없음은 미확인이며 성공으로 설명하지 않습니다.
  • HTTP200은 앱이 받은 응답의 근거입니다. 서버 수신·AI 완료·DB 저장은 현재 APK에 근거가 없으면 확인됐다고 말하지 않습니다.
  • 원본 단조 시각은 단계 경과 시간, 화면의 시각은 수집 시각입니다. 수집 지연을 서버 처리 시간으로 계산하지 않습니다.
  • 현재 APK가 기록하지 않는 클릭·콘텐츠·오디오 동작은 직접 화면과 기기 소리로 확인합니다.
“오늘 확인한 기기·앱 버전·기능·결과와 로그를 검증 기록으로 남기겠습니다. 실행하지 못했거나 실패한 항목도 함께 구분하겠습니다.”
